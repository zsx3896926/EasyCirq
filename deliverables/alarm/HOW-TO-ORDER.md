# 怎么把这块板做出来（照做即可）

> 这份文件是给**你**的，不是给 AI 的。
> 从拿到这个包，到手里有一块能测温度的板，一共四步。每步都写清做什么、用什么、大概多久。
>
> 全程**不需要你会 EDA**。需要你动手的地方只有两处：在网上下单、收板后拿万用表量几个电压。

---

## 第 0 步：先确认包是完整的（30 秒）

```bash
cd deliverables/alarm
sha256sum -c SHA256SUMS        # Linux / macOS
certutil -hashfile board-gerber.zip SHA256   # Windows，与 SHA256SUMS 里那一行对比
```

全部对上再往下。对不上说明传输坏了，重新拿一份。

## 第 1 步：下单做板（约 10 分钟填单）

### 上传什么

| 文件 | 给谁 |
|---|---|
| `board-gerber.zip` | **板厂**（做裸板） |
| `bom.csv` | 贴片服务 / 自己买料 |
| `design/snapshot/pcb-dump.json` | 不给板厂，留着追溯用 |

### 去哪

嘉立创（`jlcpcb.com` 或中文站 `jlc.com`）。**用哪家都行**，只要接受标准 Gerber。

### 关键选项怎么选

| 选项 | 选什么 | 为什么 |
|---|---|---|
| 层数 | **2 层** | Gerber 里就是 2 层铜 |
| 尺寸 | **19.5 × 21.7 mm** | 工具算出来的，见 `cost-and-leadtime.md` |
| 数量 | **5 片**（打样最少档） | 一块做坏了还有备的 |
| 板厚 | 1.6 mm（默认） | 无特殊要求 |
| 表面处理 | **喷锡 HASL**（最便宜） | 这块板没有细间距器件，不需要沉金 |
| 阻焊/丝印颜色 | 随便 | 不影响功能 |
| 过孔工艺 | 默认（树脂塞孔不需要） | 过孔不多 |

### 要不要一起贴片

**建议一起贴（SMT）**，因为：

- 8 个贴片点全是 0603 / SOP-8 / SOT-23 这类小封装，手工焊容易虚焊；
- BOM 里每个料都有立创编号（`C25804`、`C504553` 等），可以直接配单，不用你选型；
- 有 1 个直插件（`NTC1`，热敏电阻），**贴片通常不管直插**，需要你收到后自己焊两个脚。

如果只做裸板、全部自己焊，也行——`electrical-checklist.md` 里的测量步骤一样适用。

### 大概多久、多少钱

**这两个数我没法给你。** 见 `cost-and-leadtime.md`：报价取决于打样几片、要不要贴片、
加不加急，是订单选项不是板子属性。把下面五个数填进板厂的在线计价器就有准确报价：

```
19.49 × 21.72 mm  ·  2 层  ·  8 个贴片点  ·  1 个直插件  ·  6 种料（全部有 C 号）
```

## 第 2 步：等板到（周期看板厂）

收到后先别急着通电。

---

## 第 3 步：焊好、通电、测六个值

**照 `electrical-checklist.md` 做。** 那里面写了每个节点该有多少伏、六个必测的数。

这里只重复最要紧的一条：

> **`NTC_MID` 这个点的电压，必须随温度升高而下降。**
> 如果它反而上升，说明 NTC 和 R1 装反了——板子会一直响，或者永远不响。
> **光看"响不响"发现不了这个错。**

需要的工具：一个万用表（直流电压档）、一个能加热的东西（吹风机/热水袋）、
一个能看温度的东西（体温枪/温度计）。

---

## 第 4 步：把结果填进去，让工具判

1. 复制 `acceptance.example.json` 成你自己的（比如 `my-board.json`）；
2. 把三项的 `evidence` 换成**你的实测读数**，不是"通过"两个字；
3. 跑：

```bash
easycirq acceptance --file my-board.json
```

### 它会怎么判

| 你填的 | 卡片 |
|---|---|
| 三项都是 pass 且带读数 | ✅ 这块板可以交付使用 |
| 写了 pass 但 evidence 是空的 | ⏳ 还差实测证据（**不会给你绿灯**） |
| 有一项 fail | ❌ 这块板还不能算可用 |
| 某一项还是 pending | ⏳ 还差实测证据 |

**这不是形式主义**：证据为空的 pass 会被降级成"还没测"。你写多少字都行，
但必须是你量到的数。

---

## 如果没响，按这个顺序查

1. **先量 `PWR5V` 有没有 5V** —— 没有就是供电问题，别往下测；
2. **量 `NTC_MID` 随温度怎么变** —— 上升说明 NTC 与 R1 装反；
3. **量 `Q1.C`（也就是 `BUZ_SW`）** —— 超温时应该是 0.2V 左右，如果一直是 5V，说明
   Q1 没导通（可能是 U1 输出有问题，或 Q1 焊反/虚焊）；
4. **蜂鸣器两端有没有电压差** —— `BZ1.1` 接 5V、`BZ1.2` 接 `Q1.C`，两个都在 5V 就是没通。

每一步都有对应的网络名，可以对着 `schematic.svg` 找位置。

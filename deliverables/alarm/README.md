## 电路是什么

```
VCC ── R1(10k) ── NTC_MID ── NTC1(10K NTC) ── GND     温度 → 电压
VCC ── R2(10k) ── TH ───── R3(10k) ──────── GND     阈值电压
U1(LM393): IN+ ← NTC_MID,  IN− ← TH,  OUT1 → ALARM → BZ1(蜂鸣器)
C1(100nF) 跨 VCC–GND，就近去耦
```

温度超过阈值时，NTC 分压低于 TH，比较器输出翻转，蜂鸣器响。

## 成本与工期（回顾）

- 单板元器件约 **¥8–15**

## 边界

- **`✅ 可以打样` 是原理图层面的结论**；整板能下单是因为 DRC 也清了 0 违规。
- 板上有两个独立电路（LED 指示 + 温度报警），是演示用途，不是产品形态。
- **没有实物验证过**：阈值是否准、蜂鸣器够不够响、NTC 批次差异，都要等板子回来才知道。

导出后核对了内容，不是空文件：

| 检查 | 结果 |
|---|---|
| `schematic.svg` 体积 | 92,410 字节 |
| viewBox | `-10.5 -835.5 1191 846`（约 1191×846，A4 横向） |
| 图元 | 36 path · 47 rect · 104 line · 90 polyline · 10 circle · 81 text |
| 关键器件名 | `NTC` ✓ `LM393`/`U1` ✓ `BZ1` ✓ |
| 文本机制 | 每个文字是 `<text><tspan>…</tspan></text>`，字体 `宋体 10px` |

**为什么专门查这个**：`sch export-image` 的输出是 SVG，如果渲染成空白，
交付包里那张"原理图"就是一张白纸——客户打开会以为出了问题。
体积、图元计数与器件名三重确认它是有内容的。

（没有做位图渲染：本机没有把 SVG 转 PNG 的确定性工具链，
所以"看起来对不对"这件事我不能声称验证过——只能证明文件里有对应图元。）

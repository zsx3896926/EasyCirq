# 温度报警器：开工前该告诉客户的（能不能做 / 多少钱 / 多久）

> 这份文件回答终局体验的第一幕：客户说「做一个能测温度、超温就响的板子」之后，
> 他应该立刻得到一句确认——**能不能做、大概多少钱、多久**。
>
> **价格与交期没有核实。** 本轮尝试联网查嘉立创当前报价，搜索接口返回上游 403，
> 所以下面把一个板子的**价格驱动因素**全部算出来（这些是事实，来自板数据与 BOM），
> 报价本身标为 NOT RUN，标着「需按这些参数向板厂询价」。
> 不填一个看起来合理的数字，因为客户会拿它做预算。

## 一、能不能做——能

| 判据 | 这一版的值 | 出处 |
|---|---|---|
| 离线门禁 | 必查 **14/14** 通过，缺证据 0 | `card.txt` |
| PCB 检查 | 0 项违规 | `easycirq pcb drc` |
| 制造文件 | Gerber **12 层**（含两套钻孔） | `board-gerber.zip` |
| 原理图 vs PCB | 逐引脚一致 | KPI 17 |
| 原理图 vs BOM | 位号一致（9/9） | KPI 18 |
| 排版 warn | 6 项（网络标签在图框外） | 不阻断，出图可能裁到 |

**结论：可以下单。** 但「可以下单」只说明文件齐全、结构没问题，
**不说明这块板焊出来一定响**——见第五节。

## 二、多少钱——价格没核实，但驱动因素可以算

下面这些数**不是手算的**，是 `easycirq/scripts/quote_facts.py` 从板数据与 BOM 算出来的：

```
python easycirq/scripts/quote_facts.py --pcb <pcb dump> --bom deliverables/alarm/bom.csv
```

```
板框      19.49 x 21.72 mm  (4.23 cm²)
铜层      2
器件      9 个（顶层 9 / 底层 0）
贴片点    8
直插件    1
BOM       6 种料，总用量 9
钻孔      需要

注意：有 1 个直插件：需要钻孔，贴片通常不覆盖，要单独工序或手焊
注意：器件全在顶层：一次过炉即可

价格与交期：NOT RUN
```

| 参数 | 值 | 为什么影响价格 |
|---|---|---|
| 板框 | **19.49 × 21.72 mm** | 面积 4.23 cm²，两块合起来还没一张邮票大 |
| 铜层 | **2 层** | 双面板是打样最便宜的档位 |
| 贴片点 | **8** | 按点计费的那部分 |
| 直插件 | **1**（NTC1） | 需要钻孔 + 单独工序或手焊 |
| 料种 | **6 种** | 每种都有立创编号，可直接配单，减少等料 |
| 器件分布 | 全在顶层 | 一次过炉，省一次回流 |

### 为什么是「不能给一个数」

同一块板，**打样 5 片**和**小批量 100 片**的单价差一个数量级；
是否走贴片、是否加急、表面处理喷锡还是沉金，都会改变总价。
这些是**订单选项**，不是板子属性——客户不说选哪种，任何数字都是编的。

**正确做法**：把上面那几个数填进板厂在线计价器。

## 三、多久——同样未核实

交期取决于：打样/小批量、是否含贴片、是否加急、缺料替代。
BOM 里 6 种料都有立创编号，能减少「缺料等待」这一类延误，
但**具体天数必须看板厂当时的排产**。

## 五、还有一件比价格更重要的事

这块板历史上曾经在两个致命缺陷下被判「可以下单」：电源全接 GND、蜂鸣器驱动方向错。
两个都是**人读电路**发现的，不是工具。

所以打样之前，除了价格，还要接受一个事实：

> **门禁绿 ≠ 板子对。** 打样后必须按 `electrical-checklist.md` 实测那六个数，
> 特别是 `NTC_MID` 必须随温度**下降**——它上升就说明 NTC 与 R1 装反了。

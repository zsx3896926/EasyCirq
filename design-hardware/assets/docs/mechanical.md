# 机械约束与接口（模板）

用于有板框上限、外壳、安装、插拔或人机接触的项目。由 Agent 从用户约束、外壳/结构图、连接器手册和 PCB 回读中填写；用户只看结论与需要决定的项，不逐格填表。未知写 `待确认`，不填估算值冒充设计值。

- 长度统一记 mm，括号注明来源单位（EDA 命令多用 mil）；不在同一行混用 mm/mil。
- 只记录影响布局、装配或整机使用的机械约束；纯电气与工艺规则留在 [生产档案](../manufacturing-profile.md)。
- 外壳协同方法与材料边界见 [结构协同](../../references/enclosure-integration.md)；丝印标识见 [丝印与装配模板](silk-assembly.md)。
- NTC/温度传感器的自热、响应时间与热路径另见 [温度传感器热设计模板](thermal-sensor.md)，本模板只记录机械位置与可达性。

## 3. 证据与命令边界

- 板框：`easyeda pcb outline-get` 读取真实外形与渲染 bbox；`outline-fit` 只按器件包围盒加边距生成矩形，不能替代目标板框。
- 安装孔计划：`easyeda pcb mount-holes --dry-run`，默认 Ø3.2 mm（126 mil）、中心内缩 5 mm（197 mil），只生成板框角上的 MULTI-layer 铣槽；**不导入螺钉/安装孔库器件**，需要 PTH 或库封装时另建并单独记录。
- 紧固件避让：`mount-holes` 使用 `max(孔半径+40 mil, M3 垫圈/螺钉头半径 118 mil)` 的避让半径，冲突角会 WARN 并跳过，不会强放；用 `--clearance` 覆盖只适用于确认更小的紧固件。
- 器件高度/占位：`easyeda pcb list --include-bbox`；bbox 是渲染范围，不含线缆、插头和外壳。
- 层数/板厚：`easyeda pcb layers`、`easyeda pcb stackup show`。
- 视觉确认：`easyeda pcb snapshot`（需要前台 PCB 窗口；截图只作辅助，尺寸以回读或结构图为准）。
- 结构模型与首件：STEP/STL/3MF 按当前工具实际支持的格式核对单位、坐标与版本；打印小样或首件后验证插拔、按压、声孔、散热与维修。

## 5. 落盘与门禁

- `requirements.size_limit` ← M01 的尺寸上限；`requirements.enclosure_mounting` ← M03–M04 与 M17 的结论。
- `layout.board_outline`、`layout.mounting_holes` ← M01/M03 的实际回读值，不用计划值代替。
- 未关闭项写入 `design-state.json` 的 `open_items`，阻塞项标 `blocking: true`；豁免按 `design-waivers/v1` 记录理由、范围与复验日期。
- 机械约束未确认时不得冻结布局；G3 前至少完成板框、安装孔、连接器逃逸与最高器件核对。

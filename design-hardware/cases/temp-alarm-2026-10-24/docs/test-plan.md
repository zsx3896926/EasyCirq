# 测试与使用步骤（无程序）

## 0. 先决条件

- PCB 已完成布线且 DRC 清零、已打样/贴片（当前 PCB DRC 尚未清零，见交接）。
- 5V USB 电源（建议先用限流 100mA 的 USB 口或可调限流源）。
- 万用表、温度计（或已知温度环境）、小螺丝刀（调 RV1）。

## 1. 不上电检查

1. 目视：J1 USB-C 方向、D4/D5 极性、BZ1 正负、RV1 方向、U1 第 1 脚方向。
2. 万用表二极管档：+5V 对 GND 不应短路；NODE 对 GND 约 22k + NTC（室温约 32k）；VREF 对 GND 约 10k 量级（随电位器变化）。
3. 检查 J1 数据脚（A6/A7/B6/B7）确实悬空/NC，不要和相邻脚连锡。

## 2. 首次上电

1. 限流 5V/100mA，插入 USB-C。
2. 观察：D5 绿色电源灯应亮；D4 红灯和蜂鸣器应不响（室温低于设定值）。
3. 测 +5V 母线（D1 阴极）约 4.5–4.7V（SS34 有约 0.3–0.5V 压降）；整板电流应 < 50mA。
4. 若电流异常或 D5 不亮，立即断电，先查 J1 焊接和 +5V/GND 短路。

## 3. 调报警点

1. 用温度计确认当前环境温度。
2. 用小螺丝刀缓慢旋转 RV1（10k 多圈），直到 D4 刚好点亮、蜂鸣器刚好开始响。
3. 反向微调，找到“刚好触发”的位置；记录温度计读数，这就是当前设定值。
4. 回差约 1.7°C：温度降到触发点以下约 1.7°C 才会解除。若发现反复通断，可把 RV1 稍微调过触发点一点。
5. 建议在 RV1 旁用记号笔标一个参考刻度，便于以后复位。

## 4. 功能测试

1. **升温**：用手指捏住 NTC、吹热风或靠近暖源；温度超过设定值时 D4 亮、蜂鸣器响。
2. **降温**：移开热源，温度降到回差以下时 D4 灭、蜂鸣器停。
3. **NTC 开路**：拔掉/断开 NTC（若是贴片则拆焊或断开一端）；NODE 被 22k 上拉到 +5V，应触发报警（失效偏向报警）。
4. **NTC 短路**：短接 NTC；NODE=0V，不会报警。这是本方案的已知边界，测试时记录，不要把它当成正常。
5. **反复上电**：快速插拔 USB 10 次，不应误鸣、不应死机。
6. **长时间**：常温通电 1 小时，观察阈值是否漂移、蜂鸣器是否异常。

## 5. 通过标准

- 室温下不报警；超过设定值立即亮灯+响；降回回差以下自动解除。
- 设定点与温度计偏差建议控制在 ±2°C 内（NTC 公差、电位器刻度、温度计误差共同决定）。
- 整板 5V 电流 < 50mA；无异常发热。
- NTC 开路能报警；NTC 短路不报警（记录为限制）。

## 6. 没有程序

本设计没有 MCU、没有固件、没有烧录步骤。所有行为由 NTC 分压 + MCP6541 比较器 + 2N7002 完成。若以后想加“数字显示/手机提醒/可编程阈值”，再考虑加 MCU（例如 CH32V003 或 CH552G）。

# 模拟采集、基准与 ADC：带条件的计算手册

> **用途：** 把“分压能不能直接进 ADC、运放够不够快、电流采样准不准、基准和滤波怎么选、校准能消掉什么”变成一组可复算的步骤；重点是**采样建立、误差预算和稳定性条件**，不是“选一颗高位数 ADC”。
>
> **证据等级：** `E1`（分压/采样建立、运放增益带宽/噪声增益/稳定性、电流采样、基准误差、CMRR 的公式与条件已按 ANA-S01、ANA-S02、ANA-S03、ANA-S06、ANA-S07、ANA-S08、ANA-S10、ANA-S11 核对）；`E2`（噪声积分、抗混叠阶数、校准残差的工程近似，具体数值须按所选器件手册/实测核对）。
>
> **完成级别：** 离线规划（资料分析已完成）。没有 EDA、没有 PCB、没有实测波形；脚本输出 `board_verified:false`。
>
> **可执行脚本：** [`calculate.py`](../../scripts/calculate.py) 的 `divider`、`adc_settle`、`current_sense` 模式；[`rc_settle_sim.py`](../../scripts/rc_settle_sim.py)（自研二阶 RC 数值模型，不是 SPICE）；[`assets/simulation/rc_sample.cir`](../../assets/simulation/rc_sample.cir) 是 **NOT RUN** 的 SPICE 计划，不能声称已运行。
>
> **命令目录：** 下文命令均从 `design-hardware/` 目录运行（即 `scripts/` 的上一级）。

## 1. 用途与决策边界

本文回答七个会改变电路的问题：

1. **分压能不能直接进 ADC？** 先看源阻抗/采样时间，再看电阻公差、ADC 漏电、过压保护；直流比值对不等于采样结果对。
2. **什么时候必须加缓冲？** 当 `R_source` 超过 ADC 采样网络允许的上限，或分压电阻大到漏电/串扰不可接受时；加缓冲会引入新的共模/摆幅/稳定性问题。
3. **运放的增益/带宽/噪声够不够？** 用噪声增益（不是信号增益）算闭环带宽；用 GBW/NG、压摆率、输入共模、输出摆幅、容性负载稳定性五项一起判断。
4. **电流采样误差预算是多少？** 分别列分流电阻公差、增益公差、失调、量化、温漂、CMRR、自热；RSS 与最坏情况都要给。
5. **基准能不能支撑目标位数？** 初始精度、温漂、热滞回、1/f 噪声、长期漂移、负载调整分别算；12 位和 16 位的结论不同。
6. **抗混叠滤波器怎么选？** 截止频率由采样率/信号带宽/阻带要求决定，但滤波器阶数/截止频率会与多路切换的建立时间冲突；不能只看 `fc`。
7. **校准能消掉什么、不能消掉什么？** 失调/增益可校准；非线性、迟滞、噪声、两次校准之间的漂移不能靠一次校准解决。

### 不能使用的条件

- **把 ADC 位数当系统精度**：12 位 LSB 是 0.0244% 满量程，但分压公差/基准/噪声/失调很容易占掉几十个 LSB。
- **把“轨到轨”当保证**：输入共模范围、输出摆幅都随供电/负载/温度变化；必须查最坏条件（ANA-S07 只讨论增益/带宽/稳定性，不覆盖共模/摆幅）。
- **把 GBW 典型值当保证**：GBW 有离散性；ANA-S07 建议至少 5 倍裕量，但这是工程建议，不是规范。
- **把 RC 截止频率当完整抗混叠**：一阶 RC 在阻带衰减很慢；多路切换时还要满足建立时间。
- **把基准当理想电压源**：SAR 的 `VREF` 引脚有动态电荷再分配电流；ANA-S01 给出 12 位 2 MSPS 示例的峰值约 600 µA（仅该示例）。
- **没有 ADC 的 `C_SH`、`t_ACQ`、`t_CONV` 就给“能采样”的结论**：本文只能给判据和方法。

## 3. 模型与公式

### 3.1 电阻分压

- 理想：`VOUT = VIN·R_bottom/(R_top + R_bottom)`；比值 `k = R_bottom/(R_top+R_bottom)`。
- 戴维南电阻：`R_th = R_top·R_bottom/(R_top+R_bottom)`；它才是 ADC 看到的源阻抗（不是 `R_top` 或 `R_bottom` 单个）。
- 公差最坏情况：分别取 `R_top`、`R_bottom` 的 min/max，算四个组合的 `VOUT`；`calculate.py divider` 就是这样做的。
- 漏电误差：`ΔV_leak ≈ I_leak·R_th`；ADC 输入漏电、保护二极管漏电、PCB 污染都算。
- 分压电流：`I_div = VIN/(R_top+R_bottom)`；它决定功耗，也决定“能不能用低阻分压”。
- 过压：`VIN(max)` 时 `VOUT` 必须 ≤ ADC 满量程并留保护余量；不能只按标称输入算。

**假设：** 无负载（或负载阻抗远大于分压）、电阻线性、无自热；实际还有电阻电压系数、PCB 漏电、保护器件漏电。

### 3.2 SAR ADC 采样建立

- 采集时间：`t_ACQ = 1/f_sample − t_CONV(max)`（ANA-S02 第 7 页）。
- 一阶保守模型：`τ = (R_source + R_SW)·(C_ext + C_SH)`；阶跃后误差 `e^(−t/τ)`。
- 0.5 LSB 判据：`e^(−t_ACQ/τ)·2^N ≤ 0.5`，即 `t_ACQ/τ ≥ (N+1)·ln2`；所以 `τ_max = t_ACQ/((N+1)·ln2)`，`R_total,max = τ_max/(C_ext+C_SH)`。
- 外部电容经验：`C_ext = 20×C_SH`（ANA-S02 第 13 页）；`C_ext` 太小则电荷共享/采样保持误差大，太大则 RC 建立慢、带宽低。
- 只靠 RC 的源阻抗上限：ANA-S02 示例 ADS8860（`C_SH=55 pF`、`t_ACQ=290 ns`、16 位）给出约 475.4 Ω；这是该 ADC 的示例，不是通用值。
- 需要缓冲的判据：`R_source > τ_max/(C_ext+C_SH)`，或分压电阻大到漏电/串扰/带宽不可接受。
- 缓冲运放：`C_ext=20×C_SH`；`K = ln(2^(N+1)/(C_ext/C_SH+1))`；`f_Z = K/(2π·t_ACQ)`；`f_U ≥ 4·f_Z`；`R_EXT = 1/(2π·C_ext·f_Z)`；`R_O ≤ 9·R_EXT`（ANA-S02 第 17 页）。
- 二阶效应：ADC 输入还有 `C_IN`（1–10 nF）与 `C_ESD`（4–10 pF），采样开关电阻非线性；ANA-S03 用二阶低通模型，最坏情况取零/负满量程到正满量程阶跃。

**假设：** 理想阶跃源、恒定 `R_SW`、无电荷注入/漏电/介质吸收；0.5 LSB 只是建立判据，不是总精度。

### 3.3 运放：增益、带宽、噪声、稳定性

- 闭环增益：`G = NG/(1+NG/A_VOL)`；`NG` 为噪声增益：
  - 同相：信号增益 `1+R2/R1`；反相：信号增益 `−R2/R1`；两者噪声增益都是 `NG = 1+R2/R1`（ANA-S07）。
- 闭环带宽：`f_CL ≈ GBW/NG`（单极点、6 dB/oct 段）；信号频率 `f_sig` 应远小于 `f_CL`，ANA-S07 示例建议至少 5 倍裕量（工程建议，不是规范）。
- 压摆率：正弦 `SR ≥ 2π·f_sig·V_peak`；阶跃 `SR ≥ ΔV/Δt`。
- 噪声（输入参考密度）：`e_n,total = √(e_n² + (i_n·R_source)² + 4kTR_source)`；输出 `e_n,out = e_n,total·NG`；RMS `≈ e_n,out·√ENBW`，单极点 `ENBW ≈ 1.57·f_CL`。该式**不含反馈网络 R1/R2 的热噪声**；实际要按完整噪声模型加上反馈电阻贡献。
- 电阻热噪声：`e_R = √(4kTR)`；`k=1.38×10⁻²³ J/K`，`T=300 K` 时 `√(4kTR) ≈ 0.1287·√R nV/√Hz`（`R` 单位 Ω；例 10 kΩ → 12.9 nV/√Hz）。
- CMRR（差分/差放）：`CMRR_R = (G+1)/(4t)`（四个分立电阻、公差 `t`）；总 `1/CMRR_D = 1/CMRR_A + 1/CMRR_R`（ANA-S08）。匹配电阻分压对：`CMRR_R = (G+1)/t_m`。
- 容性负载：`f_p2 = 1/(2π·RO·C_LOAD)`；串联 `R_ISO` 引入零点；最优 `R_ISO = [1+√(1+8π·RO·C_LOAD·f_GBW)]/(4π·C_LOAD·f_GBW)`；相位裕度目标常取 ≥45°（ANA-S10）。`R_ISO` 会带来直流负载调整误差。
- 输入共模/输出摆幅：必须按“给定供电、给定负载、给定温度”的最坏值核对；rail-to-rail 不是全条件保证。

**假设：** 电压反馈运放、单极点开环、线性区；不覆盖压摆率引起的非线性、输入偏置电流的温漂、容性负载的详细 SPICE 稳定性。

### 3.4 电流采样误差预算

- 传递函数：`V_out = I_load·R_shunt·Gain`（低侧，ANA-S06 式 1；高侧同式，共模不同）。
- 误差项（满量程）：
  - 分流电阻公差：`ΔI_R = I_max·t_R`
  - 增益公差：`ΔI_G = I_max·t_G`
  - 失调（折到输出）：`ΔI_OS = V_OS,max/(R_shunt·Gain)`
  - 量化：`ΔI_Q = LSB/2/(R_shunt·Gain)`，`LSB = VREF/2^N`
- 合成：RSS `√ΣΔI²`；最坏情况线性相加。两者都给，不能只给 RSS。
- 温漂：`ΔI_TCR = I_max·TCR·ΔT`；增益漂移同理；CMRR：`ΔV_CM/CMRR` 折到输入。
- 自热：`P_shunt = I_max²·R_shunt`；按分流电阻额定功率/温升曲线降额；自热改变阻值/热电偶效应。
- Kelvin：`R_STRAY` 会直接加到 `R_shunt` 上（ANA-S06 式 2）；地电位差 `V_GND_OS` 产生偏移（式 3）。
- 高侧/在线：共模接近母线，PWM `dv/dt` 会产生共模瞬态；需要高 CMRR/增强 PWM 抑制的器件（ANA-S14）。

**假设：** DC、满量程、独立误差；不含非线性、噪声、参考误差、PCB 寄生、温度梯度。

### 3.5 基准误差

- 总误差：最坏情况相加或 RSS；主要项：初始精度、温漂、热滞回、长期漂移、1/f 噪声、宽带噪声、负载/线调整（ANA-S01 式 1–2）。
- 温漂换算：`Δ% = ppm/°C × ΔT(°C)/10^4`；例 6 ppm/°C × 165 °C = 990 ppm = 0.099%。
- 噪声：若基准噪声相对 ADC 噪声可忽略，基准 RMS 噪声应不大于 ADC 总噪声的 1/5（ANA-S01 式 6）；1/f 噪声在 0.1–10 Hz，实际无法滤除。
- SAR 动态负载：每次位转换在 `VREF` 引脚发生电荷再分配，电流随 MSB→LSB 非线性变化；需要紧靠引脚的储能电容/缓冲（ANA-S01 §7）。
- 布局：储能电容紧靠 ADC `REF` 引脚；多 ADC/大电流时加低噪声缓冲；有 sense 引脚时接到 ADC 的 `REF` 引脚。

**假设：** 基准在推荐负载/温度范围内；具体初始/温漂/噪声必须查该基准手册，不能把 REF3425 示例套到其他型号。

### 3.6 抗混叠与校准

- 一阶 RC：`fc = 1/(2πRC)`；`|H(f)| = 1/√(1+(f/fc)²)`；n 阶近似 `|H| ≈ 1/√(1+(f/fc)^(2n))`。
- 混叠：采样率 `fs` 下，`f_alias = |f − k·fs|`；要防止带外信号折回，需在 `fs−f_sig` 处有足够衰减。
- 建立：滤波器阶数越高、`fc` 越低，阻带越好，但阶跃建立越慢；多路切换的 `t_ACQ` 必须覆盖“滤波器+采样网络”的建立。
- 校准：两点校准消失调/增益；多点校准可改善非线性；不能消噪声、迟滞、蠕变、两次校准之间的漂移。
- 比率测量：桥/RTD 用同一激励作基准，`V_IN/V_REF` 抵消激励漂移（ANA-S09、ANA-S04）；前提是基准与输入噪声相关、滤波带宽一致。NTC 的容差/自热与 RTD 的 2/3/4 线接法分别见 ANA-S12/ANA-S04；本文不重复展开。

## 4. 判据与决策表

### 4.1 推荐工作条件 ≠ 绝对最大额定值

| 参数 | 推荐工作条件（设计判据） | 绝对最大额定值的使用 | 决策 |
|---|---|---|---|
| ADC `VREF` | 在 `VDDA−1.2 V` 到 `VDDA` 之间、且 ≥1.7 V（MCU-S01 对 STM32F4 的 `VREF+` 规则） | 绝对最大只表示不得超出；不同 ADC 不同 | 12 位用 3.3 V 基准时，`VDDA` 必须 ≥3.3 V 且留裕量；不能把 5 V 基准接 3.3 V ADC |
| 运放输入共模 | 数据手册给定的 `VCM` 范围（按供电/温度） | 绝对最大按具体运放手册；它不是可用共模范围 | 传感器共模可能接近 0/`VCC`；rail-to-rail 输入也要查端点 |
| 运放输出摆幅 | 按实际负载电阻/电流的 `VOH/VOL` | 输出短路电流是绝对边界 | 驱动 ADC/电缆时按负载算，不按空载 |
| 运放 `V+` | 推荐供电范围 | 绝对最大 | 5 V 供电的运放不能直接接 24 V 输入 |
| 基准输出电流 | 推荐负载范围 | 短路电流是绝对边界 | SAR `VREF` 动态电流可能远超静态；加缓冲/储能 |
| 分流电阻功率 | 按额定功率/温升曲线降额 | 瞬时/脉冲功率另有条件 | 10 A、5 mΩ → 0.5 W；选 ≥1 W 并核温升 |
| ADC 输入电压 | 0–`VREF`（或手册规定） | 绝对最大按具体 ADC 手册；不是可用输入范围 | 加串阻/钳位；不能靠软件限制 |
| 电阻公差 | 按误差预算选 0.1%/0.01% | 额定功率/电压是绝对边界 | 12 位 0.1% 已占约 4.7 LSB；16 位需 0.001% 或逐板校准 |

### 4.2 典型值不能替代保证值

| 参数 | 典型值用途 | 为什么不能当保证 | 设计应取 |
|---|---|---|---|
| ADC `C_SH`/`R_SW` | 初算建立 | 工艺/温度/输入电平会变；`R_SW` 非线性 | 手册最大值；用仿真/实测复核 |
| ADC 漏电 | 估漏电误差 | 随温度指数上升 | 最高温度下的最大值 |
| 运放 GBW | 初选带宽 | 有离散性、随温度/负载变 | 手册最小值或按 5× 裕量 |
| 运放 `en`/`in` | 估噪声 | 典型值在 1 kHz/25 °C；1/f 区更高 | 目标频段曲线，不是单点典型 |
| 基准初始精度 | 初估 | 初始精度是 25 °C；温漂/滞回另算 | 手册 max + 温漂 + 滞回 |
| 基准噪声 | 估 SNR | 1/f 与宽带不同；带宽条件不同 | 目标带宽内的 RMS/pp |
| 分流电阻 TCR | 估温漂 | 具体批次/安装/自热 | 手册 max TCR + 实测温升 |
| 采样放大器失调 | 估 DC 误差 | 随温度/共模变化 | 目标温度/共模下的 max |
| 电阻公差 | 估比值误差 | 温漂/电压系数另算 | 最坏公差 + 温漂 |
| 运放 CMRR | 估共模误差 | 随频率下降；典型值在 DC | 目标频率/共模下的 min |

> **典型值不能替代保证值：** 12 位系统的 1 LSB 只有 0.0244% 满量程；上表任何一项用典型值，都可能把误差预算低估数倍。算例中的 10 nV/√Hz、1 pA/√Hz、1 µA 漏电、5 mV 失调都是**假设**，不是器件保证。

### 4.3 快速判据

| 判据 | 通过条件 | 不通过时的动作 |
|---|---|---|
| 分压直接进 ADC | `R_th ≤ τ_max/(C_ext+C_SH)` 且漏电 `I_leak·R_th` ≤ 目标 LSB | 加缓冲/降低分压电阻/增大 `C_ext`/降低采样率 |
| 12 位分压精度 | 0.1% 电阻 + 漏电 + 基准后仍 ≤ 目标 LSB | 选 0.01%/匹配网络/校准/加缓冲 |
| 运放带宽 | `f_CL = GBW/NG ≥ 5×f_sig`（工程建议） | 选更高 GBW/降低 NG/加前级 |
| 运放压摆 | `SR ≥ 2π·f_sig·V_peak` | 选更高 SR/降低信号幅度/频率 |
| 运放噪声 | 输出 RMS ≤ 目标（如 0.5 LSB） | 降低 `R_source`/选低 `en`/限带 |
| 容性负载稳定 | 按 `R_ISO` 公式 + 相位裕度 ≥45°（目标） | 加 `R_ISO`/双反馈/换运放；必须仿真/实测 |
| 电流采样 1% | RSS ≤1%（按项目） | 选低失调/低增益误差/低 TCR/四线 |
| 基准 12 位 | 总误差 ≤1 LSB（或校准后） | 选更高精度/校准/换基准 |
| 抗混叠 60 dB | 在 `fs−f_sig` 处衰减 ≥60 dB | 提高阶数/降低 `fc`/提高 `fs`/用 ΔΣ |
| 多路切换建立 | 切换后 `t_ACQ` 内稳定到 0.5 LSB | 降低通道扫描率/加缓冲/增大 `t_ACQ` |

### 5.3 运放缓冲：增益、带宽、噪声与容性负载

**给定条件：** 同相缓冲/放大，`R1=1 kΩ`、`R2=10 kΩ` → `NG=11`；`GBW=10 MHz`；`en=10 nV/√Hz`；`in=1 pA/√Hz`；`R_source=10 kΩ`；信号 3 Vpp、100 kHz；`C_LOAD=10 µF`（例如驱动长电缆/ADC 参考）。

**带宽：**

- `f_CL = 10 MHz/11 = 909 kHz`
- 100 kHz 信号：`f_CL/f_sig = 9.1`，满足 ANA-S07 的 5× 工程建议；
- 500 kHz：1.8×，不足；1 MHz：0.91×，**不通过**。
- 压摆率：`SR ≥ 2π×100 kHz×1.5 V = 0.942 V/µs`；选 ≥2 V/µs 并留裕量。

**噪声（输入参考）：**

- 电阻热噪声：`√(4kT×10 kΩ) = 12.9 nV/√Hz`
- 电流噪声×源阻抗：`1 pA/√Hz×10 kΩ = 10 nV/√Hz`
- 运放电压噪声：10 nV/√Hz
- 合成：`√(10²+12.9²+10²) = 19.1 nV/√Hz`
- 输出：`19.1×11 = 210 nV/√Hz`
- `ENBW = 1.57×909 kHz = 1.43 MHz`
- 输出 RMS：`210 nV/√Hz×√1.43 MHz = 251 µVrms`
- 折合 12 位/3.3 V：`251 µV/805.7 µV = 0.31 LSB rms`；16 位：`251/50.35 = 5.0 LSB rms`

**源阻抗影响：**

| `R_source` | 输入噪声密度 | 输出 RMS | 12 位 LSB | 16 位 LSB |
|---:|---:|---:|---:|---:|
| 1 kΩ | 10.9 nV/√Hz | 143 µVrms | 0.18 | 2.8 |
| 10 kΩ | 19.1 nV/√Hz | 251 µVrms | 0.31 | 5.0 |
| 100 kΩ | 108.4 nV/√Hz | 1.42 mVrms | 1.77 | 28.2 |

**决策：** 12 位/100 kHz 用 10 kΩ 源阻抗可以（0.31 LSB rms），16 位则不够（5 LSB rms）；100 kΩ 源阻抗在 12 位已占 1.77 LSB，必须降低源阻抗或选低 `en`/低 `in` 的 FET 输入运放。噪声按 RSS 与其它误差合成，不能只看 ADC 位数。

**容性负载：** 10 µF 直接挂在输出端会把 `f_p2=1/(2π·RO·C_LOAD)` 拉进环路；按 ANA-S10 的 `R_ISO` 公式补偿。ANA-S10 的 OPA392 示例（`RO=120 Ω`、`C_LOAD=10 µF`）给出约 380 mΩ 的 `R_ISO`，相位裕度从 <1° 提升到 60°；**该值只属于该器件/负载**。本文不另给通用 `R_ISO`，因为 `RO`/`f_GBW` 必须查具体运放手册；算出后必须用 SPICE/实际阶跃验证。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：运放实际 GBW/噪声随温度/负载的变化、反馈网络 R1/R2 的热噪声、输入共模/输出摆幅、容性负载的真实相位裕度、PCB 寄生、ADC 输入非线性；`R_ISO` 未在本文计算/仿真。

### 5.4 电流采样误差预算：10 A 与 1 A 的差别

**给定条件：** 分流电阻 5 mΩ、公差 1%；增益 50（10 A 档）或 100（1 A 档）、公差 1%；失调 5 mV（折到输出）；ADC 3.3 V、12 位；`I_max=10 A` 或 `1 A`。

```bash
python scripts/calculate.py current_sense '{"shunt_ohm":0.005,"shunt_tol":0.01,"i_max_A":10,"gain":50,"gain_tol":0.01,"offset_max_V":0.005,"adc_vref_V":3.3,"adc_bits":12}'
python scripts/calculate.py current_sense '{"shunt_ohm":0.005,"shunt_tol":0.01,"i_max_A":1,"gain":100,"gain_tol":0.01,"offset_max_V":0.005,"adc_vref_V":3.3,"adc_bits":12}'
```

| 量 | 10 A 档 | 1 A 档 |
|---|---:|---:|
| `V_shunt,max` | 50 mV | 5 mV |
| `V_out,max` | 2.5 V | 0.5 V |
| `ADC headroom` | 0.8 V | 2.8 V |
| `P_shunt,max` | 0.5 W | 5 mW |
| `LSB` 折合电流 | 3.22 mA | 1.61 mA |
| 分流公差 | 0.100 A | 0.010 A |
| 增益公差 | 0.100 A | 0.010 A |
| 失调 | 0.020 A | 0.010 A |
| 量化（半 LSB） | 0.0016 A | 0.0008 A |
| **RSS** | **0.1428 A（1.43%）** | **0.01734 A（1.73%）** |
| **最坏相加** | **0.2216 A（2.22%）** | **0.0308 A（3.08%）** |

**关键判断：**

- 10 A 档：0.5 W 分流电阻需要 ≥1 W 额定并核温升；1% 电阻/增益各占 1%，失调只占 0.2%。要进 1%，必须把电阻/增益公差降到 0.1–0.25%，或校准。
- 1 A 档：失调 5 mV 折合 10 mA，已占 1%；**低端精度由失调主导，不是 ADC 位数**。12 位 LSB 1.6 mA 比误差小一个数量级，换 16 位 ADC 不会改善。
- 温度（示例假设：分流 50 ppm/°C、增益 25 ppm/°C，ΔT=60 °C）：0.3% → 10 A 档 30 mA；0.15% → 15 mA。与 RSS 合成约 0.147 A（1.47%）。
- CMRR：高侧 24 V 共模、80 dB → 2.4 mV 折到输入，5 mΩ 下 0.48 A？等一等：`2.4 mV/5 mΩ = 0.48 A`，这很大。实际采样放大器 CMRR 通常指折到输入；80 dB 在 24 V 下是 2.4 mV，确实 0.48 A。若 CMRR 120 dB → 24 µV → 4.8 mA。**这就是高侧采样必须看 CMRR 的原因。**
- 自热：0.5 W 在 1 W 电阻上，温升按厂商曲线；5 mΩ 的 TCR/热电动势会产生额外漂移。

**决策：** 10 A/1% 目标选 0.1% 分流 + 0.1% 增益 + 低失调（≤1 mV）或校准；1 A 档不要用 10 A 档的 5 mΩ + 50 增益（失调占比太大），改用更高增益/更低失调或量程切换。Kelvin 连接、地电位差按 ANA-S06 处理；PWM 共模按 ANA-S14 处理。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际 CMRR 随频率、非线性、噪声、参考误差、PCB 布局、分流电阻自热/热电偶、脉冲电流；`5 mV` 失调与 `80 dB` CMRR 是假设。

### 5.5 基准误差：12 位与 16 位的差别

**来源示例（ANA-S01 表 4-1，REF3425，仅该器件/条件）：** 初始 0.05%（500 ppm）、温漂 6 ppm/°C（−40…125 °C 折 990 ppm）、热滞回 40 ppm、1/f 噪声 15 µVpp 折 15 ppm。

| 组合方式 | 误差 | 12 位 LSB（0.0244%） | 16 位 LSB（0.001526%） |
|---|---:|---:|---:|
| 最坏情况相加 | 0.1545% | 6.33 | 101.2 |
| RSS | 0.111% | 4.55 | 72.7 |
| 25 °C 校准后 | 0.0991% | 4.06 | 64.9 |
| 25 °C + 温漂校准后 | 0.0202% | 0.83 | 13.24 |

**决策：** 12 位系统不校准也有约 4–6 LSB 的基准误差；16 位系统即使校准温漂，基准仍占约 13 LSB，必须选更高精度/更低漂移基准或做系统级校准。**基准不是“接上就行”**：SAR 的 `VREF` 动态电流需要储能电容/缓冲；基准噪声应 ≤ADC 噪声的 1/5（ANA-S01 式 6）。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：具体基准的负载调整/线调整、长期漂移、PCB 布局、ADC 参考抑制；0.1545% 等数字只属于 REF3425 的示例条件。

### 5.6 抗混叠：60 dB 与建立时间的冲突

**给定条件：** `fs=10 kSPS`；信号带宽 1 kHz；要求在 `fs−f_sig=9 kHz` 处至少 60 dB 衰减；12 位；多路切换后 `t_ACQ=10 µs` 内建立到 0.5 LSB。

| 滤波器阶数 | 所需 `fc`（9 kHz 处 60 dB） | `τ=1/(2πfc)` | 12 位 0.5 LSB 建立时间（≈9.01τ） | 10 µs 内？ |
|---:|---:|---:|---:|---|
| 1 阶 | 9 Hz | 17.7 ms | 159 ms | 否 |
| 2 阶 | 285 Hz | 558 µs | 5.03 ms | 否 |
| 4 阶 | 1.60 kHz | 99.5 µs | 0.897 ms | 否 |
| 6 阶 | 2.85 kHz | 55.8 µs | 0.503 ms | 否 |
| 8 阶 | 3.80 kHz | 41.9 µs | 0.378 ms | 否 |

**把 `fs` 提高到 100 kSPS（混叠在 99 kHz）：**

| 阶数 | `fc` | `τ` | 12 位建立 | 10 µs 内？ |
|---:|---:|---:|---:|---|
| 2 阶 | 3.13 kHz | 50.8 µs | 0.458 ms | 否 |
| 4 阶 | 17.6 kHz | 9.05 µs | 81.5 µs | 否 |
| 6 阶 | 31.3 kHz | 5.09 µs | 45.9 µs | 否 |
| 8 阶 | 41.8 kHz | 3.81 µs | 34.3 µs | 否 |

**关键区分：** 抗混叠滤波器不需要每次采样都从零阶跃到满量程；如果同一通道连续采样，它只需跟踪信号带宽。**但多路切换**时，前一通道的电压可能留在 `C_ext` 上，切换后必须在 `t_ACQ` 内建立到 0.5 LSB；上表说明“60 dB 抗混叠 + 10 µs 多路切换”在 10 kSPS 下不可兼得。

**决策：** 多路 10 kSPS/12 位要 60 dB 抗混叠，不能只靠无源 RC；选带数字滤波/过采样的 ΔΣ ADC，或降低通道扫描率（增加 `t_ACQ`），或提高 `fs` 并接受更高阶滤波器。**不要写“加一个 1 kHz RC 就抗混叠了”。**

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：滤波器实际元件公差/寄生、源阻抗、ADC 数字滤波器特性、混叠的实际频谱；阶数是近似，实际要用 SPICE/网络分析仪验证。

### 5.7 校准：能消掉与不能消掉

| 误差项 | 可否校准 | 方法 | 残差/限制 |
|---|---|---|---|
| 失调 | 可 | 零点单点校准 | 温漂、长期漂移 |
| 增益 | 可 | 两点校准 | 非线性、参考漂移 |
| 分压比 | 可 | 两点/多点 | 电阻温漂、电压系数 |
| 基准初始精度 | 可 | 用高精度表测 | 表的不确定度 |
| 基准温漂 | 可（需温度补偿） | 多点温度校准 | 温度传感器误差、滞回 |
| ADC INL | 部分 | 多点/查找表 | 校准点之间的非线性 |
| 噪声 | 不可 | 滤波/平均/降低带宽 | 带宽与速度的取舍 |
| 迟滞/蠕变 | 不可 | 选低迟滞器件 | 机械/热历史 |
| 两次校准间漂移 | 不可 | 定期校准/自校准 | 使用环境 |
| PCB 漏电 | 不可 | 清洁/护环/降低源阻抗 | 污染/湿度 |

**决策：** 12 位生产校准至少做零点+满量程两点；16 位要加温度补偿或多点校准，并明确校准周期。校准记录要写“校准温度、标准器、不确定度、校准点”，不能只写“已校准”。

| 电流采样 | 分流电阻阻值/公差/TCR/功率/四线、采样放大器增益/失调/CMRR | 换阻值/增益需重算量程 | 同封装同阻值：类 1；改阻值/增益：类 2；改封装/拓扑：类 3 |
| 基准 | 基准完整型号、初始精度、温漂、噪声、封装 | 换基准可能改 `VREF` 电压/负载 | 同电压同封装同引脚：类 2（若需改负载/噪声补偿）；否则类 3 |
| 滤波器 | R/C 值、公差、介质（C0G/X7R）、阶数 | 改 `fc`/阶数 | 类 2（若需改建立/抗混叠） |
| 校准 | 校准点、标准器、温度、固件常数 | 改校准方案需改固件/测试 | 类 2 |

**替代分级（只用这四类，定义见 [replacement-classes.md](../selection/replacement-classes.md)）：**

1. **类 1：核对条件后可直接替换。** 同阻值/同公差/同封装电阻；同 `VREF`/同封装/同引脚基准（仍需核对噪声/负载）。
2. **类 2：需要改阻容/配置/固件。** 改分压比、增益、滤波 `fc`、校准常数；换运放但引脚兼容且需重算补偿。
3. **类 3：需要改原理图/封装/PCB。** 换封装/引脚/通道数/基准电压；加缓冲/隔离/保护。
4. **类 4：资料不足，不能决定。** 只有“12 位/低噪声/轨到轨”的模糊描述，没有 `C_SH`、`t_ACQ`、GBW min、`VCM`、噪声曲线。

## 7. 制造与装配接口

完整路线见 [manufacturing-routes.md](../manufacturing-routes.md)；本节只列与模拟采集计算相关的决策。

| 计算结论 | 路线 A：商城购料 + 自焊 | 路线 B：嘉立创 PCB + SMT | 路线 C：板 + 固件/结构 + 整机 |
|---|---|---|---|
| 0.1%/0.01% 电阻 | 手焊可行；注意温度系数/批次 | 需确认可贴精度/封装；0.01% 薄膜电阻可能为扩展料 | 校准工装/标准器 |
| 运放/ADC 小封装 | QFN/DFN 手焊困难，需热风/底部加热 | 钢网/回流；引脚间距按工厂能力 | 测试点/夹具可达 |
| 基准/储能电容 | 紧靠引脚手焊 | 钢网开孔/立碑/偏压降容 | 参考点测试 |
| 分流电阻/ Kelvin | 四线焊盘手焊可做；功率电阻散热 | Kelvin 开窗/焊盘；功率电阻的铜/过孔 | 线束/端子载流 |
| 滤波器 C0G/X7R | 手焊注意介质/耐压 | 介质/公差/封装进 BOM | 温度/振动 |
| 校准 | 手焊后用标准源校准 | 工厂测试/校准工位；固件常数 | 整机校准/复校 |

**手焊 vs SMT、THT vs SMT、双面：** 手焊优先 SOIC/大封装/通孔测试点；细间距 ADC/基准/运放走 SMT；双面贴装时把模拟小信号面尽量放在一次回流完成的一面，避免二次回流/助焊剂残留影响高阻节点。THT 连接器/测试点需插件工序。

**必须与 Gerber/钻孔/BOM/CPL 对账：**

- **Gerber/叠层：** 模拟走线宽度/间距、参考地平面、保护环；叠层变化会影响阻抗/寄生（高速 ADC 尤其）。
- **钻孔：** Kelvin/屏蔽/接地过孔的孔径/数量；盘中孔是否填平。
- **BOM：** 位号、完整 MPN、阻值/公差/温漂/介质、ADC/运放/基准型号、DNP（如可选的缓冲/滤波档位）。
- **CPL：** 位号、层、旋转、极性；运放/ADC 的 pin 1 方向不能只靠丝印。
- **装配变体：** 缓冲/滤波/量程电阻的 DNP 选项必须明确；不同量程的 BOM/CPL 分开，不能只改备注。

**数量/备损/自有料：** 按每板用量×变体板数+备损−已核实自有料算；0.1% 电阻/基准/运放建议留备件（按项目风险，不写固定百分比）。自有料要核对完整型号/封装/是否拆机/是否受损；不能把散料当 SMT 工厂已备料。

**订单包含物：** 钢网、锡膏、校准/测试夹具、测试点、屏蔽罩是否包含，逐项写清。

**不一致处理：** 缺料/短装/多装/替代/ECO 按 [manufacturing-routes.md](../manufacturing-routes.md) §6；替代必须重算分压/增益/噪声/建立，不能只改 BOM 名称。

## 8. 异常状态与模型失效

| 状态 | 计算上会发生什么 | 设计动作 | 验证 |
|---|---|---|---|
| 输入过压 | 分压输出超 `VREF`，保护二极管导通/漏电 | 串阻/钳位/TVS；按 `VIN(max)` 算 | 加过压，测 ADC 引脚电流/电压 |
| 输入开路/短路 | 分压比失效，ADC 读 0/满量程 | 诊断偏置/上拉/下拉；软件范围检查 | 开路/短路测试 |
| 多路切换 | `C_ext` 残留前一通道电荷，建立不足 | 增加 `t_ACQ`/缓冲/放电开关 | 交替满量程/零，测相邻通道误差 |
| 高阻节点污染 | 漏电/吸潮导致漂移 | 护环/清洗/三防漆/降低 `R_th` | 温湿度箱/绝缘电阻 |
| 运放容性负载 | 相位裕度下降/振荡 | `R_ISO`/双反馈/换运放；仿真/实测 | 阶跃响应/相位裕度 |
| 运放输入超共模 | 输出反相/锁死/超差 | 查 `VCM` 范围；加钳位/分压 | 扫共模电压 |
| 基准负载瞬态 | `VREF` 跌落/振铃，ADC 码跳变 | 储能电容/缓冲；按 SAR 动态电流算 | 看 `VREF` 交流波形 |
| 电流采样共模瞬态 | PWM 边沿导致输出尖峰/误码 | 高 CMRR/增强 PWM 抑制/滤波/采样时刻 | 差分测输入/输出 |
| 分流电阻过热 | 阻值漂移/热电偶/失效 | 降额/加大封装/四线/Kelvin | 满载温升/阻值复测 |
| 校准后漂移 | 读数缓慢偏出 | 温度补偿/定期校准/自校准 | 高低温循环/长期 |

**模型失效的典型原因：**

- `R_SW`/`C_SH` 用了典型值，实际 max 更大。
- 忽略 ADC 输入漏电/保护二极管漏电，高阻分压被低估。
- 运放噪声只算 `en`，忽略 `in×R_source` 与电阻热噪声。
- 基准只算初始精度，忽略温漂/滞回/1/f。
- 电流采样只算电阻/增益，忽略失调、CMRR、自热。
- 抗混叠只算 `fc`，忽略多路切换建立。
- 校准只做一点，忽略增益/温漂。

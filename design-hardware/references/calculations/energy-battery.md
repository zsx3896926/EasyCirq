# 电池、续航与储能：带条件的计算手册

> **用途：** 把“这块电池能用多久、充电要多久、保护会不会误跳、超级电容能备份几秒、USB-C 供不供得动”变成可复算的状态表与能量账；重点是**电池输入侧电流、可用容量、压降/保护门限、充电热**，不是只看电芯标称 Ah。
>
> **证据等级：** `E1`（充电器/保护/超级电容/USB-C 的公式与条件已按 PWR-S07、PWR-S08、PWR-S10、PWR-S14、PWR-S15、PWR-S16、IF-S12 核对）；`E2`（自放电、老化、温度降额、Peukert、充电时间的工程近似，必须按电芯手册/实测核对）。
>
> **完成级别：** 离线规划（资料分析已完成）。没有 EDA、没有电池测试、没有充放电曲线、没有样机；脚本输出 `board_verified:false`、`lifetime_verified:false`。
>
> **可执行脚本：** [`power_budget.py`](../../scripts/power_budget.py)（电池输入侧状态预算）；[`calculate.py`](../../scripts/calculate.py) 的 `wire` 模式（线束/端子压降）。脚本不是电芯模型，不能证明寿命/安全。
>
> **命令目录：** 下文命令均从 `design-hardware/` 目录运行（即 `scripts/` 的上一级）。

## 1. 用途与决策边界

本文回答七个会改变方案的问题：

1. **续航够不够？** 按互斥状态列“每天 Ah”，再用可用容量/平均电流算天数；平均电流与峰值电流分开。
2. **容量/串并怎么选？** 能量 `Wh = V·Ah`；串联升压不升 Ah，并联升 Ah 不升压；保护/均衡/充电器随串数变。
3. **峰值电流会不会把电池/保护拉垮？** 用内阻压降 `ΔV=I·Rint` 对 UVLO/保护 UVP；用保护 IC 的门限/延时对负载峰值。
4. **充电要多快、热不热？** CC/CV 时间、输入限流、系统负载、线性/开关充电器的功耗与热调节。
5. **保护会不会误跳/该选什么门限？** OCD/OCC 测的是外部 FET 的 `Vds`，门限电流由 `Vthreshold/Rds(on)` 决定；门限/延时按型号固定（PWR-S10）。
6. **超级电容能备份多久？** `C=2TP/(η(VCF²−VCL²))`；串联容量减半；ESR 压降/漏电/变换器 UVLO 都要算。
7. **USB-C 5 V 能不能撑住？** 3 A 档的线缆/连接器压降、充电器 UVLO、Type-C 原生 15 W 上限；PD 不在本组来源内。

### 不能使用的条件

- **把标称 Ah 当可用 Ah**：温度、放电倍率、截止电压、老化、自放电都会减少可用容量；`usable_fraction` 必须显式给出。
- **把电池当理想电压源**：内阻压降在峰值电流/低温下会让电压跌到 UVLO/保护门限。
- **把保护板当充电器**：保护 IC 只做 OVP/UVP/OCC/OCD/SCP，不做 CC/CV、不做电量计（PWR-S10）。
- **把充电器当保护**：充电器的 OVP/热调节/终止不能替代电芯保护。
- **把 Type-C 3 A 广告能力当板端长期 3 A**：连接器、线缆、铜箔、热都限制；PD/EPR 未读，不能据此设计 5 V 以上。
- **用 Peukert 算锂电**：Peukert 主要适用于铅酸；锂电按电芯放电曲线/截止电压，不能直接套。
- **没有电芯手册就给温度/老化/循环数**：本文的 2%/月自放电、20% 老化、−20 °C 容量系数都是**假设示例**，不是保证。

## 3. 模型与公式

### 3.1 状态、电荷与能量

- 电荷：`Q = I·t`；`Ah = A·h`；`mAh = mA·h`。
- 能量：`Wh = V·Ah`；`J = W·s`；`1 Wh = 3600 J`。
- 每天电荷：`Q_day = Σ(I_state·t_state·n_state)/3600`（A、s → Ah）；睡眠占剩余时间：`Q_sleep = I_sleep·(86400−Σt_active)/3600`。
- 平均电流：`I_avg = Q_day/24`（A）。
- 续航：`t_days = C·usable_fraction/Q_day`。
- 状态必须**互斥**：同一时刻只能属于一个状态；总电流是电池输入侧总电流（含转换器损耗），不能把 3.3 V 负载电流直接填进去。
- 转换：`I_bat = P_rail/(η·V_bat)`；例 3.3 V/20 mA = 66 mW，`η=0.85`、`V_bat=3.7 V` → 21 mA。

**假设：** 代表日、状态互斥、电流恒定；不覆盖温度/老化/自放电/峰值/转换器启动。

### 3.2 可用容量与能量

- 可用容量 `C_usable = C·f_temp·f_age·f_rate·f_cutoff`；这些系数必须来自电芯手册/实测，不能默认 1。
- 能量 `E_usable = C_usable·V_nominal`（近似）；更准确是 `∫V·I dt` 沿放电曲线。
- 串联：`V_pack = n·V_cell`，`Ah_pack = Ah_cell`，`Wh_pack = n·Wh_cell`；需要均衡/多节保护。
- 并联：`V_pack = V_cell`，`Ah_pack = m·Ah_cell`，`Wh_pack = m·Wh_cell`；需要均流/匹配。
- 自放电：`Q_self = C·self_discharge_rate·t`；例 2%/月 → 1.5 Ah×0.02/30 = 1 mAh/天；与负载同量级时不可忽略。
- 老化：容量随循环/日历下降；`C_end = C·(1−loss)`；寿命判据（如 80% 容量）按电芯手册，不写通用循环数。
- Peukert（仅铅酸）：`t = C_p/I^k`，`C_p = I_rated^k·t_rated`；例 7 Ah/20 h、`k=1.2`，2 A 时约 2.47 h，而 `7/2=3.5 h` 高估 29%。**锂电不套此式。**

### 3.3 内阻、压降与保护

- 峰值压降：`ΔV = I_peak·Rint(T, aging)`；低温/老化 `Rint` 上升。
- 负载端电压：`V_load = V_oc − I·Rint − I·R_wire − I·R_protection`；`R_protection` 含保护 FET（通常 2 颗串联）、采样电阻、连接器。
- 保护 FET 压降：`V_fet = I·(Rds(on)_CHG + Rds(on)_DSG)`；例 2×10 mΩ、3 A → 60 mV。
- OCD/OCC 门限电流：`I_trip ≈ V_threshold/(Rds(on)_CHG+Rds(on)_DSG)`（PWR-S10：OCD 测外部 FET 两端压降）。门限/延时按型号固定，不能软件调。
- 短路：SCP 门限 `V_SCD` + 固定延时（BQ297xx `tSCD=250 µs`，±50%）；实际切断还取决于 FET 关断速度/回路电感。
- 恢复：OVP 12 ms、UVP/OCC/OCD 8 ms（BQ297xx 示例）；UVP/OCD 释放还要求 `BAT−V− > 1 V`。
- 保护 IC 功耗：NORMAL `ICC` 典型 4 µA、Shutdown 100 nA（BQ297xx 示例）；对长期待机有意义，但通常小于电芯自放电。

### 3.4 充电

- CC/CV：先恒流 `Ichg` 到 `VBAT(REG)`，再恒压到 `ITERM`；CC 时间 `t_cc ≈ C·(SOC_target−SOC_start)/Ichg`；CV 尾时间取决于 `ITERM`、电芯/温度，不能只用 CC 公式。
- 线性充电器功耗：`PD ≈ (Vin−Vbat)·Ichg + Vin·Iq`；结温 `TJ = TA + PD·θJA`；热调节门限（BQ2407x `TJ(REG)=125 °C`、`TJ(OFF)=155 °C`）会减小/关断充电。**有 power path 时 pass FET 还承载系统电流**，`PD` 要按 `Ichg+Isys` 算，不能只算充电电流。
- 开关充电器：`Pin = Pout/η`；`Iin = Pout/(η·Vin)`；热调节门限（BQ25619 `TJ(REG)=110 °C`、`TSHUT=150/130 °C`）。
- 输入限流/DPPM：输入电流 = 充电电流 + 系统电流；超过 `IIN_MAX` 时先减小充电电流，系统优先；DPPM 期间禁止终止（PWR-S07 §9.3.4）。
- USB 输入电容：USB 规范允许硬启动 10 µF，对应 >100 mA 时最大浪涌电荷 50 µC；PWR-S07 要求输入电容 <10 µF，因为这部分充电电流不受限。
- USB-C：5 V 档 500 mA/1.5 A/3 A；原生最大 15 W（3 A@5 V）；PD 不在本组来源内（PWR-S16 只读 CC 章节）。TUSB320 只支持 Type-C 1.1、无 e-marking（PWR-S15）；规范当前 Release 2.5（2026-04-08）只作为版本元数据，正文未读（PWR-S17）。因此本文只写 5 V 档，不写 PD/EPR。
- 充电时间不是“容量/电流”这么简单：系统负载、输入限流、CV 尾、温度降额、DPPM 都会拉长。

### 3.5 超级电容

- 备份能量：`E = ½C(VCF²−VCL²)`；备份时间 `T = C(VCF²−VCL²)·η/(2P)`；反解 `C = 2TP/(η(VCF²−VCL²))`（PWR-S14 Eq.5）。
- `VCF`：正常工作最坏充电电压（比较器下降门限对应值）；`VCL`：可放电到的最低电压（受变换器最小输入/UVLO 限制）；`η`：变换器效率；`P`：备份功率。
- 串联：`1/C_total = Σ1/C_i`；两颗同容串联 → 一半；需要均压/平衡。
- ESR 压降：`ΔV_ESR = I_peak·ESR`；低温 ESR 上升；对 UVLO 是瞬时跌落。
- 漏电：电容漏电 + 平衡电阻 + 变换器 `IQ`；`t_drain ≈ C·V/I_leak`；例 2.5 F、5 V、13.5 µA → 10.7 天。
- 充电限流：`I = C·dV/dt`；不限流会拉垮主电源；PWR-S14 示例把充电限到 50 mA。
- 理想二极管/ORing 提供反向阻断；PWR-S06 区分 RPP（反接保护）与 RCB（反向电流阻断），不能混为一谈。

## 4. 判据与决策表

### 4.1 推荐工作条件 ≠ 绝对最大额定值

| 参数 | 推荐工作条件（设计判据） | 绝对最大额定值的使用 | 决策 |
|---|---|---|---|
| 电芯充电电压 | 按电芯手册（例 4.2 V±1%） | 绝对最大按电芯手册；保护 OVP 是最后防线 | 充电器 4.16–4.23 V + 保护 OVP 4.275 V 示例，余量只有 45 mV，必须核对两者容差 |
| 放电截止 | 按负载 UVLO/电芯手册（例 2.8–3.0 V） | 绝对最小按电芯手册 | UVP 2.8 V/144 ms 示例；负载峰值压降不能碰到 UVP |
| 充电电流 | ≤电芯推荐（常 ≤1C，按手册/温度） | 绝对最大按电芯手册 | 1.5 Ah、0.5C=0.75 A；高温/低温柔性降额 |
| 充电温度 | 电芯允许窗口（NTC/JEITA） | 绝对最大按电芯手册 | 0 °C 以下通常不充；PWR-S07 NTC 示例对应 0/50 °C，不能套其他电芯 |
| 充电器 `Vin` | 4–13.5 V（BQ25619 推荐） | 22 V 绝对最大（BQ25619） | 5 V USB/12 V 适配器；瞬态不能靠绝对最大兜底 |
| 充电器 `TJ` | 热调节 110/125 °C 以下 | 关断 150/155 °C | 不要在热调节点附近设计；留 20–30 °C |
| 保护 FET `Vds` | 按稳态/短路电流算 | 绝对最大按 FET 手册 | OCD 门限由 `Vth/Rds(on)` 决定；FET 选小 `Rds(on)` 会提高跳闸电流 |
| 超级电容电压 | ≤额定并降额 | 绝对最大按电容手册 | 5 V 备份用 5.5 V/6.3 V 额定；串联均压 |
| USB-C 电流 | 端口/线缆/连接器实际能力 | 规范上限不是长期保证 | 3 A 广告 ≠ 板端 3 A；按线缆压降/热核算 |
| 电芯容量 | 手册最小值（按测试条件） | 不是“绝对最大” | 用 min 而非 typical；温度/老化另算 |

### 4.2 典型值不能替代保证值

| 参数 | 典型值用途 | 为什么不能当保证 | 设计应取 |
|---|---|---|---|
| 电芯容量 | 初算续航 | 测试倍率/截止/温度不同；批次差异 | 手册最小值 + 温度/老化系数 |
| 自放电 | 初估 shelf life | 随温度/荷电状态/批次 | 手册 max 或实测 |
| 内阻 | 初估压降 | 随温度/老化/荷电状态上升 | 最低温度/寿命末的最大值 |
| 保护门限/延时 | 初选 | 检测精度和延时容差分别查表，不能混用；型号固定 | 手册 min/max |
| 充电器 `VBAT(REG)` | 初算 | 4.16/4.20/4.23 min/typ/max | 用 max 对 OVP、min 对充满度 |
| 充电器效率 | 初估热 | 随 `Vin/Vbat/I` 变化 | 最坏点/实测 |
| 充电器 `θJA` | 初估结温 | 板条件不同 | 最大值/实测 |
| 超级电容容量/ESR | 初算备份 | 随温度/老化/电压下降 | 寿命末最小容量/最大 ESR |
| 超级电容漏电 | 初算保持 | 随温度/电压 | 最大值/实测 |
| USB 端口电流 | 初算充电时间 | 端口/线缆/适配器协商 | 实际端口能力/限流 |

> **典型值不能替代保证值：** 续航算例中的 2%/月自放电、20% 老化、−20 °C 容量系数都是假设；实际必须用电芯手册/实测替换。`power_budget.py` 明确输出 `lifetime_verified:false`，不能把模型天数当寿命承诺。

### 4.3 快速判据

| 判据 | 通过条件 | 不通过时的动作 |
|---|---|---|
| 续航 | `C·usable/Q_day ≥ target_days` | 降平均电流/加容量/改状态频次 |
| 峰值压降 | `V_oc − I_peak·Rint(max) − I·R_protection > UVLO` | 加 bulk 电容/降峰值/换低内阻电芯/提高 UVLO 裕量 |
| 保护不误跳 | 负载峰值 < `Vth/Rds(on)` 且持续时间 < 延时 | 换低 `Rds(on)` FET/选高门限型号/限制峰值 |
| 短路保护 | SCP 门限/延时内 FET SOA 足够 | 换 FET/加限流/缩短回路 |
| 充电时间 | `t_cc + t_cv ≤` 目标 | 提高 `Ichg`/换开关充电/提高输入限流 |
| 线性充电热 | `TJ = TA + (Vin−Vbat)·Ichg·θJA ≤` 目标 | 降 `Ichg`/换开关充电/加铜 |
| USB 输入 | `Iin ≤` 端口限流，且 `Vin` 不低于充电器 UVLO | 降充电电流/换 1.5 A/3 A 源/短粗线 |
| 超级电容备份 | `C ≥ 2TP/(η(VCF²−VCL²))` 且 ESR 压降不触 UVLO | 加容量/串并联/提高 `VCL`/降 `P` |
| 超级电容保持 | `C·V/I_leak >` 待机时间 | 降漏电/加容量/只在短时备份用 |
| 串并 | 串数满足电压，容量满足 Ah，保护/均衡匹配 | 改串并/保护/充电器 |

## 5. 算例（脚本实际运行）

### 5.1 1.5 Ah 无线传感器节点：状态表与续航

**给定条件：** 1S Li-ion，标称 3.7 V、1.5 Ah；`usable_fraction=0.75`；睡眠 20 µA；每天 96 次采集（15 mA×2 s）、96 次 MCU 活跃（8 mA×1.5 s）、96 次发射（90 mA×1.2 s）、4 次阀门（300 mA×0.8 s）；目标 90 天。所有电流已折算到**电池输入侧**。

**运行：**

```bash
python scripts/power_budget.py budget.json
```

其中 `budget.json`：

```json
{
  "capacity_Ah": 1.5,
  "usable_fraction": 0.75,
  "current_basis": "battery_input",
  "sleep_current_A": 0.00002,
  "target_days": 90,
  "states": [
    {"name": "sensor", "current_A": 0.015, "duration_s": 2.0, "events_per_day": 96},
    {"name": "mcu_active", "current_A": 0.008, "duration_s": 1.5, "events_per_day": 96},
    {"name": "radio_tx", "current_A": 0.09, "duration_s": 1.2, "events_per_day": 96},
```

### 5.2 目标未达：0.5 Ah/90 天的反例

**给定条件：** 0.5 Ah、`usable_fraction=0.7`（0.35 Ah 可用）；睡眠 100 µA；每 5 分钟发射一次（150 mA×2 s，288 次/天）+ MCU（12 mA×2 s，288 次/天）；目标 90 天。

**运行结果（实际）：**

| 量 | 值 |
|---|---:|
| 每天 Ah | 0.028288 |
| 平均电流 | 1.179 mA |
| 估算天数 | 12.37 |
| 目标 | 90 |
| 状态 | `target_missed` |

**要达到 90 天，需要把每天电荷降到 `0.35/90 = 3.889 mAh/天`**，即降到当前的 13.7%。可选：

| 方案 | 计算 | 结果 |
|---|---|---|
| 降低发射频次 | `28.288×(40/288)=3.93 mAh/天` | 约 89 天，仍略不足；39 次/天约 91 天 |
| 提高容量 | `0.5×(28.288/3.889)=3.64 Ah` | 90 天；体积/成本大幅增加 |
| 降低发射电流/时长 | 需要总电荷降 86% | 通常不可行 |
| 改能量采集/市电 | 不再按电池续航 | 方案变更 |

**决策：** 这个反例说明“0.5 Ah 小电池 + 5 分钟一次无线发射”不可能达到 90 天；不是靠 `usable_fraction` 调高能解决的。先改占空比/发射策略，再谈容量。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际发射电流/时长、重试、温度、老化；它只证明在该组假设下模型目标未达。

### 5.3 充电时间与线性/开关充电热

**给定条件：** 1.5 Ah 1S；从 20% 到 80% 需要 0.9 Ah；`Ichg=0.75 A`（0.5C）；`Vin=5 V`；`Vbat≈3.7 V`；`θJA=50 °C/W`（示例，待查）；`TA=45 °C`；USB 端口 500 mA；系统负载 300 mA。

**CC 时间：**

- 理想：`0.9 Ah/0.75 A = 1.2 h`
- CV 尾：按 `ITERM`/电芯，示例 0.3–0.5 h；总计约 1.5–1.7 h
- 500 mA 端口、系统 300 mA：充电输入 200 mA；线性充电器电池侧约 200 mA → `0.9/0.2 = 4.5 h`；开关充电器 `0.2×5×0.9/3.7 = 0.243 A` → `3.7 h`；再加 CV 尾。

| 充电方案 | `Ichg` | `PD`/损耗 | `ΔTJ`（θJA=50） | `TJ`（TA=45） | 判断 |
|---|---:|---:|---:|---:|---|
| 线性 5 V | 0.75 A | 0.975 W | 48.8 °C | 93.8 °C | 低于 125 °C 热调节，但余量 31 °C；θJA=100 时 142.5 °C → 热调节 |
| 线性 5 V | 0.50 A | 0.650 W | 32.5 °C | 77.5 °C | 可用；θJA=100 时 110 °C |
| 线性 5 V | 0.20 A | 0.260 W | 13.0 °C | 58.0 °C | 可用；充电慢 |
| 开关 5 V | 0.75 A | 约 0.308 W（η=0.9） | 15.4 °C | 60.4 °C | 热最好；需电感/EMI |

**决策：** 0.75 A 线性充电在 `θJA=50` 时还能工作，但 `θJA=100` 会进入热调节、充电时间变长；如果产品是密封壳/45 °C 环境，优先开关充电或把 `Ichg` 降到 0.5 A。USB 500 mA 端口 + 300 mA 系统负载时，充电时间 3.7–4.5 h，不能按 1.2 h 宣传。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际 `θJA`、电芯 CV 曲线、`ITERM`、DPPM、NTC 降额、USB 端口实际能力、power path 系统电流带来的额外 `PD`；0.3–0.5 h CV 尾是假设。

### 5.4 保护门限 vs 保护 FET `Rds(on)`

**给定条件（BQ29700 示例，PWR-S10）：** OVP 4.275 V/1.25 s；UVP 2.800 V/144 ms；OCC −0.100 V/8 ms；OCD 0.100 V/20 ms；SCD 0.5 V/250 µs。保护 FET 两颗串联，`Rds(on)` 分别取 5/10/20 mΩ。

| 每颗 `Rds(on)` | 串联 `R` | OCD/OCC 跳闸电流 | SCD 跳闸电流 | 3 A 负载压降 |
|---:|---:|---:|---:|---:|
| 5 mΩ | 10 mΩ | 10 A | 50 A | 30 mV |
| 10 mΩ | 20 mΩ | 5 A | 25 A | 60 mV |
| 20 mΩ | 40 mΩ | 2.5 A | 12.5 A | 120 mV |

**决策：**

- 上表是**标称门限**计算；检测电压精度与延时容差必须分别查表；不能用延时百分比作为电压误差，实际跳闸点要按 min/max 重算，不能把 5 A 当保证值。
- 若负载峰值 3 A，选 2×20 mΩ 会在 2.5 A 就触发 OCD（20 ms 后），**误跳**；必须选 2×10 mΩ 或更低，或选更高门限的型号。
- 若负载峰值 8 A（电机启动），2×10 mΩ 的 5 A 门限会跳；需要低 `Rds(on)` FET（2×5 mΩ → 10 A）或更大门限/延时型号。
- 短路 25 A/250 µs：FET 必须在 4.2 V×25 A≈105 W、250 µs 的脉冲下不超 SOA；要按 FET 的 SOA/`Zth` 核对（见 [power-thermal.md](power-thermal.md)）。
- 3 A 时 2×10 mΩ 压降 60 mV；若 UVLO 余量只有 100 mV，保护 FET 就吃掉了 60%。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：具体保护 IC 的门限/延时容差、FET 的 SOA、短路回路电感/实际切断时间、重复短路；BQ29700 数值只属于该型号。

### 5.5 超级电容备份：容量、ESR 与漏电

**给定条件：** 备份功率 `P=2 W`；时间 `T=10 s`；`VCF=5.0 V`（充满/比较器门限）；`VCL=2.5 V`（变换器 UVLO）；`η=0.85`。

`C = 2×10×2/(0.85×(25−6.25)) = 40/15.94 = 2.51 F`

- 选两颗 5 F 串联 → 2.5 F（串联容量减半）；需要均压/平衡。
- 实际 `T = 2.5×(25−6.25)×0.85/(2×2) = 9.96 s`，刚好满足 10 s（在假设内）。
- 若 `VCL` 提高到 3.0 V：`T = 2.5×16×0.85/4 = 8.5 s`，**不满足**；说明变换器 UVLO 直接吃掉备份时间。
- 若 `VCL` 降到 2.0 V：`T = 2.5×21×0.85/4 = 11.16 s`。

| `VCL` | 可用能量（`½CΔV²`） | 备份时间（η=0.85, P=2 W） | 判断 |
|---:|---:|---:|---|
| 3.0 V | 20.0 J | 8.5 s | 不满足 10 s |
| 2.5 V | 23.4 J | 9.96 s | 临界满足 |
| 2.0 V | 26.25 J | 11.16 s | 满足 |

**ESR/漏电：**

- `ESR=100 mΩ`、峰值 2 A → 200 mV 瞬时跌落；若 UVLO 余量只有 100 mV，会提前关断。选低 ESR/多颗并联。
- 漏电：平衡电阻 2.5 µA + 变换器 `IQ` 11 µA（TPS63802 典型，PWR-S09）→ 13.5 µA；`2.5 F×5 V/13.5 µA = 10.7 天`。备份电容不是长期储能，充满后若主电断开多日，能量会被漏电吃光。
- 充电限流：`I=C·dV/dt`；不限流时 5 V/2.5 F 的浪涌很大；PWR-S14 示例把充电限到 50 mA → `2.5×5/0.05 = 250 s`（4.2 min）充满。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：超级电容寿命/ESR 老化/自放电、均压失效、变换器实际 UVLO/效率、短路/浪涌；2.5 F/5 V/2 W/10 s 是算例条件。

### 5.6 USB-C 5 V/3 A 的线缆压降

**给定条件：** 5 V/3 A；线缆+连接器+PCB 总电阻 `R` 取 0.05/0.10/0.15/0.20 Ω；充电器 UVLO 4.5 V；Type-C 规范 IR drop 限值：VBUS ≤500 mV、GND ≤250 mV（IF-S12 §4.4.1）。

| `R` | 3 A 压降 | 3 A 损耗 | 充电器输入 | 2 A 压降 | 判断 |
|---:|---:|---:|---:|---:|---|
| 0.05 Ω | 0.15 V | 0.45 W | 4.85 V | 0.10 V | 可用 |
| 0.10 Ω | 0.30 V | 0.90 W | 4.70 V | 0.20 V | 可用 |
| 0.15 Ω | 0.45 V | 1.35 W | 4.55 V | 0.30 V | 接近 VBUS 500 mV 限值；UVLO 余量 50 mV |
| 0.20 Ω | 0.60 V | 1.80 W | 4.40 V | 0.40 V | **超 VBUS 限值；充电器可能掉出 UVLO** |

**决策：** 3 A 档要用短/粗线（低 `R`）并核对连接器额定；若线缆 `R` 接近 0.15 Ω，把电流限到 2 A 或提高充电器 UVLO 裕量。5 V/3 A 是 Type-C 原生 15 W 上限；PD 5 V 以上不在本组来源内，不能据此设计 9/15/20 V。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际线缆/连接器电阻、USB-C 端口协商、PD、热、插拔寿命；`R` 是假设。

## 7. 制造与装配接口

完整路线见 [manufacturing-routes.md](../manufacturing-routes.md)；本节只列与电池/储能计算相关的决策。

| 计算结论 | 路线 A：商城购料 + 自焊 | 路线 B：嘉立创 PCB + SMT | 路线 C：板 + 固件/结构 + 整机 |
|---|---|---|---|
| 电芯/电池座 | 电池座/引线手焊；极性/端子必须核对 | 电池座 THT/SMT 取决于封装；SMT 可贴性另查 | 电池仓/壳体/螺钉/防反接 |
| 保护板/FET | 保护板可外购/手焊；注意 FET 散热 | 保护 IC/FET 贴片；钢网/回流 | 保护板固定/绝缘/温度 |
| 充电器 | 线性/开关充电器手焊；热焊盘 | EPAD/散热过孔/双面回流 | 壳体散热/密封温升 |
| NTC | 手焊/引线；位置贴电芯 | NTC 贴片/引线；位置按电芯表面 | 线束/导热胶/可维护性 |
| 线束/端子 | 线径/端子按峰值/压降算 | 连接器/SMT 端子 | 线束图、长度、颜色、保险 |
| 超级电容 | 大电容手焊/引线；均压电阻 | 电容封装/高度/回流 | 固定/绝缘/防短路 |

**手焊 vs SMT、THT vs SMT、双面：** 电池座/大端子/保险丝座常为 THT，需插件/选择性焊；保护 IC/充电器 QFN/EPAD 走 SMT；双面贴装时电池座/大电容/散热器尽量放顶面，底面器件要能承受二次回流，且不能与电芯/壳体干涉。

**必须与 Gerber/钻孔/BOM/CPL 对账：**

- **Gerber/叠层：** 充电器/保护 FET 的铜面积、散热过孔；大电流路径的铜厚。
- **钻孔：** 散热/功率过孔的孔径/数量；电池座/端子孔。
- **BOM：** 电芯完整型号/化学/容量/端子、保护 IC/FET、充电器、NTC、超级电容；DNP（电池座/外部供电变体）。
- **CPL：** 电池座/连接器/保护 IC 的层、旋转、极性；电芯极性不能只靠丝印。
- **装配变体：** 1S/2S、带电池/外接电源、不同容量电芯、带/不带超级电容，必须是明确变体；BOM/CPL 分开。

**数量/备损/自有料：** 按每板用量×变体板数+备损−已核实自有料算；电芯有保质期/运输限制，备料不宜过多（具体按供应商/承运商）。自有电芯要核对型号/容量/内阻/是否拆机/是否受损；不能把旧电芯当新电芯。

**订单包含物：** 电池座、端子、线束、保险、NTC、导热胶、保护板是否包含，逐项写清；不能把“PCB+SMT”当“整机含电池”。

**不一致处理：** 缺料/短装/多装/替代/ECO 按 [manufacturing-routes.md](../manufacturing-routes.md) §6；替代电芯/保护必须重算容量/门限/充电/热，不能只改 BOM 名称。

## 8. 异常状态与模型失效

| 状态 | 计算上会发生什么 | 设计动作 | 验证 |
|---|---|---|---|
| 低温 | 容量下降、内阻上升，峰值压降触 UVLO | 低温降额/加热/提高 UVLO 裕量 | 低温箱放电/峰值 |
| 高温 | 充电热调节/老化加速 | 降 `Ichg`/散热/温度保护 | 高温充电/温升 |
| 过放 | UVP 切断；恢复需 `BAT−V−>1 V` | 避免长期存放于低电量；运输模式 | 过放/恢复测试 |
| 过充 | OVP 切断；充电器 CV 失效时保护 | 双重保护：充电器 CV + 保护 OVP | 模拟 CV 失效 |
| 负载短路 | SCP 门限/250 µs 延时；FET SOA | 低 `Rds(on)`/高 SOA FET；限流 | 短路测试（安全夹具） |
| 电机/阀门启动 | 峰值电流可能触 OCD/UVP | 软启动/限流/bulk 电容/低内阻 | 启动波形 |
| 充电器输入塌陷 | DPPM 降充电电流；系统优先 | 输入限流/大电容/适配器能力 | 可调电源扫输入 |
| 反向电流 | 电池向输入/另一路倒灌 | 理想二极管/ORing/阻断 FET | 输入断电，测反灌 |
| 超级电容漏电 | 备份能量在数天内耗尽 | 降漏电/只在短时备份/主电保持 | 断电保持测试 |
| 保护误跳 | 负载峰值接近门限/延时 | 重选 FET/门限/延时 | 峰值/脉冲矩阵 |

**模型失效的典型原因：**

- 状态不互斥/电流不是电池输入侧，导致重复计算或漏算。
- `usable_fraction` 拍脑袋给 0.9，实际温度/老化/截止后只有 0.6。
- 忽略自放电/保护 IC/转换器 `IQ`，长期续航高估。
- 忽略内阻/保护 FET 压降，峰值时 UVLO/保护误跳。
- 线性充电器只看 `Ichg`，忽略 `(Vin−Vbat)·Ichg` 的热。
- 超级电容只看容量，忽略 ESR/漏电/UVLO。
- USB-C 只看 3 A 广告，忽略线缆/连接器压降。

## 9. 验证与测量

| 对象 | 测点/仪器 | 条件 | 通过标准 | 停止条件 |
|---|---|---|---|---|
| 容量 | 电子负载/电池测试仪，四线 | 标准充/放电、指定截止 | ≥ 设计可用容量 | 过温/过放 |
| 续航 | 整机 + 电流记录仪/库仑计 | 代表日、目标温度 | ≥ 目标天数 | 提前关机 |
| 峰值压降 | 示波器差分测电池端/负载端 | 最大峰值、最低温度 | 不低于 UVLO/UVP | 触发保护 |
| 充电时间 | 电源/电子负载/记录仪 | 指定 `Vin`、`TA`、SOC 区间 | ≤ 目标时间 | 热调节/超时 |
| 充电热 | 热电偶/热像仪 | 最坏 `Vin`、最大 `Ichg`、密封壳 | `TJ` ≤ 目标 | 热关断 |
| 保护门限 | 可调电子负载/短路夹具 | 逐步加载/短路 | 在规定门限/延时动作 | 器件损坏 |
| 保护恢复 | 电源/负载 | 故障解除 | 按手册恢复 | 不恢复/反复跳 |
| 超级电容备份 | 电子负载/示波器 | 主电断开、指定 `P` | ≥ 目标时间；不低于 UVLO | 提前掉电 |
| 超级电容漏电 | 静电计/长时间记录 | 充满、常温/高温 | 保持时间 ≥ 目标 | 超漏电 |
| USB-C 压降 | 四线/示波器 | 3 A/2 A、实际线缆 | VBUS 压降 ≤500 mV、GND ≤250 mV | 超限/掉压 |

**仿真状态：** 本文未执行电芯/热/SPICE 仿真。若要补：用厂商电芯模型（OCV-Rint 或等效电路）+ 实际负载曲线 + 温度，观察电压/容量/温升；通过标准为截止电压前容量 ≥ 目标、峰值电压 ≥ UVLO、`TJ` ≤ 目标。模型不含老化/批次/安全滥用，不能替代电芯测试。

**安全：** 锂电测试要有防火/防爆容器、保险、限流、温度监控、无人值守禁止；短路/滥用测试按电芯/实验室安全规程，不得在普通桌面直接做。

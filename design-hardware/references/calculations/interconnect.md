> **用途：** 把“这条线能不能过 3 A、这个过孔够不够、这段走线要不要按传输线处理、终端/参考面怎么定”变成可复算的判据；重点是**直流压降/温升、过孔/连接器瓶颈、传输线起始宽度、临界长度、时序/参考条件**，不是套“1 mm 过 1 A”或“所有差分都等长”。

> **证据等级：** `E1`（接口电气限值/端接/IR drop 已按 IF-S01、IF-S02、IF-S03、IF-S04、IF-S07、IF-S11、IF-S12 核对）；`E2`（微带/带状线阻抗、传播延迟、载流温升、过孔电阻的工程公式，必须用板厂叠层/场求解/实测确认）。本文不把 `E2` 写成板厂保证。
>
> **完成级别：** 离线规划（资料分析已完成）。没有 EDA、没有叠层、没有 Gerber/钻孔、没有 TDR/VNA/热成像；脚本输出 `board_verified:false`。
>
> **可执行脚本：** [`calculate.py`](../../scripts/calculate.py) 的 `wire` 模式（矩形铜导体的直流电阻/压降/损耗/电流密度）。传输线/过孔/连接器公式在文中给出，未封装成脚本。

## 1. 用途与决策边界

本文回答八个会改变设计的问题：

1. **走线/线束/端子要多大？** 先算直流电阻/压降/损耗，再用“用户设定的电流密度筛选值”初筛；温升必须用实际叠层/铜厚/环境/实测，不能用统一“A/mm²”当保证。
2. **瓶颈在哪？** 焊盘颈缩、过孔、连接器、保险丝、端子往往比长走线更窄；只加宽中间线段不解决问题。
3. **过孔够不够？** 按钻孔/镀层厚度算桶壁电阻；电流额定/温升要按板厂/标准/实测，不能把走线的 A/mm² 直接套到过孔。
4. **这段线要不要按传输线处理？** 用上升时间/传播延迟算临界长度；低于临界长度按集总 RC，高于则要阻抗/端接/参考。
5. **微带/带状线起始宽度是多少？** 用叠层 `h`、`εr`、铜厚 `t` 算 `Z0` 起点；最终宽度必须由板厂场求解/阻抗测试确认。
6. **时序/等长怎么定？** 先算传播延迟和时序预算，再决定等长公差；不是所有线越等长越好。
7. **参考面怎么连续？** 微带要相邻参考层，带状线要在两平面之间；跨分割/换层要提供回流路径；差分也需共模回流。
8. **接口的端接/共模/支线条件是什么？** USB 90 Ω 差分、以太网 100 Ω、CAN 120 Ω 端接、RS-485 90–120 Ω 端接、I²C 总线电容/上拉；这些是接口条件，不是“随便画”。

### 不能使用的条件

- **没有叠层就算阻抗**：`εr`、`h`、铜厚、阻焊厚度未知时，公式只能给起点，不能给“已实现 50 Ω”。
- **把“1 A/过孔”或“1 mm/1 A”当规则**：过孔/走线的温升取决于铜厚、长度、层、环境、气流、相邻铜；必须按实际条件核算/实测。
- **把电流密度筛选当温度保证**：脚本的 `max_current_density_A_per_mm2` 是**用户设定**的筛选值，不是标准/保证。
- **把差分当“两根线等长就行”**：还要参考连续、共模回流、过孔/连接器、对内/对间偏斜。
- **把端接电阻当“每个节点都装”**：CAN/RS-485 只在总线两端；USB/Ethernet 的端接可能在芯片/连接器/磁性件内。
- **没有时序预算就等长**：等长公差来自建立/保持/偏斜预算，不是固定 mil 数。
- **把接口规范上限当板级保证**：400 pF、32 U.L.、1200 m、90 Ω±15% 等是标准/器件条件，实际板还要回查器件/叠层/连接器。

## 3. 模型与公式

### 3.1 直流载流：走线、线束、过孔、连接器

- 矩形铜导体电阻：`R = ρ·l/A`；`A = w·t`；`ρ(θ) = 1.72×10⁻⁸·[1+0.00393·(θ−20)] Ω·m`（`θ` °C）。
- 压降：`ΔV = I·R`；损耗：`P = I²R`；电流密度：`J = I/A`。
- 脚本 `wire` 用上式计算；`max_current_density_A_per_mm2` 是用户筛选值，不是标准。
- 线束：多根并联时 `1/R_total = Σ1/R_i`；端子/压接/连接器接触电阻另加，往往主导。
- 过孔桶壁：`R_via ≈ ρ·l/(π(r_o²−r_i²))`；`r_o = 钻孔半径`，`r_i = r_o − 镀层厚度`；长度取板厚/层间。例 0.3 mm 钻孔、25 µm 镀层、1.6 mm 长 → 约 1.42 mΩ（见 5.1）。
- 连接器：`R_contact` 从手册取（例 20 mΩ，待查）；`ΔV = I·R_contact`；`P = I²R_contact`；多针并联需均流/降额。
- 焊盘/颈缩：实际最窄处可能是焊盘入口/热焊盘辐条；用最窄宽度算，不能用长线宽度。

**假设：** 均匀直流、矩形截面、无趋肤/邻近效应；实际还有端子/压接/镀层/孔壁粗糙度/温度分布。

### 3.2 温升与电流密度

- 走线温升取决于：铜厚、宽度、长度、层（内/外）、环境、气流、相邻铜、阻焊、脉冲/连续。**没有单一 A/mm² 通用规则。**
- 工程筛选：先设定 `J_max`（例 10–20 A/mm²，按项目/经验）和 `ΔT_max`（例 10 °C），再用实际板/热仿真/实测确认；脚本只做 `J` 筛选。
- 内层走线散热通常比外层差；同样宽度/铜厚，内层温升更高。
- 脉冲：热时间常数远大于脉冲时按平均功率；短脉冲按 `Zth`/热容；保险/熔断另算。
- 温升测量：热电偶/热像仪，稳定后记录 `TA`、走线/端子/过孔温度；不能只摸一下。

### 3.3 传输线：微带/带状线起始宽度

- 微带（IPC-2141 形式，`0.1<w/h<2`、`1<εr<15`）：
  `Z0 ≈ (87/√(εr+1.41))·ln(5.98h/(0.8w+t))`
- 带状线（近似）：
  `Z0 ≈ (60/√εr)·ln(4b/(0.67πw(0.8+t/w)))`，`b` 为两平面间距。
- 有效介电常数（微带）：
  `εeff ≈ (εr+1)/2 + (εr−1)/2·1/√(1+12h/w)`
- 传播延迟：`tpd = 3.333·√εeff` ns/m（微带）；带状线 `tpd = 3.333·√εr` ns/m（全嵌入）。
- 差分：`Zdiff ≈ 2·Z0·(1−k)`，`k` 为耦合系数；**不要用单端公式直接给差分阻抗**；用场求解/板厂。
- 公式只给起点；最终宽度/间距由板厂叠层、阻焊、铜厚、场求解/阻抗测试确认。

**假设：** 无限宽参考面、均匀介质、无阻焊/过孔/连接器；实际边缘场/阻焊/铜箔粗糙度会偏移。

### 3.4 临界长度、时序与等长

- 临界长度（集总→分布）：`l_c ≈ tr/(2·tpd)`；保守用 `tr/(6·tpd)`。低于 `l_c` 可先按集总 RC，高于则要考虑反射/端接/阻抗。
- 时序：`t_flight = l·tpd`；建立/保持预算 `t_setup ≥ t_flight + t_skew + t_jitter + t_margin`；等长公差 `Δl = Δt/tpd`。
- 差分对内偏斜：`Δl = Δt_skew/tpd`；例 5 ps、5.94 ns/m → 0.84 mm。
- 对间偏斜：按接口时序预算，不是固定值；DDR/并行总线要按实际协议。
- 等长不是目的：先保证拓扑/参考/端接，再补偿有明确缺口的偏斜；蛇形线会增加耦合/损耗。

### 3.5 参考面与回流

- 微带：相邻层必须是完整参考（GND 优先）；参考面开槽/分割会让回流绕行，阻抗/串扰/EMI 变差。
- 带状线：两平面之间；一面是电源时，换层/过孔附近要有缝合电容提供高频回流。
- 换层：信号过孔旁放回流过孔；距离按场求解/原厂指南，本文不给通用 mm 数。
- 跨分割：不要跨；必须跨时加桥接/缝合电容，并验证（不是画一个电容就解决）。
- 连接器：地针/屏蔽要按配对连接器定义；差分对极性/ lane 映射要核对。
- 差分：共模回流仍存在；参考不连续/不对称会导致共模/EMI。

### 3.6 集总 vs 分布：接口条件

- I²C：总线是 RC 集总（典型板内/<10 m），上限由 `Cb`、`tr`、`IOL` 决定；`Rp(max)=tr/(0.8473·Cb)`，`Rp(min)=(VDD−VOL)/IOL`（IF-S01/S02）。超过 400 pF 用分段/缓冲，每段各 400 pF；TCA9517 的 B 侧有静态偏移，不能 B 侧对 B 侧串联（IF-S10）。
- RS-485：`数据率(bps)×长度(m) ≤ 10^8`（经验）；终端 `ZT` 在 `Zo±20%`，约 90–120 Ω；两端各一个（IF-S03）。
- CAN：120 Ω 双绞，两端各 120 Ω；分裂端接 2×60 Ω+4.7 nF；支线 ≤1/3 临界长度；1 Mbps/40 m/30 节点/支线 ≤0.3 m（IF-S04）。
- USB 2.0 FS：电缆 90 Ω±15%，驱动器 28–44 Ω（含 `RS`），D+ 1.5 kΩ±5% 上拉；全速最大单向延时 26 ns（IF-S11）。
- Ethernet 10/100：MDI <2 in、100 Ω±10%、对内 20 mil（1G）/50 mil（100M）；MII <6 in、单端 50 Ω±10%（IF-S07）。PHY 的 `RBIAS` 4.87 kΩ±1%、磁性件中心抽头与 `AVD` 同电位（IF-S13，仅 DP83822）；换 PHY 必须重查。
- USB-C：CC/VCONN/SBU 是低速控制；IR drop VBUS ≤500 mV、GND ≤250 mV（IF-S12）；数据 D+/D− 仍按 USB 2.0。

## 4. 判据与决策表

### 4.1 推荐工作条件 ≠ 绝对最大额定值

| 参数 | 推荐工作条件（设计判据） | 绝对最大额定值的使用 | 决策 |
|---|---|---|---|
| 走线电流 | 按 `ΔV`/`ΔT` 预算算宽度/铜厚 | 没有“绝对最大电流”这种通用额定；熔断/温升是条件 | 先算 `R/ΔV/P`，再按板厂铜厚/温升验证 |
| 过孔电流 | 按板厂/标准/实测的载流/温升 | 钻孔/镀层最小厚度是工艺边界 | 大电流用多孔并联；不要用走线 `J` 直接套 |
| 连接器电流 | 按触点额定/温度降额/多针均流 | 额定电流不是任意针数/温度下的保证 | 3 A 用 ≥3 A 降额后的触点；压降/热一起看 |
| 走线电压 | 按间距/爬电/阻焊/标准 | 介质击穿是绝对边界 | 24 V/48 V 按标准/板厂能力查间距 |
| 微带 `Z0` | 目标 ±10%（按接口） | 不是绝对最大 | 50 Ω 单端/90–100 Ω 差分按接口；板厂阻抗测试 |
| USB 差分 | 90 Ω±15%（FS 电缆），驱动器 28–44 Ω | 不是绝对最大 | 按 PHY/连接器/线缆条件；不能只看 `Zdiff` |
| 以太网 MDI | 100 Ω±10%，MDI <2 in | — | 按 PHY/磁性件/连接器；中心抽头按 PHY |
| CAN/RS-485 共模 | CAN −2…+7 V、RS-485 −7…+12 V | 收发器绝对最大可能更高 | 共模超范围要隔离/接地；不能靠绝对最大 |
| I²C `Cb` | 400 pF（Sm/Fm）、550 pF（Fm+） | 不是绝对最大 | 超了分段/缓冲/降速；不是“加大上拉” |
| 时序 | 按建立/保持/偏斜预算 | 器件绝对最大频率不是可用频率 | 先算 `tpd`/偏斜，再决定等长 |

### 4.2 典型值不能替代保证值

| 参数 | 典型值用途 | 为什么不能当保证 | 设计应取 |
|---|---|---|---|
| 铜厚 | 初算电阻 | 板厂实际铜厚/镀层有公差 | 最小铜厚/实测 |
| `εr` | 初算阻抗 | 随频率/树脂/叠层/批次变 | 板厂叠层数据/阻抗测试 |
| 过孔镀层 | 初算电阻 | 孔内镀层厚度不均/最小值 | 板厂最小镀层/实测 |
| 连接器接触电阻 | 初算压降 | 随寿命/污染/插拔/温度上升 | 手册 max/寿命末 |
| 线缆电阻 | 初算压降 | 温度/长度/线规/端子 | 最坏温度/实测 |
| 驱动器 `tr` | 初算临界长度 | 随负载/温度/工艺变 | 手册 max/实测 |
| 接口 `Z0` | 初算宽度 | 板厂叠层/阻焊/蚀刻偏差 | 场求解/阻抗测试 |
| 时序参数 | 初算预算 | 器件 min/max、温度/电压 | 手册 min/max |
| 电流密度筛选 | 初筛 | 不是温升保证 | 热仿真/实测 |

> **典型值不能替代保证值：** 3 A 走线算例中的 35 µm/50 °C/20 A/mm² 都是假设；实际板厂铜厚、温升、连接器/端子压降必须用叠层/手册/实测替换。脚本输出 `board_verified:false`。

### 4.3 快速判据

| 判据 | 通过条件 | 不通过时的动作 |
|---|---|---|
| 走线压降 | `I·R ≤ ΔV_budget` | 加宽/加铜/缩短/提高电压/远端稳压 |
| 走线温升 | 实测/热仿真 `ΔT ≤` 目标 | 加宽/加铜/开窗/加过孔/降流 |
| 过孔 | 桶壁 `R`/温升/工艺满足 | 多孔并联/更大钻孔/更厚镀层 |
| 连接器 | 触点额定/压降/温升满足 | 多针/更大连接器/缩短/降流 |
| 线束 | 压降/温升/弯折/端子满足 | 加粗/缩短/提高电压/远端稳压 |
| 传输线 | `l < tr/(6·tpd)` 可集总；否则按分布 | 端接/阻抗/缩短/降速 |
| 阻抗 | 板厂场求解/测试在目标±公差 | 调宽度/间距/叠层/换材料 |
| 时序 | `t_flight+t_skew+t_jitter+margin ≤ t_budget` | 缩短/调拓扑/等长/降速 |
| 参考 | 相邻完整参考/换层有回流 | 改层/改走线/加回流过孔/桥接 |
| 端接 | 按接口只在规定位置装 | 去掉多余端接/补缺失端接 |
| I²C | `Rp(min) ≤ Rp ≤ Rp(max)` | 降 `Cb`/分段/缓冲/降速/提高 `IOL` |

## 5. 算例（脚本实际运行）

### 5.1 3 A 走线：宽度/铜厚/压降/电流密度

**给定条件：** 走线长 50 mm；电流 3 A；铜厚 35 µm（1 oz）或 70 µm（2 oz）；温度 50 °C；用户筛选值 `J_max=20 A/mm²`；允许压降按 5 V 的 1%（50 mV）和 24 V 的 1%（240 mV）分别看。

```bash
python scripts/calculate.py wire '{"length_m":0.05,"current_A":3,"width_m":0.002,"copper_thickness_um":35,"temp_c":50,"max_current_density_A_per_mm2":20}'
```

### 5.2 过孔与连接器：谁才是瓶颈

**过孔：** 0.3 mm 钻孔、板厚 1.6 mm、镀层 20/25/30 µm；`ρ` 按 50 °C。

| 镀层 | 桶壁截面 | 单孔电阻 | 3 A 压降 | 3 A 损耗 |
|---:|---:|---:|---:|---:|
| 20 µm | 0.01759 mm² | 1.75 mΩ | 5.25 mV | 15.7 mW |
| 25 µm | 0.02160 mm² | 1.42 mΩ | 4.27 mV | 12.8 mW |
| 30 µm | 0.02545 mm² | 1.21 mΩ | 3.63 mV | 10.9 mW |

**连接器（假设接触电阻，待查手册）：**

| 单触点 `R` | 3 A 压降 | 3 A 损耗/触点 | 电源+回流两触点损耗 | 判断 |
|---:|---:|---:|---:|---|
| 5 mΩ | 15 mV | 45 mW | 90 mW | 好 |
| 10 mΩ | 30 mV | 90 mW | 180 mW | 可接受 |
| 20 mΩ | 60 mV | 180 mW | 360 mW | 5 V 系统占 1.2%；需核对温升 |
| 50 mΩ | 150 mV | 450 mW | 900 mW | 5 V/3 A 不可接受；换连接器/降流 |

**决策：** 单孔 25 µm 在 3 A 下只有 4.3 mV，过孔通常不是瓶颈；20 mΩ 连接器两触点 120 mV/0.36 W 才是 5 V 系统的主要压降/热点。**先查连接器/端子/焊盘颈缩，再考虑加过孔。** 大电流用多孔并联时，要按孔位/铜皮均流，不能只看孔数。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：过孔温升/载流额定（需板厂/标准/实测）、镀层均匀性、连接器寿命/污染/温升、端子压接电阻；20 mΩ 是假设。

### 5.3 微带/带状线：50 Ω 起始宽度

**给定叠层（示例，待板厂确认）：** 4 层、1.6 mm；L1–L2 介质 `h=0.2 mm`；`εr=4.2`；铜厚 `t=35 µm`；阻焊忽略。

`Z0 ≈ (87/√(4.2+1.41))·ln(5.98×0.2/(0.8w+0.035)) = 36.72·ln(1.196/(0.8w+0.035))`

| `w` | `w/h` | `Z0`（微带） | 说明 |
|---:|---:|---:|---|
| 0.20 mm | 1.0 | 66.6 Ω | 偏窄 |
| 0.30 mm | 1.5 | 54.0 Ω | 接近 50 Ω |
| 0.34 mm | 1.7 | 49.9 Ω | 50 Ω 起点 |
| 0.36 mm | 1.8 | 48.1 Ω | 50 Ω 附近 |
| 0.40 mm | 2.0 | 44.6 Ω | 偏宽 |
| 0.50 mm | 2.5 | 37.1 Ω | 超出公式常用范围（`w/h<2`），仅参考 |

**带状线（`b=0.4 mm`、`εr=4.2`、`t=35 µm`）：**

| `w` | `Z0`（带状线） | 说明 |
|---:|---:|---|
| 0.12 mm | 51.5 Ω | 50 Ω 起点 |
| 0.20 mm | 39.9 Ω | 偏宽 |

**决策：** 该叠层下 50 Ω 微带约 `w=0.34 mm`，50 Ω 带状线约 `w=0.12 mm`（`b=0.4 mm`）。**这是公式起点，不是板厂保证**：阻焊、蚀刻、铜箔粗糙度、叠层公差会偏移；下单时要求板厂按叠层场求解/阻抗测试，尤其 90/100 Ω 差分。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际阻抗、差分阻抗、损耗、串扰、板厂能力；`εr/h/t` 是示例，不是任何板厂叠层。

### 5.4 临界长度与时序：什么时候才需要等长

**传播延迟：** 微带 `εeff≈3.18`（`w=0.36 mm`、`h=0.2 mm`）→ `tpd≈5.94 ns/m`；带状线 `εr=4.2` → `tpd≈6.83 ns/m`。

| 上升时间 `tr` | 微带 `l_c=tr/(2tpd)` | 微带保守 `tr/(6tpd)` | 带状线 `l_c` | 判断 |
|---:|---:|---:|---:|---|
| 10 ns | 842 mm | 281 mm | 732 mm | 100 mm 板内可集总 |
| 2 ns | 168 mm | 56 mm | 146 mm | 100 mm 接近保守临界 |
| 1 ns | 84 mm | 28 mm | 73 mm | 100 mm 应按分布处理 |
| 0.5 ns | 42 mm | 14 mm | 37 mm | 短走线也要注意 |
| 100 ps | 8.4 mm | 2.8 mm | 7.3 mm | 几乎全部按分布 |

**接口时间条件（来自来源）：**

| 接口 | 条件 | 计算/判断 |
|---|---|---|
| USB 2.0 FS | 电缆 90 Ω±15%；全速最大单向延时 26 ns | 5.94 ns/m → 26 ns 约 4.4 m；板内 0.1 m 可忽略 |
| CAN | 5 ns/m；1 Mbps/40 m；支线 ≤0.3 m | 40 m 单程 200 ns；1 µs 位时间足够；支线按标准更严 |
| RS-485 | `bps×m ≤10^8`；1200 m 最大 | 1 Mbps→100 m；500 m→200 kbps；1200 m→83 kbps |
| Ethernet MDI | <2 in（50.8 mm）；100 Ω±10%；对内 20/50 mil | 板内短线；对内偏斜按 mil 给，不按 ns |
| I²C | `Cb≤400 pF`；`tr≤300 ns`（Fm） | `Rp(max)=300 ns/(0.8473×Cb)`；400 pF→885 Ω |

**I²C 上拉冲突算例（3.3 V、Fm、`VOL=0.4 V`、`IOL=3 mA`）：**

- `Rp(min)=(3.3−0.4)/3 mA=967 Ω`
- `Cb=200 pF`：`Rp(max)=300 ns/(0.8473×200 pF)=1.77 kΩ` → 可选 1.5 kΩ。
- `Cb=400 pF`：`Rp(max)=885 Ω < Rp(min)=967 Ω` → **无解**；必须降低 `Cb`、提高 `IOL`/降低 `VOL`（Fm+ 20 mA）、分段/缓冲或降速。

**决策：** 1 ns 边沿、100 mm 走线已经超过保守临界长度，不能当普通短线；USB FS/CAN/RS-485 的板内短线通常不是传输线问题，但连接器/支线/端接仍是。**等长前先看 `tr` 与 `tpd`；10 ns 边沿的 100 mm 线不需要按 1 ns 的规则等长。**

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际驱动器 `tr`、封装/连接器延迟、时序预算、眼图/抖动；`tpd` 是公式估算。

### 7.3 手焊 vs SMT、THT vs SMT、单面 vs 双面

| 项目 | 判断 | 本文相关动作 |
|---|---|---|
| 0402/0.5 mm QFP/0.4 mm QFN | 手焊困难/需热风/底部加热；SMT 更稳 | 连接器/ESD 若为细间距，优先 SMT 或选大封装 |
| THT 连接器/端子 | 手焊/波峰/选择性焊；SMT 路线需插件工序 | 大电流端子常为 THT；核对孔径/焊盘/载流 |
| 双面贴装 | 两次回流；底面器件受二次回流/掉件影响 | 大连接器/重器件尽量放顶面；底面用胶/支撑 |
| 手焊大铜/散热焊盘 | 需要足够热容/预热；否则虚焊 | 过孔/铜面积大时，手焊工艺要验证 |
| 单面 vs 双面 | 单面成本低；双面增加工序/对位 | 高密度/细间距才双面；连接器方向按装配视角 |

### 7.4 Paste/Mask、钢网与盘中孔

- **Paste（锡膏层）：** EPAD/散热焊盘要按面积比开孔（不是 1:1 全开），避免锡珠/偏移；大焊盘可分格。
- **Mask（阻焊）：** 开窗/桥/覆盖按板厂能力；测试点/金手指/连接器要明确。
- **钢网：** 厚度/开孔/面积比影响锡量；细间距/EPAD 需要激光切割/电抛光（按板厂）。
- **盘中孔（via-in-pad）：** 需要填孔/电镀/研磨，否则 SMT 漏锡/空洞；会增加成本/工序。**不是所有板厂都默认填孔，必须在下单页确认。**
- **过孔盖油/开窗：** 测试点/散热孔/大电流孔要明确；盖油过孔不能当测试点。

### 7.5 数量、备损、自有料与余料

- 公式：`需购 = ceil((每板用量×该变体板数 + 明确备损 − 已核实可用自有料)/包装步进)×包装步进`（按实际 MOQ/步进）。
- 连接器/端子/线束：易损/易错，建议按项目风险留备件；不写固定百分比。
- 自有料：核对完整型号/封装/针数/额定/是否拆机/是否受损；不能把个人散料当 SMT 工厂已备料。
- 余料：记录剩余数量/包装/批次；下次项目优先使用，但不能跨变体重复抵扣。
- 订单包含物：钢网、锡膏、阻抗测试、填孔、拼板、测试夹具是否包含，逐项写清。

### 7.6 不一致、缺料、替代与 ECO

| 情况 | 处理 | 不能做什么 |
|---|---|---|
| Gerber/钻孔/BOM/CPL 不一致 | 停下，按同版对账；记录差异/影响/修复 | 不能“先下单再说” |
| 缺料/短装 | 核对替代/补料/改期；影响交期/成本要说明 | 不能悄悄换型号 |
| 多装/错装 | 核对 `RefDes`/`DNP`/变体；必要时返修 | 不能把多装当“备件” |
| 自有料 | 核对型号/封装/状态/可焊性；SMT 需工厂接受 | 不能直接把散料当工厂库存 |
| 替代 | 按类 1–4 判定；重算载流/阻抗/时序/热 | 不能只改 BOM 名称 |
| ECO | 记录变更原因/版本/影响；重跑受影响检查/对账 | 不能跳过版本/验证 |

**替代分级：** 1 类=核对条件后直接替换；2 类=需改阻容/配置/固件；3 类=需改原理图/封装/PCB；4 类=资料不足，不能决定。连接器/线束的替代尤其要看针数/间距/额定/配对/结构，不是“长得像”。

### 7.7 路线 C：固件/配置、外壳/线束与整机验收

| 交付物 | 必须字段 | 与互连计算的关系 |
|---|---|---|
| 固件/配置 | 版本号/哈希、构建配置、引脚映射、驱动强度/预加重、端接/DNP 配置 | 驱动强度/端接影响 `tr`、反射、EMI；配置必须与硬件变体对应 |
| 线束图 | 连接器/端子、线规、长度、颜色、屏蔽/双绞、配对端 | 线径/长度决定压降/温升；屏蔽/双绞决定共模/串扰 |
| 外壳/结构 | 开孔/连接器位置、插拔空间、弯线半径、固定/屏蔽 | 连接器方向/高度/线缆弯折影响装配与信号；机械/屏蔽也影响 EMC |
| 测试/验收 | 测试点、夹具、通过标准（压降/温升/眼图/EMC/USB/RS-485） | 计算判据转为可执行验收项；未测项标 `NOT RUN` |

**整机验收不能只看“板子亮灯”：** 至少覆盖满载压降/温升、连接器插拔、线束弯折、USB/RS-485 通信、EMC 预扫（按项目）；每项记录版本/条件/结果，不能把工厂 AOI/飞针报告当整机功能通过。


## 8. 异常状态与模型失效

| 状态 | 计算上会发生什么 | 设计动作 | 验证 |
|---|---|---|---|
| 连接器接触电阻上升 | 压降/损耗增加，局部过热 | 降额/多针/更好端子/缩短 | 寿命/插拔/温升 |
| 端子压接不良 | 接触电阻大，发热/起火风险 | 按端子工具/拉力/压接高度 | 压接剖面/拉力/温升 |
| 过孔镀层不足 | 桶壁电阻大/开裂 | 板厂镀层能力/多孔/更大孔 | 切片/热循环 |
| 走线颈缩 | 局部电流密度高/熔断 | 加宽颈缩/热焊盘辐条 | 红外/温升 |
| 跨分割/参考不连续 | 阻抗突变/回流绕行/EMI | 改层/桥接/回流过孔 | TDR/眼图/EMI |
| 换层无回流过孔 | 回流路径长/辐射 | 加回流过孔/缝合电容 | TDR/近场探头 |
| 差分对内偏斜 | 共模/眼图闭合 | 等长/调拓扑/换层对称 | TDR/眼图 |
| 端接缺失/多余 | 反射/过载/功耗 | 按接口只装规定端接 | 眼图/总线波形 |
| 支线过长 | 反射/振铃 | 缩短支线/改拓扑 | 眼图/振铃 |
| 线束压降 | 负载端欠压/复位 | 加粗/缩短/远端稳压 | 满载压降 |
| 连接器/线束过热 | 绝缘老化/熔断 | 降流/加粗/散热 | 温升/热像 |

**模型失效的典型原因：**

- 只用长走线宽度，忽略焊盘/过孔/连接器瓶颈。
- 铜厚用了标称 1 oz，实际板厂最小 0.5 oz/镀层薄。
- 电流密度筛选当温升保证；内层/密闭壳实际更热。
- 微带公式用了不含阻焊/蚀刻的 `w`，实际阻抗偏移。
- 临界长度用了典型 `tr`，实际驱动器更慢/更快。
- 等长只看长度，忽略过孔/层/封装延迟。
- 参考面有槽/分割，回流绕行没在 2D 图上看出来。
- 端接按“每端都装”，与接口/芯片内部终端冲突。

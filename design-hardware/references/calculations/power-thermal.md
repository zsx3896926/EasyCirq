# 电源、瞬态与热：带条件的计算手册

> **用途：** 把“电源够不够、电感会不会饱和、MOSFET 会不会烧、结温是多少”变成一组有顺序、带单位和条件的计算，而不是只看额定电流或典型值。
>
> **证据等级：** `E1`（公式与条件已按 PWR-S01、PWR-S02、PWR-S03、PWR-S04、PWR-S09、PWR-S11、PWR-S12、PWR-S13、DRV-S05 核对）；`E2`（热瞬态、电感铁损、开关损耗的工程近似，具体系数必须按所选器件手册/厂商曲线核对）。本文不把 `E2` 写成保证值。
>
> **完成级别：** 离线规划（资料分析已完成）。所有算例是计算与脚本输出，**没有 EDA 工程、没有打板、没有热像仪/示波器实测**。脚本输出一律带 `board_verified:false`。
>
> **可执行脚本：** [`calculate.py`](../../scripts/calculate.py) 的 `buck`、`boost`、`ldo`、`wire` 模式；[`power_budget.py`](../../scripts/power_budget.py)。本文所有数字均由这些脚本或文中列出的公式实际运行/代入得到，未使用搜索结果或记忆中的器件值。热瞬态、电感铁损、MOSFET 开关/SOA 没有封装脚本，文中公式不构成仿真或实测。
>
> **命令目录：** 下文命令均从 `design-hardware/` 目录运行（即 `scripts/` 的上一级）。

## 1. 用途与决策边界

本文回答六个会改变方案的问题：

1. **输入电源要多大？** 按各路最大同时负载、转换效率、启动/峰值分别算，不用“典型电流求和”。
2. **电感选多大、会不会饱和？** 先算峰值与 RMS，再按实际最高温度下的 `ISAT`、`IRMS`、DCR 和铁损选，不用“电感量相同”替代。
3. **MOSFET 用哪颗、要不要散热？** 分别算导通、开关、栅极驱动损耗，再用实际 `TC` 与脉冲宽度核对 SOA；`ID(MAX)` 不是可用电流。
4. **结温是多少、封装能不能用？** `Tj = Ta + P·θJA` 只是初估；有散热焊盘/散热器时走 `θJC + θCS + θSA` 链；短脉冲用 `Zth`。
5. **热插拔/浪涌会不会超 SOA？** 分启动、热短路、带短路启动三种场景；最坏是热短路，SOA 基于 `TC=25 °C`，必须按实际壳温降额。
6. **保险丝/eFuse 能不能协调？** 按 70% 安全系数与温度降额选保险，按 `I²t` 核浪涌；eFuse 的限流/断路器/快速跳闸是不同行为，不能只看“有保护”。

### 不能使用的条件

- **DCM/BCM、轻载 PFM、多相、耦合电感、GaN、隔离拓扑**：本文的 Buck/Boost 公式建立在 CCM 上；这些情况必须用对应拓扑/控制器手册重算。
- **环路补偿与相位裕度**：PWR-S01 明确不涉及补偿与稳定性；本文只能给功率级元件，不能证明环路稳定。
- **把 `θJA` 当常数**：PWR-S03 §5 明确 `θJA` 随铜面积、层数、气流、High-K/Low-K 测试板变化；同一封装在不同板上可差数倍。
- **把 `ID(MAX)`、`ISAT`、`ILIM(typ)` 当保证值**：它们各有测试条件；设计判据用最小值/最大值，或按实际温度曲线降额。
- **没有器件手册就给具体数字**：本文的 24 V/3 A、5 V/0.3 A 等是算例条件，不是任何具体型号的保证值。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时的处理 |
|---|---|---|---|
| 输入电压范围 | `VIN(min/max)` V | 电源树、适配器、电池、线缆压降后的实际值 | **阻断**：占空比、峰值、应力都依赖 |
| 输出电压与容差 | `VOUT`、±% | 负载要求 | **阻断** |
| 输出电流（连续/峰值/同时性） | `IOUT(max)` A | 负载预算、状态表 | **阻断**：峰值与热都依赖 |
| 开关频率最小值 | `fS(min)` Hz | 控制器手册（固定或可编程） | **阻断**：纹波按最小 `fS` 算 |
| 开关限流最小值 | `ILIM(min)` A | 控制器电气表 | **阻断**：决定芯片实际能输出多少 |
| 效率估计 | `η` | 手册曲线/同类实测 | 可先用 0.9（Buck）/0.88（Boost）估算，标注未核 |
| 目标纹波比例 | `ΔIL/IOUT` | 设计选择，常用 0.2–0.4 | 可用 0.3 先算，标注假设 |
| 电感参数 | `L`、`ISAT`、`IRMS`、DCR、尺寸 | 电感厂商手册/曲线 | **阻断**：饱和与温升判据不能凭空给 |
| MOSFET 参数 | `RDS(on)(Tj)`、`Qg`、`Coss`、`SOA`、`ZthJC`、`VGS(max)` | 器件手册 | **阻断**：损耗与 SOA 不能只用 `ID` |
| 环境/壳温 | `TA`、`TC` °C | 产品规格、壳体热测试 | 未知时按最坏环境，并标“待实测” |
| 封装热阻 | `θJA` 或 `θJC` | 器件手册热信息 | 未知时不能给结温数字，只能给所需上限 |
| 保险/eFuse 参数 | 额定电流、I²t、动作时间、限流值 | 器件手册/厂商选择指南 | **阻断**：协调不能只比额定电流 |

**阻断项：** `VIN`、`VOUT`、`IOUT`、`fS(min)`、`ILIM(min)`、电感 `ISAT/IRMS`、MOSFET `RDS(on)/SOA`。缺这些时，本文只能给公式，不能给“能用/不能用”的结论。

## 3. 模型与公式

### 3.1 功率预算

- 直流功率：`P = V·I`；能量：`E = P·t`；电荷：`Q = I·t`。
- 转换器输入功率：`PIN = POUT/η`；输入电流：`IIN = POUT/(η·VIN)`。
- 多路负载：先列“同时出现”的组合，再取最大；**平均电流用于续航，峰值电流用于器件应力/保护**，两者不能互相替代。
- 启动/容性负载：`Icharge = C·dV/dt`；恒流限流时 `t = C·V/I`；电容储能 `E = ½CV²`。
- 线缆/走线：`Vdrop = I·R`，`Ploss = I²R`；R 随温度上升（见 [interconnect.md](interconnect.md)）。

**假设：** 稳态、集总效率、无开关瞬态；效率随 `VIN`、负载、温度变化，`η` 只是估算，不能用来证明热或续航。

### 3.2 线性稳压器（LDO）

- 功耗：`PD ≈ (VIN − VOUT)·IOUT + VIN·IQ`（PWR-S03 §3）。
- 结温：`TJ = TA + PD·θJA`；有散热器时 `θJA(max) ≥ θJC + θCS + θSA`（PWR-S03 §4–§5）。
- 压差：`VIN(min) − VOUT(max) − VDO(max) ≥ 0` 才可能稳压；`VDO` 是额定电流下的值，低于额定电流时按比例下降（PWR-S04 §7.3.5 的 CMOS 调整管换算 `RDS(ON)=VDO/IRATED` 只适用于该器件）。
- 效率：`Eff ≈ VOUT/VIN`（忽略 `IQ`）；轻载时 `IQ` 占比大（PWR-S03 §8.1）。
- 反向电流：输入塌陷时输出电容会向输入倒灌；PWR-S04 §7.3.2 给出该器件“反向电流 ≤ 额定电流 5%、只允许短时间”的限制，**不能推广到所有 LDO**。

**假设：** 线性工作、无开关、无限流/热关断；`θJA` 是具体板条件，不是封装常数。

### 3.3 Buck/Boost 功率级

脚本 `buck`/`boost` 的公式与 PWR-S01/PWR-S02 一致：

| 量 | Buck（CCM） | Boost（CCM） |
|---|---|---|
| 占空比 | `D = VOUT/(VIN·η)`，用 `VIN(max)` 算最大开关电流 | `D = 1 − VIN·η/VOUT`，用 `VIN(min)` 算最大开关电流 |
| 电感纹波 | `ΔIL = (VIN − VOUT)·D/(fS·L)` | `ΔIL = VIN·D/(fS·L)` |
| 峰值 | `ISW(max) = IOUT + ΔIL/2` | `ISW(max) = IOUT/(1−D) + ΔIL/2` |
| 芯片可输出 | `IMAXOUT = ILIM(min) − ΔIL/2` | `IMAXOUT = ILIM(min)·(1−D) − ΔIL/2` |
| 输出电容 | `COUT(min) = ΔIL/(8·fS·ΔVOUT)` | `COUT(min) = IOUT·D/(fS·ΔVOUT)` |
| 二极管平均电流 | `IF = IOUT·(1−D)` | `IF = IOUT` |

**单位：** V、A、Hz、H、F。**假设：** 理想 CCM、无 DCR/二极管压降/死区、集总 `η`；不覆盖补偿、瞬态、EMI、热。

### 3.4 电感：饱和、RMS 与损耗

- 峰值：由 3.3 的 `ISW(max)` 得到；电感**在实际最高温度下**的 `ISAT` 必须大于该峰值。
- RMS：梯形波近似 `IL,rms ≈ √(IOUT² + ΔIL²/12)`（Buck，连续输出电流）；Boost 的输入侧 RMS 按 `IIN` 与 `ΔIL` 计算，脚本取各输入端点/最坏纹波点的最大值。
- 铜损：`Pcu = IL,rms²·DCR`；`DCR` 用实际温度下的值（铜电阻正温度系数）。
- 铁损：`Pcore = k·f^α·ΔB^β·Ve`；`k、α、β、Ve` 只能来自厂商曲线/材料手册，**本文不给通用系数**。工程上直接用厂商在目标频率/纹波下的损耗曲线或实测。
- `ISAT` 的定义各厂不同（10%/20%/30% 电感下降），**不同定义的 `ISAT` 不能直接比大小**；`IRMS` 的温升条件也各不同。
- 饱和裕量：PWR-S09 §10.2.2.2 对 TPS63802 建议“饱和电流比计算峰值高 20%”；这是**该器件的建议**，不是所有电感的通用规则（见 [F12](../failures/f12-inductor-saturation.md)）。

### 3.5 MOSFET：导通、开关、驱动与 SOA

- 导通：`Pcond = IL,rms²·RDS(on)(Tj)·D`（低侧）；高侧用对应占空比。`RDS(on)(Tj)` 用**该器件在目标结温下的最大值**，不是 25 °C 典型值。
- 硬开关：`Psw ≈ ½·VDS·ID·(tr + tf)·fS`；这是线性近似，实际随栅极电荷、米勒平台、负载性质变化。
- 栅极驱动：`Pgate = Qg·VGS·fS`；峰值驱动电流 `Ig,pk ≈ VDRV/(Rg,ext + Rg,int)`；`Qg/Ig` 只是电荷转移时间，**不等于**实际开关时间（米勒平台会拉长）。
- 输出电容：`Poss ≈ ½·Coss·VDS²·fS`（硬开关、能量不回收）；同步整流/软开关可能部分回收，不能直接套。
- SOA：曲线是“某 `TC`、某脉冲宽度下可承受的 V-I 组合”，不是恒功率；五条限制线为 `RDS(on)` 线、封装最大电流线、最大功率线、热不稳定线、击穿电压线（DRV-S05 §6）。
- 热不稳定：`VDS·∂ID/∂T > 1/ZthJC(tpulse)` 时可能无法达到热平衡（DRV-S05 §6，Spirito 效应）；低 `VGS` 线性区尤其要查。
- 热插拔：`ILIM = MIN(ILIM,CL, PLIM/VDS)`；纯容性、仅功率限制时 `TSTART = COUT/2·(VIN²/PLIM + PLIM/ILIM²)`；`TTIMER` 必须大于 `TSTART`（PWR-S11 §2.2）。最坏应力约为 `PLIM` 持续 `TTIMER` 秒；热短路（hot-short）比冷启动更严苛，因为起始结温更高。
- `VGS` 瞬态：功率 MOSFET 的 `VGS` 限制通常约 ±20 V（具体手册为准）；快速 `dv/dt` 经 `CGD` 耦合到栅极，可能误导通；`QGD/QGS` 越低越不易误导通（DRV-S05 §5、§7）。

### 3.6 热瞬态

- 单脉冲：`ΔTJ = P·ZthJC(tpulse)`；`ZthJC(t)` 从器件手册曲线取，不能假设。
- 重复脉冲：用叠加/平均功率：`TJ ≈ TA + Pavg·θJA + Ppk·Zth(tp) − Pavg·Zth(tp)`（近似）；更严格的做法是按脉冲序列做热网络仿真。
- 占空比 `D = tp/T`；`Pavg = Ppk·D`。短脉冲、低占空比时 `Zth` 可能远小于 `θJA`，但**不能因此忽略**峰值结温与热不稳定。
- 散热路径：`θJA = θJC + θCS + θSA`（有散热器）；`θCS` 对 TO-220 用界面材料典型 0.1–1 °C/W，不用界面材料可高到 5 °C/W（PWR-S03 §5）；PowerPAD/TO-263 直接焊到 PCB 铜时 `θCS` 近似 0。
- `θJA` 随铜面积/层数/气流变化；PWR-S03 Figure 4 的 SOT-223 曲线约 30–180 °C/W，Figure 5 的封装范围如 DCK 314–478、SOT-23 DBV 154–330、SOIC D 58–83、PowerPAD 22–58 °C/W（无气流、仅比较，须查具体手册）。

### 3.7 保险丝/eFuse 协调

- 保险丝：工程安全系数取 70%；额定值以 25 °C 为基准，60 °C 约降额到 95%；`Irequired = Icontinuous/(0.7×0.95)`（PWR-S13）。
- 浪涌：先算 `∫i²dt`；矩形脉冲 `I²t = I²·t`；重复浪涌按次数再降额（PWR-S13 示例：10 万次取 0.35）。
- 温升：UL 248-14 要求不超过 75 K（PWR-S13）。
- eFuse：限流型把电流钳在 `ILIM` 直到过载消失或结温到 `TTSD`；断路器型超 `ILIM` 后启动故障定时器，到期断开；快速跳闸比较器 `IFASTRIP = 1.6×ILIM`，可在 <200 ns 切断短路峰值（PWR-S12 §3.2–§3.3，数值属于 TPS25942/44 等特定型号）。
- 选择性：不能只比额定电流；要比较动作时间、`I²t`、故障能量与下游器件/铜线/连接器的承受能力。本文来源没有给出通用的“保险丝一定先断”规则，**不得这样断言**。

## 4. 判据与决策表

### 4.1 推荐工作条件 ≠ 绝对最大额定值

| 参数 | 推荐工作条件（设计判据） | 绝对最大额定值的使用 | 决策 |
|---|---|---|---|
| Buck `VIN` | 含纹波/瞬态后的最高值仍 ≤ 推荐上限；例：18–26 V | 绝对最大按所选控制器手册，只表示“不得超出”，不是可连续工作点 | 按 26 V 算 D/峰值；热插拔/浪涌另加 TVS，实测 SW 振铃 |
| LDO `VIN` | 最低输入 ≥ `VOUT(max)+VDO(max)`；例 4.5–5.5 V | 绝对最大只用于故障边界 | 5.5 V 时算最坏 `PD`；4.5 V 时算压差 |
| MOSFET `VGS` | 驱动电压按器件规定（逻辑级 4.5 V 或标准 10 V） | 绝对最大通常约 ±20 V；栅极振铃可能瞬时超过 | 栅阻/ TVS/慢开关；示波器实测 `VGS` 峰值 |
| MOSFET `VDS` | 稳态/开关峰值 ≤ 额定的 70–80%（按项目降额） | 击穿电压是绝对边界 | 24 V 母线选 40 V 以上并测振铃；不能按 24 V 选 30 V 管 |
| 结温 `TJ` | 设计目标 ≤100–110 °C（按寿命要求） | 绝对最大 150 °C 不是设计点 | 用目标 `TJ` 反算 `θJA`，不是用 150 °C 反算 |
| 电感 `ISAT` | 实际最高温度下 `ISAT` > 峰值并留裕量 | `ISAT` 不是绝对最大，是“电感下降 x%”的定义点 | 超过 `ISAT` 后电感量下降、峰值进一步上升；不能靠“没坏”放行 |
| 电容耐压 | 实际偏压/温度下有效容量满足纹波/稳定 | 额定电压是绝对边界 | 陶瓷电容按偏压降容；LDO 输出电容还有**上限**（PWR-S04） |
| 保险丝电流 | `Icontinuous/(0.7×0.95)` | 额定电流不是连续能力 | 1.5 A 连续 → 2.5 A 保险（60 °C） |
| `θJA` | 用最大值或实测 | 不是“最大额定值” | 手册 `θJA` 的测试板与实际板不同；接近限值时实测 |

### 4.2 典型值不能替代保证值

| 参数 | 典型值的用途 | 为什么不能当保证 | 设计应取 |
|---|---|---|---|
| `RDS(on)` | 初估导通损耗 | 典型值是 25 °C、某 `VGS`；热态会明显高于 25 °C 值（按器件曲线） | 目标 `Tj` 下的最大值 |
| `ILIM` | 估算标称输出 | 最小值才决定最坏样片能否带载 | `ILIM(min)` |
| `θJA` | 封装间比较 | 随铜面积/层数/气流变化；手册条件常是 JEDEC 板 | 最大值或实测 |
| 电感 `ISAT` | 初选尺寸 | 定义（10/20/30% 下降）与温度条件不同 | 实际温度、同一定义下的最小值 |
| 电感 `IRMS` | 初估温升 | 温升条件（40 °C?）与安装方式不同 | 厂商在实际板条件下的曲线/实测 |
| 效率 `η` | 功率预算初估 | 随 `VIN`、负载、温度变化 | 手册曲线的最坏点或实测 |
| 保险丝 `I²t` | 浪涌初筛 | 典型 `I²t` 在 10 倍额定电流下测得 | 实际波形积分 + 重复次数降额 |
| SOA | 读图方法 | 曲线是 `TC=25 °C`、单脉冲/特定条件 | 实际 `TC`、实际脉冲宽度、降额后 |

> **典型值不能替代保证值：** 上表任何一行，只要用于“能不能带载/会不会过热”的最终判断，就必须换成 min/max 或实际温度下的曲线值。算例中出现的 0.9 效率、30 mΩ 热态 `RDS(on)`、20 mΩ DCR 都是**假设**，不是器件保证。

### 4.3 快速判据

| 判据 | 通过条件 | 不通过时的动作 |
|---|---|---|
| Buck 可调压 | `VIN(min)·η > VOUT` 且 `VIN(max) > VOUT` | 换拓扑（Buck-Boost/Boost）或降低 `VOUT` |
| 芯片带载 | `ILIM(min) − ΔIL/2 ≥ IOUT(max)` | 换更大限流芯片/降低纹波/降载 |
| 电感饱和 | 实际最高温度 `ISAT > ISW(max)`（按项目裕量） | 换大 `ISAT`/降纹波/提高 `fS` |
| 电感温升 | `IL,rms ≤ IRMS`（同一温升条件）且 DCR 损耗可接受 | 换低 DCR/大尺寸/并联（需均流） |
| LDO 稳压 | `VIN(min) − VOUT(max) − VDO(max) ≥ 0` | 换低 `VDO` LDO/提高输入/改 Buck |
| LDO 热 | `TJ = TA + PD·θJA ≤` 目标 `TJ` | 降电流/换封装/加铜/改开关电源 |
| MOSFET 热 | `TJ = TA + (Pcond+Psw+Pgate)·θJA ≤` 目标 | 降 `fS`/换低 `RDS(on)`/加散热 |
| SOA | 实际 `(VDS, ID, tp)` 点在实际 `TC` 的 SOA 内并有裕量 | 降 `ILIM`/缩短 `TTIMER`/换大 SOA 管/dv/dt |
| 保险丝 | `Icontinuous ≤ 0.7×0.95×In`，且 `I²t` 满足浪涌 | 选更大额定/慢断/改用 eFuse |
| 输入电容 RMS | 每颗电容的允许纹波电流 ≥ 分担值（含温度降额） | 并联/换低 ESR/提高耐压 |

### 5.1 Buck 24 V→5 V/3 A：占空比、电感、电容与损耗

**给定条件：**


| `duty_min` | 0.2137 | `VIN(max)` 时占空比，用于峰值 |
| `inductor_ripple_A` | 0.900 | 目标纹波 |
| `inductor_min_H` | 11.22 µH | 按 `VIN(max)` 算 |

- `POUT = 15 W`；`PIN = 15/0.9 = 16.67 W`；总损耗 1.67 W。
- 若控制器+电感+电容合计 1.67 W，允许 50 °C 温升需要 `θJA ≤ 50/1.67 = 30 °C/W`——这对小封装很紧，必须分项：电感 0.18 W 铜损 + 铁损（厂商曲线）、开关管导通/开关损耗、控制器静态/驱动损耗、电容 ESR。
- 若实测/估算 IC 功耗 1.0 W、`θJA = 40 °C/W`、`TA = 50 °C`，则 `TJ ≈ 90 °C`；`θJA = 60 °C/W` 时 `TJ ≈ 110 °C`，接近目标上限，需要散热焊盘/铜/过孔或降低损耗。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：环路稳定性、轻载 DCM/PFM、最小导通/关断时间、SW 振铃/EMI、电感铁损与高温饱和、电容偏压降容、实际壳内温升。

### 5.3 低侧 MOSFET 24 V/2 A：导通、开关、驱动与频率取舍

**给定条件：** `VDS = 24 V`；`ID = 2 A`；`D = 0.5`；`fS = 20 kHz`；`tr = tf = 100 ns`；热态 `RDS(on) = 30 mΩ`（假设，按目标 `Tj` 的最大值）；`Qg = 20 nC`；`VGS = 10 V`；`θJA = 50 °C/W`；`TA = 60 °C`。

- 导通：`Pcond = 2²×0.03×0.5 = 0.060 W`
- 开关：`Psw = 0.5×24×2×(100+100) ns×20 kHz = 0.096 W`
- 栅极：`Pgate = 20 nC×10 V×20 kHz = 0.004 W`
- 合计 `P = 0.160 W`；`ΔTJ = 0.160×50 = 8.0 °C`；`TJ ≈ 68 °C`
- 迭代：68 °C 时 `RDS(on)` 若为 25 °C 的 1.2 倍（30 mΩ 已是热态值则不再乘），`Pcond` 不变；若 30 mΩ 是 25 °C 值，热态 36 mΩ → `Pcond = 0.072 W`，总 0.172 W，`TJ ≈ 68.6 °C`，收敛。

**频率取舍（同一 `RDS(on)` 热态 30 mΩ，忽略 `RDS(on)` 随温度的二阶变化）：**

| `fS` | `Psw` | `Ptotal` | `ΔTJ` | `TJ`（`TA=60`） | 判断 |
|---:|---:|---:|---:|---:|---|
| 20 kHz | 0.096 W | 0.160 W | 8.0 °C | 68 °C | 可用 |
| 50 kHz | 0.240 W | 0.304 W | 15.2 °C | 75 °C | 可用 |
| 100 kHz | 0.480 W | 0.544 W | 27.2 °C | 87 °C | 可用，需留裕量 |
| 200 kHz | 0.960 W | 1.024 W | 51.2 °C | 111 °C | 接近目标上限；需更好散热/更低 `Qg` |
| 300 kHz | 1.440 W | 1.504 W | 75.2 °C | 135 °C | 超过 125 °C 目标；淘汰 |

**驱动：** `Ig,pk ≈ 10 V/(10 Ω + 3 Ω) = 0.77 A`；`Qg/Ig = 26 ns`，小于设定的 100 ns，说明栅阻不是唯一限制；实际开关时间由米勒平台/`Ciss` 决定，必须看器件栅极电荷曲线。若 `Rg` 过大，开关损耗上升；过小则振铃/EMI/误导通风险上升。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：实际 `RDS(on)(Tj)`、米勒平台/开关波形、栅极振铃、体二极管反向恢复、雪崩、并联均流、PCB 热阻；100 ns 是假设，不是器件保证。

### 5.4 热插拔/浪涌：三种场景与 SOA

**给定条件：** `VIN = 24 V`；`COUT = 100 µF`；限流 `ILIM = 2 A`；功率限制 `PLIM = 20 W`；定时器 `TTIMER` 待定；MOSFET 的 SOA 曲线待按具体型号查（本文不给具体管的 SOA 数字）。

| 场景 | `VDS` | `ID` | 持续时间 | 能量/应力 | 判据 |
|---|---|---:|---|---:|---|
| 冷启动容性负载 | 24 V→0（随 `VOUT` 上升下降） | 2 A | `t = C·V/I = 1.2 ms` | `½CV² = 28.8 mJ`；平均 `P = 24 W` | SOA 在 1.2 ms 允许 2 A@24 V |
| 输出热短路（hot-short） | 24 V | 2 A | `TTIMER` | `P = 48 W`；1 ms→48 mJ，10 ms→480 mJ | SOA 在实际 `TC`、`TTIMER` 允许 48 W；起始结温更高 |
| 带短路启动 | 24 V | 2 A | `TTIMER` | 同 hot-short，但起始温度较低 | 仍按 hot-short 的最坏 `TC` 核对 |

**功率限制的影响：** `ILIM,allowed = PLIM/VDS = 20/24 = 0.833 A`；实际限流取 `min(2 A, 0.833 A) = 0.833 A`。按 PWR-S11 的 `TSTART` 公式：

`TSTART = 100 µF/2 × (24²/20 + 20/0.833²) = 50 µF × (28.8 + 28.8) = 2.88 ms`

`TTIMER` 必须 >2.88 ms；若设 3 ms，热短路能量 `P×t = 20 W×3 ms = 60 mJ`（按功率限制，不是 48 W×3 ms）。**这就是功率限制的价值：把最坏应力从 48 W 降到 20 W。**

**SOA 读法：** 在 `TTIMER` 对应的脉冲宽度、实际最高 `TC` 下，把 `(24 V, 0.833 A)` 或 `(24 V, 2 A)` 画到 SOA 上；同时看热不稳定线，不能只看最大功率线。SOA 数据基于 `TC=25 °C`，实际壳温 60 °C 时必须降额或查高温 SOA。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：具体 MOSFET 的 SOA 是否足够、线缆电感导致的振铃、并联均流、重复插拔累积、`VGS` 瞬态；没有具体型号的 SOA 曲线，不能给出“能承受多少安”的保证值（见 [F13](../failures/f13-mosfet-soa.md)）。

### 5.5 电感：饱和、RMS 与损耗的合成判断

以 5.1 的 15 µH 为例：

| 判据 | 数值 | 结论 |
|---|---:|---|
| 峰值 `ISW(max)` | 3.374 A | `ISAT` 在实际最高温度下必须 >3.374 A |
| 若按 TPS63802 的 20% 建议 | 4.049 A | 仅该器件条件；不是通用规则 |
| RMS | 3.008 A | `IRMS` 的温升条件必须 ≥ 实际板条件 |
| DCR 20 mΩ 铜损 | 0.181 W | 与铁损相加后按厂商温升曲线判断 |
| 铁损 | 厂商曲线 | 本文不提供通用 `k/α/β`；必须按材料/频率/`ΔB` 查 |

**决策：** 若厂商只给 25 °C 的 `ISAT`，而实际电感温度 90 °C，必须按厂商的 `ISAT`-温度曲线降额；没有曲线时，不能把 25 °C 的 `ISAT` 当高温保证。若 `ISAT` 刚好等于峰值，启动/负载跃变/输入最高压时就会进入饱和，应换更大 `ISAT` 或降低纹波。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：电感在实际 `ΔB`/频率下的铁损、绕组交流损耗（趋肤/邻近效应）、饱和曲线的批次差异、长期热老化。

### 5.6 负载阶跃与输出电容：先看环路，再加大电容

**给定条件：** `ΔI = 1 A`；环路响应时间 `tR` 假设 10 µs；`ESR = 5 mΩ`；目标 `ΔV ≤ 100 mV`。

`ΔV ≈ ΔI·tR/C + ΔI·ESR`：

| `C`（有效） | `tR = 5 µs` | `tR = 10 µs` | `tR = 20 µs` |
|---:|---:|---:|---:|
| 22 µF | 0.232 V | 0.460 V | 0.914 V |
| 47 µF | 0.111 V | 0.218 V | 0.431 V |
| 100 µF | 0.055 V | 0.105 V | 0.205 V |
| 220 µF | 0.028 V | 0.050 V | 0.096 V |

**决策：** 10 µs 响应、100 mV 目标需要约 105 µF 有效容量；若只能放 22 µF，必须把环路响应压到约 2 µs 或放宽瞬态目标。**但内补偿转换器不能只加大 `COUT`**：PWR-S01 §7 要求按数据手册推荐的 L/C 或 L×C 比例调整；加大电容可能破坏稳定性。先确认控制器允许的 `COUT` 范围，再谈加大。

**结论与限制：** 上述结论只在给定条件下成立；这个算例不能证明：环路相位裕度、ESR/ESL、电容偏压降容、负载阶跃的实际 di/dt、控制器的非线性响应。

**替代分级只用这四类**（定义见 [replacement-classes.md](../selection/replacement-classes.md)）：

2. **类 2：需要改阻容/配置/固件。** 例如换 `fS` 或电感量后重算补偿/软启动；换 MOSFET 后改栅阻；换 LDO 后改前馈/输出电容。

## 7. 制造与装配接口

本文的计算结果会直接改变制造文件和装配方式。完整的三条路线、字段、对账和异常处理见 [manufacturing-routes.md](../manufacturing-routes.md)；本节只列与热/功率计算相关的决策。

| 计算结论 | 路线 A：商城购料 + 自焊 | 路线 B：嘉立创 PCB + SMT | 路线 C：板 + 固件/结构 + 整机 |
|---|---|---|---|
| 电感 `ISAT`/尺寸 | 手焊可选大尺寸/引线电感；核对焊盘与高度 | 屏蔽电感需贴片；高度/吸嘴/钢网开孔 | 电感高度不能与壳体/线束干涉 |
| MOSFET/控制器散热焊盘 | EPAD 手焊困难，需热风/底部加热；过孔必须通 | EPAD 需钢网开窗、散热过孔、回流曲线；双面贴装时注意二次回流 | 散热器/导热垫/壳体接触要在装配图中固定 |
| `θJA` 依赖铜面积 | 手焊板铜面积通常不足，热结论更差 | 铜厚（1 oz/2 oz）、层数、过孔数量按计算要求写进 PCB 订单 | 整机壳内温升、风道、密封影响最终 `TA` |
| 保险丝/eFuse | 保险丝座/THT 可选；eFuse 为 SMT | 保险丝/eFuse 的封装与可贴性另查；保险丝额定/特性不能替代 | 更换保险丝的可维护性、端子/线束载流 |
| 输入/输出电容 | 大容量电解/聚合物可手焊；陶瓷注意裂纹 | 多颗 MLCC 的钢网/立碑/偏压降容 | 电容高度、固定胶、振动 |
| 电流采样/热敏 | Kelvin 线手焊可做，但要走线短 | Kelvin 焊盘/开窗、热敏位置 | 热敏/线束位置反映真实温度 |

**手焊 vs SMT、THT vs SMT、双面：** 手焊优先大封装/引线器件/THT 端子；细间距 QFN、EPAD、双面贴装走 SMT 更稳。双面贴装时把大电感/大电容/散热器放顶面，底面器件要能承受二次回流；THT 端子/保险丝座需插件/选择性焊工序，不能默认 SMT 工厂会免费处理。

**必须与 Gerber/钻孔/BOM/CPL 对账的字段：**

- **Gerber/叠层：** 铜厚（1 oz=35 µm，2 oz=70 µm）、层数、介质厚度；热/载流计算用的铜厚必须与下单叠层一致，不能拿“默认 1 oz”算完却下 0.5 oz。
- **钻孔：** 散热过孔/盘中孔的数量、孔径、是否填孔/盖油；盘中孔（via-in-pad）需要填平/电镀，否则 SMT 漏锡/空洞。
- **BOM：** 位号、完整 MPN、封装、`ISAT`/`IRMS`/DCR、`RDS(on)` max、`θJA`、数量、DNP。
- **CPL/坐标：** 位号、层（顶/底）、旋转、极性；MOSFET/电感/电解电容的极性不能只靠丝印。
- **装配变体：** 散热器、额外铜/风扇、不同电感/电容档位必须是明确变体，不能只在备注写“可选”。

**数量/备损/自有料：** 按“每板用量 × 该变体板数 + 明确备损 − 已核实可用自有料”算；功率器件/保险丝建议至少 1–2 个备件（按项目风险，不写固定百分比）。自有料要核对完整型号/封装/是否拆机/是否受损；不能把个人散料直接当 SMT 工厂已备料。

**订单包含物：** 钢网、锡膏、散热器、导热垫、保险丝座、线束/端子是否包含，逐项写清；不能把“PCB 价格”当“整机成本”。

**不一致处理：** 缺料/短装/多装/替代/ECO 按 [manufacturing-routes.md](../manufacturing-routes.md) §6 处理；替代必须回到本文重算热/峰值/SOA，不能只改 BOM 名称。

## 8. 异常状态与模型失效

| 状态 | 计算上会发生什么 | 设计动作 | 验证 |
|---|---|---|---|
| 启动/容性负载 | 限流/功率限制触发；`TSTART` 可能大于定时器 | `TTIMER > TSTART`；软启动/dv/dt；核对 SOA | 不同输入斜率/最大 `COUT` 上电，测 `VDS/ID` |
| 输出热短路 | `VDS≈VIN`、`ID=ILIM`，`P=48 W` 量级；起始结温高 | 缩短 `TTIMER`/降低 `PLIM`/换大 SOA | 运行中短接输出，差分测 `VDS/ID` |
| 输入热插拔/浪涌 | 线缆电感振铃、`VDS` 超过稳态；`VGS` 可能耦合尖峰 | TVS/RC 缓冲/栅极钳位；按绝对最大留裕量 | 热插拔重复试验，测 `VIN/VDS/VGS` |
| 电感饱和 | `ΔIL` 变大、峰值进一步上升、限流误触发/过热 | `ISAT` 按实际温度选；降纹波/提高 `fS` | 满载+高温看电感电流斜率/峰值 |
| 轻载 | 进入 DCM/PFM，纹波/频率变化 | 查控制器轻载模式与最小负载 | 10 mA/100 mA 负载测纹波/效率 |
| 输入低于 `VOUT` | Buck 进入 100% 占空比/dropout，输出跟随输入 | 核对最大占空比/UVLO；必要时 Buck-Boost | 扫输入电压，测 `VOUT` |
| 过热 | 热关断/限流降额；`θJA` 实际值可能远大于手册 | 按实测 `θJA`/壳温降额；加铜/散热器 | 热箱/热像仪，稳定 30 min |
| 风扇/气流失效 | `θJA` 上升，`TJ` 超限 | 按无气流最坏条件设计，或加温度保护 | 堵风/停风扇测试 |
| 并联 MOSFET 不均流 | 个别管承担大部分电流，SOA/热超限 | 对称布局、独立栅阻、源极 Kelvin | 分别测每管电流/温度 |
| 保险丝与 MOSFET 不协调 | 故障时保险丝未断，MOSFET 先超 SOA | 按 `I²t`/动作时间/故障能量协调，不只看额定 | 故障注入，测动作顺序 |

**模型失效的典型原因：**

- 效率 `η` 用了典型曲线的最佳点，实际轻载/高压/低温效率更低。
- `θJA` 用了手册 JEDEC 板，实际板铜面积/层数/气流不同。
- 电感 `ISAT` 用了 25 °C 标称，实际 90 °C 已降额。
- MOSFET `RDS(on)` 用了 25 °C 典型，实际热态高 1.3–2 倍。
- SOA 用了 `TC=25 °C` 曲线，实际壳温 60–80 °C。
- 忽略启动/短路/热插拔的瞬态，只算稳态。
- 忽略 PCB 走线/过孔/连接器的压降与热。

## 9. 验证与测量

| 对象 | 测点/仪器 | 条件 | 预期/通过标准 | 停止条件 |
|---|---|---|---|---|
| 效率 | 四线法 `VIN/IIN/VOUT/IOUT`，电子负载 | 10%/50%/100% 负载，`VIN(min/max)` | 效率不低于预算；`PIN` 与计算偏差可解释 | 器件超目标温度/效率骤降 |
| 输出纹波 | 示波器 20 MHz 带宽限制、弹簧地环、探头跨 `COUT` | 满载、`VIN(min/max)` | ≤ 设计值（例 50 mV） | 超限或振铃严重 |
| 负载阶跃 | 电子负载 10–90%，重复频率低于热时间常数 | 最坏 `VIN`、满载 | 跌落/过冲/恢复在预算内 | 触发限流/振荡 |
| 电感电流 | 电流探头/差分测采样电阻 | 满载、最高/最低 `VIN`、高温 | 峰值 < `ISAT`（实际温度）；无斜率突变 | 峰值超 `ISAT`/饱和 |
| 电感/开关温度 | 热电偶/热像仪，稳定 30 min | 最高 `TA`、满载 | `TJ` 估算 ≤ 目标；电感温升 ≤ 额定 | 超目标/热关断 |
| MOSFET SOA | 差分探头测 `VDS/ID`，同步壳温 | 启动、hot-short、带短路启动 | 轨迹在实际 `TC` 的 SOA 内 | 超出 SOA/失效 |
| 栅极波形 | 差分/隔离探头，短地线 | 最高 `VIN`、最大负载 | `VGS` 峰值 < 绝对最大；无误导通 | 超绝对最大/直通 |
| LDO 压差 | 可调电源扫 `VIN`，测 `VOUT` | `IOUT(max)`、`TA(max)` | `VOUT` 在容差内直到 `VIN(min)` | 掉出稳压 |
| 保险/eFuse 动作 | 可调电源+电子负载/短路开关 | 过载/短路/浪涌 | 动作顺序符合设计；下游不超应力 | 器件损坏/动作不清 |

**仿真状态：** 本文未执行 SPICE/热仿真。若要补：用控制器厂商模型 + 实际 L/C/ESR + 实际 MOSFET 模型，激励为 `VIN` 阶跃、负载阶跃、输出短路，观察 `IL` 峰值、`VOUT`、`VDS/ID` 轨迹、结温估算；通过标准为峰值 <`ILIM(min)`、`VOUT` 在容差内、SOA 内。模型不含 PCB 寄生、热耦合与器件批次差异，不能替代实测。

**测量安全：** 高压/浮动节点（SW、热插拔 `VDS`、离线母线）必须用差分/隔离探头；普通接地示波器不能直接接开关节点。高压/大电流测试要有保险、限流、隔离和两人在场/远程急停（按项目风险）。

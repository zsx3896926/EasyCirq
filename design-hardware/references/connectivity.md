# 离线连接表与自检契约

这是本Skill的轻量只读交换格式，不是任何EDA工具的原生格式。优先沿用项目/执行器已有权威数据，按字段明确映射后再检查；不要维护两份互不一致的权威网络。

## 输入
见 [示例](../assets/example-connectivity.json)。示例全部为虚构抽象器件，不可直接落图或作为真实料号/脚号参考。
- `components`：待核对器件数组；`ref`为稳定且非空位号，`pins`为物理引脚ID→网名，`nc`为显式不连接引脚数组。
- `physical_pins`：从适用手册/真实库取得的完整物理引脚ID列表，支持A1/B1/EP等非连续编号。脚本检查集合而非只数数量；未提供即报告覆盖不足。相同数量不能证明引脚正确。
- `pin_count`：旧格式可保留为注释信息，但不能替代`physical_pins`或证明脚位完整。
- `fitted`：布尔值，省略视为当前变体装配；DNP写false。结构仍检查，但不用于证明当前装配态的电气要求。
- `power_nets`、`ground_nets`：可选显式分类，不按名字自动判别电气身份；不能同列一个网。多个地不自动等价。
- `external_nets`：在当前数据范围外延续的网络，只作为不提示单脚网络的范围声明，不证明其实际外部连接。
- `net_rules`：可选显式需求。`{"BUS_SDA":{"pullup":true,"power_net":"VLOGIC"}}`要求所给网到指定电源存在已装配的两脚电阻（`kind: resistor`）。无证据不自动从SDA/SCL名推导硬门禁。
网名区分大小写；网名叫NC不等于引脚已标NC，只有`nc`数组表示不连接。不要自动去掉下划线/连字符合并网络。

## 运行
```bash
python scripts/netlist_check.py path/to/design.json --json
```
退出码：0=输入中未发现结构阻断，仍可能有建议/缺测；1=发现结构冲突或显式装配要求不满足；2=输入格式/类型错误。所有结果含`board_verified:false`，不能用退出0或无告警证明工程正确。
状态为`blocked / incomplete / needs_review / no_structural_issues`之一，必须同时查看问题、引脚表覆盖、适用范围和未检查项。

## 检查能力
确定检查：位号重复、占位位号、网络空值、同脚连接与NC冲突、与给定完整引脚表比较的遗漏/额外脚、显式电源/地分类冲突、显式上拉要求在当前装配变体是否存在。
提示核查：未声明外部延续的单脚网络、仅大小写/分隔符不同的网名、两端同网无源器件。它们不自动成为缺陷，也不自动合并/删除对象。
不检查：手册/库引脚表本身是否真实、数据是否来自完整工程、推挽冲突、实际电源地短路、器件额定/阻值/上拉电压适配、每脚去耦/布局距离/稳定性、真实跨页连通、PCB铜连接、DRC、保存、仿真和样机实测。
用一个电容或电容数量判断全板去耦合格、用R位号猜上拉、将DNP当已装元件、用脚数证明脚位正确，均不受支持。

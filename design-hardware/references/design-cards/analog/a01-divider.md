# 电阻分压采样

> **一句话用途：** 把高于 ADC 量程的直流或缓变电压按确定比例降到量程内，并用“分压比 → 源阻抗 → 采集时间 → 误差预算 → 保护”的顺序判断这组电阻能否在给定采样率下达到目标精度。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> 本卡证据构成：§3 的采样网络、§4 步骤 2 的采集时间判据、§5 候选 A 的 290 ns / 55 pF / 475.4 Ω 来自 ANA-S02（页码见 §12）；R_SW 不可忽略与二阶模型来自 ANA-S03；高源阻抗导致串扰、R_source 由采样频率决定来自 ANA-S13。§4.5 的比率误差公式为本卡推导（E3，仅数学）。分压电阻公差/温漂的定量、ADC 输入漏电、过压保护器件选型在本次来源中**未被覆盖**，正文逐处标注“待按具体器件手册核对”（E2）。
>
> **不能替代：** 具体 ADC 与电阻手册、项目约束、EDA 回读、仿真、测量或安全签核。

## 1. 用途与适用范围

用于把电源母线、电池、0–10 V 工业信号或传感器激励电压降到 ADC 输入范围内。典型输入是 0–5 V 至 0–60 V 的直流或带宽远低于采样率的缓变信号；典型输出是 ADC 满量程的 80%–95%。适用拓扑是两颗电阻构成的单端分压，可选并联电容 C_ext 和入口保护。

本卡的重点不是“算出比例”，而是判断**分压器的戴维南电阻能否在 ADC 的采集窗口内建立到 ½ LSB**。这一步决定了同样的比例下是选 411 Ω 还是 12 kΩ，以及要不要加缓冲（缓冲本身见 [运放缓冲](a02-opamp-buffer.md)）。

### 不能使用的条件

- **信号带宽接近或超过采样率**：分压结点与 C_ext 构成低通，本卡的直流误差模型不覆盖相位与混叠。
- **目标位数下的绝对精度未做增益校准**：分压比公差直接成为增益误差，16 位系统通常做不到 §5 的结论。
- **需要电气隔离**：分压器不能替代隔离放大器或隔离 ADC，隔离边界要单独设计（见 DM21、SC38）。
- **输入可能长期超过电阻或 ADC 的绝对最大额定值**：本卡只给保护检查框架，不给器件值；持续过压必须另做钳位与限流设计。
- **被测源本身高阻且不允许加载**：分压器会改变源的工作点，需先确认源输出阻抗与允许负载。
- **需要测量交流有效值或功率**：分压后仍需真有效值转换或同步采样，本卡不覆盖。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

 V_in ──┬── R1 ──┬──────────────┬──► ADC IN
        │        │              │
        │        │            C_ext（可选，靠近 ADC）
        │        │              │
        │        └── R2 ── AGND ┘
        │
      保护（TVS/钳位，放在入口或连接器侧）
```

分压比只由 R1、R2 决定：

```text
k = R2 / (R1 + R2)
V_node = V_in × k
R_th = R1 ∥ R2 = R2 × (1 − k) = R1 × k
```

外部电容预充时，快速电荷共享后的误差幅度约为ΔV·C_SH/(C_EXT+C_SH)，R_SW足够小时慢恢复时间常数约为R_source·(C_EXT+C_SH)；快过程还受R_SW影响。不能把C_EXT存在时的慢时间常数写成R_source·C_SH。全网络零初值输入阶跃与预充/通道切换是不同初始条件，须用对应两节点模型或原厂仿真核对。

关键回路：V_in → R1 → 结点 → R2 → AGND。这个回路同时是精度回路和漏电回路，PCB 上的助焊剂、潮气和保护器件漏电都会叠加在结点上。

## 4. 参数确定步骤

计算顺序的理由：**先定比例**（由量程决定，与 ADC 时序无关），**再定 R_th 上限**（由 ADC 采集时间决定），**最后在功率、公差与保护约束下选具体阻值**。反过来先选“常用 10 kΩ/100 kΩ”会让源阻抗远超采集能力，或者为了低阻抗把功耗做得不可接受。

### 4.1 定分压比

1. **目标**：最高被测电压对应的结点电压不超过 ADC 输入范围，并留出过压与基准容差余量。
2. **公式**：
   ```text
   k = V_node,max / V_in,max
   R1 = R2 × (1 − k) / k
   ```
3. **假设**：ADC 输入范围为 0…V_REF（单端、无内部 PGA）；结点不接其他负载。
4. **保证值**：V_REF 用 min/max；V_in,max 用系统规定的最大值，不用典型值。
5. **选择**：先定 k，再由 k 与后述 R_th 反算 R1、R2。余量取多少取决于 ADC 绝对最大额定值和钳位方案，本卡不给统一百分比。

### 4.2 由采集时间反算源阻抗上限

1. **目标**：C_SH 在 t_ACQ 内建立到 ½ LSB。
2. **公式**（ANA-S02 第 7 页）：
   ```text
   t_ACQ = 1/f_s − t_conv,max
   l = ln(2^N)          # 讲义用法，对应 1 LSB
   τ = t_ACQ / l
   R_source,max ≤ τ / C_SH
   ```
3. **假设**：源为理想阶跃、单时间常数主导、忽略运放输出阻抗与压摆率。ANA-S03 的结论是：加入 R_SW 后是二阶网络，但只保留主时间常数的简化式在其实测用例中与精确式终值差别可忽略。
4. **保证值**：t_conv,max、C_SH、R_SW 取手册最大值；τ 是由它们算出的派生量，不是器件参数。
5. **注意两处口径差异**：
   - 讲义用 `ln(2^N)`，对应 1 LSB；若按 ½ LSB 应使用 `ln(2^(N+1))`，16 位时从 11.09 变为 11.78（+6.25%）。
   - 讲义同页又写 `C_EXT = 20 × C_SH` 并给出 `R_source ≤ τ / C_EXT`，但其示例代入的是 C_SH（55 pF）而不是 C_EXT（1.1 nF），两种算法相差 20 倍。**这是讲义自身的口径不一致**，设计时必须用 ADC 手册的输入模型或厂商计算工具复核，不能只抄其中一个数（详见 §5）。
6. **R_SW 必须计入**：实际时间常数为 `(R_th + R_SW) × C_SH`。若手册给出 R_SW，先用它扣减 R_th 预算；若没有，只能仿真或实测。

### 4.3 C_ext 的取舍

1. **目标**：给采样开关提供本地电荷、滤除高频、降低通道切换时的电荷注入。
2. **公式**：
   ```text
   f_p = 1 / (2π × R_th × C_ext)
   ```
外部电容预充时，快速电荷共享后的误差幅度约为ΔV·C_SH/(C_EXT+C_SH)，R_SW足够小时慢恢复时间常数约为R_source·(C_EXT+C_SH)；快过程还受R_SW影响。不能把C_EXT存在时的慢时间常数写成R_source·C_SH。全网络零初值输入阶跃与预充/通道切换是不同初始条件，须用对应两节点模型或原厂仿真核对。
4. **取舍**：C_ext 越大，滤波越好、初始阶跃越小，但过压恢复越慢、通道切换后的建立越慢、对保护器件漏电的积分越大。讲义建议 `C_EXT = 20 × C_SH`（ANA-S02 第 13、17 页），这是起点不是保证值。
5. **选择**：先按 20×C_SH 取值，再用 `f_p` 与信号带宽核对；不给出与具体 ADC 无关的固定 pF 值。

### 4.4 选具体阻值并核对功耗

1. **目标**：在 `R_th ≤ R_th,max` 下选 E 系列值，同时满足功耗与电压额定。
2. **公式**：
   ```text
   R2 = R_th / (1 − k)
   R1 = R_th / k
   I_div = V_in / (R1 + R2)
   P_R1 = I_div² × R1
   ```
3. **假设**：电阻为理想电阻，忽略 TCR 与自热。
4. **核对**：额定功率要按厂家降额曲线和实际环境温度取值，不能只看 25 °C 额定；R1 承受几乎全部电压，其最高工作电压与脉冲耐压要单独核对。**具体额定值待按所选电阻手册核对。**
5. **迭代**：若功耗不可接受，只有三条路：提高 R_th 并加缓冲（[ANA-02](a02-opamp-buffer.md)）、降低采样率换取更长 t_ACQ、或改用更大量程的 ADC/前端。

### 4.5 误差预算

按下列各项逐条合成，最坏情况相加与 RSS 各算一遍：

| 误差项 | 公式 | 说明 |
|---|---|---|
| 比率公差 | `δk/k ≈ (1 − k) × (δR2/R2 − δR1/R1)`，最坏 `(1 − k)(t1 + t2)` | 本卡推导；两只电阻同公差时最坏仍为 `(1−k)×2t`，不是 t |
| 温漂失配 | 同式，把 t 换成 ΔTCR×ΔT | 同型号同批次跟踪更好；不同封装温升不同 |
| ADC 漏电 | `V_err = I_leak,max × R_th` | 高阻分压的主要直流误差；I_leak 随温度上升 |
| 基准误差 | 见 [ANA-05](a05-vref.md) | 作为增益误差直接乘到所有码上 |
| 建立残差 | `e^(−t_ACQ/τ)` 对应的 LSB | 必须 ≤ ½ LSB |
| PCB 表面漏电 | 与湿度、助焊剂、涂层有关 | 无法用公式保证，只能设计与验证 |

### 4.6 保护与异常

1. **目标**：过压、反接、ESD 时 ADC 引脚不超过绝对最大额定值，且保护器件在正常工作时不影响精度。
2. **顺序**：入口串阻/保险 → 钳位/TVS → 分压器 → ADC。钳位放在分压器之前会让钳位电流经过 R1，需要重算 R1 的脉冲功率；钳位放在结点上则其漏电直接进入高阻结点。
3. **必须核对**：钳位电压在最大钳位电流下是否低于 ADC 绝对最大额定值；钳位器件在最高工作温度下的漏电是否远小于 `V_REF/(2^(N+1))/R_th`；钳位电容是否影响建立。
4. **本卡不给数值**：TVS/钳位二极管的钳位电压、漏电、电容必须按具体器件手册和实际浪涌波形核对（E2）。

## 5. 完整算例

**给定条件（全为演示假设）：** 0–10V输入，30kΩ/10kΩ分压，ADC3.3V/12位，R_SW=100Ω、C_EXT=1nF、C_SH=4pF，采集10µs；两个电容初始0，理想源输入阶跃。器件型号、漏电、保护和参考误差未绑定。

空载分压比=1/4，10V→2.5V；R_th=7.5kΩ，分压电流0.25mA。按`calculate.py adc_settle`满量程阶跃两节点解析模型，误差约1085.50LSB，不能满足0.5LSB；不是只按R_th·C_SH判断。缩小到3kΩ/1kΩ后R_th=750Ω，分压电流2.5mA，10µs解析误差约0.00700LSB，只在该模型内满足建立。

若输入漏电假设1µA，源阻抗7.5kΩ带来约7.5mV误差，750Ω则0.75mV，仍应与0.806mV/LSB及其他误差预算比较；采样建立通过不表示直流精度满足。输入超过范围、断电注入与保护寄生另查。

**候选选择：** 低阻分压增加功耗；高阻+缓冲需查运放偏置/建立/稳定；降低采样率需重算实际采集窗。保留方案取舍，未指定真实料号。

**结论与限制：** 这里只验证空载分压与声明初始条件的RC模型。外部电容已预充、连续采样或通道切换时需采用相应初始条件，不能用本结果直接保证ADC准确度/保护或制造可行。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 分压电阻 R1/R2 | 比率公差、TCR、额定功率、最高工作电压、长期稳定性、脉冲耐压 | 厚膜 1% 用于 16 位未校准；TCR 只给 typical；额定电压低于母线电压 | 0805/1206 兼顾散热与爬电；高压端按实际电压查爬电 | 同型号同批次 TCR 跟踪优于绝对值；两只电阻温升不同会破坏跟踪 |
| C_ext | C0G/NP0、耐压、绝缘电阻、介质吸收 | X7R 用于高精度直流（电压系数、介质吸收）；耐压不足 | 0603/0805，靠近 ADC 引脚 | 容值按 20×C_SH 起步，再用 f_p 核对 |
| 钳位/TVS | 钳位电压（在规定电流下）、漏电、电容、极性 | 漏电大的 TVS 直接并在高阻结点；钳位电压高于 ADC 绝对最大额定值 | 入口侧，泄放路径短 | 必须按实际浪涌波形核对，不用“工业级”名称代替 |
| ADC | C_SH、R_SW、I_leak、输入绝对最大额定值、输入范围 | 只按分辨率选型；不看输入结构 | 引脚与封装按手册 | 见 [ANA-04](a04-adc-driver.md) |
| 可选缓冲 | 输入偏置电流、输入共模范围、输出摆幅、GBW | 普通双极输入运放用于 1.5 kΩ 高阻结点（IB×R_th 超标） | 见 ANA-02 | 本卡不推荐具体型号 |

区分“推荐工作条件”和“绝对最大额定值”：分压比按推荐工作范围设计，保护按绝对最大额定值校核。**TCR、漏电、额定功率都不能用 typical 代替保证值**；手册只给 typical 时，必须按最坏假设留余量并标注。

## 7. 逐脚与外围核对

| 引脚/外围 | 必须核对 | 常见错误 | 适用检查 ID |
|---|---|---|---|
| ADC 模拟输入脚 | 绝对最大额定值、C_SH、R_SW、I_leak、输入范围 | 只看 V_REF 不看绝对最大值；把 R_SW 当 0 | SC34、SC37 |
| ADC VREF 脚 | 基准输出能力、旁路、回流（见 ANA-05） | 把基准当理想电压源，忽略采样瞬间的动态电流 | SC35 |
| ADC AGND/回流 | 分压地与被测源地是否同一回路；地压降是否进入测量 | 把分压地接到开关电源功率地，读数随负载跳变 | RT21、RT06 |
| 分压结点 | 是否只连接 R1、R2、C_ext、ADC；有无测试点/保护支路漏电 | 结点上挂 LED、指示灯或 Debug 排针 | SC37、PL22 |
| 保护支路 | 正常工作是否导通、反向漏电、钳位电压 | TVS 反向漏电随温度上升，低量程时造成偏移 | SC37、SC15 |
| 高压端网络 | 网络命名、爬电/间隙、是否被其他页误接 | 24 V 网络用全局网名，被别的模块当 3.3 V 连接 | SC41、SC37 |
| 可选缓冲 | 输入共模、IB、输出摆幅、稳定性 | 缓冲输入低于其共模下限，输出削顶 | SC33 |

## 8. 原理图表达

- 分压器作为一个局部功能块画在一起：R1 在上、R2 在下、结点水平引出到 C_ext 与 ADC；不要为了“整齐”把 R1、R2 拆到两张图。
- 结点只保留必要的局部短线，C_ext 与 ADC 输入之间的连接用短线；高压端用页内网络或带前缀的网络名（如 `VBUS_SENSE_HV`），不要做成易被误接的全局 `VIN`。
- 注释写四件事：被测电压范围与故障值、分压比、R_th、以及“结点为高阻节点，禁止挂测试负载”。这些是 SC43 要求的“为何如此”，不是抄手册。
- 保护器件画在入口或连接器侧，并用单独网络标出钳位节点；若钳位接在分压结点上，必须在注释里写明其漏电已计入误差预算。
- 模块归属：分压器属于“模拟采集”模块，接口边界是高压端网络与 ADC 输入网络；不要与电源模块的功率地混在同一层次块里。

## 9. PCB 要求

| 项目 | 要求 | 依据/条件 |
|---|---|---|
| 关键电流回路 | 分压电流回路（V_in → R1 → 结点 → R2 → AGND）面积小，远离开关电源与数字时钟 | 高阻结点易受容性/感性耦合；本卡为几何要求，未实际布局 |
| 器件相对位置 | 分压器紧靠 ADC 输入；C_ext 在 ADC 引脚旁；保护器件在入口 | 缩短高阻结点与 C_ext 回路 |
| 参考层/回流 | 分压器下方保持连续 AGND，回流不要穿过数字或功率地分割 | RT21、RT06；具体层叠待定 |
| 禁区/净空 | R1 高压端与低压铜、安装孔、板边之间按实际工作电压、污染等级和适用标准留爬电/间隙 | 本卡不给统一毫米值；见 DM46 |
| 测试点/探测 | 高阻结点测试点会增加漏电与电容，只在调试版本保留并注明；正式版如需测试，用缓冲后的低阻点 | PL22、RT22 |
| 清洗/涂覆 | 高阻结点区域明确清洗要求；必要时局部保形涂层 | 助焊剂与潮气会形成并联漏电，无法用原理图表达 |
| 保护泄放 | TVS 到地的泄放路径短，不经过分压器或 ADC 地 | SC37、RT08 |

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| R2 开路 | 结点被 R1 拉到 V_in，ADC 输入过压，可能损坏 | 钳位 + 串联限流；钳位电流按 R1 计算 | 断开 R2，用限流源加 24 V，测结点电压与钳位电流 |
| R1 开路 | 结点被 R2 拉到 0，读数恒为 0，可能被误判为“正常 0 V” | 诊断：范围内合理性检查、注入小电流检测 | 断开 R1，确认软件能报故障 |
| 输入过压至 28.8 V 或更高 | 结点超过 V_REF，钳位导通；R1 功耗上升 | 按 ADC 绝对最大额定值与钳位电压设计；核对 R1 脉冲功率 | 阶梯升压，测结点、钳位电流、ADC 是否复位 |
| 反接 | R1 承受反向电压，钳位二极管可能正向导通，电流经保护路径流入电源 | 入口反接保护（见电源卡）；确认反向时钳位电流不经过 ADC | 反接电源，测各点电压与电流 |
| 热插拔/ESD | 连接器引入瞬态，经分压器耦合到 ADC | 入口 TVS + 串阻；TVS 泄放路径短 | ESD 枪/浪涌发生器（如具备），测后复校精度 |
| 潮湿/污染 | 高阻结点表面漏电，读数偏低且随湿度漂移 | 清洗、涂层、减小结点面积、必要时护环 | 湿热试验前后在同一点复测 |
| 多通道复用串扰 | 前一通道留在 C_SH 上的电荷影响当前通道（ANA-S13 第 5–6 页） | 增加 C_ext、增加采集时间、降低源阻抗 | 交替输入满量程与零，观察相邻通道读数 |
| 采样率提高 | t_ACQ 缩短，建立不足，读数偏低且非线性 | 按 §4.2 重算；必要时加缓冲或降采样率 | 扫采样率，观察码值与线性度变化 |

不适用的状态不强行列表：本拓扑不涉及隔离、储能或大电流通流，相关状态见对应卡片。

## 11. 验证办法

- **工具检查：** 网表确认没有把高压网络直接连到 ADC 引脚；ERC 检查单端输入有无悬空；BOM 中 R1/R2 的阻值、公差、功率、耐压与图面一致。DRC 通过不能证明精度。
- **计算复核：** 用 R1/R2 的 min/max、TCR 极值、V_REF min/max、t_conv,max、C_SH max、R_SW max 重跑 §4.5；最坏情况与 RSS 各算一遍；确认 ½ LSB 判据在最低采样率与最高温度下仍成立。
- **仿真：** 本次**未执行**。计划：用 ADC 厂商提供的输入等效模型，或 ANA-S03 的二阶模型（R1=R_IN、C1=C_IN+C_ESD、R2=R_SW、C2=C_SH），做 NFS→PFS 阶跃，观察 t_ACQ 结束时的误差是否 ≤ ½ LSB；扫描 C_SH、R_SW、温度。**这是数值模型，不是 SPICE 实测，也不能代替实测。**
- **测量：**
  - 用 6½ 位 DMM 测分压结点。注意表的内阻会加载：10 MΩ 表对 1.481 kΩ 的负载误差约 0.015%（约 2.4 LSB @16 位、3 V），对 411 Ω 约 0.004%；必须在报告中修正或改用高阻缓冲。
  - 用校准源在 0 V、12 V、24 V 三点比对，记录读数与温度。
  - 动态建立不能用普通示波器探头直接接高阻结点：探头电容（10 pF 量级）会改变时间常数；如需观察，在缓冲输出端测，或使用低电容有源探头并记录其电容。
- **通过标准：** 三点读数误差在设计预算内；过压/反接测试后漏电与精度不劣化；多通道串扰低于 ½ LSB。
- **不能证明：** ESD/浪涌耐受、长期漂移、湿热后的表面漏电、ADC 内部 R_SW 的真实值、多通道串扰的具体数值。

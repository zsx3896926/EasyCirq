# 运放缓冲 / 同相放大

> **一句话用途：** 在“源阻抗高、ADC 需要低阻驱动”或“信号幅度不足”的场合，用单位增益缓冲或同相放大把信号搬到 ADC 量程内，并用噪声增益、GBW、压摆率、输入共模、输出摆幅、容性负载六项判据决定这颗运放能不能用。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> 本卡证据构成：噪声增益、GBW/闭环带宽、稳定性判据、去补偿运放的增益限制来自 ANA-S07（MT-033，第 3、6–7 页）；容性负载极点与隔离电阻公式、相位裕度 45° 目标来自 ANA-S10（SBOA418，第 3–7 页）。**输入共模范围、输出摆幅与负载、压摆率、噪声计算在本次来源中未被覆盖**，正文按公式给出判据并标注“待按具体运放手册核对”（E2）；§5 的噪声估算为本卡推导（E3）。
>
> **不能替代：** 具体运放手册、SPICE/TINA 模型、项目约束、EDA 回读、测量或安全签核。

## 1. 用途与适用范围

两种用法：

1. **缓冲（单位增益）**：把高阻分压、传感器或滤波器输出与 ADC 采样电容隔离，提供低输出阻抗。反馈网络是 R_f = 0、R_g = 开路，噪声增益为 1。
2. **同相放大**：把小信号放大到 ADC 量程，反馈为 R_f 从输出到反相输入、R_g 从反相输入到地（或到参考，用于电平搬移）。

适用条件：单端、直流或低速信号；运放工作在推荐电源范围内；负载是 ADC 输入、后级滤波器或短电缆。反相放大不在本卡展开，但其噪声增益同样是 `1 + R_f/R_g`，稳定性判据相同（ANA-S07 第 3 页）。

### 不能使用的条件

- **输入共模超出运放范围**：同相放大时输入共模等于 V_in，0 V 附近或接近正电源时需要真正的轨到轨输入；普通“轨到轨输出”不代表输入也到轨。
- **输出需要到轨而负载较重**：输出摆幅是负载与温度的函数，“轨到轨”不是保证值。
- **需要驱动大容性负载且不能接受隔离电阻的直流误差**：R_ISO 会降低负载调整率；双反馈等替代补偿本卡未覆盖。
- **信号带宽接近运放 GBW 的 1/5**：本卡的单一极点估算不成立，需要完整环路分析。
- **需要低于运放噪声底限的测量**：噪声预算不在本次来源内，必须另算。
- **需要电气隔离或高共模**：见隔离卡与高侧采样卡。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

                ┌──────── R_f ────────┐
                │                     │
                │   ┌── −             │
 V_in ── R_s ───┼───┤                 │
                │   └── + ──┐         │
                │           │         │
                │        （同相输入）  │
                │                     │
                └──── R_g ── GND/REF  └──────┬────► V_out
                                              │
                                             C_L
```

- **缓冲**：R_f = 0（或省略），R_g = 开路；输出直接接反相输入。噪声增益 N_G = 1。
- **同相放大**：`G = 1 + R_f/R_g`；噪声增益 `N_G = 1 + R_f/R_g`（与信号增益相同）。若 R_g 接地改为接参考 V_REF，则输出为 `V_out = G × V_in − (G − 1) × V_REF`，用于电平搬移。
- **反相放大**：信号增益 `−R_f/R_g`，但噪声增益仍是 `1 + R_f/R_g`。**稳定性由噪声增益决定，不由信号增益决定**（ANA-S07 第 3 页）。

关键回路：输出 → R_f → 反相输入 → 运放 → 输出，这个环路包含运放输入电容与 PCB 寄生；C_L 在环路外但通过 R_O 形成第二个极点。反馈取样点必须在 R_ISO 之后还是之前，决定了 R_ISO 是否被环路补偿，也决定了负载调整率，见 §9。

## 4. 参数确定步骤

顺序理由：**先确认电平可行性（电源、输入共模、输出摆幅），再算带宽与建立**。如果输入共模或输出摆幅不成立，后面的 GBW 计算没有意义；反过来先挑一颗高 GBW 运放，常常在 0.5 V 输入或 2.5 V 输出处才发现它根本不工作。

### 4.1 定增益与反馈网络

1. **目标**：`V_out,fs = G × V_in,fs`，并给输出留余量（不贴轨）。
2. **公式**：
   ```text
   G = V_out,fs / V_in,fs
   R_f / R_g = G − 1
   ```
3. **假设**：理想运放、开环增益足够大。实际闭环增益为 `G = N_G / (1 + N_G/A_VOL)`（ANA-S07 式 1），A_VOL 有限时会有增益误差，需按手册的 A_VOL 最小值核算。
4. **选择**：先按 E96 选一对标准值，再回算实际增益与名义误差。E96 通常无法精确得到整数比，剩余误差要么用 0.01% 网络，要么在系统校准中吸收。
5. **电阻取值**：R_f 太大会与运放输入电容形成反馈极点、增加噪声与偏置误差；太小会增加输出负载与功耗。先用 `f_p = 1/(2π × R_f × C_in)` 核对反馈极点是否远高于闭环带宽，再定值。C_in 待按具体运放手册核对。

### 4.2 噪声增益、闭环带宽与建立

1. **目标**：在给定建立时间内达到 ½ LSB。
2. **公式**（ANA-S07 第 3、6 页）：
   ```text
   N_G = 1 + R_f/R_g            # 缓冲为 1
   f_CL = GBW / N_G
   τ = 1 / (2π × f_CL)
   t_s = ln(2^(N+1)) × τ        # ½ LSB 单极点建立
   ```
3. **假设**：单极点、无压摆限制、无容性负载导致的双极点。
4. **保证值**：GBW 用手册最小值（多数手册只给 typical，此时必须按最坏假设降额并标注）。
5. **裕量**：ANA-S07 第 6 页的例子是“需要增益 10、带宽 100 kHz，理论最小 GBW 1 MHz，建议至少 5 倍裕量选 5 MHz”，理由是交点处已 −3 dB 且 GBW 有离散性。**5 倍是作者建议，不是强制规范**，本卡把它作为起点。

### 4.3 压摆率

1. **目标**：大信号阶跃不被压摆限制。
2. **公式**：
   ```text
   正弦：SR ≥ 2π × f × V_pk
   阶跃：t_slew = ΔV / SR，要求 t_slew 只占建立预算的一小部分
   ```
3. **假设**：运放输出级对称；上升与下降压摆率相同（不对称时取较差者）。
4. **选择**：先按分配比例（例如建立预算的 10%–20%）算所需 SR，再与手册最小值比较。SR 与 GBW 不必匹配，低功耗精密运放常出现 GBW 够而 SR 不够的情况。

### 4.4 输入共模与输出摆幅

1. **目标**：在整个温度与负载范围内，输入共模与输出都在手册规定的推荐工作区内。
2. **核对项**：
   - 同相：`V_CM = V_in`；缓冲：`V_CM = V_in`。
   - 输出：`V_out,max` 在指定负载与温度下的最小值；`V_out,min` 在灌电流下的最大值。
3. **常见错误**：把“轨到轨输出”当成 0 V 与 V+ 都能到；忽略灌电流（sink）时的摆幅比拉电流（source）差；忽略低温/高温下摆幅收缩。
4. **本卡不给数值**：摆幅与共模范围必须按具体运放手册的测试条件读取（E2）。

### 4.5 容性负载与稳定性

1. **目标**：C_L 不把环路变成双极点导致振荡或振铃。
2. **公式**（ANA-S10 第 3–7 页）：
   ```text
   f_p2 = 1 / (2π × R_O × C_L)
   R_ISO = [1 + sqrt(1 + 8π × R_O × C_L × f_gbw)] / (4π × C_L × f_gbw)
   ```
3. **判据**：若 `f_p2` 落在环路带宽内（工程上常要求 `f_p2` 明显高于交越频率），AOL 与 1/β 以 40 dB/dec 相交，可能不稳定；R_ISO 在 AOL 中引入零点抵消 f_p2（ANA-S10 第 6–7 页）。
4. **相位裕度**：ANA-S10 用 ≥45° 作为常用目标；ANA-S07 指出相位裕度低会在交点前出现增益尖峰。
5. **代价**：R_ISO 会降低直流负载调整率与输出精度。R_ISO 放在反馈环内还是环外，结果不同：环内可被补偿但环路本身要重新分析，环外则 `V_load = V_out − I_load × R_ISO`，必须把压降计入误差预算。
6. **验证**：ANA-S10 明确建议用 TINA-TI 等 SPICE 验证所选 R_ISO。本卡不把公式当作稳定性的证明。

### 4.6 偏置、噪声与误差

1. **输入偏置电流**：`V_os,IB = I_B+ × R_s − I_B− × (R_f ∥ R_g)`。令 `R_s ≈ R_f ∥ R_g` 可一阶抵消，但 I_B 随温度与共模变化，不能完全抵消。
2. **失调**：V_OS 直接进入输出，同相放大时还要乘噪声增益（ANA-S07 第 3 页）。
3. **噪声**（本卡推导，E3）：
   ```text
   e_n,in ≈ sqrt(e_n² + 4kT × (R_s + R_f ∥ R_g))
   e_n,out = N_G × e_n,in
   ```
   4kT 在 300 K 约为 1.66×10⁻²⁰ J。电阻热噪声只在有实际电阻时存在；若源是传感器而非电阻，按传感器输出阻抗的实部计算。
4. **噪声带宽**：单极点系统的等效噪声带宽约为 `1.57 × f_CL`；ADC 前有抗混叠滤波时按实际滤波计算，不能直接用 f_CL。

## 5. 完整算例

**给定条件：**

- 传感器输出 0–0.5 V，输出阻抗 R_s = 10 kΩ（电阻性）。
- ADC：16 位，满量程 0–2.5 V，每次采样可用于模拟前级建立的时间 5 µs。
- 电源：3.3 V 单电源；负载 R_L = 10 kΩ；ADC 输入电容与布线合计 C_L = 100 pF。
- 环境：−40…85 °C。
- 目标：增益 5，输出 0–2.5 V。

**计算：**

1. 增益与反馈网络：
   ```text
   G = 2.5 V / 0.5 V = 5
   R_f / R_g = 4
   取 R_g = 10.0 kΩ，R_f = 40.2 kΩ（E96）
   实际 G = 1 + 40.2/10.0 = 5.02   （名义偏差 +0.4%）
   ```
   0.4% 是 E96 取值造成的，不是电阻公差；即使 0.01% 电阻也消不掉，必须靠系统增益校准或另选网络。
2. 建立时间与带宽：
   ```text
   N_G = 5.02
   ½ LSB 建立：ln(2^17) = 11.783
   τ ≤ 5 µs / 11.783 = 424.3 ns
   f_CL ≥ 1/(2π × 424.3 ns) = 375.1 kHz
   GBW ≥ N_G × f_CL = 5.02 × 375.1 kHz = 1.883 MHz
   按 ANA-S07 的 5 倍裕量：GBW ≥ 9.4 MHz
   ```
3. 压摆率：
   ```text
   阶跃：2.5 V / 5 µs = 0.5 V/µs（平均）
   若把压摆限制在 0.5 µs 内：SR ≥ 2.5 V / 0.5 µs = 5 V/µs
   正弦 200 kHz、2.5 Vpp：SR ≥ 2π × 200 kHz × 1.25 V = 1.57 V/µs
   ```
   取两者较严者：SR ≥ 5 V/µs（按 10% 预算分配；分配比例可按项目调整）。
4. 输入偏置电流上限：
   ```text
   ½ LSB = 2.5 V / 2^17 = 19.07 µV
   I_B,max = 19.07µV/(10kΩ × 5.02) = 0.380nA（未做偏置补偿的输出预算）
   ```
   若所选运放 I_B 为几十 nA（双极输入常见），仅源阻抗一项就产生 0.2–1 mV 失调，远超预算；必须选 FET/CMOS 输入、做偏置补偿，或在系统校准中吸收。**具体 I_B 待按手册核对。**
5. 偏置抵消：
   ```text
   R_f ∥ R_g = 40.2 k ∥ 10.0 k = 8.01 kΩ
   ```
   +端总源阻抗应与Rf∥Rg约8.01kΩ比较；本例已有10kΩ源，不能再串8.01kΩ补偿。需改变阻值/源阻抗或选低偏置器件，再核对两输入偏置差与噪声。
6. 输出摆幅：2.5 V、10 kΩ 负载、3.3 V 电源、全温度范围。**待按具体运放手册的 V_OH 条件核对**；本卡不给数值。
7. 输入共模：0–0.5 V。若运放输入共模下限高于 0 V，则在输入接近 0 时失效；**待按手册核对**，必要时改用带负电源或真正轨到轨输入的器件。
8. 容性负载：
   ```text
   要求 f_p2 ≥ GBW（10 MHz 量级）：
   R_O ≤ 1/(2π × 10 MHz × 100 pF) = 159 Ω
   ```
   R_O 是开环输出阻抗，多数手册不直接给，需从 SPICE 模型或手册曲线取得。若 R_O 大于该值，按 ANA-S10 式 2 加 R_ISO，或减小 C_L。**不得把 159 Ω 当成某颗运放的参数，它只是本算例的允许上限。**
9. 噪声（E3 推导）：
   ```text
   R_eq = R_s + R_f ∥ R_g = 10.0 k + 8.01 k = 18.0 kΩ
   电阻热噪声 = sqrt(4kT × 18.0 k) ≈ 17.3 nV/√Hz
   输出噪声密度 ≈ 5.02 × 17.3 nV/√Hz = 86.8 nV/√Hz（未计运放 e_n）
   噪声带宽 ≈ 1.57 × 375 kHz = 589 kHz
   输出 RMS ≈ 86.8 nV/√Hz × sqrt(589 kHz) ≈ 66 µV ≈ 3.5 LSB
   ```
   若 ADC 前有截止频率更低的抗混叠滤波，按实际带宽重算；若运放 e_n 大于 17 nV/√Hz，以运放噪声为主。
10. 反馈极点：
    ```text
    f_p,fb = 1/(2π × R_f × C_in)
    ```
    C_in 待按手册核对；若该极点接近 375 kHz，会在环路中增加相移，需要减小 R_f、加 C_f 或换运放。

**候选选择：**

- 增益网络：R_g = 10.0 kΩ、R_f = 40.2 kΩ 被选中，因为 E96 内最接近 5 倍且 R_f ∥ R_g ≈ 8 kΩ 便于偏置抵消；代价是 +0.4% 名义增益误差，必须校准。
- 运放筛选条件（不是推荐型号）：单位增益稳定、GBW ≥ 9.4 MHz、SR ≥ 5 V/µs、I_B ≤0.380nA（或可补偿）、输入共模覆盖 0–0.5 V、输出在 10 kΩ 负载下覆盖 2.5 V、R_O ≤ 159 Ω（100 pF 负载）、e_n 与 17 nV/√Hz 同量级或更低。**具体型号待按手册逐项核对，本卡不推荐料号。**
- 被淘汰的方案：去补偿运放（如 ANA-S07 第 6–7 页的 AD847/AD848/AD849 系列，分别在单位增益、增益 ≥5、增益 ≥25 时稳定，且为 ±15 V 条件）。本算例是 3.3 V 单电源、增益 5，这些器件的电源与增益条件都不匹配，不能直接套用。

**结论与限制：**

- 满足：增益、建立时间（按 9.4 MHz GBW 与 5 V/µs SR 选型）、偏置电流上限已量化。
- 未确认：输出摆幅、输入共模、R_O、C_in、e_n、A_VOL 最小值、长期漂移。
- 稳定性：只用单极点与 f_p2 判据做了初筛，**没有做环路分析或 SPICE**，不能宣称稳定。
- 噪声：66 µV RMS 已相当于 3.5 LSB，若系统要求 ½ LSB 必须降低 R_s/R_f 或加滤波；这是本算例暴露出的真实矛盾。

> 算例中的具体型号、阻容、脚号、层数、线宽只适用于本算例条件，不能推广到其他芯片或板。

**这个算例不能证明：**

- 不能证明所选运放在 100 pF 负载下稳定（需要 SPICE 或阶跃实测的相位裕度）；
- 不能证明输出在 2.5 V、10 kΩ、85 °C 时仍在线性区；
- 不能证明输入共模覆盖 0 V；
- 不能证明噪声、THD、建立非线性满足 16 位；
- 不能证明 PCB 寄生（反馈走线电容、地弹）不影响结果。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 运放 | GBW（最小值）、SR、I_B、V_OS、CM 范围、输出摆幅（按负载）、R_O、C_in、e_n、A_VOL、单位增益稳定性 | 只给 typical GBW；去补偿器件用于低于其最小增益；双极输入用于高源阻抗 | 小封装散热差，输出大电流时看 θ_JA；引脚与封装按手册 | “轨到轨”不能替代摆幅表 |
| 反馈电阻 R_f/R_g | 比率公差、TCR、热噪声、额定功率 | 高阻值用于低噪声前端；1% 厚膜用于 16 位未校准 | 0402/0603 靠近反相输入 | R_f 与 C_in 形成反馈极点 |
| R_ISO | 阻值、功率、精度 | 用大阻值补偿容性负载却不核算直流压降 | 靠近输出 | 环内/环外接法不同 |
| 去耦电容 | 容值、耐压、ESR、温度特性 | 只看容值不看偏压降容 | 靠近电源脚 | 见 PL17/PL18 |
| 输入保护 | 漏电、电容、钳位电压 | 漏电与运放 I_B 同量级 | 高阻节点 | 见 SC37 |

推荐工作条件与绝对最大额定值必须分开：**输入共模、输出摆幅、GBW、SR 都不能用 typical 代替保证值**；手册只给 typical 时，按最坏情况降额并在报告中写明。

## 7. 逐脚与外围核对

| 引脚/外围 | 必须核对 | 常见错误 | 适用检查 ID |
|---|---|---|---|
| 同相输入 + | 输入共模范围（含 0 V 附近）、偏置电流、保护二极管是否在输入超出电源时导通 | 把 0 V 输入接到非轨到轨输入；输入先于电源上电导致闩锁 | SC33、SC11 |
| 反相输入 − | 反馈网络接点、寄生电容、与 + 端的对称性 | 反馈走线过长，形成极点/拾取噪声 | SC33、RT22 |
| 输出 | 负载下的摆幅、容性负载、短路电流 | 直接接大电容或长电缆，无 R_ISO | SC33、PL22 |
| 正/负电源脚 | 去耦、上电顺序、单电源时 V− 接地 | 去耦远离引脚；V− 悬空 | SC03、PL17 |
| EN/SHDN（如有） | 默认态、阈值、悬空行为 | 使能脚悬空，上电时输出不确定 | SC14、SC21 |
| NC/DNC | 是否真 NC，是否有内部连接 | 把 DNC 当地或接信号 | SC04 |
| EPAD | 是否需接地/散热，是否与内部相连 | EPAD 未接地或误接 | SC03 |
| 反馈电阻 | 阻值、公差、TCR、功率 | 只算增益不算噪声与极点 | SC33 |

## 8. 原理图表达

- 运放符号周围保留局部连接：+ 输入、− 输入、反馈电阻、输出构成一个不可拆的功能块；不要用网络标签把反馈网络拆散到不同页。
- 反馈节点（− 输入）面积最小，R_f/R_g 紧靠该脚；这是 RT22 的“高阻与反馈”要求。
- 注释写：增益、噪声增益、输入范围、输出范围、负载、GBW/ SR 选型依据、R_ISO 的环内/环外接法。不要写“按手册”。
- 单电源时明确画出 V− 接地与去耦；双电源时标明电源域与上电顺序。
- 若 R_g 接参考而不是地，参考网络单独画，并注明其误差直接加到输出。
- 模块归属：属于“模拟前端”；接口边界是输入网络与 ADC 输入网络。缓冲器的输入若来自分压器，应在图上标出 R_th，提醒读者看 ANA-01。

## 9. PCB 要求

| 项目 | 要求 | 依据/条件 |
|---|---|---|
| 关键电流回路 | 输出 → 负载 → 地的回流与输入回路分开；反馈取样点从负载端而不是运放引脚端取（若要求远端调整） | 负载电流在走线电阻上的压降会成为增益误差 |
| 器件相对位置 | R_f/R_g 紧靠反相输入；去耦紧靠电源脚；R_ISO 靠近输出 | RT22、PL17 |
| 参考层/回流 | 运放下方连续 AGND；输入高阻节点下方不要走数字或开关信号 | RT22；具体层叠待定 |
| 禁区/净空 | 高阻输入节点远离开关电源、时钟、连接器脏区；必要时护环，护环电位按电路定 | PL22；护环不能随意接地铜包围 |
| 测试点/探测 | 输出可留测试点；反相输入节点加测试点会增加电容，需评估 | RT22 |
| 容性负载 | 长电缆/大电容按 R_ISO 或双反馈处理，R_ISO 的焊盘与走线不引入额外电感 | ANA-S10 |
| 散热 | 输出大电流或高电源电压时核算结温；小封装 θ_JA 待查手册 | PL16 |

以上为草案，未实际布局；稳定性结论必须来自仿真或实测，不能由布局“看起来紧凑”推出。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 输入开路 | 同相输入失去偏置，输出可能饱和到任一轨 | 输入对地/对参考加高阻偏置；软件做范围检查 | 断开输入，测输出与恢复时间 |
| 输入短路到地/电源 | 输入电流经保护二极管流入电源或地，可能闩锁 | 串限流电阻；核对绝对最大输入电流 | 限流源短接，测输入电流与温升 |
| 输出短路 | 运放限流或过热；部分器件可恢复 | 查手册短路电流与热阻；必要时外部限流 | 短接输出，测电流与结温 |
| 容性负载阶跃 | 振铃、过冲、甚至振荡 | R_ISO、减小 C_L、选大相位裕度器件 | 方波激励，看阶跃响应过冲与振铃 |
| 上电/掉电顺序 | 输入有信号而运放未上电，电流经输入保护二极管灌入电源 | 核对绝对最大输入电流与 Ioff 行为；必要时加隔离 | 先加输入后加电源，测灌入电流 |
| EN 误动作 | 输出进入高阻，ADC 读到浮空电平 | EN 加默认态；输出加下拉或由系统控制 | 拉低 EN，测输出 |
| 反馈开路 | 开环，输出饱和 | 反馈电阻布局可靠；必要时加冗余 | 断开反馈，测输出 |

## 11. 验证办法

- **工具检查：** 网表核对反馈网络、电源脚、EN 默认态；ERC 检查输入悬空与电源短路；BOM 核对运放完整型号（带宽/温度/封装后缀）。
- **计算复核：** 用 GBW 最小值、SR 最小值、I_B 最大值、C_L 最大值、R_f/R_g 的 min/max 重跑 §4.2–§4.6；确认最坏角落仍满足 ½ LSB。
- **仿真：** 本次**未执行**。计划：用厂商 SPICE/TINA 模型，做（a）AC 开环/闭环波特图，读相位裕度与增益裕度；（b）10%–90% 阶跃，观察建立到 ½ LSB 的时间与过冲；（c）100 pF 与 10×C_L 两种负载；（d）−40/25/85 °C。通过标准：相位裕度 ≥45°、阶跃过冲与振铃可接受、建立时间 ≤ 预算。**未执行就不能声称稳定。**
- **测量：** 直流转移特性（多点输入，测增益与失调）、−3 dB 带宽、阶跃响应（看振铃）、输出摆幅（带实际负载）、输入共模边界（缓慢抬高共模，看输出何时失真）、电源抑制。探头接输出，不要接反相输入（探头电容会改变环路）。
- **通过标准：** 增益误差在校准前 ≤ 设计值、建立时间 ≤ 预算、无持续振铃、输出不削顶、共模范围内无相位反转。
- **不能证明：** 长期漂移、EMC/ESD、PCB 寄生在量产板上的分布、ADC 采样瞬间的电荷反冲对运放的影响（需与 ANA-04 联调）。

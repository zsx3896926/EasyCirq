# 差分放大

> **一句话用途：** 在存在共模电压的场合提取两线之间的差值，并用“先查输入共模是否可行 → 再定增益 → 再由允许误差反推 CMRR → 再选电阻匹配等级”的顺序，判断四电阻差分放大能否达到目标精度，还是必须改用匹配网络、仪表放大器或专用电流检测放大器。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> 本卡证据构成：CMRR 定义、电阻比率失配公式、离散电阻与匹配分压对的差异、OPA387 示例来自 ANA-S08（SBOA582，第 3–7 页）。**输入共模范围、参考引脚接法、AC CMRR/频率特性、PCB 寄生匹配在本次来源中未被覆盖**，正文按公式给出判据并标注“待按具体器件手册核对”（E2）。§5 的输入共模算术与误差反推为本卡推导（E3，仅数学）。
>
> **不能替代：** 具体运放/仪表放大器手册、电阻匹配数据、项目约束、EDA 回读、仿真或测量。

## 1. 用途与适用范围

用于测量两个节点之间的电压差，而这两个节点同时带着较高的共模电压：电流采样（采样电阻两端）、桥式传感器输出、4–20 mA 采样电阻、电池组单体的差分监测。

本卡讨论的是**四电阻差分放大器**（一颗运放 + R1–R4），以及由它衍生的匹配电阻分压对。集成差分放大器/仪表放大器/电流检测放大器属于同一判据族，但它们的内部电阻已匹配，选型时应直接看手册的 CMRR、共模范围与增益误差，不能把本卡的 `(G+1)/(4t)` 套到内部匹配的器件上。

### 不能使用的条件

- **共模电压超出运放输入范围**：四电阻结构只把共模按 `R4/(R3+R4)` 衰减，衰减后仍可能高于电源；这是最常见的失效，必须先算。
- **需要高共模（几十伏以上）而运放是低压器件**：改用高共模电流检测放大器、仪表放大器或隔离方案（见 ANA-07、SC38）。
- **需要高 AC CMRR（开关噪声、PWM 共模瞬态）**：本卡的公式只给直流/低频电阻失配，AC CMRR 由运放与寄生决定，本次来源未覆盖。
- **需要单电源、输入接近 0 V 的差分信号**：运放输入共模下限可能不允许。
- **源阻抗不可忽略**：源阻抗直接串入 R1/R3，造成增益误差，需先算。
- **需要电气隔离**：见隔离卡。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 差模输入范围 | V_dm,min / V_dm,max（V） | 传感器/采样电阻规格 | 阻断 |
| 共模电压范围 | V_cm,min / V_cm,max（V） | 系统共模、地偏移 | 阻断：决定拓扑是否可行 |

**阻断项**：V_cm 范围、电源、增益、电阻匹配等级、运放 CMRR。**非阻断项**：源阻抗、参考误差可先用最坏假设推进。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

 V_in+ ── R1 ──┬── R2 ──┐
               │        │
              (+)       │
               │   ┌────┴──── V_out
               └───┤ −
                   │ +
                   │
 V_in− ── R3 ──┬── R4 ── V_REF（或 GND）
               │
              (−)
```

平衡条件与传递函数：

```text
R2/R1 = R4/R3 = G
V_out = G × (V_in+ − V_in−) + V_REF
```

运放同相输入端的共模电压：

```text
V+ = V_cm × R4/(R3 + R4) = V_cm × G/(G + 1)
V− ≈ V+（负反馈平衡时）
```

这个式子说明：**四电阻结构对共模的衰减只有 `G/(G+1)`**。增益越低，衰减越少，共模越容易超出运放范围；增益越高，衰减越多，但差模信号也被同样放大。共模可行性必须在算 CMRR 之前检查。

共模抑制的来源有两部分：

1. **电阻网络**：R2/R1 与 R4/R3 的比率失配把共模转成差模。
2. **运放自身**：输入级失配。

两者并联（ANA-S08 式 8）：

```text
1/CMRR_D = 1/CMRR_A + 1/CMRR_R
```

## 4. 参数确定步骤

顺序理由：**先算共模是否落在运放输入范围内**（不可行则拓扑直接淘汰，后面的 CMRR 计算没有意义）；**再由输出范围定增益**；**再由允许误差反推所需 CMRR**；**最后才选电阻匹配等级与运放**。反过来先挑“0.1% 电阻”常常做出 58 dB 的电路，却要求 76 dB。

### 4.1 共模可行性（先做）

1. **目标**：`V+ = V_cm × G/(G+1)` 在整个共模范围内落在运放输入共模范围内，且留有余量。
2. **公式**：见 §3。
3. **注意**：这是**衰减后**的共模；很多人只看到“运放供电 3.3 V”就以为 12 V 共模没问题，实际 8.5 V 已经远超。
4. **不可行时的选项**：
   - 降低共模（改接地参考、加电平搬移、改变传感器接法）；
   - 用高共模电流检测放大器/仪表放大器（见 ANA-07）；
   - 前置高压分压，但分压会同时衰减差模，需重新分配增益并核算电阻匹配；
   - 隔离。

### 4.2 定增益

1. **目标**：`G × V_dm,max + V_REF` 不超过 ADC 满量程，并留余量。
2. **公式**：`G = (V_out,max − V_REF) / V_dm,max`。
3. **选择**：先定 G，再按 `R2/R1 = R4/R3 = G` 选电阻对。E96 往往无法精确得到 G，剩余误差进入系统校准。
4. **注意**：`V_REF` 直接加到输出，误差 1:1 传递；若参考就是 ADC 的基准，可做比率测量抵消部分漂移。

### 4.3 由允许误差反推 CMRR

1. **目标**：共模在输出端产生的误差不超过预算。
2. **公式**：
   ```text
   V_err,cm = V_cm / CMRR_D（线性比）
   CMRR_D ≥ V_cm,max / V_err,budget
   CMRR_dB = 20 log10(CMRR_D)
   ```
3. **选择**：用共模范围的**最大值**（不是典型值）计算；若共模会变化，按变化量 ΔV_cm 计算更合理，因为固定共模可以被校准掉。

### 4.4 电阻网络 CMRR

1. **公式**（ANA-S08 第 5–6 页）：
   ```text
   四只分立电阻，公差 t（Ω/Ω）：
   CMRR_R = (G + 1) / (4t)

   匹配电阻分压对，比率匹配公差 t_m：
   CMRR_R = (G + 1) / t_m
   ```
2. **理解**：`t` 是单只电阻的公差，四只最坏叠加后等效为 `4t`；匹配分压对的 `t_m` 是“两组分压比之间的匹配误差”，通常比单只公差小一个数量级以上。
3. **示例核对**：ANA-S08 第 4–5 页用 OPA387（CMRR 典型 150 dB、5.5 V 供电、指定共模范围）配 0.5%、1 kΩ 分立电阻，G = 1 时最坏 CMRR_D 只有 40 dB。代入公式：`(1+1)/(4×0.005) = 100 = 40 dB`，与原文一致。
4. **提高 CMRR 的方向**：提高 G（分子增大）、选匹配网络（分母从 4t 变成 t_m）、或校准。

### 4.5 总 CMRR 与运放选择

```text
1/CMRR_D = 1/CMRR_A + 1/CMRR_R
```

- 低频时电阻网络通常主导（ANA-S08 第 4–5 页：OPA387 的 150 dB 被 0.5% 电阻拉低到 40 dB）。
- 高频时运放 AOL 下降，CMRR_A 变差，可能转由运放主导（ANA-S08 图 2-4 的描述）。
- 选运放时，CMRR_A 只需比 CMRR_R 高 10–20 dB，再高也被电阻网络盖住；但 AC CMRR 与共模范围另算。

### 4.6 参考、源阻抗与噪声

1. **参考**：`V_out = G(V+ − V−) + V_REF`；参考误差 1:1 到输出。参考必须低阻、干净，且其回流不经过输入信号地。
2. **源阻抗**：源阻抗串入 R1/R3，造成增益误差 `≈ R_s/(R1 + R_s)`；若源阻抗不平衡，还会把共模转成差模。必须把源阻抗计入 R1/R3 的实际值，或选 R1 ≫ R_s。
3. **噪声**：四只电阻的热噪声都进入输出，R1/R3 的噪声按增益放大；低噪声设计要降低阻值，但阻值降低会增加源负载。本卡不给数值，按 `sqrt(4kT R)` 与噪声增益估算（E3）。
4. **输入偏置**：I_B 在 R1/R3 上产生失调，且随共模变化；高阻网络需选低 I_B 运放。

## 5. 完整算例

**给定条件：**

- 差模信号 0–1 V，共模 12 V（工业现场地偏移），源阻抗可忽略（<1 Ω）。
- 电源 3.3 V 单电源；ADC 12 位、满量程 0–2.5 V。
- 目标：输出 0–2.4 V（留 0.1 V 余量）；共模引起的输出误差 ≤ ½ LSB。
- 环境：−40…85 °C；先用 0.1% 分立电阻，再与 0.01% 匹配分压对比较。

**计算：**

1. 增益：
   ```text
   G = 2.4 V / 1 V = 2.4
   R2/R1 = R4/R3 = 2.4
   取 R1 = R3 = 10.0 kΩ，R2 = R4 = 24.0 kΩ
   ```
2. 共模可行性（先查）：
   ```text
   V+ = 12 V × 24.0/(10.0 + 24.0) = 12 × 0.7059 = 8.47 V
   ```
   8.47 V 远高于 3.3 V 电源，**四电阻拓扑在 12 V 共模下不可用**。此时不需要再算 CMRR；必须改拓扑或降低共模。
3. 降共模后的方案：把共模移到 2.0 V（例如改变传感器参考或加电平搬移）：
   ```text
   V+ = 2.0 × 0.7059 = 1.41 V
   ```
   1.41 V 落在 0–3.3 V 内，但仍需核对运放输入共模范围（含温度与共模变化），**待按具体运放手册核对**。
4. 所需 CMRR：
   ```text
   ½ LSB = 2.5 V / 2^13 = 305.2 µV
   CMRR_D ≥ 2.0 V / 305.2 µV = 6554 = 76.3 dB
   ```
5. 电阻网络 CMRR：
   ```text
   0.1% 分立电阻：CMRR_R = (2.4 + 1)/(4 × 0.001) = 850 = 58.6 dB
   0.01% 匹配分压对：CMRR_R = 3.4 / 0.0001 = 34 000 = 90.6 dB
   ```
   0.1% 分立电阻比要求低 17.7 dB，**不满足**；0.01% 匹配对高出 14.3 dB。
6. 总 CMRR（设运放 CMRR_A = 100 dB = 100 000）：
   ```text
   CMRR_D = 1/(1/34 000 + 1/100 000) = 25 373 = 88.1 dB
   ```
   仍高于 76.3 dB。共模误差：
   ```text
   V_err,out = 2.0 V / 25 373 = 78.8 µV = 0.26 LSB
   ```
7. 参考误差：
   ```text
   输出偏移预算 ½ LSB = 305.2 µV
   参考误差直接 1:1 到输出，因此 V_REF 的直流误差必须 ≤ 305 µV
   ```
   若参考就是 ADC 基准，误差可能与 ADC 增益误差相关，可部分抵消；若参考是独立 LDO，必须按 305 µV 核对（见 [ANA-05](a05-vref.md)）。
8. 源阻抗影响：
   ```text
   若源阻抗 R_s = 100 Ω（不平衡），增益误差 ≈ 100/(10 000 + 100) = 0.99%
   ```
   即约 1% 的增益误差，远超 12 位预算；必须让源阻抗 ≪ R1，或把 R_s 计入电阻值。
9. 输出余量检查：
   ```text
   V_out,max = 2.4 V，V_REF = 0 时
   ADC 满量程 2.5 V，余量 0.1 V（4%）
   ```
   共模误差 78.8 µV 与参考误差都在这 0.1 V 内，但运放输出摆幅到 2.4 V 的能力需按手册核对。

**候选选择：**

- 12 V 共模 + 3.3 V 运放：**淘汰**，输入共模 8.47 V 超出电源。
- 2.0 V 共模 + 0.1% 分立电阻：**淘汰**，CMRR 58.6 dB < 76.3 dB。
- 2.0 V 共模 + 0.01% 匹配分压对：**选中**，CMRR 90.6 dB，总 CMRR 88.1 dB，余量 11.8 dB。
- 若不能降低共模：改用高共模电流检测放大器/仪表放大器（见 ANA-07），其共模范围与 CMRR 按器件手册核对，不能套用本卡的电阻公式。
- 电阻值：10.0 kΩ/24.0 kΩ 被选中，因为源阻抗 <1 Ω 时增益误差可忽略、功耗低（2 V/34 kΩ ≈ 58.8 µA）；代价是输入阻抗 20 kΩ 对源有加载。

**结论与限制：**

- 满足（在 2.0 V 共模下）：增益、CMRR、输出范围、参考预算。
- 未确认：运放输入共模范围、输出摆幅到 2.4 V、AC CMRR、电阻匹配随温度的漂移、PCB 寄生导致的失配。
- 关键结论：**共模可行性优先于 CMRR**；12 V 共模下这颗 3.3 V 运放根本不工作，任何电阻匹配都救不了。

> 算例中的具体型号、阻容、脚号、层数、线宽只适用于本算例条件，不能推广到其他芯片或板。

**这个算例不能证明：**

- 不能证明 0.01% 匹配网络在 −40…85 °C 内仍保持 0.01% 的比率匹配（需查其 TCR 跟踪指标）；
- 不能证明 AC CMRR（PWM/开关噪声）满足要求；
- 不能证明 PCB 上 R1–R4 的寄生电容与走线电阻不破坏匹配；
- 不能证明参考在 ADC 采样瞬间的动态行为；
- 不能证明源阻抗在真实传感器下仍可忽略。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 运放 | CMRR（最小值）、输入共模范围、输出摆幅、GBW、I_B、A_VOL | 只看典型 CMRR；共模范围不含衰减后的 V+；输出摆幅不够 | 封装按手册 | CMRR_A 只需比 CMRR_R 高 10–20 dB |
| 分立电阻 R1–R4 | 公差、TCR、比率跟踪、额定功率 | 1%/0.5% 用于 >12 位；TCR 不跟踪 | 同型号同批次、同封装、相邻布局 | 四只最坏叠加为 4t |
| 匹配分压对 | 比率匹配 t_m、TCR 跟踪、绝对阻值 | 只看单只公差，不看匹配指标 | 同一封装内匹配 | 分母从 4t 变为 t_m，改善约 12 dB 以上 |
| 仪表放大器/电流检测放大器 | 共模范围、CMRR、增益误差、输入偏置、带宽 | 把内部匹配器件套用 `(G+1)/(4t)` | 按手册 | 高共模场合优先 |
| 参考 | 初始精度、温漂、输出阻抗、负载调整 | 用电源分压当参考 | 见 ANA-05 | 误差 1:1 到输出 |
| 输入保护 | 漏电、电容、钳位电压 | 保护漏电在 R1/R3 上产生失调 | 高阻节点 | 见 SC37 |

推荐工作条件与绝对最大额定值分开：共模范围按推荐工作条件，保护按绝对最大额定值。**CMRR、增益误差、TCR 都不能用 typical 代替保证值。**

## 7. 逐脚与外围核对

| 引脚/外围 | 必须核对 | 常见错误 | 适用检查 ID |
|---|---|---|---|
| 同相输入 + | 衰减后的共模 `V_cm×G/(G+1)` 是否在范围内 | 直接按电源电压判断共模可行性 | SC33 |
| 反相输入 − | 反馈网络 R2、R4 接点与对称性 | R2/R4 走线不对称，破坏匹配 | SC33、RT21 |

| 电源脚 | 去耦、共模范围与电源的关系 | 去耦不足，共模瞬态耦合进输出 | PL17 |
| 输入保护 | 漏电、电容、钳位 | TVS 漏电在 10 kΩ 上产生失调 | SC37 |
| 电阻网络 | 四只电阻的匹配、TCR、功率 | 用四只独立 1% 电阻当“差分放大器” | SC36、RT21 |
| EN/NC/EPAD | 默认态、内部连接 | 使能悬空；EPAD 未接地 | SC14、SC03 |

## 8. 原理图表达

- 四只电阻与运放画成一个不可拆的差分放大块；R1/R2 与 R3/R4 两臂上下对称摆放，便于肉眼检查比率。
- 标注：`G`、`V_cm` 范围、衰减后的 `V+`、`V_REF`、电阻匹配等级（`t` 或 `t_m`）。这些是 SC43 要求的“为何如此”。
- 参考端单独画，不要用“GND”符号代替可调参考；若参考就是 ADC 基准，用同一网络名并在注释中说明比率关系。
- 输入网络用局部短线连接到保护器件；不要把差分对拆成两个全局网络标签，避免被其他页误接。
- 模块归属：属于“模拟采集”；接口边界是 V_in+/V_in− 与 ADC 输入。若前端是采样电阻，需在图上标出 Kelvin 取样点（见 ANA-06）。

## 9. PCB 要求

| 项目 | 要求 | 依据/条件 |
|---|---|---|
| 关键电流回路 | 差分输入的两条路径（R1/R2 与 R3/R4）走线长度、过孔数、邻近参考保持一致 | 走线电阻/电容失配直接变成 CMRR 损失；RT21 |
| 器件相对位置 | 四只电阻紧靠运放，两臂对称；R1/R3 靠近输入，R2/R4 靠近运放 | 减小寄生与热梯度 |
| 参考层/回流 | 差分对下方连续 AGND，不要在两条路径之间穿插数字或功率走线 | RT21 |
| 禁区/净空 | 输入网络远离开关电源、PWM、继电器；高共模节点按实际电压留爬电 | PL21、DM26 |
| 测试点/探测 | 输入两端测试点必须成对且对称，否则测试本身破坏 CMRR | RT21 |
| 热对称 | 四只电阻的热梯度要小；不要把一只放在热源旁 | 热梯度造成 TCR 失配 |
| 保护泄放 | TVS 泄放路径不要经过电阻网络或参考地 | SC37、RT08 |

以上为草案；CMRR 的 PCB 部分无法用几何规则保证，必须靠对称布局与实测。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 共模超出范围 | 运放输入饱和/相位反转，输出错误但不一定报错 | 先算 §4.1；选高共模器件或加钳位 | 缓慢抬高共模，观察输出何时失真 |
| 一端输入开路 | 输出饱和到轨，可能被误读为满量程 | 输入端加偏置/下拉；软件范围检查 | 断开一端，测输出 |
| 采样电阻开路 | 差分输入失去回路，输出漂移 | 诊断电流/合理性检查 | 断开采样电阻，测输出 |
| 参考开路 | 输出偏移不确定 | 参考加下拉或监测 | 断开参考，测输出 |
| 输入过压/反接 | 保护二极管导通，电流经 R1/R3 流入电源 | 串限流、核对绝对最大输入电流 | 限流源加过压，测电流与温升 |
| 共模瞬态（PWM） | 输出尖峰，采样时刻错误 | 提高 AC CMRR、加共模滤波、避开开关沿采样 | 在开关沿附近扫描采样相位 |
| 电阻一只开路 | 增益突变，输出饱和 | 诊断/冗余 | 逐只断开，记录输出 |

## 11. 验证办法

- **工具检查：** 网表核对 R1–R4 的阻值与匹配等级、参考网络、输入保护；ERC 检查输入悬空；BOM 核对匹配网络的完整型号与匹配指标。
- **计算复核：** 用 V_cm,max、G、t 或 t_m、CMRR_A 最小值、温度范围重跑 §4.3–§4.5；确认最坏情况 CMRR 仍满足预算。
- **仿真：** 本次**未执行**。计划：DC 扫描共模（差模固定为 0），测输出变化得到 DC CMRR；AC 扫描共模注入，得到 CMRR 随频率；蒙特卡洛改 R1–R4（按公差与 TCR）看 CMRR 分布；阶跃共模看恢复。通过标准：DC CMRR ≥ 设计值、AC CMRR 在关注频段满足预算。
- **测量：**
  - DC CMRR：把两输入端短接到同一个共模源，差模为 0，改变共模，测输出变化。测试夹具的两只分压电阻必须匹配，否则测到的是夹具的 CMRR。
  - 共模范围：固定差模，缓慢抬高共模直到输出失真，记录边界。
  - 增益与参考：分别测差模增益、参考传递比。
- **通过标准：** DC CMRR 满足 §4.3 的预算；共模范围内输出不饱和；参考误差在预算内。
- **不能证明：** AC CMRR 在真实 PWM 频谱下的表现、长期匹配漂移、PCB 寄生在量产板的分布、隔离耐压。

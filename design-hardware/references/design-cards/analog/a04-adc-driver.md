# SAR ADC 驱动

> **一句话用途：** 判断一个 SAR ADC 的输入端能否由“电阻分压/传感器 + RC”直接驱动；不能时，按采集时间反推所需驱动运放的带宽、串联电阻与输出阻抗，并同时核对基准脚在逐次逼近过程中的动态电流。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> 本卡证据构成：`t_ACQ` 定义、RC 判据、驱动运放 `K/f_Z/f_U/R_EXT/R_O` 判据与 ADS8860 示例来自 ANA-S02（第 7、9、12–19 页）；二阶采样模型与 R_SW 的作用来自 ANA-S03；基准脚动态负载与布局建议来自 ANA-S01（第 7 节、图 7-2）。**运放压摆率、建立非线性、输入保护漏电、具体 ADC 数据手册条件未在本次来源中覆盖**，正文按公式给出判据并标注“待按具体器件手册核对”（E2）。
>
> **不能替代：** 具体 ADC 数据手册、厂商输入模型、SPICE 仿真、项目约束、EDA 回读或测量。

## 1. 用途与适用范围

适用对象是逐次逼近型（SAR）ADC 的模拟输入与基准输入。典型场景：多通道复用、采样率从几十 kS/s 到几 MS/s、分辨率 12–18 位、前端是分压器/传感器/运放缓冲。

本卡回答三个问题：

1. 现有源阻抗能否在采集窗口内把采样电容充到 ½ LSB（RC-only 路径）。
2. 若不能，驱动运放需要多大 GBW、多大串联电阻、多大输出阻抗允许值（driver 路径）。
3. 基准脚在逐次逼近时抽取的动态电流由谁提供，旁路电容与缓冲是否足够。

### 不能使用的条件

- **Delta-Sigma ADC**：本卡的电荷桶模型与 `t_ACQ` 判据不适用（ANA-S02 第 21–54 页的 Delta-Sigma 部分本次未读）。
- **ADC 内部已集成驱动器/缓冲**：应先看手册，直接套本卡会过度设计。
- **采样开关非线性主导**：ANA-S03 明确 R_SW 随输入电平非线性，线性化模型只在有限范围成立；高失真要求必须仿真/实测。
- **输入超出 ADC 绝对最大额定值**：本卡不覆盖保护设计，见 ANA-01 与 SC37。
- **需要 18 位以上或极低失真**：本卡的简化判据不足，需要完整电荷桶模型与实测。
- **基准与输入不相关且要求极高精度**：需要按 ANA-05 单独做基准预算。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

                     R_EXT                ADC 内部
 V_source ──┬───/\/\/\/───┬──────────────┬── R_SW ──┬── C_SH ── AGND
            │             │              │          │
           R_div         C_EXT          C_IN/C_ESD  │
            │             │              │          │
           AGND          AGND           AGND     （采样开关）
```

采样阶段：开关闭合，C_SH 与外部网络并联，外部网络必须在 t_ACQ 内把 C_SH 充到目标精度。转换阶段：开关断开，C_SH 上的电荷被逐次比较，同时基准脚在每一位切换时抽取电荷（ANA-S01 第 7 节）。

两个独立的问题必须分开算：

1. **输入建立**：源阻抗 + R_EXT + C_EXT + C_SH + R_SW。
2. **基准建立**：V_REF 引脚 + 旁路电容 + 基准输出阻抗/缓冲。

把两者混为一谈（例如以为“基准够大就行”）会得到输入建立不足、或基准被抽塌的结果。

## 4. 参数确定步骤

顺序理由：**先算 t_ACQ**（由采样率与转换时间决定，是硬约束）；**再判断 RC-only 是否够**（成本最低）；**不够才引入驱动运放**（运放带宽由 t_ACQ 反推，不能先选运放）；**最后核对基准与失真**。反过来先挑一颗“高速运放”再算，往往发现它输出的 R_EXT 与 ADC 电容形成的新极点又限制了带宽。

### 4.1 可用采集时间

```text
t_ACQ = 1/f_s − t_conv,max
```

（ANA-S02 第 7 页。）t_conv,max 取手册最大值，不能用典型值；多通道复用时还要减去通道切换与建立开销（若手册单列）。

### 4.2 RC-only 判据

1. **目标**：C_SH 在 t_ACQ 内建立到 ½ LSB 或 1 LSB。
2. **公式**（ANA-S02 第 13–14 页）：
   ```text
   C_EXT = 20 × C_SH
   l = ln(2^N)                 # 讲义用法，对应 1 LSB
   τ = t_ACQ / l
   R_source ≤ τ / C_SH         # 按讲义第 14 页实际代入的口径
   ```
3. **必须知道的矛盾**：讲义同页写的是 `R_source ≤ τ / C_EXT`，但其 ADS8860 示例（C_SH=55 pF、C_EXT=1.1 nF、t_ACQ=290 ns、N=16）算出 475.4 Ω 时，分母用的是 55 pF 而不是 1.1 nF。按写出的 `C_EXT` 计算会得到 23.8 Ω，两者相差 20 倍。**这是讲义自身的口径不一致**，本卡不替它选一个，而是要求用 ADC 手册/厂商计算工具复核。
4. **物理解释（本卡分析，E3）**：C_EXT ≫ C_SH 时，电荷共享的时间常数近似由 `R_source × C_SH` 决定，C_EXT 主要减小初始阶跃幅度，并不会按 C_EXT/C_SH 的比例放宽 R_source；因此 475 Ω 量级比 23.8 Ω 更接近实际，但初始阶跃减小确实允许略少的时间常数。最终仍以仿真/实测为准。
5. **若按 ½ LSB**：把 `l` 换成 `ln(2^(N+1))`，16 位时 11.09 → 11.78（+6.25%），R_source 上限相应收紧。

### 4.3 驱动运放判据

1. **目标**：由运放给 C_EXT 充电，使 C_SH 在 t_ACQ 内建立。
2. **公式**（ANA-S02 第 17 页）：
   ```text
   C_EXT = 20 × C_SH
   K = ln( 2^(N+1) / (C_EXT/C_SH + 1) )
   f_Z = K / (2π × t_ACQ)
   f_U ≥ 4 × f_Z
   R_EXT = 1 / (2π × C_EXT × f_Z)
   R_O ≤ 9 × R_EXT
   ```
3. **含义**：`f_Z` 是由建立要求反推的闭环带宽目标；`f_U` 是运放单位增益带宽；`R_EXT` 与 C_EXT 构成建立网络；`R_O` 限制运放开环输出阻抗，避免它在该带宽内引入额外极点。
4. **注意**：`K` 用的是 `2^(N+1)`（½ LSB），比 §4.2 的 `ln(2^N)` 更保守；两条路径的判据口径不同，不能把 475 Ω 与 19.2 MHz 当成同一假设下的结果。
5. **裕量**：`f_U ≥ 4f_Z` 是讲义判据；ANA-S02 的示例实际选了 192 MHz（约 10×）。裕量不是强制值，但 4× 只是下限。

### 4.4 压摆率与输出摆幅

1. **压摆率**：
   ```text
   SR ≥ ΔV / t_slew,allocated
   ```
   若要求在 t_ACQ 内完成满量程阶跃，`t_slew,allocated` 最多等于 t_ACQ；实际应只占一部分，把剩余时间留给线性建立。按 1 V 阶跃、290 ns 全部用于压摆，需要 3.45 V/µs per volt；5 V 阶跃即 17.2 V/µs。**这只是下限，真实需求还要看建立非线性。**
2. **输出摆幅**：必须覆盖 0–V_REF（或实际输入范围）在负载与温度下的最小值；待按运放手册核对。
3. **建立非线性**：运放从大信号阶跃恢复到 ½ LSB 的过程不是单指数，datasheet 的 0.1%/0.01% 建立时间不能直接换算成 16 位建立；必须仿真或实测。

### 4.5 基准脚

1. **机理**：SAR 每一位切换都在 V_REF 引脚发生电荷再分配，电流随 MSB→LSB 非线性变化，并随输入幅度变化，形成非线性/谐波误差（ANA-S01 第 7 节）。
2. **对策**：
   - 储能电容紧靠 ADC REF 引脚（ANA-S01 第 7 节）。
   - 多 ADC 共用或电流需求大时加低噪声缓冲（同上）。
   - 缩短走线以减小电阻/电感；有 sense 引脚时接到 ADC 的 REF 引脚。
3. **不能外推的数值**：ANA-S01 图 7-2 的示例是 12 位 ADS7049、2 MHz 采样、64 MHz 时钟、REF 引脚 10 µF、1 V 输入，峰值约 600 µA。**这个 600 µA 只适用于该例**，不能按位数或采样率线性外推到其他 ADC。

### 4.6 二阶模型复核

ANA-S03 把 ADC 输入等效为二阶低通：

```text
R1 = R_IN
C1 = C_IN + C_ESD
R2 = R_SW
C2 = C_SH
```

最坏情况取输入从零/负满量程阶跃到正满量程，目标是 C2 在 t_ACQ 内建立到 ½ LSB。C_ESD 约 4–10 pF，C_IN 约 1–10 nF；当 C_IN ≫ C_ESD 时可忽略 C_ESD。该文同时指出 R_SW 不可忽略且随输入电平非线性，分析时取线性区平均导通电阻。

## 5. 完整算例

**给定条件：**

- ADC：16 位 SAR，按 ANA-S02 第 14 页 ADS8860 示例条件取 `C_SH = 55 pF`、`t_ACQ = 290 ns`。**ADS8860 数据手册的实际条件本次未核对**，f_s、V_REF、V_REF 动态电流均待查。
- 前端：源阻抗 10 kΩ（例如 24 V 分压器的高阻版本，见 [ANA-01](a01-divider.md)）。
- 目标：输入建立到 ½ LSB；基准由外部提供；满量程阶跃按 5 V 估算压摆需求（示例假设）。
- 环境：−40…85 °C。

**计算：**

1. 可用采集时间：题设为 290 ns（由 `1/f_s − t_conv,max` 得到，具体 f_s 与 t_conv,max 待按 ADC 手册核对）。
2. RC-only 判断：
   ```text
   C_EXT = 20 × 55 pF = 1.1 nF
   l = ln(2^16) = 11.09
   τ = 290 ns / 11.09 = 26.15 ns
   按讲义第 14 页代入 C_SH：R_source ≤ 26.15 ns / 55 pF = 475.4 Ω
   按讲义写出的 C_EXT：R_source ≤ 26.15 ns / 1.1 nF = 23.8 Ω
   ```
   源阻抗 10 kΩ，两种口径都远超上限（21–420 倍）。**RC-only 被淘汰**，必须加驱动运放。
3. 驱动运放参数：
   ```text
   C_EXT = 1.1 nF
   C_EXT/C_SH = 20
   K = ln(2^17 / (20 + 1)) = ln(131072 / 21) = ln(6241.5) = 8.739
   f_Z = 8.739 / (2π × 290 ns) = 4.796 MHz
   f_U ≥ 4 × 4.796 MHz = 19.18 MHz
   R_EXT = 1 / (2π × 1.1 nF × 4.796 MHz) = 30.17 Ω
   R_O ≤ 9 × 30.17 Ω = 271.5 Ω
   ```
   与讲义第 17–19 页的 4.8 MHz / 19.2 MHz / 30.1 Ω / 270.9 Ω 一致。
4. 压摆率（示例 5 V 阶跃）：
   ```text
   SR ≥ 5 V / 290 ns = 17.2 V/µs
   ```
   若只给压摆分配一半时间，则需 34.5 V/µs。**具体运放 SR 待按手册核对。**
5. 串联电阻的选择：
   ```text
   R_EXT = 30.1 Ω（E96）
   ```
   该电阻与 C_EXT 形成 4.8 MHz 的建立极点；同时它隔离运放输出与 ADC 输入电容，降低对 R_O 的要求。阻值增大会降低带宽，减小会增加运放负载与振铃风险。
6. 基准：
   ```text
   V_REF 引脚需要本地储能电容 + 低阻抗源
   ```
   具体容值按 ADC 手册推荐；ANA-S01 的 10 µF/600 µA 示例不能直接搬用。若基准输出阻抗在采样瞬间产生超过 ½ LSB 的跌落，必须加缓冲。
7. 失真检查（定性）：
   ```text
   电荷反冲 → 与输入幅度相关的非线性 → 谐波/INL
   ```
   判定方法：在关注频点做相干采样 FFT，看谐波与杂散；本卡不给“多少 dB 合格”，由系统决定。

**候选选择：**

- RC-only（475 Ω 或 23.8 Ω 口径）：源阻抗 10 kΩ 时**淘汰**。若源阻抗本身 <400 Ω（如低阻分压），可优先选它，成本最低。
- 驱动运放 + R_EXT 30.1 Ω + C_EXT 1.1 nF：**选中**。运放需满足 `f_U ≥ 19.2 MHz`、`R_O ≤ 271 Ω`、`SR ≥ 17.2 V/µs`（5 V 阶跃）、单位增益稳定、输出覆盖 0–V_REF、噪声与失真满足系统要求。
- 讲义第 18–19 页选 OPA836（192 MHz）作示例，是 10× 裕量下的选择；**本卡不把它当作推荐料号**，其 R_O、SR、输出摆幅必须按该器件手册核对。
- 被淘汰的方案：只加 C_EXT 不加运放（电荷共享时间常数不变，仍建立不了）；只提高采样率（t_ACQ 更短，更糟）。

**结论与限制：**

- 满足：按讲义判据，19.2 MHz / 30.1 Ω / 271 Ω 的组合在 290 ns 内可建立到 ½ LSB（这是讲义的计算结论，不是本卡的实测）。
- 未确认：运放 SR、建立非线性、输出摆幅、噪声、ADC 的 R_SW 与 C_IN 实际值、基准动态跌落、失真。
- 关键教训：**RC-only 的两个口径相差 20 倍**，必须用厂商工具/仿真确认；直接抄 475 Ω 或 23.8 Ω 都可能出错。

> 算例中的具体型号、阻容、脚号、层数、线宽只适用于本算例条件，不能推广到其他芯片或板。ADS8860 的 C_SH/t_ACQ 来自培训讲义示例，不是本次核对的数据手册条件。

**这个算例不能证明：**

- 不能证明所选运放在 30.1 Ω 负载下稳定；
- 不能证明 16 位建立（讲义判据是 ½ LSB 的一阶估算，未含建立非线性）；
- 不能证明基准在真实采样电流下的跌落；
- 不能证明失真/INL 满足系统要求；
- 不能证明 PCB 寄生（R_EXT 到 ADC 的走线电感、C_EXT 的 ESL）不影响结果。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| ADC | C_SH、R_SW、t_conv,max、V_REF 动态电流、输入范围、绝对最大额定值 | 只按采样率/位数选型；不看输入结构 | 引脚与封装按手册 | 见 SC34 |
| 驱动运放 | f_U、R_O、SR、输出摆幅、e_n、建立时间、单位增益稳定性 | f_U 只给 typical；R_O 未给且无法从模型取得；SR 不足 | 小封装散热 | 讲义 4×f_Z 是下限 |
| R_EXT | 阻值、公差、功率、寄生电感 | 用大阻值“滤波”却不知道它限制带宽 | 0402/0603 靠近 ADC | 30.1 Ω 只适用于本算例 |
| C_EXT | C0G/NP0、耐压、ESL、介质吸收 | X7R 用于高精度（电压系数/介质吸收） | 靠近 ADC 引脚 | 20×C_SH 是起点 |
| 基准旁路 | 容值、ESR、耐压、温度特性 | 只看容值不看 ESR 与偏压降容 | 紧靠 REF 引脚 | 见 ANA-05 |
| 基准缓冲 | 输出电流、噪声、稳定性 | 用普通运放驱动大容性基准节点而不看稳定性 | 见 ANA-02 | ANA-S01 建议多 ADC 时加缓冲 |

**不能用 typical 代替保证值**的项：C_SH、R_SW、t_conv、运放 f_U、SR、R_O。手册只给典型值时，按最坏情况降额并在报告中写明。

## 7. 逐脚与外围核对

| 引脚/外围 | 必须核对 | 常见错误 | 适用检查 ID |
|---|---|---|---|
| ADC 模拟输入 | C_SH、R_SW、输入范围、绝对最大额定值 | 只看分辨率；忽略采样瞬间的电荷反冲 | SC34 |
| ADC VREF | 动态电流、旁路要求、sense 引脚 | 把基准当理想源；旁路电容离引脚远 | SC35 |
| ADC AGND | 采样电容回流路径、与基准地的关系 | 数字回流穿过模拟地 | RT21、RT23 |
| 驱动运放输出 | R_EXT 位置、容性负载稳定性 | R_EXT 放在远端，起不到隔离作用 | SC33、PL23 |
| 驱动运放反馈 | 反馈取样点在 R_EXT 之前还是之后 | 取在 R_EXT 之后导致环路含 ADC 电容 | SC33 |
| 驱动运放电源 | 去耦、输出摆幅与电源的关系 | 去耦不足，阶跃时电源跌落 | PL17 |

## 8. 原理图表达

- 把“驱动运放 + R_EXT + C_EXT + ADC 输入”画成一个连续的模拟链，不要用网络标签跨页拆开；这条链的寄生就是精度的一部分。
- 标注：N、f_s、t_ACQ、C_SH、C_EXT、R_EXT、f_Z、f_U 要求、R_O 上限。这些是 SC43 要求的“为何如此”，也方便后续复核。
- 基准单独画：V_REF 源 → 旁路电容 → ADC REF 引脚，回流到 ADC 的 AGND；不要与输入链的地混在一起。
- 若有多通道复用，画出 MUX 与各通道的源阻抗，注明“通道切换建立”另算。
- 模块归属：属于“模拟采集”；接口边界是驱动运放输入与 ADC 数字输出。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 输入过压 | 保护二极管导通，电荷注入 C_SH，读数错误甚至损坏 | 钳位 + 串阻；核对绝对最大输入电流 | 阶梯升压，测输入电流与读数 |
| 基准跌落 | 采样瞬间 V_REF 塌陷，所有码偏低且非线性 | 旁路紧靠引脚；必要时加缓冲 | 在 REF 引脚用低电容探头观察采样瞬间 |
| 驱动运放饱和 | 输入超出输出摆幅，建立时间剧增 | 核对输出摆幅；留余量 | 输入阶跃到边界，测恢复时间 |
| 驱动运放振荡 | 容性负载导致振铃，读数抖动 | R_EXT、R_ISO、相位裕度 | 阶跃响应看振铃 |
| 通道切换 | 前一通道电荷影响当前通道 | 增加采集时间/C_EXT；降低源阻抗 | 交替满量程/零，看相邻通道 |
| 采样率提高 | t_ACQ 缩短，建立不足 | 重算 §4.2/§4.3；降采样率或换运放 | 扫采样率看码值/INL |
| 掉电/上电 | 输入有信号而 ADC 未上电，电流经保护二极管灌入 | 核对绝对最大输入电流与上电顺序 | 先加输入后加电源，测灌入电流 |
| 基准关断 | V_REF=0，读数全 0 或不确定 | 基准使能默认态；软件检测 | 关断基准，测读数 |

## 11. 验证办法

- **工具检查：** 网表核对 R_EXT、C_EXT、基准旁路、AGND 连接；ERC 检查输入悬空与电源短路；BOM 核对 ADC 与运放的完整型号（速度等级/温度/封装）。
- **计算复核：** 用 C_SH max、R_SW max、t_conv max、f_s max、运放 f_U min、R_O max 重跑 §4.1–§4.4；两种 RC 口径都算，取更严者并说明选择理由。
- **仿真：** 本次**未执行**。计划：用 ADC 厂商提供的输入模型（含 R_SW、C_SH、C_IN、C_ESD）与运放 SPICE 模型，做（a）NFS→PFS 阶跃，测 t_ACQ 末端误差；（b）相干采样 FFT，看谐波/杂散；（c）基准脚电流阶跃，看 V_REF 跌落；（d）−40/25/85 °C。通过标准：建立 ≤ ½ LSB、SFDR/THD 满足系统、V_REF 跌落 ≤ ½ LSB。**未执行就不能声称满足。**
- **测量：**
  - 直流/低速：多点输入，测码值与线性度。
  - 建立：在输入端加阶跃（或用 MUX 切换），在采样时刻附近扫描相位，观察码值随相位的变化。
  - 基准：在 REF 引脚用低电容探头（或专用缓冲）观察采样瞬间的跌落；普通探头会引入额外电容。
  - 失真：相干采样 + FFT，记录采样率、输入频率、窗函数与平均次数。
- **通过标准：** 建立误差 ≤ ½ LSB；INL/DNL 在手册范围内；关注频点的谐波低于系统要求；基准跌落 ≤ 预算。
- **不能证明：** 长期漂移、温循后的建立变化、PCB 寄生在量产板的分布、EMC 干扰下的读数稳定性。

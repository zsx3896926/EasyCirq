# 电压基准

> **一句话用途：** 把“基准误差”拆成初始精度、温漂、热滞回、1/f 噪声、宽带噪声与负载调整六项，按最坏情况与 RSS 各合成一次，判断在目标位数与温度范围内能否不校准达标；并核对基准脚在 SAR 采样瞬间的动态电流由谁提供。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> 本卡证据构成：误差分类、初始精度分档、温漂换算表、REF3425 示例、噪声 1/5 判据、SAR 基准动态负载、布局建议来自 ANA-S01（SNAA320B，第 1–14 页；表 2-1、3-1、3-2、4-1；图 4-1、7-2）。容性负载稳定性与隔离电阻来自 ANA-S10（第 3–7 页）。**具体基准的负载调整、线调整、长期漂移、输出阻抗在本次来源中未被覆盖**，正文标注“待按具体器件手册核对”（E2）。§5 的合成算术与位数换算为本卡推导（E3）。
>
> **不能替代：** 具体基准手册、ADC 噪声数据、项目约束、EDA 回读、仿真或测量。

## 1. 用途与适用范围

用于给 ADC、DAC 或比较器提供参考电压，并回答：

- 这颗基准的初始精度/温漂/噪声在目标温度范围内够不够；
- 误差是作为增益误差还是偏移误差进入系统；
- 基准脚在 SAR 逐次逼近时的动态电流需要多大旁路、要不要缓冲；
- 校准能消掉哪几项、消不掉哪几项。

适用对象：串联型或并联型电压基准，单独器件或 ADC 内置基准。系统可能是 8–18 位、采样率从低速到几 MS/s。

### 不能使用的条件

- **需要基准直接驱动大负载（LED、运放电源、其他模块）**：基准不是电源，负载调整与功耗都不允许（ANA-S01 明确不能把基准当普通电源随意挂负载）。
- **基准噪声不是系统瓶颈**：若 ADC 噪声远大于基准噪声，本卡的噪声预算不必要，但仍要核对直流精度。
- **需要双极性或可编程基准**：本卡只讨论固定正基准；可编程基准的接口与建立另算。
- **基准与输入不相关却要求极高绝对精度**：见 §5，必须校准或改比率测量。
- **需要低温漂到 ppm 级而只查了 typical**：手册的 max 温漂才是判据，typical 只能估算。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 目标分辨率 | N（bit） | ADC 选型 | 阻断 |
| 基准电压 | V_REF（V） | 系统设计 | 阻断 |
| 温度范围 | T_A,min / T_A,max（°C） | 项目约束 | 阻断温漂预算 |
| 初始精度 | %(ppm) | 基准手册（max） | 阻断 |
| 温漂 | ppm/°C 或 ppm（box） | 基准手册（max） | 阻断 |
| 热滞回 | ppm | 基准手册 | 缺失时按最坏假设并标注 |
| 长期漂移 | ppm/1000 h 或 ppm/年 | 基准手册 | 缺失时留空并标注“待查” |
| 1/f 噪声 | µVpp（0.1–10 Hz） | 基准手册 | 缺失时留空 |
| 宽带噪声 | µVrms/√Hz 或 µVrms（带宽） | 基准手册 | 缺失时留空 |
| 负载调整/线调整 | ppm/mA、ppm/V | 基准手册 | 阻断动态负载判断 |
| 输出电流能力 | mA（source/sink） | 基准手册 | 阻断缓冲判断 |
| ADC 噪声 | µVrms 或 LSB | ADC 手册 | 无法做 1/5 判据 |
| ADC 基准脚动态电流 | mA 峰值、波形 | ADC 手册/厂商模型 | 只能定性判断 |
| 旁路要求 | 容值、ESR | ADC/基准手册 | 按手册推荐，不自行假设 |

**阻断项**：N、V_REF、温度范围、初始精度、温漂。**非阻断项**：长期漂移、噪声可以留空，但报告中必须写明“未计入”。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

 V_IN ──┬──── 基准 ────┬──── V_REF ────┬──── ADC REF
        │   (串联/并联) │               │
       C_IN            C_OUT          C_REF（紧靠 ADC）
        │               │               │
       AGND            AGND            AGND
```

- **串联型基准**：输入高于输出，输出由内部带隙/齐纳与缓冲维持；静态电流与压差决定功耗。
- **并联型基准**：相当于一个精密钳位，需要外部限流电阻；功耗随负载变化。
- **缓冲**：当基准输出电流不足、或多个 ADC 共用、或 SAR 动态电流较大时，在基准与 ADC 之间加低噪声缓冲（ANA-S01 第 7 节）。

误差进入系统的方式：

```text
ADC 输出码 ∝ V_in / V_REF
V_REF 的相对误差 → 增益误差（所有码按比例缩放）
V_REF 的绝对偏移 → 同样表现为增益误差，不是偏移误差
```

这一点很重要：基准误差不能靠“零点校准”消掉，只能靠增益校准或比率测量。

## 4. 参数确定步骤

顺序理由：**先算目标位数对应的 ppm 预算**（1 LSB 是多少 ppm），**再把基准的六项误差换算成 ppm 并合成**，**然后判断校准能消掉哪几项**，**最后才看动态负载与旁路**。反过来先挑“低噪声基准”常常发现初始精度已经吃掉整个预算。

### 4.1 把位数换成 ppm

```text
1 LSB = V_REF / 2^N
相对值 = 1/2^N
12 位：244 ppm
16 位：15.3 ppm
18 位：3.8 ppm
```

基准误差直接是增益误差，因此“基准允许误差”应小于系统分配给增益的预算，通常取 ¼–1 LSB，取决于是否校准。

### 4.2 六项误差

1. **初始精度**：25 °C 下的输出偏差，用 max 值。ANA-S01 表 3-1 给出典型范围 0.05%–2%（500–20,000 ppm），并把 <0.1% 称高精度、0.1%–0.5% 中、>0.5% 低。**这是分类，不是选型保证。**
2. **温漂**：把 ppm/°C 乘以温度跨度，或直接用手册的 box 值。ANA-S01 表 3-2 的换算（−40…85 °C）：
   ```text
   1 ppm/°C   → 0.0125% (125 ppm)
   5 ppm/°C   → 0.0625% (625 ppm)
   10 ppm/°C  → 0.125%  (1250 ppm)
   50 ppm/°C  → 0.625%  (6250 ppm)
   100 ppm/°C → 1.25%   (12500 ppm)
   ```
   同一表另给 0…70 °C 与 −40…125 °C 列，本卡只用 −40…85 °C 列。
3. **热滞回**：温度循环后回到 25 °C 的不可逆偏移，单位 ppm。校准一次可以消掉当前值，但下一次温循又会变。
4. **长期漂移**：随时间的老化，单位 ppm/1000 h 或 ppm/年。**本次来源未给出具体模型与数值**，必须查器件手册。
5. **1/f 噪声**：0.1–10 Hz，ANA-S01 明确它**无法用滤波消除**；只能选低噪声器件或多次平均/斩波。
6. **宽带噪声**：可用 RC 或数字滤波衰减（ANA-S01 第 6.1、6.2 节）。

### 4.3 合成

```text
最坏情况：Σ|e_i|
RSS：sqrt(Σ e_i²)
```

两种都要算：最坏情况用于安全/规格声明，RSS 用于统计意义上的设计判断。**不能只报 RSS 就宣称满足最坏情况规格。**

### 4.4 噪声判据

ANA-S01 式 6：若基准噪声相对 ADC 噪声可忽略，基准 RMS 噪声应不大于 ADC 总噪声的 1/5。

```text
e_n,REF(rms) ≤ 0.2 × e_n,ADC(rms)
```

注意单位：手册常给 µVpp（0.1–10 Hz），换算成 RMS 需要知道噪声的峰均比与带宽，不能直接把 µVpp 当 µVrms；本次来源没有给出换算系数，必须按器件手册的定义处理。

### 4.5 动态负载与旁路

1. **机理**：SAR 每一位切换都在 V_REF 引脚发生电荷再分配，电流随 MSB→LSB 非线性变化，并随输入幅度变化（ANA-S01 第 7 节）。
2. **对策**：
   - 储能电容紧靠 ADC REF 引脚；
   - 多 ADC 共用或电流需求大时加低噪声缓冲；
   - 缩短走线，减小电阻/电感；
   - 有 sense 引脚时接到 ADC 的 REF 引脚。
3. **判定**：`ΔV_REF = I_REF,peak × (R_out + ESL 项)` 与 `Q/C_REF` 两项都要算；具体电流波形待按 ADC 手册/模型核对。
4. **缓冲稳定性**：缓冲驱动大容性负载时需要 R_ISO 或专用补偿，公式与限制见 ANA-S10 与 [ANA-02](a02-opamp-buffer.md)。

### 4.6 校准策略

| 校准方式 | 消掉的项 | 消不掉的项 |
|---|---|---|
| 不校准 | — | 全部 |
| 25 °C 单点增益校准 | 初始精度、当前热滞回 | 温漂、后续热滞回、长期漂移、噪声 |
| 25 °C + 温度校准 | 初始、温漂、当前热滞回 | 后续热滞回、长期漂移、噪声 |
| 比率测量（基准与输入同源） | 基准的绝对误差与部分漂移 | 源内阻失配、噪声不相关部分 |

ANA-S01 的 REF3425 示例正是按这几种策略分别给出总误差（表 4-1）。

## 5. 完整算例

**给定条件：**

- 按 ANA-S01 表 4-1 的 REF3425 示例条件：初始精度 0.05%（500 ppm）、温漂 6 ppm/°C（40…125 °C 折 990 ppm）、热滞回 40 ppm、1/f 噪声 15 µVpp 折 15 ppm。
- 目标：12 位 ADC、V_REF = 2.5 V、基准引起的增益误差 ≤ 0.1%（1000 ppm）。
- 环境：与表 4-1 相同的 40…125 °C 条件（**注意：不是 −40…85 °C**；换温区必须重新取温漂值）。

**计算：**

1. 位数换算：
   ```text
   12 位 1 LSB = 1/4096 = 244 ppm
   1000 ppm ≈ 4.1 LSB
   16 位 1 LSB = 15.3 ppm
   ```
2. 最坏情况合成：
   ```text
   500 + 990 + 40 + 15 = 1545 ppm = 0.1545%
   ```
   与 ANA-S01 表 4-1 的 0.1545% 一致。
3. RSS：
   ```text
   sqrt(500² + 990² + 40² + 15²)
   = sqrt(250000 + 980100 + 1600 + 225)
   = sqrt(1 231 925) = 1109.9 ppm = 0.1110%
   ```
   与表 4-1 的 0.111% 一致。
4. 25 °C 校准后（去掉初始精度项）：
   ```text
   sqrt(990² + 40² + 15²) = sqrt(981 925) = 990.9 ppm = 0.0991%
   ```
   与表 4-1 的 0.0991% 一致，但相对 1000 ppm 预算只剩 0.9% 余量。
5. 25 °C + 温漂校准后：
   ```text
   sqrt(198² + 40² + 15²) = 202.56ppm ≈ 0.02026%（保留校准后198ppm温漂残差）
   ```
   表4-1温漂校准按80%改善，990ppm仍余198ppm，不能当作温漂完全消失。依该表量值计算约0.02026%，与0.0202%相符。原表温区/噪声折算自身仍有需核对的条件，不能当所有参考源的保证预算。

6. 与预算比较：

   | 校准策略 | 结果（ppm） | 相对 1000 ppm | 判定 |
   |---|---|---|---|
   | 不校准、最坏 | 1545 | 154.5% | 不满足 |
   | 不校准、RSS | 1110 | 111% | 不满足（边缘） |
   | 25 °C 校准 | 991 | 99.1% | 勉强满足，无余量 |
   | 25 °C + 温漂校准 | 202.56（本卡算术） | 20.256% | 满足，但长期漂移未计 |

7. 16 位视角：
   ```text
   991 ppm / 15.3 ppm = 64.8 LSB
   ```
   即使 25 °C 校准，12 位刚够的基准在 16 位下仍差 65 LSB。**16 位绝对精度必须做温度校准或比率测量**，不能靠选一颗“好基准”解决。
8. 噪声判据（只给形式）：
   ```text
   e_n,REF(rms) ≤ 0.2 × e_n,ADC(rms)
   ```
   ADC 噪声待查手册；REF3425 的 15 µVpp 属于 1/f 项，不能直接与 ADC 的 µVrms 比较，必须统一单位与带宽。

**候选选择：**

- REF3425 示例在“25 °C 校准 + 12 位 + 0.1% 预算”下**勉强可用**（991 ppm），但没有余量，长期漂移一加入就会超。
- 若要求 12 位不校准：1545 ppm（最坏）或 1110 ppm（RSS）都超过 1000 ppm，**淘汰**。
- 若要求 16 位：本例若不改善参考指标/校准方法则不满足，不能推广为所有16位系统都必须温度校准，应改为（a）逐温度校准，或（b）比率测量（基准与输入同源，见 [ANA-04](a04-adc-driver.md)、桥式/RTD 卡），或（c）放宽绝对精度要求。
- 温区从 40…125 °C 改到 −40…85 °C 时：温漂项必须按器件手册对应温区重取，不能把 990 ppm 直接搬用。

**结论与限制：**

- 满足：12 位、0.1% 预算、25 °C 校准下勉强满足（991 ppm）。
- 不满足：不校准的最坏情况与 RSS；16 位绝对精度。
- 未确认：长期漂移、负载调整、线调整、输出阻抗、具体旁路要求。
- 数值差异：表4-1的0.0202%须保留校准后198ppm温漂残差才能复现；不代表任意器件的保证值。

> 算例中的具体型号、阻容、脚号、层数、线宽只适用于本算例条件，不能推广到其他芯片或板；REF3425 的数值来自 TI 应用报告表 4-1，不是本次核对的 REF3425 数据手册条件。

**这个算例不能证明：**

- 不能证明该基准在实际 PCB 上的噪声（布局、旁路、回流都会改变）；
- 不能证明负载调整在 SAR 动态电流下仍满足；
- 不能证明长期漂移与热滞回在多次温循后的累积；
- 不能证明 16 位系统的 INL/DNL；
- 不能证明基准与 ADC 组合后的实际增益误差（需实测）。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 基准 | 初始精度（max）、温漂（max，注明温区）、热滞回、长期漂移、1/f 与宽带噪声、负载/线调整、输出电流、输出阻抗 | 只给 typical 温漂；不注明温区；输出电流不足以驱动 ADC 动态负载 | 封装热阻影响自热；小封装在高温下漂移 | 串联/并联拓扑按输入电压与功耗选 |
| 基准缓冲 | 噪声、输出电流、容性负载稳定性、失调 | 用普通运放直接驱动大容性节点而不看稳定性 | 见 ANA-02 | ANA-S01 建议多 ADC 时加缓冲 |
| 旁路电容 | 容值、ESR、耐压、温度特性、介质吸收 | 只看容值；X7R 在高偏压下容值下降 | 紧靠 REF 引脚 | 具体值按 ADC/基准手册 |
| 输入限流（并联基准） | 阻值、功率、温度系数 | 限流电阻随温度变化未计入 | 功耗按最大输入电压算 | 并联基准特有 |
| 参考走线/ sense | 走线电阻、sense 接点 | 把 sense 接在基准输出而不是 ADC REF 引脚 | 见 RT23 | ANA-S01 第 7 节 |

**不能用 typical 代替保证值**：初始精度、温漂、热滞回、噪声、负载调整都必须用 max 或保证值；typical 只能用于早期估算并标注。

## 7. 逐脚与外围核对

| 引脚/外围 | 必须核对 | 常见错误 | 适用检查 ID |
|---|---|---|---|
| V_IN | 输入范围、压差、功耗、去耦 | 输入低于压差，输出跌落 | SC35 |
| V_OUT | 负载电流、负载调整、旁路要求 | 直接挂 LED 或其他负载 | SC35 |

| 缓冲（如有） | 输入/输出范围、容性负载、使能 | 缓冲输入偏置流过基准输出阻抗 | SC33 |
| 基准与 ADC 的地 | 是否同一点汇合 | 数字回流穿过基准地 | RT23、RT06 |

## 8. 原理图表达

- 基准、旁路、ADC REF 引脚画成一条连续链；不要用网络标签把旁路电容放到另一页。
- 标注：V_REF、初始精度、温漂（含温区）、噪声、旁路值、是否校准、sense 接点。这些是 SC43 要求的“为何如此”。
- 若基准同时给多个 ADC，画出分配网络与每个 ADC 的本地旁路，注明“共用时的动态电流叠加”。
- 缓冲单独画，反馈与输出串联电阻按 ANA-02/ANA-S10 处理。
- 模块归属：属于“模拟采集/基准”；接口边界是基准输出网络与各 ADC 的 REF 引脚。

## 9. PCB 要求

| 项目 | 要求 | 依据/条件 |
|---|---|---|
| 关键电流回路 | 旁路电容的充电回路（基准输出 → C_REF → AGND）面积最小；ADC 采样电流不经过基准的长走线 | PL23、RT23 |
| 器件相对位置 | C_REF 紧靠 ADC REF 引脚；基准靠近 ADC；缓冲靠近基准 | ANA-S01 第 7 节 |
| 参考层/回流 | 基准地与 ADC AGND 在 ADC 处汇合；数字回流不穿过 | RT23、RT06 |
| 禁区/净空 | 基准输出远离开关电源、时钟、数字总线 | PL23 |
| 测试点/探测 | REF 引脚测试点会增加电容，测量时用低电容探头或缓冲 | RT22 |
| 热 | 基准自热会改变输出；避免靠近热源，按手册热阻核算 | PL16 |
| sense 走线 | 若有 sense，按差分对走到 ADC REF 引脚，不与其他电流共段 | RT23 |

以上为草案；基准噪声与动态跌落必须靠实测/仿真，不能由布局保证。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 基准未上电/关断 | ADC 读到 0 或不确定值，可能被误判为输入为 0 | 基准使能默认态；软件检测 V_REF 或使用 PG | 关断基准，测 ADC 读数 |
| 基准输出短路 | 限流或损坏；ADC 读数全 0 | 核对短路电流与热；必要时串联限流 | 短接输出，测电流与温升 |
| 输入过压 | 基准损坏或输出过冲 | 输入钳位/限流；核对绝对最大额定值 | 阶梯升压，测输出 |
| 负载阶跃（SAR 采样） | V_REF 跌落，码值偏低且非线性 | 旁路紧靠；必要时加缓冲 | 观察采样瞬间 V_REF |
| 温度循环 | 热滞回导致回不到原值 | 选低滞回器件；校准策略 | 温循后复测 25 °C 输出 |
| 长期老化 | 输出缓慢漂移 | 定期校准；选低长期漂移器件 | 长期记录（本次未执行） |
| 多 ADC 共用 | 动态电流叠加，跌落加大 | 每片本地旁路；加缓冲 | 多通道同时采样，看 V_REF |

## 11. 验证办法

- **工具检查：** 网表核对基准输出、旁路、sense、地连接；ERC 检查使能悬空；BOM 核对基准的完整型号（精度/温度等级/封装）。
- **计算复核：** 用初始精度 max、温漂 max（对应实际温区）、热滞回、长期漂移、噪声重跑 §4.3；最坏与 RSS 各一次；确认校准策略后的余量。
- **仿真：** 本次**未执行**。计划：用基准的 SPICE 模型（若有）做负载阶跃与容性负载稳定性；用 ADC 的 REF 电流模型做采样瞬间跌落。无模型时只能实测。
- **测量：**
  - 初始精度：6½ 位 DMM 在 25 °C 测输出，记录 DMM 自身的校准不确定度（0.05% 对应 2.5 V 的 1.25 mV，DMM 的精度必须优于它）。
  - 温漂：至少 3 个温度点（冷、常温、热），每点稳定后测；按 box 法或端点法计算，注明方法。
  - 噪声：0.1–10 Hz 用低噪声放大器 + 记录仪/FFT；宽带用频谱仪，注明带宽与增益。
  - 负载阶跃：电子负载或模拟 ADC 电流源，观察跌落与恢复。
  - 热滞回：温循后回 25 °C 复测。
- **通过标准：** 各温度点误差在预算内；噪声 ≤ ADC 噪声的 1/5；采样瞬间跌落 ≤ ½ LSB。
- **不能证明：** 长期漂移（需数月/数年数据）、批次一致性、PCB 漏电与污染的影响、与具体 ADC 组合后的 INL。

# SPI 点对点

> **一句话用途：** 在"一个主控、一个从机"的四线 SPI 上，先把 CPOL/CPHA 与帧格式对齐，再把半个周期的建立窗口算清，最后判断这条线到底需不需要串阻——而不是默认加 33 Ω。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> **本卡结论：** 四线定义、`CS` 低有效、四种 CPOL/CPHA 模式、帧长/位序/`CS` 行为由从机决定、`CS` 必须在整帧期间保持低，已按 TI SBOA621（2025-08）p.1–3 与 Table 3 核对。**SPI 没有统一的时序参数：`tSU`/`tH`/`tDIS`/`tCLK(min)` 全部来自具体主控与从机手册，SBOA621 一条也没给。** 本卡的时序预算、短线判据与串阻上限是工程推导（公式可复算），不是手册条款；具体数值必须替换为你手上两个器件的手册值。
>
> **不能替代：** 主控与从机的数据手册时序表、IBIS/实测边沿、布局后的实际走线与叠层、示波器测量。

## 1. 用途与适用范围

SPI 是同步、全双工、以片选寻址的总线（IF-S08 Table 1）。它**不定义报文格式**：帧长、位序、`CS` 在帧内的行为、空闲电平全部由从机决定（IF-S08 p.2）。本卡处理点对点（单主单从）的四件事：

1. **模式对齐**：`CPOL`/`CPHA` 决定"哪个边沿发送、哪个边沿采样"；两端不一致时常常在低速能通、高速失败。
2. **时序预算**：数据只有**半个时钟周期**从发送端走到接收端并建立，这个窗口比多数人以为的小一半。
3. **片选与三态**：`CS` 必须覆盖整帧；`CS` 撤销到 `MISO` 真正高阻之间有延迟。
4. **阻尼**：串阻不是默认件，它的上限由建立余量决定，不是由"经验值"决定。

适用：3.3 V/1.8 V 单端 CMOS SPI，Mode 0–3，时钟从几百 kHz 到几十 MHz，板内或短排线。

### 不能使用的条件

- **多从机共享 MISO**：本卡只算点对点；共享总线的争用、死区与片选默认态见 [SPI 多从机](i04-spi-multi.md)。
- **菊花链**：所有器件串在一个 `CS` 下，时序是累加的，不能用点对点预算。
- **三线双向 DIO**：收发方向切换的 `tDIS`/`tEN` 两个方向都要算，本卡不覆盖。
- **差分/低压摆幅 SPI（如 LVDS、SLVS）**：传输线与端接规则完全不同。
- **长线或跨板排线**：超过"电短"判据后必须按传输线处理（见第 4 节第 6 步），本卡的集中电容模型失效。
- **主控或从机手册没有给出 `tSU`/`tH` 保证值**：只能实测，不能按"一般够用"签核。
- **需要协议层确认**：SPI 没有 ACK、没有地址、没有错误检测；通信"看起来成功"不代表从机收到了正确命令。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

  主控                                     从机
  ┌──────┐   PICO (SDO) ───────────────►  SDI   ┌──────┐
  │      │   POCI (SDI) ◄───────────────  SDO   │      │
  │ SPI  │   SCLK      ─────────────────►  SCLK  │      │
  │      │   CS_n      ─────────────────►  CS_n  │      │
  └──────┘                                      └──────┘
            （可选）Rs 串在驱动端，靠近源

  Mode 0（CPOL=0, CPHA=0）一个位的窗口：
       CS_n ‾‾\____________________________________/‾‾
   SCLK    ____/‾‾‾\___/‾‾‾\___/‾‾‾\___/‾‾‾\______
                ↑ 采样    ↑ 采样    ↑ 采样
              ↑ 发送    ↑ 发送    ↑ 发送
       |←—— T/2 ——→|←—— T/2 ——→|
       发送边沿到下一个采样边沿只有半个周期
```

四个模式（IF-S08 Table 3）：

| 模式 | CPOL | CPHA | 空闲电平 | 采样边沿 |
|---|---|---|---|---|
| 0 | 0 | 0 | 低 | 上升沿 |
| 1 | 0 | 1 | 低 | 下降沿 |
| 2 | 1 | 0 | 高 | 下降沿 |
| 3 | 1 | 1 | 高 | 上升沿 |

关键结构事实：

逐方向检查建立/保持；读方向包含SCLK前行、从机输出、MISO返回，写方向按相对偏斜，不使用通用单程预算。
- **CPHA=0 的额外约束**：第一位必须在第一个有效边沿**之前**就建立好，因此 `CS` 拉低到第一个时钟沿的间隔也要满足 `tSU`。
- **`CS` 覆盖整帧**：IF-S08 举的 TXE8116/24 例子是固定 24 bit、MSB first、Mode 0，`CS` 必须在整个 24 bit 期间保持低（p.3）。把 `CS` 当成"每个字节一个脉冲"是常见错误。
- **`CS` 低有效**：`CS` 高（空闲）时从机应释放 `MISO`；释放需要时间 `tDIS`，这段时间内主控不能开始采样下一个器件。

## 4. 参数确定步骤

顺序理由：模式错了，后面所有时序计算都是白算；模式确定后才能知道"哪两个边沿之间是 `T/2` 窗口"；电平与时序都成立之后，才轮到串阻——因为串阻会吃掉建立余量，必须最后选。

1. **判据：模式一致。**
   **做法：** 把主控的 `CPOL`/`CPHA` 配置与从机时序图逐项对齐（IF-S08 Table 3）。不要用"别人这么配"代替。
   **含义：** 模式错时，从机在数据未建立时采样，表现为"低速能读、高速读错"或"读到的值整体移位一位"。移位一位是 CPHA 错的典型症状。

2. **判据：帧格式与 `CS` 行为。**
   **依据（IF-S08 p.2–3）：** SPI 不像 I²C 那样定义统一报文格式；帧长/位序/`CS` 行为由具体器件决定。
   **做法：** 从手册确认：帧长（8/16/24/32 bit）、位序（MSB/LSB first）、`CS` 是否整帧保持低、命令字节与数据字节的顺序、是否需要 dummy 周期。

3. **判据：时序预算（核心）。**
   读取方向必须计时钟先到从机、再输出数据返回主机：`T/2 ≥ tCLK_forward + tCO_slave(max) + tMISO_return + tSU_master + jitter/skew预算`。写方向比较主机数据与时钟到从机的相对延迟：`T/2 ≥ |tPD_CLK − tPD_DATA| + tCO_master(max) + tSU_slave + jitter`；保持时间：`tH_slave ≤ tCO_master(min) + tPD_DATA − tPD_CLK`（按实际边沿与SPI模式取符号），不能用tCO(max)或单个T/2公式包办。传播延迟为长度除传播速度，150mm/ns只是示例。两方向及CS时序分别查实际手册。

4. **判据：`CS` 与三态。**
   **要求：** `CS` 拉低到第一个时钟沿 ≥ `tSU(第一位) + tPD`（CPHA=0 尤其重要）；`CS` 拉高后保持高电平 ≥ `tDIS(max)` 才能开始下一次访问或切换到别的从机。
   **注意：** `tDIS` 通常是 max 值；手册若只给 typical，按实测加余量。

5. **判据：电平兼容。**
   **公式（IF-S06 §1 的三条判据）：** 驱动器 `VOH(min) > 接收器 VIH(max)`；驱动器 `VOL(max) < 接收器 VIL(min)`；驱动器输出不得超过接收器 I/O 耐压。
   **做法：** 逐线核对四条线，不要只核 SCLK。`MISO` 方向常常是唯一不兼容的一条（从机低压、主控高压），却最容易被忽略。

6. **判据：这条线是"电短"还是"电长"。**
   **判据（本卡采用，工程惯例）：** 若 `tPD(单程) < tr/6`，按集中电容处理；否则按传输线处理，需要端接与阻抗控制（RT11）。
   **计算：** `长度上限 ≈ tr / (6 × 6.7 ps/mm)`。`tr=2 ns` 时约 **50 mm**。
   **含义：** 几十毫米、几十 MHz 的板内 SPI 通常是电短的，**不需要端接**；此时串阻的作用是压边沿/降 EMI，不是阻抗匹配。把"串阻"当成"端接"是常见概念混淆。

7. **判据：串阻是否需要、最大多少。**
   **先判是否需要（RT20）：** 只有出现振铃、过冲超过器件绝对最大值、或 EMI 测试不过时才加；"别人都加"不是理由。
   **上限公式（本卡推导）：** 串阻 `Rs` 与负载电容 `C_L` 形成的边沿延迟约 `1.2 × Rs × C_L`（RC 充到 `0.7×VDD` 的时间常数倍率 `ln(1/0.3)=1.204`）。要求该延迟不超过第 3 步算出的建立余量：
**上限公式：** `1.2 × Rs × C_L ≤ 该方向剩余建立余量`，即 `Rs,max = 余量 / (1.2 × C_L)`；`C_L` 取最大（从机 `Cin` + 走线电容 + 连接器/探头），读/写方向分别用各自的余量，不能复用一个方向的预算。
   **下限：** 由需要的阻尼量决定，通常只要"源端阻抗 + `Rs` 接近线阻抗"即可；驱动器的 `R_drv` 极少给保证值，需 IBIS 或实测。
   **副作用：** `Rs` 会与从机 `Cin` 形成低通，降低可用最高频率；预留但未装的焊盘同样有寄生（RT20）。

8. **判据：`CS` 默认态。**
   **要求：** 主控复位/bootloader 期间 GPIO 可能是高阻，`CS` 必须由外部上拉（到从机 I/O 域）保持无效；否则从机会被随机选中，甚至在 `MISO` 上驱动。
   **核对：** `CS` 是否与启动 strap 复用（见 [SPI 多从机](i04-spi-multi.md) 的 RP2040 实例）。

## 5. 完整算例

**给定条件（演示假设，不是具体器件保证值）：** Mode0、25MHz，半周期20ns；时钟前向与MISO返回各5ns，从机tCO(max)=8ns，主机建立4ns。目标核对读方向是否成立。

读方向所需时间=5+8+5+4=22ns，大于20ns，差2ns，不能以单程5ns得到的17ns结论放行。仅按这项反推频率上限约1/(2×22ns)=22.73MHz，还须加入抖动/偏斜与器件自身上限。写方向需独立查主控tCO(max)、从机建立以及SCLK/数据相对延迟；缺这些值时保持待确认。保持需最小输出延迟与最早数据改变，不能拿tCO(max)替代。

串阻按两方向已确认的时序余量和真实负载估算RC延迟，再用IBIS/测量核对；余量为负时不能靠选33Ω放行。CS首位/末位和多从机三态交接独立检查。

**候选选择：** 当前25MHz读方向不满足；降频是候选，不能保证仅降到22.73MHz就满足全部接口。元件与线长未绑定真实工程。

**结论与限制：** 这是传播时序反例；不能证明任一真实器件/PCB的信号完整性、EMC或通信功能，亦不能给通用串阻/最高速率。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 主控 SPI 外设 | 支持的 `CPOL/CPHA`、最高 `fSCLK`、FIFO/CS 数量、可变帧长 | 不支持从机要求的模式；帧长不可配 | — | 先查外设，再查引脚复用（SC25） |
| 从机 | `tCLK(min)`、`tSU`/`tH`、`tDIS`、`Cin`、支持的帧长/位序 | 时序表只有 typical；模式固定且主控不支持 | — | 手册时序图必须逐条读 |
| 串阻 | 阻值、容差、寄生 | 附加延迟超过建立余量 | 0402，靠近驱动端 | 默认 DNP，见 RT20 |
| 电平转换 | 方向、速率、`Ioff` | 只支持推挽单向而总线需要双向 | — | 见 IF-12 |
| `CS` 上拉 | 阻值、默认态 | 与启动 strap 冲突 | — | 见 IF-04 |
| 连接器/排线 | 针数、地针比例、长度 | 地针过少 | — | 每根信号配一根地 |

**推荐工作条件与绝对最大额定值分开写：** 从机的 `fSCLK(max)` 是推荐工作条件，绝对最大值只表示"不损坏"；超过 `fSCLK(max)` 可能仍"能读到数据"，但没有任何保证。**时序参数必须用 max/min，不能用 typical。**

## 8. 原理图表达

- **四条线画成一组**，`CS` 紧跟 SCLK，不要分散到页面各处；组内标 `Mode 0 (CPOL=0, CPHA=0)`。
- **`CS` 的上拉画出来**并注明"复位期间保持无效"。
- **串阻标 DNP**：`Rs (DNP, 0R)`，旁边写"装配后须重算建立余量"。
- **从机的 `tCLK(min)`/`tSU` 写在器件旁**，让改板的人知道约束来自哪里。
- **不要把 SPI 与 I²C 用同名网络**：`SCL`/`SCLK` 一字之差会造成误接。
- **模块边界**：SPI 属于"数字接口"模块，与电源/模拟分区，`CS` 的默认态由主控页负责。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 上电/复位 | 主控 GPIO 高阻，`CS` 悬空，从机可能被选中 | `CS` 外部上拉；核对从机上电默认态 | 上电瞬间抓 `CS` 与 `MISO` |
| 模式错配 | 数据整体移位或只在高频出错 | 按 Table 3 逐项对齐 | 低速与高速各读一次已知图案 |
| 从机未上电 | I/O 经 ESD 二极管把总线钳到其电源轨 | 串阻限流、`Ioff` 器件、电源顺序 | 单独给从机断电，测总线电平 |
| `CS` 提前拉高 | 帧被截断，从机状态机停在半途 | `CS` 覆盖整帧；固件核对 | 逻辑分析仪数 `CS` 低期间的时钟数 |
| `MISO` 争用 | 两个驱动源对打，电流过大 | 点对点本不应发生；多从机见 IF-04 | 测 `MISO` 低电平是否被抬高 |
| 边沿过冲 | 超过绝对最大值，长期损伤 | 串阻/降边沿 | 示波器看振铃 |
| 地弹 | 多个输出同时翻转，采样错 | 增加地针、降低边沿 | 同时翻转多位测试 |

## 11. 验证办法

- **工具检查：** 网表确认四线点对点、无多余分支；核对外设模式配置与从机手册；确认 `CS` 上拉（SC28、SC45）。
- **计算复核：** 用最慢 `tr`、最长走线、最小 `T/2` 复算建立余量；用最快 `tr` 复算保持余量；两个方向都算。
- **仿真：** 未执行。若做：IBIS 模型 + 实际叠层，观察从机引脚处的建立/保持窗口；通过标准为 `tSU_实际 ≥ tSU(手册)` 且 `tH_实际 ≥ tH(手册)`。IBIS 不含封装内部的全部效应。
- **测量：** 示波器三通道（SCLK、MOSI、CS）或四通道加 MISO，探头接在**从机引脚**；用已知图案（如 0xAA/0x55）在最低与最高温度、最低与最高 `VDD` 下各测；测 `CS` 撤销到 `MISO` 高阻的时间。
- **通过标准：** 数据在采样边沿前后均满足 `tSU`/`tH`；`CS` 覆盖整帧；连续读写 ≥10⁶ 帧无错误；无超过绝对最大值的过冲。
- **不能证明：** 从机的协议层正确性（SPI 无 ACK）、EMC、长期可靠性、固件时序（中断延迟导致的 `CS` 抖动）。

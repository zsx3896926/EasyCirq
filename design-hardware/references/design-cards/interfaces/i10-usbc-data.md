# USB-C 数据与 CC

> **一句话用途：** 设计 USB Type-C 端口的数据与 CC 通道：Source/Sink/DRP 角色、CC1/CC2 双端检测与正反插、SBU、VBUS 门控、连接器/ESD 和 IR Drop 预算。

> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>

## 1. 用途与适用范围

本卡用于 USB Type-C 端口的数据与 Configuration Channel（CC）设计：Source 在 CC1/CC2 上放 `Rp` 并监测，Sink 在 CC1/CC2 上放 `Rd`；用哪一根 CC 电压更高判断插头方向；`Ra` 表示有源电缆/附件；Source 检测到 `Ra` 才在未用于 CC 通信的那根 CC 上提供 VCONN（IF-S12 §4.5.1.2/§4.5.1.3，第 160–167 页）。

本卡重点回答四个决定：

1. 端口是 Source、Sink 还是 DRP；CC1/CC2 是否分别处理；
2. 正反插如何判断，SBU/D+/D−/SS 对如何随方向映射；
3. VBUS 什么时候允许上电，CC 去抖/断开时间是多少；
4. VBUS/地 IR Drop、ESD、连接器和 CC 走线如何满足规范。

### 不能使用的条件

- **USB PD / 高压快充 / PPS**：本卡只覆盖 CC 的连接检测、角色和方向，未读 PD 协议、Alternate Mode、VCONN 完整规范；PD 项目必须另查 USB PD 规范和所选控制器手册。
- **USB4 / Thunderbolt / DisplayPort Alt Mode**：SBU 和高速 lane 的复用、Enter Mode 流程本卡未覆盖；不能只按“SBU 可悬空”处理 Alt Mode 设计。
- **把本卡当 USB-C 电源（Sink/Source）设计卡**：VBUS 开关、限流、放电、保护是 PWR-12/PWR-13 的范围；本卡只给 CC 对 VBUS 的门控前提。
- **连接器机械、防水、大电流端子、EMC/ESD 认证**：IF-S12 本次未读连接器机械与 ESD 章节；本卡只给电气/状态机层面的检查，不能替代连接器规格和认证。
- **具体 `Rp`/`Rd` 阻值**：本次来源未能从规范文本层提取 5.1 kΩ、56 kΩ/22 kΩ/10 kΩ 等阻值（它们在 Figure 4-5/4-7/4-9 等图形内）。本卡**不把这些数值写成已验证**；可先参考 [PWR-12](../power/p12-usbc-sink.md) 与 [x08](../../examples/x08-usbc.md) 的示例，但必须按所用规范版本的图表和 CC 控制器手册核对。使用前确认规范版本，不能把示例值当规范条文。
- **无 CC 控制器、用电阻硬做 Source/Sink**：电阻可以实现基本角色，但过流/VCONN/DRP/保护要另做；不能把“能识别”当成“全功能”。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

  Source 侧                                 Sink 侧
  ┌──────────────────┐                    ┌──────────────────┐
  │ VBUS 开关         │──── VBUS ─────────│ VBUS 检测         │
  │                  │                    │                  │
  │ CC1 ●── Rp ──┐   │                    │   ┌── Rd ──● CC1  │
  │              │   │                    │   │                │
  │ CC2 ●── Rp ──┤   │                    │   ├── Rd ──● CC2  │
  │              │   │                    │   │                │
  │ 监测 CC1/CC2  │   │                    │ 监测 CC1/CC2      │
  │                  │                    │                  │
  │ SBU1/SBU2 ───────┼──── 电缆交叉 ──────┼───── SBU1/SBU2   │
  │ D+/D− / SS ──────┼────────────────────┼───── D+/D− / SS  │
  └──────────────────┘                    └──────────────────┘

  方向判断（Sink）：
    CC1 电压 > CC2 → 插头某一方向；CC2 > CC1 → 反向
    SBU1/SBU2 在电缆内交叉，方向翻转时 SBTX/SBRX 映射要交换
```

**CC 模型：** Source 在 CC1、CC2 上各放一个 `Rp` 上拉并同时监测；Sink 在 CC1、CC2 上各放一个 `Rd` 下拉。Source 看到任一 CC 电压低于未端接电压即判为连接；`Rp` 的取值表示 Source 能提供的 USB Type-C 电流档。Sink 侧用哪一根 CC 电压更高来判断插头方向。`Ra` 表示有源电缆/附件；Source 检测到 `Ra` 才需要提供 VCONN，VCONN 加在未用于 CC 通信的那根 CC 上（IF-S12 §4.5.1.2/§4.5.1.3，第 160–167 页）。

**连接状态：** IF-S12 Table 4-10 给出 CC1/CC2 组合：全开=未连接；Rd/Open 或 Open/Rd=接入 Sink；Open/Ra 或 Ra/Open=仅接入有源电缆；Rd/Ra=有源电缆+Sink/VPA/VPD；Rd/Rd=调试附件；Ra/Ra=液体腐蚀缓解模式。不要把“有一根 CC 为低”简单当成“已连接”，要按两根 CC 的组合判。

**VBUS 门控：** Source 在确认连接前不得给 VBUS/VCONN 上电；未供电时 VBUS 对地电容须受限（Table 4-2）。Sink 以 VBUS 有电判断 Source 已接入（IF-S12 §4.4.2、§4.5.1）。

**时间：** `tCCDebounce` 100–200 ms；`tPDDebounce` 10–20 ms；`tSRCDisconnect` ≤20 ms；DRP 的 `tDRP` 50–100 ms、`dcSRC.DRP` 30%–70%、`tDRPTransition` ≤1 ms（Table 4-34）。

**SBU：** 不实现 USB4/Alternate Mode 的端口，SBU1/SBU2 必须开路或经不弱于 `zSBUTermination` 的弱下拉；实现时在进入前同样只能开路或弱下拉；SBU1/SBU2 在电缆内交叉连接，方向翻转时要相应交换 SBTX/SBRX 映射（IF-S12 §4.3，第 150–152 页）。

**IR Drop：** 电缆地压降 ≤250 mV，VBUS 压降 ≤500 mV（按电缆最大额定电流）（IF-S12 §4.4.1，第 150–152 页）。

## 4. 参数确定步骤

顺序原则：**先定角色和 CC 模型，再定 VBUS 门控/时间去抖，最后算 IR Drop、SBU 和 ESD**。如果先选连接器/线缆再发现 CC 电阻/角色不对，整个端口要重做；如果先做 VBUS 大电流再发现地压降超 250 mV，也要改线缆/连接器。

1. **目标/判据：** 明确端口角色和数据角色。
   **方法：** Source 在 CC1/CC2 各放 `Rp`；Sink 各放 `Rd`；DRP 在 Source/Sink 之间切换。数据角色（DFP/UFP/DRD）与电源角色分开记录，不能默认“Source 就是主机”。
   **假设：** 无 PD 时按默认 USB 电流档；有 PD 时另做。
   **来源：** IF-S12 §4.5.1。

2. **目标/判据：** CC1/CC2 分别处理，支持正反插。
   **方法：** 两根 CC 各自走线、各自电阻/控制器引脚，不得短成一个节点；Sink 比较 CC1/CC2 电压判方向；Source 同时监测两根。
   **假设：** 连接器/电缆的 CC 映射按规范；实际连接器引脚定义要对照 SC40。
   **来源：** IF-S12 §4.5.1.2/§4.5.1.3。

3. **目标/判据：** `Rp`/`Rd` 取值与电流档一致。
   **方法：** 按所用规范版本的 Figure 4-5/4-7/4-9 和 CC 控制器手册选 `Rp`/`Rd`；用 Table 4-36 的 Sink CC 电压窗口验证：默认 USB 0.277–0.612 V；1.5 A 0.746–1.164 V；3.0 A 1.369–2.042 V；断开阈值 0.276 V（`Rd ±10%`）。
   **保证值：** 电压窗口是规范值；`Rp`/`Rd` 的具体阻值本卡不写（来源文本层未提取到），必须按图表/器件手册核对。
   **选择/迭代：** 先选 `Rp`/`Rd`，再算/测 CC 电压，落在目标窗口且留容差；不能只看“典型 5.1 kΩ”而不算 ±10%/接触电阻。

4. **目标/判据：** Source 在确认连接前不上 VBUS/VCONN。
   **方法：** 画状态机：未连接 → 检测 CC → 去抖 → 上 VBUS/VCONN；Sink 以 VBUS 有电判断 Source 接入。VBUS 开关的默认态必须是关断。
   **假设：** 控制器内部状态机/外部 MCU 实现；具体寄存器/时序按控制器手册。
   **来源：** IF-S12 §4.4.2、§4.5.1。

5. **目标/判据：** 去抖/断开/DRP 时间符合规范。
   **方法：** `tCCDebounce` 100–200 ms、`tPDDebounce` 10–20 ms、`tSRCDisconnect` ≤20 ms；DRP `tDRP` 50–100 ms、`dcSRC.DRP` 30%–70%、`tDRPTransition` ≤1 ms。用控制器时钟/固件定时器实现并留容差。
   **假设：** 控制器内部定时已满足；如果软件轮询，轮询周期要远小于最短时间去抖。
   **来源：** IF-S12 Table 4-34。

6. **目标/判据：** SBU 按用途处理。
   **方法：** 不用 USB4/Alt Mode：SBU1/SBU2 开路或弱下拉（不弱于 `zSBUTermination`）；使用时按 Alt Mode 要求切换，进入前保持开路/弱下拉；方向翻转时交换 SBTX/SBRX。
   **假设：** 具体 `zSBUTermination` 数值按规范/连接器手册；本卡不写。
   **来源：** IF-S12 §4.3。

7. **目标/判据：** VBUS/地 IR Drop 满足。
   **公式：** `V_drop = I × R_path`；地 ≤250 mV、VBUS ≤500 mV（按电缆最大额定电流）。
   **假设：** 电阻包括电缆导体、连接器接触、PCB 走线/过孔；按最坏温度和接触电阻。
   **选择/迭代：** 先按目标电流算允许总电阻，再分配电缆/连接器/PCB；不满足就降电流、换更粗导体/更好连接器。

8. **目标/判据：** ESD/连接器/数据对映射正确。
   **方法：** CC/SBU/VBUS/D+/D−/SS 的 ESD 器件工作电压覆盖 VBUS；连接器正反插时 SS 对和 SBU 映射要交换；屏蔽/地脚按连接器规格。
   **检查：** SC30、SC31、SC40、DM29、PL15。

## 5. 完整算例

**给定条件：**

- USB-C Sink，captive cable，目标 3 A 档；Source VBUS 空载 5.00 V。
- 实测 Sink 端 VBUS 4.65 V（压降 350 mV）；地路径压降 0.28 V（280 mV）。
- 实测 CC 电压 0.50 V（Sink 侧，某一方向）。
- 连接器 + PCB 地路径估计 20 mΩ（假设，待实测）；电缆地导体电阻待查规格书。
- 未做 PD；SBU 不使用；ESD 器件未选。

**计算：**

1. **VBUS 压降：**
   `V_drop,VBUS = 5.00 − 4.65 = 0.35 V = 350 mV`。
   规范上限 500 mV（IF-S12 §4.4.1），350 mV < 500 mV，VBUS 压降通过。

2. **地压降：**
   `V_drop,GND = 0.28 V = 280 mV`。
   规范上限 250 mV，280 mV > 250 mV，**不通过**。地压降超限会让 Sink 侧参考地抬高、CC/数据电平偏移，也可能让 Source 误判。

3. **允许地电阻：**
   `R_GND,max = 250 mV / 3 A = 83.3 mΩ`。
   若连接器 + PCB 地路径 20 mΩ，则电缆地导体允许 `83.3 − 20 = 63.3 mΩ`。按电缆规格书的单位长度导体电阻选型；本算例不写线规/AWG 数值。

4. **降到 1.5 A 的复核：**
   同一 93.3 mΩ 地路径（280 mV/3 A）：`V_drop,GND = 1.5 A × 93.3 mΩ = 140 mV < 250 mV`，地压降通过。但 1.5 A 档要求 CC 电压落在 0.746–1.164 V（Table 4-36），实测 0.50 V 不在该窗口。

5. **CC 电压判档：**
   实测 0.50 V 落在默认 USB 窗口 0.277–0.612 V（Table 4-36），表示默认 USB 电流档，不是 1.5 A 或 3.0 A 档。若产品要 3 A，CC 指示与负载目标不一致；必须回查 `Rp`/`Rd` 取值、CC 走线/接触电阻和 Source 能力。**本卡不写 `Rp`/`Rd` 具体阻值**，因为本次来源文本层未提取到；按规范图表和 CC 控制器手册核对。
   同时注意：0.50 V 高于断开阈值 0.276 V，说明 CC 仍处于连接状态，不是“未连接”。

6. **去抖复核：**
   若固件轮询周期 10 ms，`tCCDebounce` 最小 100 ms，至少需要 10 次一致采样；`tPDDebounce` 最小 10 ms，至少 1–2 次采样。轮询周期不能接近 100 ms，否则会漏掉短连接/断开。DRP 若使用，`tDRP` 50–100 ms，`dcSRC.DRP` 30%–70%，`tDRPTransition` ≤1 ms；软件切换要保证占空比和过渡时间。

7. **SBU：**
   不使用 Alt Mode，SBU1/SBU2 开路或弱下拉（不弱于 `zSBUTermination`）。不能把 SBU 直接短到地或 VBUS；方向翻转时如果未来加 Alt Mode，SBTX/SBRX 要交换。

**候选选择：**

- 3 A 方案：地压降 280 mV 不满足；淘汰原电缆/连接器组合，改用更低电阻地路径，或降到 1.5 A。
- 1.5 A 方案：地压降 140 mV 满足，但 CC 0.50 V 仍是默认档，不满足 1.5 A 窗口；必须同时修正 CC（`Rp`/`Rd`/接触电阻），不能只降电流。
- 默认 USB 方案：CC 0.50 V 与默认档一致；地压降按实际电流（≤0.5 A 或 1 A）重算，通常远低于 250 mV；这是本算例中唯一“CC 与电流目标一致”的候选。
- 结论：先修正 CC 档位，再按目标电流选地路径；不能只改线缆而忽略 CC，也不能只改 CC 而忽略地压降。

**结论与限制：**

- VBUS 压降 350 mV 通过；地压降 280 mV 不通过，3 A 方案被淘汰。
- 3 A 下允许地总电阻 83.3 mΩ；连接器/PCB 占 20 mΩ 时，电缆地导体要 ≤63.3 mΩ。
- 实测 CC 0.50 V 属于默认 USB 窗口，不是 1.5 A/3 A 档；CC 与电流目标不一致，必须先修正 `Rp`/`Rd`/接触电阻。
- 本算例不能证明：`Rp`/`Rd` 的具体值、Source 实际能力、PD 协商、ESD、连接器机械寿命、正反插两面都通过、电缆高频性能。

> 算例中的具体型号、阻容、脚号、层数、线宽只适用于本算例条件，不能推广到其他芯片或板。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| CC 控制器/PHY | Source/Sink/DRP、CC1/CC2 双路、VCONN、去抖、VBUS 控制 | 只支持单 CC；无 VBUS 门控；去抖不满足 | 封装、引脚、固件 | 具体型号手册核对 |
| `Rp`/`Rd` 电阻 | 阻值、容差、温度系数、布局 | 阻值/容差使 CC 电压出窗口；只装一根 CC | 靠连接器/控制器 | 本卡不给具体阻值；按规范图表 |
| VCONN 开关 | 电流、限流、反向阻断、控制 | 无 `Ra` 检测却常开；无限流 | 靠连接器 | 有源电缆才需要 |

| 连接器 | 引脚、正反插、CC/SBU/SS、屏蔽/地脚 | 引脚映射错；无屏蔽/锁扣 | 插拔空间、装配 | SC40 |
| 电缆 | 导体电阻、CC 线、屏蔽、额定电流 | 地电阻使 3 A 压降 >250 mV | 线径/弯折 | 按 IR Drop 预算选 |

推荐工作条件与绝对最大额定值分开：CC 电压窗口、VBUS 5 V、3 A 是工作参数；CC/SBU/VBUS 对地绝对最大、ESD 等级、连接器额定是生存参数。设计判据用 min/max 保证值，`typical` 只能用于初选。

## 7. 逐脚与外围核对

| 引脚/外围 | 必须核对 | 常见错误 | 适用检查 ID |
|---|---|---|---|
| CC1 | 独立走线、`Rp`/`Rd`、ESD、连接器映射 | 与 CC2 短成一个节点，正反插失效 | SC30 |
| CC2 | 独立走线、`Rp`/`Rd`、ESD、连接器映射 | 只处理一根 CC，另一方向不识别 | SC30 |
| SBU1/SBU2 | 开路/弱下拉、Alt Mode 映射、方向交换 | 直接短地/VBUS；方向翻转不交换 | SC30、SC40 |
| VBUS | 开关/检测、去耦、IR Drop、ESD | Source 未确认连接就上 VBUS；Sink 反灌 | SC30、SC10 |
| GND | 地路径电阻、连接器地脚、屏蔽 | 地压降 >250 mV；地脚数量不足 | SC40、RT01 |

只列本拓扑真正相关的脚；具体 CC 控制器的脚号、寄存器、VCONN 开关极性必须按该型号手册核对，本卡不写脚号。

## 8. 原理图表达

- CC1/CC2 分成两根独立网络，从连接器到控制器/电阻，不得合并；旁边注明“正反插检测，禁止短接”。
- Source 的 `Rp` 画在 CC1/CC2 到 `VTERM`/VCONN 逻辑上，Sink 的 `Rd` 画到地；不要只画一个电阻符号而不标角色。
- VCONN 开关画清“仅在检测到 `Ra` 时给未用于 CC 通信的那根 CC 上电”；默认关断。
- SBU1/SBU2 画开路或弱下拉，并注明“不用 Alt Mode 时保持开路/弱下拉”；如果使用，画清方向交换。
- VBUS 开关/检测画清默认态、去抖、限流和放电；Source 未确认连接前 VBUS 必须关断。
- ESD 器件画在连接器入口，标注 standoff/钳位/电容；不要只写“Type-C 保护”。
- 连接器符号旁画正反插/引脚映射表，特别是 SS 对和 SBU 的交换；不要只依赖网名。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 正插/反插 | CC1/CC2 电压交换，SBU/SS 映射翻转 | 双 CC 检测；SBU/SS 交换；连接器映射 | 两面各插一次，测 CC/数据 |
| 未连接 | CC 全开，Source 不上 VBUS | 状态机默认关断；去抖 | 空载测 CC/VBUS |
| 接入 Sink | 一根 CC 被 Rd 拉低，Source 识别 | 按 Table 4-10 组合判；去抖 100–200 ms | 接 Sink，测 CC/VBUS |
| 有源电缆 `Ra` | Source 需在另一根 CC 提供 VCONN | 检测 `Ra`；VCONN 开关/限流 | 接有源电缆，测 VCONN |
| 调试附件 Rd/Rd | 进入调试附件状态 | 状态机支持；不要误当普通 Sink | 接调试附件，测 CC |
| VBUS 短路/过流 | Source 过流、连接器/线缆过热 | VBUS 开关限流、保护、地路径 | 限流源/短路测试 |
| CC 短路/开路 | 误判连接/方向；Source 误上 VBUS | CC 串阻/ESD；状态机容错 | 短/开 CC，测状态 |
| ESD | CC/SBU/VBUS 损坏、锁死 | ESD 靠连接器、地回流 | IEC 61000-4-2（按产品规范） |
| 掉电/死电池 | Sink 无电，CC 仍可能被 Source 检测 | Rd 保持；VBUS 检测；Ioff | 断 Sink 电，测 CC/VBUS |

不适用状态要写理由：例如纯 Sink、只用 A-to-C 线、不做 DRP 的端口，可不算 DRP 占空比和 VCONN；但仍要算正反插、VBUS 门控、IR Drop 和 ESD。

## 11. 验证办法

- **工具检查：** 原理图核对 SC30（USB-C 角色/CC/VBUS）、SC31（USB 器件差异）、SC40（连接器视角）、SC26（电平）、SC15（保护）；PCB 核对 PL15（保护靠边界）、RT11/RT12（差分/阻抗）、RT18（连接器映射）、RT01/RT02（VBUS/地载流）。不能用“能充电”代替 CC/正反插检查。
- **计算复核：** 用 VBUS/地路径最坏电阻、最大电流、连接器接触电阻、CC 电阻容差复算：VBUS/地 IR Drop、CC 电压窗口、去抖时间。至少覆盖：正插/反插、3 A/1.5 A/默认档、最低/最高 VBUS、最坏接触电阻。
- **仿真：** 本卡未执行仿真。若要仿真，应使用连接器/电缆/ESD 模型和 CC 状态机模型，激励为正反插、VBUS 热插拔、CC 短/开；观察 CC 电压、VBUS/地压降、VCONN 和状态迁移；通过标准是 Table 4-36 窗口和 IR Drop 限值。没有模型/未执行时写“未执行”，不生成假波形。
- **测量：** 用高阻探头测 CC1/CC2（不影响 Rd/Rp），同时测 VBUS、GND、VCONN；正反插各测一次。测量项目：CC 电压、VBUS/地压降、VCONN、去抖/断开时间、SBU 电平、ESD 前后漏电。停止条件：CC 电压出窗口、VBUS/地压降超限、连接器/线缆过热。
- **通过标准：** CC 电压落在目标档窗口（默认 0.277–0.612 V、1.5 A 0.746–1.164 V、3.0 A 1.369–2.042 V）；VBUS 压降 ≤500 mV、地压降 ≤250 mV；正反插都能识别；Source 未确认连接前 VBUS 关断；去抖/断开时间符合 Table 4-34。
- **不能证明：** 本卡方法不能覆盖 PD/Alt Mode、USB4、连接器机械寿命、系统级 ESD/EMC、线缆高频性能和长期可靠性；这些需要专门测试/认证。

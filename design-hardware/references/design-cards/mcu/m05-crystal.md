# 晶体振荡器

> **一句话用途：** 由晶体参数（CL、ESR、C0、驱动电平）与 MCU 的跨导算出负载电容、负阻余量和串联电阻，判断“能不能可靠起振”，而不是照抄 18 pF 或参考板的 20 pF。
>
> **证据等级：** `E1`。负载电容公式、gmcrit、gain margin ≥5、驱动电平、RExt 初值、安全因子 Sf ≥5（HSE）/≥3（LSE）、LSE 启动 1–5 s、PCB 准则已按 AN2867 Rev 24 §1–§3、§7.1–§7.2 核对；LSE 的 CL ≤7 pF 与“不要用 12.5 pF”按 AN4488 §6 核对；**具体晶体的 CL/ESR/C0/DL 与 MCU 的 gm 必须查各自数据手册**，本卡算例使用文档教学值，不代表任何料号。
>
> **不能替代：** 晶体与 MCU 数据手册、负阻实测、驱动电平实测、温度/湿度试验、EMC。

## 1. 用途与适用范围

解决五件事：

1. **负载电容**：CL 由晶体厂给定，外部电容要把它“配”出来，且要减去寄生 Cs。
2. **负阻余量**：gm/gmcrit > 5 才算安全；余量不足会“样机起振、量产不起振”。
3. **驱动电平**：超过晶体允许的 DL 会加速老化甚至振裂；必要时加 RExt，但 RExt 会吃掉负阻余量。
4. **启动时间**：MHz 级几 ms，32.768 kHz 约 1–5 s，固件等待时间必须覆盖。
5. **布局**：短、局部地、guard ring、远离高速与开关节点。

适用：Pierce 型皮尔斯振荡器（MCU 内置反相器 + 外部晶体），HSE 与 LSE 均适用。

### 不能使用的条件

- **有源晶振/外部时钟输入**：不适用负载电容与负阻计算，转 [MCU-06](m06-external-clock.md)。
- **MCU 内部已集成负载电容且不可调**：只需选 CL 匹配的晶体，不能再按外部 CL1/CL2 算。
- **陶瓷谐振器**：ESR/精度模型不同，本卡不覆盖。
- **需要 ±ppm 级频率精度**：晶体 + MCU 内部负载电容的初始误差可能不够，需 TCXO/校准，转 MCU-06。
- **未取得 gm 或 Gm_crit_max**：无法做负阻判据，只能按实测安全因子判断。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

        ┌──────── MCU 内部 ────────┐
        │       反相器 gm           │
  OSC_IN ──┤▷o───────────────┬── OSC_OUT
        │                    │
        │        RF（多数内置）│
        └────────────────────┘
             │                 │
            CL1               CL2
             │                 │
            GND               GND
        （RExt 可串在 OSC_OUT 与 CL2 之间，限驱动）

  晶体模型：C0 并联支路 + (Lm–Cm–Rm 串联支路)，ESR = Rm
  负阻：−R = 振荡器可提供的能量补充能力；判据 Sf = |−R|/ESR
```

- **CL1/CL2 不是“越大越稳”**：它们与晶体 CL 共同决定频率，过大还会降低负阻余量、延长启动。
- **RExt 不是必需**：只有驱动电平超晶体额定或需要抑制泛音时才加。
- **RF（反馈电阻）**多数 ST MCU 已内置，不要再外加（AN2867 §3 Table 3 的数值仅用于理解）。

## 4. 参数确定步骤

顺序理由：**先由 CL 定电容，再算负阻余量，最后才决定要不要 RExt**；因为 RExt 会反过来降低余量，必须放在最后迭代。

1. **判据：** 负载电容。
   **公式：** `CL = CL1·CL2/(CL1+CL2) + Cs`，Cs 为芯片引脚与 PCB 寄生电容之和。
   **取 CL1 = CL2 = C 时：** `C = 2·(CL − Cs)`。
   **算例（AN2867 §3）：** CL = 15 pF、Cs = 5 pF → CL1 = CL2 = 20 pF。

2. **判据：** 负阻临界跨导。
   **公式：** `gmcrit = 4·ESR·(2πF)²·(C0+CL)²`；`gain margin = gm/gmcrit`，要求 **> 5**（HSE）。
   **替代：** 若手册给 `Gm_crit_max`，要求 `gmcrit < Gm_crit_max`，且 `Gm_crit_max = gm/5`。
   **注意：** 加 RExt 后必须用 `ESR+RExt` 重算。

3. **判据：** 安全因子（实测）。
   **公式：** `Sf = 振荡器负阻 / 晶体 ESR = (RADD + ESR)/ESR`。
   **判据：** HSE **Sf ≥ 5**；LSE **Sf ≥ 3**；3 ≤ Sf < 5 对 HSE 不安全。
   **方法：** 串可调电阻 RADD，逐步增大到刚好停振，此时的 RADD 即负阻。

4. **判据：** 驱动电平。
   **公式：** `DL = ESR·IQ²`（IQ 为流过晶体的 RMS 电流）；`IQmax(RMS) = √(DLmax/ESR)`，`IQmax(PP) = 2√2·√(DLmax/ESR)`。
   **示波器法：** `DL = ESR·(πF·Ctot)²·Vpp²/2`，`Ctot = CL1 + Cs/2 + Cprobe`；测 LSE 用 **0.1 pF** 输入电容探头。

5. **判据：** 是否需要 RExt。
   **初值：** `RExt = 1/(2πF·CL2)`；AN2867 算例 8 MHz、CL2 = 15 pF → 约 **1326 Ω**。
   **规则（AN2867 §3）：** 若晶体实际功耗低于厂商标称 DL，**不建议加 RExt（取 0 Ω）**；加了必须重算 gmcrit。

6. **判据：** 启动时间与固件等待。
   **依据：** 几 MHz 晶体典型几 ms；**32.768 kHz 约 1–5 s**。
   **选择：** 固件等待时间 ≥ 5 s，或改用外部 RTC/有源时钟。

7. **判据：** 频率误差。
   **公式：** `Pullability (ppm/pF) = Cm×10⁶ / (2·(C0+CL)²)`。
   **含义：** CL 越大可拉性越低；负载电容容差直接变成频率误差（AN2867 算例：0.175 pF × 45 ppm/pF ≈ 7.8 ppm）。

## 5. 完整算例

**给定条件（AN2867 §3 教学算例条件）：** F = 8 MHz，C0 = 7 pF，CL = 10 pF，ESR = 80 Ω，gm = 25 mA/V；PCB + 引脚寄生 Cs = 5 pF；晶体允许驱动电平 DLmax = 100 µW（示例，须查所选晶体）。目标 HSE，要求 gain margin > 5。

**计算：**

1. **负载电容：** `C = 2·(CL − Cs) = 2 × (10 − 5) = 10 pF` → CL1 = CL2 = **10 pF**。
   校验：`10×10/(10+10) + 5 = 5 + 5 = 10 pF`，与晶体 CL 一致。

2. **临界跨导：**
   `2πF = 2π × 8 MHz = 5.027×10⁷ rad/s`
   `(2πF)² = 2.527×10¹⁵`
   `(C0 + CL)² = (17 pF)² = 2.89×10⁻²² F²`
   `gmcrit = 4 × 80 Ω × 2.527×10¹⁵ × 2.89×10⁻²² = 2.34×10⁻⁴ A/V = 0.234 mA/V`

3. **负阻余量：** `gm/gmcrit = 25 / 0.234 = 107`，远大于 5，**通过**。

4. **驱动电平估算（假设 CL1 处 Vpp ≈ 1 V，须实测）：**
   `Ctot = CL1 + Cs/2 + Cprobe = 10 + 2.5 + 0 = 12.5 pF`
   `πF·Ctot = π × 8×10⁶ × 12.5×10⁻¹² = 3.14×10⁻⁴`
   `DL = ESR·(πF·Ctot)²·Vpp²/2 = 80 × (3.14×10⁻⁴)² × 1² / 2 = 3.9×10⁻⁶ W ≈ 3.9 µW`
   远低于 100 µW → **不需要 RExt**。

5. **若误加 RExt = 1/(2πF·CL2) = 1/(5.027×10⁷ × 10×10⁻¹²) = 1989 Ω：**
   `gmcrit' = 4 × (80 + 1989) × 2.527×10¹⁵ × 2.89×10⁻²² = 6.05 mA/V`
   `margin = 25 / 6.05 = 4.1 < 5` → **余量不合格**。
   说明“RExt 初值公式”是过驱动时的起点，不是默认要装的值。

6. **若坚持要限驱动，迭代 RExt = 470 Ω：**
   `gmcrit' = 0.234 × (80+470)/80 = 1.61 mA/V`，`margin = 25/1.61 = 15.5 > 5` → 合格。
   实际驱动电平降幅取决于振荡器工作点，**必须用 Vpp 实测按第 4 步公式复算**，不能用串联分压百分比代替。

7. **LSE 校验：** 32.768 kHz 晶体取 CL = 7 pF、Cs = 2 pF → `C = 2 × (7 − 2) = 10 pF`，在 CL1/CL2 的 **15 pF** 上限内（AN4488 §6）。
   若用 CL = 12.5 pF：`C = 2 × (12.5 − 2) = 21 pF` > 15 pF → **不可用**，这正是 AN4488 明确“绝不要用 CL = 12.5 pF”的原因。

**候选选择：**

- **晶体：** 优先 ESR 低、CL 与 Cs 匹配的型号。若候选 ESR 从 80 Ω 升到 150 Ω，gmcrit 变为 `0.234 × 150/80 = 0.44 mA/V`，margin 降到 57——仍合格，但余量下降说明 ESR 是首要筛选参数。
- **负载电容：** C0G/NP0、1% 或更高精度、低温度系数；X7R 的容值随电压/温度变化会直接把 CL 拉偏。
- **RExt：** 算例中淘汰 2 kΩ（margin 4.1）、选 0 Ω；若实测 DL 超限，再选 470 Ω 或更小并复算。

**结论与限制：**

满足：CL 配置、负阻余量、驱动电平、LSE CL 上限均有量化依据。
仍待确认：gm = 25 mA/V 是 AN2867 教学值，**必须换成该 MCU 数据手册的 min 值**（用 min 才算保守）；C0/ESR/DL 必须用所选晶体的 max 值；Cs 的实际值取决于封装与叠层；1 Vpp 是假设，须实测。

> 算例中的 8 MHz/80 Ω/25 mA/V 只用于演示顺序，不代表任何具体晶体或 MCU。

**这个算例不能证明：** 实际起振（需负阻实测）、全温度范围余量、老化后的频差、湿度/污染下的漏电影响。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 晶体 | F、CL、ESR(max)、C0、DL(max)、精度 | 无 ESR/C0；CL 与可用电容不匹配 | 3225/2016 等按空间 | ESR 越低余量越大 |
| 负载电容 | 容值、精度、C0G/NP0、电压系数 | X7R/Y5V 用于 CL | 0402 | 精度直接变频率误差 |
| RExt | 阻值、精度、寄生 | 未复算 margin 就加 | 0402 | 0 Ω 是常见正解 |
| 反馈电阻 RF | — | 芯片已内置还外加 | — | 多数 ST MCU 内置 |
| RTC 晶体 | CL、ESR、DL | ESR 超 MCU 允许；CL > 7 pF（F4 LSE） | 3215/2012 | 启动 1–5 s |
| 三防漆 | 绝缘电阻 | 高湿环境未涂覆 | 工艺 | 漏电会延长启动甚至不起振 |

**工作条件 vs 绝对最大：** 晶体的 DLmax 是“不得超过”的额定，不是推荐工作点；ESR 用 max 值设计，不能用典型值。gm 用 MCU 数据手册的 min 值。

## 8. 原理图表达

- 晶体、CL1、CL2、RExt 画成**一个局部块**，紧邻 MCU 时钟脚；不要用网络标签拉到远处。
- **标明“晶体”还是“外部时钟”**：符号与注释写清，二者不能共用一个输入网络。
- **CL 值标注计算依据**：如 `CL1=CL2=10 pF（CL=10 pF, Cs=5 pF）`，方便后人复核。
- **RExt 标 DNP 或 0 Ω** 并注明“仅当实测 DL 超限时装配”。
- LSE 若同时作 GPIO，画跳线或 0 Ω 选项并注明“不可同时使用”。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 不起振 | 停在 HSI，USB/CAN 失效 | 提高 margin（低 ESR、合适 CL）；查焊接 | 上电测 OSC_OUT，负阻法 |
| 样机起振、量产不起振 | margin 在 3–5 之间 | 按 min gm/max ESR 重算，目标 margin 远大于 5 | 多批晶体 + 高低温 |
| 过驱动 | 频率漂移、老化加速、晶体振裂 | 加 RExt 并复算 margin | 测 Vpp 算 DL |
| 频率偏 | CL 与标称不符、电容容差 | C0G、按 Cs 修正 | 频率计 |
| LSE 启动慢 | 固件等不到 | 等 ≥5 s 或改有源 RTC | 冷启动计时 |
| 高湿漏电 | 启动时间变长或不起振 | 三防漆、guard ring | 湿热试验 |
| 探头导致停振 | 测量即失效 | 用高阻/低电容探头，短时探测 | 对比探测前后 |

## 11. 验证办法

- **工具检查：** 网表确认 OSC_IN/OUT 只连晶体网络；BOM 确认 CL 值与晶体 CL 匹配；检查是否有误装的 RF/RExt。
- **计算复核：** 用 gm(min)、ESR(max)、C0(max)、Cs(max) 重算 margin；用 CL 容差 ± 计算频差；用 DLmax 复算允许 Vpp。
- **仿真：** 未执行。若做：用晶体等效模型 + MCU 反相器模型做起振仿真，观察起振时间与稳态幅度；通过标准为 margin >5 且幅度稳定。
- **测量：** 负阻法串 RADD 测停振点；驱动电平用 0.1 pF 探头（LSE）或高阻探头测 Vpp 后按公式算；频率用频率计；启动时间用示波器单次触发。探测本身会改变振荡条件，测完移除。
- **通过标准：** HSE Sf ≥5、LSE Sf ≥3；DL ≤ 晶体额定；启动时间在固件等待内；频率误差在系统预算内。
- **不能证明：** 全批次/全温度余量、老化后频差、EMC、机械应力下的长期可靠性。

# LDO 线性稳压

> **一句话用途：** 判断某一路电源到底能不能用 LDO：先看压差和结温是否过得去，再看输出电容是否落在器件允许的稳定窗口内，最后处理输入塌陷时的反向电流与 EN/PG 状态。它把“5 V 降到 3.3 V 随便找颗 LDO”变成一组可复算的判据。
>
> **证据等级：** `E1`。`PD≈(Vin−Vout)·Iout`、`TJ=TA+PD·θJA`、θJA 随铜面积/层数/气流变化、LDO 的效率定义与压差定义已按 TI SLVA118A §3–§8 核对；压差按额定电流定义并可换算 RDS(ON)、输出电容有**上下限**、有效容量按标称 50% 估算的经验、反向电流不超过额定 5% 已按 TPS7A02 数据手册 SBVS277C §6.3、§7.3.2、§7.3.5、§8.1 核对。**环路稳定性（相位裕度、ESR 稳定区）、PSRR、噪声没有通用来源**，本卡只给“电容是否在器件允许窗口内”的器件级判据，正文明确标注。反向电流的四种解法只读到标题级索引（PWR-S05），不作为选型依据。
>
> **不能替代：** 所选 LDO 的完整数据手册（尤其 θJA、TJ(max)、ESR 稳定区、反向电流耐受）、实际 PCB 热测试、负载瞬态与纹波测量、EMC/安规签核。

## 1. 用途与适用范围

解决五类决策：

1. **该不该用 LDO**：输入输出压差、电流、环境温度决定它是不是一个“受控电阻”，效率上限就是 `Vout/Vin`。
2. **压差够不够**：不是看典型压差，而是看**最大额定电流下的最大压差**，再按实际电流换算。
3. **热能不能过**：`PD` 与 `θJA` 的乘积决定结温；封装名称不能推断可耗散瓦数。
4. **输出电容能不能用**：很多 LDO 要求有效容量落在**上下限之间**，且对 ESR 有窗口；“越大越好”不成立。
5. **掉电/输入塌陷时会不会倒灌**：输出储能经调整管或体二极管反送到输入，可能损坏器件或放掉 holdup 电容。

适用：低压差（TI 口径 VDO<1 V）、小到中等电流、噪声/成本敏感、开关电源后级净化、电池供电的常开小负载轨。

### 不能使用的条件

- **压差不足**：`Vin(min) − Vout(max) < VDO(max) @ Iout(max)` 时，LDO 进入 dropout，输出跟随输入，纹波与 PSRR 全部失效。此时必须改拓扑（Buck，见 [PWR-02](p02-buck.md)）或降低输出。
- **功耗超过封装/板的热能力**：没有该器件在实际板上的 θJA，就不能声称“能过”；用 JEDEC 板 θJA 只能做初估。
- **效率是硬指标**：LDO 的效率近似 `Vout/Vin`，5 V→1.8 V 即使理想也只有 36%；电池长期待机负载应优先开关变换器。
- **输入可能低于输出且器件无反向阻断**：输出电容会向输入倒灌；只靠“active discharge”不能解决大电容倒灌。
- **需要任意大输出电容或任意 ESR**：稳定窗口由具体器件决定，超出窗口可能振荡。
- **需要环路稳定性签核**：本卡没有相位裕度/ESR 零点分析来源，不能替代具体 LDO 的稳定性章节或仿真。
- **PSRR/噪声是硬指标**：本组来源未核对 PSRR 曲线与噪声密度，须查具体器件手册并实测。
- **输入瞬态可能超过绝对最大额定值**：推荐工作范围不是绝对最大值；热插拔/电感反冲要另加钳位。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 输入电压范围 | `Vin(min/max)` V | 上游电源树、适配器/电池规格 | **阻断**：压差与功耗都依赖它 |
| 输出电压与容差 | `Vout`、±% | 负载要求 | **阻断** |
| 负载电流（连续/峰值/持续时间/占空） | `Iout` A、ms、% | 负载预算、实测或器件手册 | **阻断**：峰值决定限流与瞬态，不能只用平均值 |
| 环境温度与气流 | `TA` °C、m/s | 产品规格、壳体内部实测 | 未知时按最坏（密闭、最高温）设计 |
| 封装/板级热阻 | `θJA` °C/W | 具体器件数据手册的热信息 + 实际板条件 | 可用手册范围下限/上限做区间估算，标注待实测 |
| 额定电流下的最大压差 | `VDO(max)` V @ `IRATED` | 数据手册电气特性表 | **阻断**：不能用 typical |
| 输出电容稳定范围与 ESR 要求 | µF、Ω | 数据手册推荐工作条件/稳定性章节 | **阻断**：不能凭经验选 10 µF |
| 静态电流 | `IQ` A | 数据手册 | 轻载效率估算用；不影响重载热 |
| 反向电流耐受 | mA 或 A | 数据手册绝对最大/应用章节 | 未知时按“必须外部阻断”处理 |
| EN/PG 门限与类型 | V、开漏/推挽 | 数据手册 | 未知时按最坏门限并加上拉/分压 |
| 负载瞬态要求 | A/µs、允许跌落 mV | 负载手册/系统预算 | 未知时按输出电容公式反推所需容量 |

**阻断项：** `Vin`、`Vout`、`Iout`（含峰值）、`VDO(max)`、输出电容稳定范围、`θJA` 的可用区间。缺这些时只能做拓扑级判断，不能给出“能过”的结论。`IQ`、PSRR、噪声可在非硬指标时后置。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

  Vin ──┬───────────────┬── [ pass device ] ──┬────────────── Vout
        │               │      (PMOS/NMOS)    │
       CIN              │         │           COUT
        │               │      error amp       │
       GND              └───────┤−              GND
                                │+
                           VREF ─┘
                                ▲
                          FB ───┴── R1/R2 分压（从 Vout 取）
```

- **调整管**工作在线性区，等效为一个由误差放大器控制的电阻。输入输出压差全部落在它上面，所以 `PD≈(Vin−Vout)·Iout`。
- **CIN** 主要抑制输入源阻抗与线路电感造成的瞬态跌落，不是所有 LDO 的稳定必需件；TPS7A02 的资料给出的判据是“源阻抗 >0.5 Ω 时建议加”。
- **COUT** 对多数 LDO 是环路的一部分：容量、ESR、直流偏压后的有效值都会影响稳定性；部分器件允许的容量有上限。
- **反向路径**：PMOS 调整管在输入塌陷时可能经体二极管/寄生路径从输出向输入导通；是否允许、允许多大，由具体器件规定。
- **参考与反馈**：输出精度由 VREF 精度、FB 比较器失调与分压电阻容差共同决定；分压电流必须远大于 FB 偏置电流（具体倍数查器件手册；本组来源没有 LDO 的通用倍数）。

## 4. 参数确定步骤

顺序理由：**先用功耗/压差淘汰拓扑，再算热，最后选电容**。反过来先挑一颗“看起来合适”的 LDO，常见结果是热算不过或电容不在稳定窗口，全部重来。

1. **判据：拓扑可行性（先算最坏功耗）。**
   **公式：** `PD(max) ≈ (Vin(max) − Vout(min)) · Iout(max) + Vin(max) · IQ`
   **依据：** SLVA118A §3 给出线性稳压器输入电流≈输出电流，`PD = PI − PO ≈ (VI − VO)·IO`；加静态电流时 `PI = PO + PD + PQ`。文中 TPS78925 例（3.3→2.5 V、100 mA）PD≈80 mW，而 PQ≈56 µW，故热计算通常忽略 IQ。
   **假设：** 连续直流负载；峰值按占空比折算或单独做瞬态热评估。
   **选择：** 若 `PD(max)` 已经超过封装在目标环境下的可耗散量级，直接改 Buck，不要继续选型。

2. **判据：压差余量。**
   **公式：** `Vin(min) − Vout(max) ≥ VDO(max) @ Iout(max) + 裕量`
   **依据：** SLVA118A §8.2 定义 VDO 为维持规定调节所需的最小 `VI−VO`；VI 低于 `VO+VDO` 后输出跟随输入。TPS7A02 SBVS277C §7.3.5 明确 VDO 是在**额定输出电流 IRATED**、调整管完全导通时测得，并给出 CMOS 调整管的换算 `RDS(ON) = VDO / IRATED`，低于额定电流时压差近似按比例下降。
   **假设：** 调整管近似电阻；低压差时误差放大器的增益下降未计入。
   **注意：** 用**最大** VDO，不用 typical；若数据手册只给某几个输出/电流点的 VDO，其余点按 RDS(ON) 估算并标注待核。

3. **判据：结温。**
   **公式：** `TJ = TA + PD · θJA`；反解所需热阻 `θJA(max) = (TJ(max) − TA) / PD(max)`
   **依据：** SLVA118A §4 Eq.6–7；§5 指出 θJA 随铜面积、层数、气流、High-K/Low-K 测试板变化，Figure 4 的 SOT-223 曲线约在 30–180 °C/W 范围。该文档为 2003/2008 年，封装热数据不能直接用于现代小封装。
   **假设：** 稳态；不计瞬态热容。
   **选择：** 用 `θJA(max)` 作为**上限**去筛器件/封装；数据手册 θJA 低于它才算通过。实际板铜面积不足时，手册值偏乐观。

4. **判据：效率与轻载。**
   **公式：** `Eff = VO/VI × 100%`（忽略 IQ）；`Eff = VO·IO / [VI·(IO + IQ)] × 100%`
   **依据：** SLVA118A §8.1（Eq.13–16）。该简化只适用于线性稳压器。
   **用途：** 判断“用 LDO 是否本身就是错误”。例：3.3/5=66%；若 IQ=1 mA、负载 1 mA，则效率只有 33%；负载 100 µA 时约 6%。

5. **判据：输出电容落在稳定窗口。**
   **方法：** 先按数据手册的推荐范围取**有效容量**，再把标称值按直流偏压/温度降额折算。
   **依据：** TPS7A02 SBVS277C §6.3 脚注 + §8.1.2：COUT 标称 1–22 µF，**有效输出电容最小 0.5 µF 才能稳定**，**降额后最大 22 µF**；§8.1.1 给出“按标称值 50% 估算”的经验，并推荐 X7R/X5R/C0G，不建议 Y5V。
   **假设：** 50% 只是经验起点，不是保证值；必须用所选电容在目标直流偏压/温度下的实际降额曲线复核。
   **选择：** 先算有效容量，再回算标称值；同时核对 ESR 是否在器件允许范围（本组来源未给通用 ESR 窗口，须查具体手册）。

6. **判据：反向电流。**
   **依据：** TPS7A02 SBVS277C §7.3.2：不要依靠 active discharge 放掉大量输出电容，输入塌陷时可能从输出向输入倒灌并损坏器件；**反向电流应限制在器件额定电流的 5% 以内，且只允许短时间**。
   **计算：** 给定输出电容 `C` 与输入塌陷时间 `Δt`，平均反向电流约 `Irev ≈ C·ΔV/Δt`；反过来允许的电压斜率 `dV/dt ≤ Irev(max)/C`。
   **选择：** 超过限额时，加串联肖特基/理想二极管，或改用带反向阻断的 LDO/负载开关。PWR-S05 只列出四类方法名称（肖特基、LDO 前串二极管、第二个 FET、MOSFET bulk 接 GND），**没有读到条件与数值**，不能据此判断哪种更优。

7. **判据：EN/PG 与上电顺序。**
   **依据：** SC14。EN 门限、绝对最大、内部上拉/下拉、PG 开漏上拉域都要查；PG 未上拉不会凭网名成为有效高电平。
   **选择：** EN 分压从受控电源取，不要从可能先上电的轨取；PG 上拉到本域或受控域，避免反灌（SC11 的先后上电问题）。

## 5. 完整算例

**给定条件：**

- 输入：5 V ±5%，即 **4.75–5.25 V**；上游为 USB 适配器，线缆+磁珠的源阻抗未知。
- 输出：**3.3 V ±2%**（允许 3.234–3.366 V）。
- 负载：连续 **150 mA**；另有 **180 mA / 1 ms** 的短脉冲（每秒一次）。
- 环境：密闭塑料壳内 **TA = 50 °C**，无强制气流。
- 设计目标：稳态 `TJ ≤ 110 °C`（本算例自定的裕量目标，不是器件保证值）。
- 候选：**TPS7A02**（SBVS277C）：VIN 推荐 1.5–6.0 V；200 mA；VOUT 固定 0.8–5.0 V；IQ typ 25 nA；VOUT=3.3 V、200 mA 时 **VDO max 270 mV**；θJA **179.1–201.1 °C/W**（视封装/板条件）；COUT 有效 **0.5–22 µF**；过热关断 170 °C、恢复 145 °C。

**计算：**

1. **压差（按实际电流换算）：**
   - `RDS(ON) = VDO / IRATED = 0.270 V / 0.200 A = 1.35 Ω`
   - 150 mA：`VDO ≈ 1.35 Ω × 0.150 A = 0.2025 V`
   - 180 mA：`VDO ≈ 1.35 Ω × 0.180 A = 0.243 V`
   - 可用压差：`4.75 − 3.30 = 1.45 V`
   - **余量 1.45 − 0.243 = 1.207 V**，压差判据通过（余量很大，说明这颗器件不是被压差限制）。

2. **功耗（最坏输入）：**
   - `PD = (5.25 − 3.30) × 0.150 = 1.95 × 0.150 = 0.2925 W`
   - IQ 项：`5.25 × 25 nA = 0.13 µW`，可忽略（与 SLVA118A §3 的例子一致）。
   - 180 mA 脉冲期间：`PD = 1.95 × 0.180 = 0.351 W`。

3. **结温（稳态，用 θJA 两端）：**
   - 最坏：`TJ = 50 + 0.2925 × 201.1 = 50 + 58.8 = 108.8 °C`
   - 较好：`TJ = 50 + 0.2925 × 179.1 = 50 + 52.4 = 102.4 °C`
   - 对 110 °C 目标：最坏情况只剩 **1.2 °C** 余量，**不能算通过**；需要更大铜面积/更好封装，或降低输入电压/电流。
   - 180 mA 脉冲若按稳态算：`50 + 0.351 × 201.1 = 120.6 °C`，超过目标。1 ms 脉冲的实际温升由瞬态热阻抗决定，远小于稳态值；但本组来源没有瞬态热阻抗数据，**不能据此声称脉冲安全**。

4. **效率：**
   - 重载：`3.3/5 = 66.0%`（忽略 IQ）。
   - 轻载演示：若 IQ=1 mA（示例，不是 TPS7A02 的值），1 mA 负载时 `3.3×1m / [5×(1m+1m)] = 33%`；100 µA 负载时约 6%。这说明“低 IQ”对小电流常开轨是硬指标。

5. **输出电容：**
   - 目标：标称 10 µF、X5R、10 V、0805。
   - 按 50% 经验降额：有效 `≈ 5 µF`，落在 **0.5–22 µF** 窗口内。
   - 若改用 22 µF 标称、降额后 11 µF，仍在窗口内；若用 47 µF 标称、降额后 23.5 µF，**超过 22 µF 上限**，不满足该器件的稳定条件。
   - **注意：** 50% 只是经验；必须用该电容在 3.3 V 直流偏压与 50 °C 下的实际容量曲线复核，并核对 ESR。

6. **反向电流（输入塌陷）：**
   - 输出电容 10 µF、充到 3.3 V；允许反向电流按 5% 额定：`0.05 × 200 mA = 10 mA`。
   - 允许斜率：`dV/dt ≤ 10 mA / 10 µF = 1000 V/s = 1 V/ms`。
   - 3.3 V 全塌陷至少需要 **3.3 ms**；若上游热插拔/短路使输入在 1 ms 内塌陷，平均反向电流 `10 µF × 3.3 V / 1 ms = 33 mA`，**超过 10 mA 限额**。
   - 储能：`E = ½CV² = 0.5 × 10 µF × 3.3² = 54.5 µJ`；能量不大，但电流集中在调整管上。
   - **对策：** 限制输入塌陷斜率，或在输入端加反向阻断（肖特基/理想二极管），或减小输出电容并重做瞬态核算。

**候选选择：**

- TPS7A02 在压差、电容窗口上通过；热在 50 °C 密闭、最坏 θJA 下只剩 1.2 °C 余量，**按本算例的 110 °C 目标判为临界不通过**。这不是说器件不好，而是说“200 mA 级小封装 + 1.95 V 压差 + 50 °C 环境”这个组合本身很紧。
- 若实际峰值是 250 mA / 10 ms，则 200 mA 额定直接淘汰（峰值超过额定，折返限流可能动作），必须换 ≥300 mA 的器件并重算其 VDO/θJA/稳定窗口；本卡不替该假想器件编数值。
- 淘汰“只看 typical 压差”的候选：没有 max VDO 就无法证明 4.75 V 输入下仍能调节。
- 淘汰“输出电容越大越好”的做法：超过器件允许的有效容量上限同样破坏稳定性。

**结论与限制：**

满足：压差余量、输出电容窗口、反向电流的斜率条件（在 3.3 ms 以上塌陷时）。
不满足/待确认：50 °C 密闭 + 201.1 °C/W 下稳态结温 108.8 °C，对 110 °C 目标余量不足；**TPS7A02 的 TJ(max) 本笔记未读到**，不能用 170 °C 过热关断点当设计上限；实际板 θJA 未测；所选电容的实际降额与 ESR 未核；1 ms 脉冲的瞬态热未建模；PSRR/噪声未核。

> 算例中的 5 V/3.3 V/150 mA/50 °C、10 µF、50% 降额与 110 °C 目标只适用于本算例条件；TPS7A02 的 270 mV、0.5–22 µF、179.1–201.1 °C/W 只属于该型号该版本手册。

**这个算例不能证明：** 环路相位裕度、负载瞬态跌落、PSRR/噪声、实际壳内温升、反向电流下的器件生存、长期可靠性。

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| LDO（低 IQ、小电流） | IQ、VDO(max) @ IRATED、θJA、COUT 稳定窗口、反向电流 | 无 max VDO；COUT 只给标称值；无 θJA | 小封装 θJA 可达 200 °C/W 量级 | 适合常开小负载；不适合大压差大电流 |
| LDO（较大电流） | 同上 + 限流方式（折返/恒流）、热关断点 | 峰值超过额定且无脉冲余量 | 需散热焊盘/铜面积 | 峰值电流决定选型，不只看平均值 |
| 外部 pass FET + 控制器 | FET SOA、Vgs、RDS(ON)、环路补偿 | 无 SOA/热数据 | 占板大，但散热可控 | 超出本卡范围，仅作大电流备选 |
| 开关 Buck | 效率曲线、L/C、EMI | 噪声敏感且无后级滤波 | 需电感/电容/布局 | 5 V→1.8 V 等大压差应优先评估，见 [PWR-02](p02-buck.md) |
| 负载开关 | RDS(ON)、限流、反向阻断、EN 门限 | 无反向阻断却用于双电源 | 小封装 | 只做通断/保护，不调压 |
| 反向阻断器件 | 正向压降、反向漏电、耐压 | 用普通肖特基做大电流 | 散热 | 见 [PWR-09](p09-reverse-polarity.md) |

**推荐工作条件 vs 绝对最大额定值：** 压差、输出电流、COUT 范围、θJA 都取自推荐工作条件/热信息；绝对最大额定值只用于“不得超出”。TPS7A02 的推荐输入上限是 6.0 V，5 V±5%=5.25 V 在范围内，但**绝对最大输入本笔记未读到**，热插拔尖峰必须另查并加钳位。

**不能用 typical 代替保证值的地方：** VDO、θJA、IQ、限流点、热关断点、COUT 稳定范围。typical 只能用于估算并标注。

## 8. 原理图表达

- **模块边界清楚**：LDO、CIN、COUT、EN 分压、PG 上拉、反馈分压画在同一功能块内；不要把 COUT 用网络标签丢到另一页，否则“电容在哪、回路多长”在图上无法判断。
- **局部短线保留**：CIN/COUT 与 IN/OUT/GND 脚之间用真实导线画，不靠网名；EN、PG、FB 可以用网络标签，但分压电阻必须画在 FB 脚旁。
- **注释写判据，不写口号**：在器件旁标注 `Vin 4.75–5.25, Vout 3.3±2%, Iout 150 mA, PD 0.29 W, TJ est 109 °C @50 °C, COUT 10 µF X5R (eff ~5 µF)`；这比“注意散热”可执行。
- **标注稳定窗口**：`COUT effective 0.5–22 µF`（仅当器件手册确实这样规定）；提醒后人不要随手加大电容。
- **标注反向电流条件**：`Irev ≤ 10 mA; input must not collapse faster than 1 V/ms` 或注明外部阻断器件。
- **装配选项**：DNP 的备用电容/阻断二极管要标明“本变体不装，不等于无连接”（SC08）；互斥的 EN 分压选项写清可装组合。
- **PG 上拉域**：上拉电阻画到哪个轨要显式，不能只写 `PG` 网名。

## 9. PCB 要求

| 项目 | 要求 | 依据/条件 |
|---|---|---|
| 散热路径 | EPAD/散热焊盘接足够铜面积与过孔；按实际铜面积重估 θJA | PL16；SLVA118A §5 明确 θJA 随铜面积/层数/气流变化 |
| 输入/输出电容落点 | 电容端子到 IN/OUT 与 GND 的回路尽量短，不要从长支路“接同网” | PL10 的通用电流回路方法；SC12 |
| 输出/输入走线 | 按持续电流与允许压降选宽度，检查焊盘颈缩与过孔瓶颈 | RT01、RT02 |
| 反馈取样 | 从输出电容后的规定点取，分压靠近 FB，参考干净 | PL12 |
| 热源隔离 | 远离 DCDC 电感、功率 MOS、发热连接器；温度传感器不要测到隔壁稳压器 | PL16 |
| 地回流 | 输入电容地、输出电容地、反馈地在同一参考上汇合，避免负载电流穿过 FB 参考 | RT06 |
| 测试点 | VIN、VOUT、EN、PG、GND 可探；测试点不引入大支路 | SC18、MF15 |
| 反向阻断器件 | 若加二极管/理想二极管，按入口边界布置，先保护后走线 | PL15 |

以上是几何/布局判据；是否真正满足热与稳定，必须靠实测与器件手册，不能由“铺了大铜”推断。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 启动 | COUT 充电产生浪涌；EN 未到门限时输出不确定 | 核对限流/软启动；EN 分压从受控轨取 | 不同输入斜率上电，测 IIN 与 VOUT |
| 掉电 | 输入塌陷，输出电容向输入倒灌 | 限制 dV/dt 或加反向阻断；反向电流 ≤5% 额定 | 继电器/MOSFET 切断输入，测反向电流 |
| 输入瞬态 | 超过绝对最大或触发上游 OVP | 加 TVS/钳位；核对推荐上限与绝对最大 | 热插拔/浪涌注入 |
| 输出短路 | 折返限流，功耗可能集中在调整管 | 核对短路电流与热关断；必要时外部限流 | 短时短路试验，测电流与温度 |
| 过热 | 热关断（TPS7A02 为 170 °C，恢复 145 °C） | 降额设计，不靠关断点当工作点 | 热箱/热像仪，记录关断与恢复 |
| EN 悬空 | 状态不确定，可能随机开/关 | 加明确下拉/上拉 | 断网测试 |
| 输入低于输出（dropout） | 输出跟随输入，PG 可能误判 | 监控输入或选带 UVLO 的器件 | 可调电源扫输入 |
| 输出预偏置 | 启动瞬间反向电流 | 查器件是否支持 pre-bias；否则加阻断 | 预充输出后上电，测反向电流 |

不适用状态要写理由：本卡不涉及隔离/高压，故不列隔离失效；若输入来自市电，必须另按 DM45/DM46 处理。

## 11. 验证办法

- **工具检查：** ERC 查 EN/PG 是否有明确驱动与上拉；网表确认 COUT 接在 OUT 与 GND 之间、EPAD 接地；BOM 确认封装与热焊盘；回读实际网络而不是只看图。
- **计算复核（角落条件）：** 用 `Vin(max)+Iout(max)+TA(max)+θJA(max)` 复算 TJ；用 `Vin(min)+Iout(max)+VDO(max)` 复算压差；用最小/最大有效容量复算稳定窗口；用最快输入塌陷复算反向电流。
- **仿真：** 未执行。若做：用厂商 SPICE 模型 + 实际负载阶跃（如 10–90%、1 A/µs），观察跌落/恢复与是否振荡；通过标准为 `Vout` 回到 ±2% 内、无持续振荡、峰值电流未触发限流。模型不含热与 PCB 寄生，不能替代实测。
- **测量（纹波）：** 示波器 20 MHz 带宽限制、弹簧地环、探头尖端直接跨 COUT 端子；不能用地线夹长引线（会引入开关噪声）。记录 VIN/VOUT、负载、温度。
- **测量（瞬态）：** 电子负载做 10–90% 阶跃，重复频率低于热时间常数；看跌落、恢复时间、过冲。
- **测量（热）：** 热电偶贴 EPAD 附近铜或热像仪，稳定 30 min；记录 TA、PD、壳温；停止条件为 TJ 估算超过目标或触发关断。
- **测量（反向电流）：** 输入串小电阻/电流探头，用低侧 MOSFET 快速切断输入；示波器单次触发；停止条件为反向电流超过 5% 额定。
- **通过标准：** 全输入/负载范围内 `Vout` 在容差内；压差余量 >0；TJ 低于目标并有裕量；反向电流低于器件限额；无持续振荡。
- **不能证明：** 相位裕度、PSRR、噪声、EMC、长期寿命、极端温度下的稳定性。

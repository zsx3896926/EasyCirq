# Boost 升压变换器

> **一句话用途：** 用最小输入电压算 Boost 的占空比与输入电流，再算电感、峰值应力、输出电容与二极管/开关电压，并用 `ILIM(min)` 反推“高占空比下到底还能输出多少电流”。它特别用来识别“输入 3.3 V 升 12 V”这类占空比接近 0.8、看起来简单但实际上被限流、最小关断时间和输出电容纹波电流卡住的方案。
>
> **证据等级：** `E1`。占空比按 `VIN(min)` 计算、输入电流 `IOUT/(1−D)`、`ISW(max)`、`ILIM(min)` 反推输出、二极管平均电流、输出电容含 D 的公式、ESR 纹波与反馈 100× 规则，已按 TI SLVA372D §1–§7 核对；**谷值限流式 `IOUT=(1−D)(ILIM+ΔIL/2)` 与 TPS61023 SLVSF14B Equation 1 核对；峰值限流式 `(1−D)(ILIM−ΔIL/2)` 与 SLVA372D Eq.3 的峰值定义核对**。热初估按 SLVA118A §3–§5 核对。**本卡不覆盖 DCM、峰值电流模式斜坡补偿、右半平面零点与环路带宽、多相/耦合电感**；SLVA372D 明确不涉及补偿。
>
> **不能替代：** 具体 Boost 控制器手册（限流 min/max、最小关断时间、最大占空比、内部补偿推荐 L/C、θJA）、效率曲线、环路仿真、EMI 与热实测。

## 1. 用途与适用范围

解决六类决策：

1. **占空比与输入电流**：用 `VIN(min)` 算 D，因为它给出最大开关电流；`IIN = IOUT/(1−D)` 决定电感与输入路径的电流等级。
2. **电感**：纹波按 `(0.2–0.4)·IOUT·VOUT/VIN` 估，L 由 `VIN·D/(ΔIL·fS)` 得到；饱和电流必须高于峰值。
3. **芯片能不能带这个负载**：高占空比下输出能力会显著缩水。先分清限流类型：**谷值限流**用 `IMAXOUT = (1−D)·(ILIM(min)+ΔIL/2)`；**峰值限流**用 `IMAXOUT = (1−D)·(ILIM(min)−ΔIL/2)`。TI SLVSF14B 的 TPS61023 是谷值限流（Equation 1 为 `(1-D)×(ILIM+ΔIL(P-P)/2)`），不能套峰值式。
4. **二极管/开关电压与电流**：二极管承受 `VOUT` 反向电压、平均电流等于 `IOUT`、峰值等于开关峰值。
5. **输出电容**：纹波公式含 D，且电容要承受 `IOUT·√(D/(1−D))` 量级的 RMS 纹波电流。
6. **不能断开输出**：Boost 的输入到输出存在“电感 + 整流路径”的直流通路（非同步为二极管，同步为高侧 FET 体二极管），关断时输出约等于 `VIN−VF`（同步方案约 `VIN` 减体二极管压降），需要负载开关才能真断电。

适用：集成开关、**CCM** 的升压功率级；同步整流时除二极管功耗公式外其余公式仍适用（SLVA372D §1）。

### 不能使用的条件

- **DCM/轻载 PFM**：公式基于 CCM；轻载进入 DCM 后输入电流与纹波关系改变。
- **占空比接近器件上限**：`D=0.78` 时最小关断时间只剩几百 ns；器件可能无法维持，导致输出电压跌落或跳周期。
- **需要环路补偿/右半平面零点分析**：SLVA372D 不覆盖；Boost 的 RHP 零点限制可用带宽，本卡不给公式与数值。
- **需要输出真正断开**：非同步 Boost 关断时输出仍经电感/二极管连到输入；必须外加负载开关/理想二极管。
- **输入可能高于输出**：此时 Boost 不能调压，需 Buck-Boost（[PWR-04](p04-buck-boost.md)）。
- **多相/耦合电感/隔离**：不在来源范围。
- **用典型效率代替曲线**：η 只是估算，轻载/高压比下误差大。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 输入电压范围 | `VIN(min/max)` V | 上游电源树/电池 | **阻断**：D 与输入电流依赖 |
| 输出电压与容差 | `VOUT`、±% | 负载要求 | **阻断** |
| 输出电流 | `IOUT(max)` A | 负载预算 | **阻断** |
| 开关频率最小值 | `fS(min)` Hz | 控制器手册 | **阻断** |
| 开关限流最小值 | `ILIM(min)` A | 控制器电气表 | **阻断**：高占空比下决定输出能力 |
| 最大占空比/最小关断时间 | %、ns | 控制器手册 | 未知时算出 D 与 tOFF 并标注待核 |
| 目标纹波比例 | `ΔIL` A | 设计选择 | 用 0.3×`IOUT·VOUT/VIN` 先算 |
| 效率估计 | `η` | 曲线/实测 | 先用 0.85 估算，标注未核 |
| 反馈电压/FB 偏置 | `VFB` V、`IFB` A | 控制器手册 | **阻断** |
| 输出纹波要求 | `ΔVOUT` mV | 负载手册 | 用 1% VOUT 先算 |
| 环境温度/θJA | `TA` °C、°C/W | 产品规格/热信息 | 按最坏环境与手册上限 |
| 二极管 VF/VR（非同步） | V | 二极管手册 | **阻断**（若非同步） |

**阻断项：** `VIN`、`VOUT`、`IOUT`、`fS(min)`、`ILIM(min)`、`VFB`、最大占空比/最小关断时间。缺限流值时不能回答“能不能带 0.4 A”。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

  VIN ──[ L ]──┬──[ D ]──┬──── VOUT
               │         │
             SW node    COUT
               │         │
            LS FET       GND
               │
              PGND

  导通（LS FET on）：VIN → L → LS FET → PGND，电感储能；D 截止，COUT 单独供负载
  关断（LS FET off）：L → D → COUT/负载，电感释能；SW 节点跳到 VOUT+VF
```

- **控制量**：`D = 1 − VIN(min)·η/VOUT`。D 随 Vin 下降而上升，所以**最大开关电流出现在 Vin(min)**（SLVA372D §1）。
- **输入电流连续**：电感在输入侧，输入电流是连续的（这是 Boost 与 Buck 的关键差别）；输出侧电流是脉冲的，输出电容承受大 RMS 纹波。
- **开关电压应力**：SW 节点关断时约为 `VOUT + VF`（加振铃），开关与二极管的电压额定必须按此取。
- **不能断开**：即使 LS FET 全关，`VIN → L → D → VOUT` 仍导通，输出约为 `VIN − VF`。
- **反馈**：从输出电容之后取，FB 是高阻节点，远离 SW 与二极管。

## 4. 参数确定步骤

顺序理由：**先用 VIN(min) 定 D 与输入电流，再定 L，再用峰值校核限流与器件电压，最后选输出电容与反馈**。高占空比方案经常在“限流反推输出”这一步被淘汰，越早算越好。

1. **判据：占空比（最大开关电流点）。**
   **公式：** `D = 1 − VIN(min)·η / VOUT`
   **依据：** SLVA372D Eq.1；文中 η 举例 80%。用 VIN(min) 是因为它给出最大开关电流。
   **检查：** `D` 是否超过器件最大占空比；最小关断时间 `tOFF = (1−D)/fS` 是否大于器件最小值。

2. **判据：输入电流。**
   **公式：** `IIN(avg) = IOUT(max) / (1 − D)`
   **依据：** SLVA372D Eq.4 的电流关系；输入平均电流即电感平均电流。
   **用途：** 电感 Irms、输入电容、输入走线、连接器额定都按它取。

3. **判据：电感纹波与电感量。**
   **公式：** `ΔIL = VIN(min)·D / (fS·L)`；纹波估算 `ΔIL = (0.2…0.4)·IOUT·VOUT/VIN`
   **依据：** SLVA372D Eq.2、Eq.6。
   **假设：** CCM、理想电感；实际电感量随直流偏置下降。
   **选择：** 先算 L，选标准值后回算 ΔIL；额定电流（饱和）必须高于 `ISW(max)`。

4. **判据：峰值与 RMS。**
   **公式：** `ISW(max) = IOUT(max)/(1−D) + ΔIL/2`；`IL,rms ≈ √(IIN² + ΔIL²/12)`
   **依据：** SLVA372D Eq.4；RMS 为梯形波近似（本卡推导）。
   **用途：** 开关/二极管峰值、电感饱和、输出电容 ESR 纹波都取这个峰值。

5. **判据：芯片实际可输出电流。**
   **公式（先看限流类型）：** 谷值限流 `IMAXOUT = (1−D)·(ILIM(min)+ΔIL/2)`；峰值限流 `IMAXOUT = (1−D)·(ILIM(min)−ΔIL/2)`。
   **依据：** 谷值式与 TI SLVSF14B（TPS61023）Equation 1 一致；峰值式与 SLVA372D Eq.3 的峰值限流定义一致。两者不能混用。
   **选择：** 若 `IMAXOUT < IOUT(max)`，高占空比下这颗芯片带不动；换更高限流或改变拓扑/输入。谷值限流加半纹波、峰值限流减半纹波，必须按手册限流定义选式。

6. **判据：二极管（非同步）。**
   **公式：** `IF(avg) = IOUT(max)`；`PD = IF·VF`
   **依据：** SLVA372D Eq.7–8；文档把 IF 定义为导通期平均正向电流，功耗按 `IF·VF`。
   **电压：** 反向电压 ≥ `VOUT` 加振铃裕量；峰值电流 = `ISW(max)`。
   **同步整流：** 高侧 FET 导通损耗约 `IOUT²·D·RDS(ON)`（近似），二极管公式不再适用。

7. **判据：输出电容。**
   **公式：** `COUT(min) = IOUT(max)·D / (fS·ΔVOUT)`；`ΔVOUT(ESR) = ESR·[IOUT/(1−D) + ΔIL/2]`
   **依据：** SLVA372D Eq.12–13。
   **RMS 纹波电流（本卡推导）：** `ICOUT,rms ≈ IOUT·√(D/(1−D))`；必须小于电容的允许纹波电流（含温度/频率修正）。
   **选择：** 容量与 RMS 电流同时满足；低 ESR 陶瓷/X5R 或更好。

8. **判据：输入电容。**
   **依据：** SLVA372D §6：低 ESR 陶瓷、X5R 或更好；内补偿时按数据手册推荐 L×C。
   **计算（本卡推导）：** 输入电流连续，CIN 主要承受 `ΔIL/√12` 的纹波；`ΔVIN ≈ ΔIL/(8·fS·CIN) + ESR·ΔIL`。
   **选择：** 按数据手册最小值与源阻抗加；输入源远时加 bulk。

9. **判据：反馈分压。**
   **公式：** `Idiv ≥ 100·IFB`；`R2 = VFB/Idiv`；`R1 = R2·(VOUT/VFB − 1)`
   **依据：** SLVA372D Eq.9–11，与 Buck 文档同一条 100× 规则。

## 5. 完整算例

**给定条件：**

- 输入：**3.3 V ±5%**，即 **3.135–3.465 V**。
- 输出：**12 V ±3%**（11.64–12.36 V），负载 **0.4 A**（4.8 W）。
- 开关频率：**fS = 600 kHz**；η 估计 **0.85**。
- 目标输出纹波 **≤100 mV**；`TA = 50 °C`，允许 60 °C 温升（自定目标）。
- 假设（须按具体控制器核对）：`VFB = 0.8 V`、`IFB = 1 µA`、`ILIM(min) = 3.0 A`、最大占空比 ≥0.85、最小关断时间 ≤300 ns。

**计算：**

1. **占空比与关断时间：**
   - `D = 1 − 3.135 × 0.85 / 12 = 1 − 2.66475/12 = 1 − 0.22206 = 0.7779`
   - 最大输入：`D = 1 − 3.465 × 0.85/12 = 1 − 0.24544 = 0.7546`
   - `tOFF(min Vin) = (1 − 0.7779)/600 kHz = 0.2221/600k = 370 ns`
   - `tOFF(max Vin) = 0.2454/600k = 409 ns`
   - **待核：** 器件最小关断时间必须小于 370 ns，否则在 3.135 V 输入时无法维持 12 V。

2. **输入电流：**
   - `IIN = 0.4 / (1 − 0.7779) = 0.4 / 0.22206 = 1.801 A`
   - 输入功率（理想）：`3.135 × 1.801 = 5.65 W`；输出 4.8 W，差值为损耗（与 η=0.85 一致：4.8/0.85=5.65 W）。

3. **电感：**
   - 目标纹波：`ΔIL = 0.3 × 0.4 × 12/3.135 = 0.3 × 1.531 = 0.459 A`
   - `L = VIN·D/(ΔIL·fS) = 3.135 × 0.7779 / (0.459 × 600 kHz) = 2.439 / 275,400 = 8.85 µH`
   - 选 **10 µH**；回算 `ΔIL = 2.439/(10 µH × 600 kHz) = 2.439/6 = 0.4065 A`。

4. **峰值与 RMS：**
   - `ISW(max) = 1.801 + 0.4065/2 = 1.801 + 0.203 = 2.005 A`
   - `IL,rms = √(1.801² + 0.4065²/12) = √(3.244 + 0.0138) = 1.805 A`
   - 电感饱和电流 **>2.01 A**，并按高温/偏置降额留裕量；Irms 额定 >1.81 A。

5. **限流校核：**
   - 本卡假设的是**谷值限流**：`IMAXOUT = (1−D)·(ILIM(min)+ΔIL/2) = 0.22206 × (3.0+0.203) = 0.711 A`，大于 0.4 A，通过（余量 78%）。
   - 若 `ILIM(min) = 2.5 A`：`0.22206 × (2.5+0.203) = 0.600 A > 0.4 A`，**仍可通过**，不是“淘汰”。
   - 若 `ILIM(min) = 1.6 A`：`0.22206 × (1.6+0.203) = 0.400 A`，刚好边界；低于此值才带不动。
   - 这说明高占空比下“3 A 限流”不是 3 A 输出，但也不是旧式 `ILIM·(1−D) − ΔIL/2` 算出的 0.46 A；必须按谷值/峰值定义选式。若该器件实际是**峰值限流**，则用 `0.22206 × (3.0−0.203)=0.621 A`；仍 >0.4 A，2.5 A 时 `0.510 A` 也通过。两种定义下 2.5 A 都不应被淘汰。

6. **二极管（非同步）：**
   - `IF = 0.4 A`；峰值 `2.005 A`；反向电压 ≥12 V + 振铃裕量。
   - 取 `VF = 0.4 V`（示例，须查实际器件在 0.4 A/高温下）：`PD = 0.16 W`；结温按二极管 θJA 另算。
   - 同步整流对照：高侧 FET `RDS(ON)=50 mΩ`（示例）：`P ≈ 0.4² × 0.778 × 0.05 = 6.2 mW`，但栅极驱动与开关损耗另计。

7. **输出电容：**
   - `COUT = 0.4 × 0.7779 / (600 kHz × 0.1) = 0.3112/60,000 = 5.19 µF`
   - ESR 项（ESR=5 mΩ）：`ΔV = 5 mΩ × 2.005 A = 10.0 mV`
   - RMS 纹波电流：`0.4 × √(0.7779/0.22206) = 0.4 × 1.872 = 0.749 A`
   - 选 2×22 µF 标称、按 50% 降额约 22 µF 有效；每颗 RMS 约 0.37 A，须查电容在该频率/温度下的允许值。
   - 若只用 10 µF 标称（有效 5 µF），容量刚好卡在 5.19 µF 附近，且 RMS 电流余量小，**不建议**。

8. **输入电容：**
   - `ΔIL/√12 = 0.4065/3.464 = 0.117 A`；选 10 µF X5R/X7R，靠近电感与 LS FET。
   - 输入纹波 `≈ 0.4065/(8 × 600 kHz × 10 µF) = 8.5 mV`，加 ESR 项。

9. **反馈分压：**
   - `Idiv ≥ 100 µA`；`R2 = 0.8/100µ = 8 kΩ` → 8.06 kΩ；`R1 = 8.06k × (12/0.8 − 1) = 8.06k × 14 = 112.84 kΩ` → 113 kΩ。
   - 回算 `VOUT = 0.8 × (1 + 113/8.06) = 12.016 V`，误差 +0.13%。

10. **损耗/热一致性：**
    - `POUT = 4.8 W`；按 η=0.85，`PIN = 5.647 W`，总损耗 **0.847 W**。
    - 若允许 60 °C 温升，所需 `θJA ≤ 60/0.847 = 70.8 °C/W`。
    - 电感 DCR 损耗示例（DCR=50 mΩ）：`1.801² × 0.05 = 0.162 W`；二极管 0.16 W；其余为开关/驱动/磁芯损耗。

**候选选择：**

- 选 **谷值限流 ≥2.5 A（峰值限流按各自公式复算）、最大占空比 ≥0.85、最小关断时间 ≤300 ns、600 kHz 以上**的 Boost；3 A 以上是更保守的余量选择。10 µH/2 A 级以上电感；2×22 µF 输出电容。
- **不能按旧式 `ILIM·(1−D) − ΔIL/2` 淘汰 2.5 A 器件**：谷值限流下 `IMAXOUT=0.22206×(2.5+0.203)=0.600 A >0.4 A`，仍可通过；是否选 3 A 以上取决于高温降额、效率/热和瞬态余量，不是“2.5 A 一定带不动”。
- 淘汰“只看输出电压、不看 tOFF”的方案：370 ns 的关断时间会卡住很多器件。
- 淘汰 10 µF 输出电容：容量与 RMS 电流都太临界。
- 若输入其实是 5 V 而非 3.3 V，D 降到 `1−5×0.85/12=0.646`，上述应力全部变松；这说明**输入范围必须写清**，不能用“3.3 V 左右”含糊。

**结论与限制：**

满足：占空比、输入电流、电感量、峰值/RMS、限流（3.0 A 假设下）、输出电容容量与 RMS、反馈分压。
待确认：器件真实 `ILIM(min)`、最大占空比、最小关断时间、`VFB/IFB`、内部补偿推荐 L/C、效率曲线；电感饱和与 DCR；电容的实际降额与纹波电流额定；二极管 VF/热；SW 振铃与 EMI。

> 算例中的 3.3→12 V/0.4 A/600 kHz/10 µH/2×22 µF 只适用于本算例；`VFB=0.8 V`、`IFB=1 µA`、`ILIM=3.0 A` 是假设值。

**这个算例不能证明：** 右半平面零点下的环路稳定性、轻载 DCM 行为、最小关断时间极限、启动浪涌、输出短路行为、EMI、实际温升。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 集成 Boost | `VIN` 范围、`ILIM(min)`、最大 D、最小 tOFF、fS、内部补偿 L/C、θJA | 最大 D < 计算 D；tOFF 不够；只有 typical 限流 | QFN/EPAD 散热 | 首选 |
| 控制器 + 外部 FET | 栅驱、死区、补偿、电流采样、SOA | 无补偿/无 SOA | 占板大 | 大功率 |
| 功率电感 | L、Isat、Irms、DCR、偏置曲线 | Isat ≤ 峰值；DCR 过大 | 屏蔽式，漏磁远离 FB | 输入侧连续电流 |
| 二极管（非同步） | VF、VR、Ifsm、热 | VR ≤ VOUT；VF 过高 | 散热 | 肖特基/超快恢复按频率选 |
| 输出电容 | 有效容量、ESR、RMS 纹波电流、耐压 | RMS 额定不足 | 多颗并联 | 脉冲电流大 |
| 输入电容 | 有效容量、ESR、RMS | 只用 Y5V | 靠近电感 | 连续电流，纹波较小 |
| 负载开关（若需断电） | RDS(ON)、反向阻断、EN | 无反向阻断 | 小封装 | Boost 不能自身断开输出 |

**推荐工作条件 vs 绝对最大：** SW 节点电压在关断时可达 `VOUT+VF` 加振铃，绝对最大必须覆盖；`ILIM(min)`、`Dmax`、`tOFF(min)` 取自推荐/电气表。**不能用 typical 限流或 typical 效率做设计。**

## 8. 原理图表达

- **功率级局部画全**：VIN、L、SW、D、COUT、PGND 用真实导线画；SW 与二极管阳极是同一节点，不要用网名拆散。
- **标注“输出不能断开”**：在 VOUT 旁写 `VOUT≈VIN−VF when disabled; add load switch for true off`。
- **反馈取样点**：在 COUT 之后画 sense 点，分压靠近 FB；注明“sense after COUT”。
- **注释工作点**：`VIN 3.135–3.465 V, VOUT 12 V/0.4 A, fS 600 kHz, L 10 µH, Dmax 0.778, ISW 2.0 A, ILIM(min) 3.0 A`。
- **标注二极管应力**：`VR ≥ 12 V + ringing, IF 0.4 A, peak 2.0 A`。
- **EN/PG 域**：显式画出；PG 上拉到本域。
- **装配选项**：不同 L/COUT 组合的 DNP 标注清（SC08）。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 启动 | 输出经 L/D 预充到 `VIN−VF`；负载提前得电 | 软启动/负载开关；核对下游 UVLO | 不同输入斜率上电，测 VOUT/IIN |
| 关断 | 输出不能到 0 V，仍有 `VIN−VF` | 加负载开关/理想二极管 | 关断后测 VOUT |
| 输出短路 | 二极管/开关承受大电流；可能触发限流 | 核对限流与二极管 Ifsm | 短时短路，测电流/温度 |
| 反馈断线 | 输出失控上升 | 器件 OVP 或外加 OVP | 断开 FB，测 VOUT 上限 |
| 空载/轻载 | 输出过冲、进入 PFM/DCM | 核对最小负载/轻载模式 | 空载到满载扫描 |
| 占空比饱和 | 输入低时输出跌落 | 核对 Dmax/tOFF；必要时降额 | 可调电源扫输入 |
| 电感饱和 | 电流尖峰、限流误触发 | Isat > 峰值并留高温裕量 | 满载高温看 IL 波形 |
| 输入瞬态 | SW 过压/振铃 | TVS/RC 缓冲；核对绝对最大 | 热插拔/浪涌 |
| 过热 | 热关断/降额 | 按损耗与 θJA 设计 | 热箱/热像仪 |

## 11. 验证办法

- **工具检查：** 网表确认 L 在 VIN 与 SW 之间、D 从 SW 到 VOUT、COUT 跨 VOUT/PGND、FB 分压只连 FB；ERC 查 EN/PG；BOM 核对电感 Isat/Irms、二极管 VR、电容 RMS 额定。
- **计算复核：** `VIN(min)+IOUT(max)+fS(min)` 复算 D、IIN、峰值；`ILIM(min)` 复算 `IMAXOUT`；`Dmax/tOFF` 对器件极限；`TA(max)+θJA` 复算结温；最小/最大电容复算纹波与 RMS。
- **仿真：** 未执行。若做：用控制器模型 + 实际 L/D/COUT，激励为输入阶跃与负载阶跃，观察 IL 峰值、VOUT 跌落、占空比是否饱和、是否触发限流；通过标准为峰值 <`ILIM(min)`、VOUT 在容差内、无次谐波振荡。模型不含 PCB 寄生与热。
- **测量（效率）：** 四线法测 VIN/IIN/VOUT/IOUT，覆盖 10%/50%/100% 负载与 VIN(min/max)。
- **测量（SW/IL）：** 20 MHz 带宽限制、弹簧地环、探头尖端直接跨引脚；电流用电流探头或分流器，注意共模。看 SW 振铃峰值（是否超过 VR）、IL 斜坡与峰值。
- **测量（纹波）：** 直接跨 COUT 端子，带宽限制；记录负载与温度。
- **测量（热）：** 热电偶/热像仪稳定 30 min；记录二极管、电感、开关温度；停止条件为超目标。
- **通过标准：** 全范围 VOUT 在容差内；峰值 <`ILIM(min)`；SW 峰值低于器件绝对最大；纹波满足预算；温度低于目标；关断后 VOUT 行为符合设计。
- **不能证明：** RHP 零点下的相位裕度、EMI、极端占空比下的稳定性、长期可靠性。

# 天线接口与匹配

> **一句话用途：** 在模组/芯片 RF 端口到天线之间，确定 50 Ω 馈线、匹配网络拓扑与初值、天线净空、外壳距离和测试口，并明确哪些值只是调谐起点、哪些必须用 VNA/整机测试确认。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> **不能替代：** 具体器件手册、项目约束、EDA 回读、仿真、测量或安全签核。

## 1. 用途与适用范围

本卡处理“RF 端口—匹配—馈线—天线—外壳”这一段接口。典型输入是模组/芯片 RF 端口阻抗与参考匹配、天线形式与阻抗、工作频段、叠层、外壳/电池/螺钉位置、测试设备；典型输出是馈线阻抗与走向、匹配元件拓扑与初值、净空区、测试口和验证计划。

它不设计天线本身，也不替代天线厂的调谐报告或整机认证。模组组合层面的检查见 [模块设计卡](../../module-cards.md) 第 5 节。

### 不能使用的条件

- 模组已含天线或已含匹配网络时，不能再串一套“参考匹配”；先确认模组 RF 端口是 50 Ω 输出还是直接接天线（DM33）。
- 没有天线阻抗/厂商数据、没有叠层参数时，本卡只能给初值和净空规则，不能声称已匹配。
- 需要多频段/多天线共存、MIMO、金属外壳或人体附近使用时，单端口 50 Ω 方法不足，必须做整机 RF 测试。
- 认证/法规要求（CE/FCC/SRRC 等）不能由原理图或 DRC 证明。
- 天线净空是“天线到最近导体”的规则，不是“PCB 边缘留白”的规则；电池、螺钉、排线、屏蔽罩都算导体（PL27、DM34）。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 模组/芯片 RF 端口阻抗与参考匹配 | Ω | datasheet/硬件设计指南 | 阻断：不能确定匹配拓扑 |
| 天线形式、频段、阻抗、增益 | Ω、MHz、dBi | 天线 datasheet/厂商图纸 | 阻断：不能定净空与初值 |
| 叠层（介质厚度、εr、铜厚、阻焊） | mm、— | 板厂叠层/阻抗报告 | 先用假设算线宽，标“待板厂确认” |
| 外壳、电池、螺钉、排线位置 | mm | 结构 3D | 净空只能标“草案”，不得签核 |
| 馈线长度与走向 | mm | 布局草案 | 先按最短路径预留，后续复核 |
| 测试口/调试方式 | — | 产品定义 | 无测试口时只能整机 OTA，失效难定位 |
| 天线厂调谐报告/参考值 | pF、nH | 天线厂 | 只能把参考值当起点，不能当已验证 |

阻断项是 RF 端口阻抗、天线形式和频段；叠层与结构可以先用假设，但必须把假设写进评审记录。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）
模组/芯片 RF ── CLC 匹配 ── 50 Ω 馈线 ──┬── 天线
                                        └── 测试口（可选，调试/认证用）
参考地：RF 走线下方连续地平面；匹配件地过孔就近
```

RF 端口、匹配网络、馈线、天线共同决定 S11。匹配网络把天线阻抗变换到端口需要的阻抗；馈线是传输线，长度、参考面和过孔都会改变相位与损耗。天线净空决定辐射效率，外壳和电池会改变天线的输入阻抗，因此“在裸板上调好的匹配”装壳后仍可能失配。测试口用于 VNA/认证，但支路本身是 stub，必须按高频支路处理，不能随手加（RT25、RT26）。

## 4. 参数确定步骤

1. **先判定集成边界。** 模组带天线：只做净空和结构；模组带 IPEX：做 50 Ω 馈线+天线；裸芯片：做匹配+馈线+天线。顺序不能反，否则会重复匹配或漏掉匹配（DM33）。
2. **定叠层与 50 Ω 目标。** 用板厂实际叠层算/确认线宽，RF 走外层、参考相邻地、不打孔、短且不分叉；软件默认 50 Ω 不代表已实现（RT25、RT11）。
3. **选匹配拓扑。** 按芯片/模组指南选 CLC、LC 或仅串联/并联位；匹配件靠近 RF 端口，优先 0201，地过孔就近。参考值只是起点（RF-S01“RF Circuit”“RF Tuning”）。
4. **算初值与灵敏度。** 用工作频率算各候选件的电抗，判断 0.1 pF/0.1 nH 的变化是否显著；显著时选更小容差/更小封装，或预留可调位。
5. **定净空。** 按天线厂/模组指南逐层检查铜、过孔、器件、电池、螺钉、外壳；PCB 天线下方挖空、不居中；外壳间隙按天线厂要求，不能只按 PCB 顶视图（PL27）。
6. **定测试口。** 需要 VNA/认证时留测试连接器或耦合方式；测试支路按 50 Ω、短 stub 处理，不需要时不要留长分支（RT25）。
7. **调谐与整机复测。** 裸板调 S11，装壳/装电池后再调，最后做 OTA/吞吐；匹配值以实测为准。

先做 1–2 再做 3–4，是因为拓扑和叠层决定匹配件是否必要；净空和结构放后面，但必须在天线定稿前完成，否则匹配值会被结构推翻。

**器件实例（条件限定）：**

- `ESP32-S3` 检查表：RF 走线 50 Ω；芯片侧匹配网络靠近芯片，优先 CLC；天线阻抗约 50 Ω 并加 ESD；调谐目标写作 S11 约“35+j0”、S21 低于 −35 dB @4.8 GHz 与 7.2 GHz；建议匹配范围 C11 1.2–1.8 pF、L2 2.0–3.0 nH、C12 1.8–1.2 pF，封装 0201；RF 关闭时 RF 脚可悬空，开启时必须接天线（RF-S01，“RF Circuit”“RF Tuning”）。注意：来源笔记对“35+j0”的单位/定义记录不完整，使用前应回读原页确认，不能直接把“35+j0”当成数值验收门限。
- `ESP32-S3` 布局：RF 走外层、不打孔、短且不分叉；拐角 135° 或圆弧；相邻地完整，尽量不在 RF 线下走线；0201 CLC；stub 长 15 mil、目标 100 Ω ±10%，0402 及以上不需要 stub；IPEX 区域所有层净空；PCB 天线需实测并在附近留调谐位（RF-S02，“RF”）。
- 模组天线：天线伸出底板之外、馈点靠近板边；做不到时在天线旁/下方挖空底板、不要居中放置，并在天线附近提供地铜与密集过孔；外壳间隙各方向“至少 15 mm”；最终必须做 RF 测试（RF-S02，“General Principles of PCB Layout for Modules”）。
- GNSS 芯片天线旁证：u-blox 给出芯片天线隔离/keep-out 典型 5 mm，且地平面尺寸与安装方式共同决定性能（RF-S04，UBX-15030289 R03，§2.3/§3.3.1）。这是 GNSS 芯片天线的条件，不能直接套到 2.4 GHz PCB 天线。

## 5. 完整算例

**给定条件：** 2.45 GHz Wi-Fi/BLE；RF 端口与天线目标 50 Ω；参考匹配拓扑为 CLC（并联 C11—串联 L2—并联 C12）；`ESP32-S3` 检查表给出的参考范围 C11 1.2–1.8 pF、L2 2.0–3.0 nH、C12 1.8–1.2 pF，0201；叠层假设 εeff=3.3（仅用于估算电长度，实际以板厂叠层为准）；天线阻抗未知。

**计算：**

1. 角频率：`ω = 2πf = 2π × 2.45×10⁹ = 15.39×10⁹ rad/s`。
2. 并联电容电抗：`X_C = 1/(ωC)`。C=1.2 pF：`X_C = 1/(15.39×10⁹ × 1.2×10⁻¹²) = 54.1 Ω`；C=1.5 pF：`43.3 Ω`；C=1.8 pF：`36.1 Ω`。
3. 串联电感电抗：`X_L = ωL`。L=2.0 nH：`30.8 Ω`；L=2.5 nH：`38.5 Ω`；L=3.0 nH：`46.2 Ω`。
4. 灵敏度：在 1.5 pF 处，`ΔX_C/X_C ≈ ΔC/C`，0.1 pF 对应 `43.3 × 0.1/1.5 = 2.9 Ω`；在 2.5 nH 处，0.1 nH 对应 `38.5 × 0.1/2.5 = 1.5 Ω`。因此 0201 的容差/焊接寄生会明显移动匹配点，不能把参考值当“已调好”。
5. 电长度：`λ0 = c/f = 3×10⁸ / 2.45×10⁹ = 0.1224 m = 122.4 mm`；`λg = λ0/√εeff = 122.4/√3.3 = 67.4 mm`。10 mm 馈线约为 `0.148λg = 53°`，已不是“可以忽略的短线”，所以 RF 走线要短、参考连续、不要随意加测试支路。

**候选选择：** 以 C11=1.5 pF、L2=2.5 nH、C12=1.5 pF 作为 0201 初值，原因是它们落在 `ESP32-S3` 检查表给出的参考范围中部，便于向两侧调；没有选 0402，是因为 0.1 pF/0.1 nH 的寄生与容差在 2.45 GHz 下已产生数欧姆级电抗变化。初值只用于打样，最终值由 VNA 实测决定。

**结论与限制：** 参考范围、0201、50 Ω、短馈线和净空规则可以落到 PCB；但本算例没有天线阻抗数据，不能计算 S11，也不能证明匹配。`εeff=3.3` 是假设，实际线宽/电长度必须用板厂叠层和阻抗报告；装壳、电池、手部靠近都会改变天线阻抗，必须整机复测。

> 算例中的具体型号、阻容、脚号、层数、线宽只适用于本算例条件，不能推广到其他芯片或板。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| PCB 天线 | 频段、带宽、增益、净空、地平面尺寸 | 净空被电池/螺钉/外壳占用 | 天线下方挖空、不居中 | 需天线厂数据与整机测试 |
| 陶瓷/芯片天线 | 尺寸、带宽、keep-out、安装方式 | 地平面不足仍宣称性能 | 按天线厂推荐的禁布区 | 不能照抄 PCB 模组净空 |
| IPEX/U.FL 连接器 | 阻抗、频率、插拔次数、中心/屏蔽 | 用普通排针替代 | 全层净空、装配高度 | 线缆损耗需计入 |
| 匹配电容 | 容值、容差、Q、ESR、电压 | 大封装/大容差导致失配 | 0201 优先；靠近 RF 脚 | 参考值只是起点 |
| 匹配电感 | 感值、容差、Q、DCR、自谐振 | 自谐振接近工作频率 | 0201 优先；地过孔就近 | 高 Q 不等于已匹配 |
| 馈线/叠层 | 50 Ω、介质厚度、εr、铜厚 | 用默认叠层不确认阻抗 | 外层、短、不打孔 | 以板厂阻抗报告为准 |
| 屏蔽罩/外壳 | 材料、开孔、与天线距离 | 金属外壳贴天线 | 按天线厂净空 | 金属会改变谐振 |
| 测试口 | 阻抗、插损、可重复性 | 长 stub、无参考地 | 认证/调试需要时留 | 不需要时不要留长支路 |

“50 Ω”是馈线目标，不是天线阻抗保证；匹配件的 Q、容差、自谐振必须按具体器件手册核对，不能用理想元件公式代替。典型值只能用于初选，设计判据用 min/max 或厂商保证值。

## 8. 原理图表达

RF 段画成一个有边界的块：`RF 端口 → CLC → 馈线/连接器 → 天线`，匹配件按实际拓扑串联/并联，地过孔用符号或注释标出。不要用长网名把 RF 线拉到原理图另一页；RF 是局部短连接，跨页只保留端口定义。测试口画成可选支路，注明“调试/认证用，不装时留 0 Ω 或断开”，不能画成长期并联的长 stub。若模组已含天线/匹配，在符号旁注明“内部已集成”，避免重复（DM33）。

注释写清：工作频段、目标阻抗、匹配初值来源（哪个检查表/哪一版）、哪些位是“待调”、测试口装配状态。接口边界写清 RF 端口、地参考、天线/连接器、测试口。

## 9. PCB 要求

| 项目 | 要求 | 依据/条件 |
|---|---|---|
| 馈线阻抗 | 50 Ω，按实际叠层/板厂阻抗报告；外层优先 | RF-S01/RF-S02；RT25、RT11 |
| 走向 | 短、直、不打孔、不分叉；拐角 135° 或圆弧 | RF-S02“RF” |
| 参考层 | RF 下方连续地，不在 RF 线下走线；相邻地完整 | RF-S02；RT04 |
| 匹配件 | 靠近 RF 端口，0201 优先；地过孔就近 | RF-S01“RF Tuning”；RT25 |
| stub | 15 mil 长、目标 100 Ω ±10%；0402 及以上不需要 stub | RF-S02，ESP32-S3 条件 |
| IPEX/连接器 | 所有层净空；中心/屏蔽按器件 | RF-S02；PL27 |
| 天线净空 | 按天线/模组指南逐层查铜、过孔、器件、电池、螺钉、外壳 | PL27、DM34 |
| 模组天线 | 伸出底板；做不到时天线下方挖空、不居中；外壳 ≥15 mm | RF-S02，ESP32-S3 条件 |
| 测试点 | 不放在 RF 主线；测试支路按 50 Ω 短 stub | RT25 |

几何检查只能证明“按规则留了空”，不能证明辐射效率；未装壳、未装电池前的净空不算最终状态（RT26）。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 天线开路 | S11 恶化、输出功率反射、距离下降 | 连接器防脱、测试口可诊断 | VNA S11、OTA |
| 天线短路 | 可能损坏 PA 或触发保护 | 匹配件/连接器检查；按芯片耐受 | VNA、限流电源测试 |
| 装壳/装电池后失配 | 谐振偏移、效率下降 | 结构净空；装壳后复调 | 装壳前后 S11/OTA 对比 |
| 手/人体靠近 | 阻抗变化、功率下降 | 天线位置远离握持区 | 手持/人体模型测试 |
| 匹配件虚焊/错件 | 频偏、驻波差 | 0201 可焊性、AOI、首件 VNA | 首件 S11、X-ray/AOI |
| 测试支路过长 | 形成 stub，带内陷波 | 测试口可控断开/短 stub | VNA 看带内波动 |
| ESD 经天线注入 | 损坏 RF 前端 | 天线端口 ESD，按芯片要求 | ESD 测试 |

不适用状态写理由，例如没有外部天线连接器时不需要“连接器插拔”行。

## 11. 验证办法

- **工具检查：** PCB 检查 RF 线宽/参考/过孔/分支、匹配件位置、IPEX 全层净空、天线禁布区；原理图检查匹配拓扑与装配位。DRC 不能替代 VNA。
- **计算复核：** 用实际叠层复算 50 Ω 线宽与电长度；用实际天线阻抗复算匹配件电抗；至少覆盖频段低/中/高三个点。
- **仿真：** 未执行。若执行，需要天线阻抗模型、叠层/过孔模型和匹配件模型，观察 S11/S21；通过标准按产品/芯片要求。不得生成假波形。
- **测量：** VNA 单端口测 S11（校准到连接器/测试口），必要时双端口测 S21；OTA 在暗室/标准场地测吞吐/灵敏度；装壳、装电池、手持状态分别测。停止条件是 S11 在工作频段超标或 OTA 不达标。
- **通过标准：** 工作频段内 S11 满足芯片/模组要求（具体门限按原厂页复核，不能直接用本卡记录的“35+j0”）；谐波/带外满足 S21 要求；整机吞吐/灵敏度满足产品要求。
- **不能证明：** 天线效率、MIMO 性能、整机 EMC/法规、长期可靠性、批量一致性。

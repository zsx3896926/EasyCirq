# D2 时钟系统完整检查

> **用途：** 把“时钟能不能用”拆成五个可分别证明的问题：**起振（负阻/增益裕度）、频率（CL/晶体容差）、驱动电平（老化/振裂）、启动时间（固件等待）、抖动（协议/射频）**，并给出原理图、PCB、测量三层检查顺序。适用于 MCU 的 HSE/LSE、有源晶振、外部时钟/旁路模式，以及“模组内部已含晶体”的集成场景；不适用于纯内部 RC 且没有精度/协议要求的低风险场景。
>
> **证据分级：** `[原厂]` 为已核对原厂手册/应用笔记的数值与条件；`[设计文件]` 为可直接复查的开源设计文件/作者记录（位号/网络/页码/行号）；`[推断]` 为基于机理的工程推断；`[构造]` 为写明假设的构造案例/算例，不是实测；`[未执行]` 为没有做的仿真/测量；`[待核]` 为缺型号资料、待按型号核对的点。本稿没有做任何实物测量，也没有把公式结果当成实测。
>
> **与现有内容的关系：** 本文不重复 [MCU-05 晶体振荡器](../../design-cards/mcu/m05-crystal.md) 的逐项参数步骤，也不重复 [MCU-06 外部时钟](../../design-cards/mcu/m06-external-clock.md) 的有源晶振选型；本文补的是**跨方案判据、真实设计读图证据、测量扰动、模组时钟所有权**，以及“公式用错会把好设计判死”的边界。晶体失效排查的通用结构见 [F05](../../failures/f05-crystal-load-esr.md)；探头与接地假象见 [simulation-measurement.md §5](../../simulation-measurement.md)；模组“已集成外围”的去重表见 [module-integration.md §10](../../module-integration.md)。

## 0. 什么时候需要，什么时候不需要

**需要完整时钟检查的条件（满足任一）：**

- 板上有时钟脚接晶体/谐振器/有源晶振，且固件依赖它做 USB、CAN、以太网、射频、精确 UART、ADC 采样或 RTC。
- 产品要求频率误差在 ±ppm 级；或客户/协议给了 ppm 预算，但还没有把晶体容差、CL 误差、温度、老化分项列出。
- 出现“样机正常、量产部分不起振”“低温不起振”“探头一碰就停”“RTC 越走越偏”“射频距离不达标”这类与时钟相关或不相关的现象。
- 采用模组方案，模组数据手册的参考电路要求外部 32.768 kHz 晶体或外部时钟；或模组内部已含晶体，需要确认“板级不再加”的所有权。
- 采用有源晶振，需要核对输出电平、OE/ST 默认态、启动时间、负载与抖动。
- 生产测试需要定义“时钟通过”的判据，而不是只测“板子能跑”。

**不需要优先做完整检查的情况：**

- 只用 MCU 内部 RC，且没有 USB/CAN/射频/精确计时要求；此时仍要记录内部 RC 的精度来源与温漂，但不必做晶体负阻/CL 计算。
- 时钟由另一块已认证模组提供，且模组手册明确给出输出电平、频率精度、启动时间；此时检查接口电平和所有权即可，不要重复设计晶体。
- 只是教学点灯、无通信、无计时；可以先不展开，但不能把“能跑”写成“时钟已验证”。

**最小判据（工程规则，`[推断]`）：**

```text
ppm_total = ppm_crystal + ppm_CL + ppm_temp + ppm_age + ppm_solder + ppm_measure
margin_gain = gm(min) / gmcrit(max)         要求 > 5（HSE）
Sf = (RADD + ESR) / ESR                    要求 ≥ 5（HSE）、≥ 3（LSE）
DL = ESR · IQ²                             要求 ≤ 晶体 DLmax
t_start + t_firmware_wait < 产品启动预算
```

五项里任何一项没有数据，结论只能是“待核”，不能写“通过”。`ppm_total` 的符号和相关性要按最坏情况处理：CL 偏差、温度、老化通常不是独立随机项，不能一律 RSS。

## 1. 必须先知道的条件

| 输入 | 符号/单位 | 为什么需要 | 缺失时怎么办 |
|---|---|---|---|
| 目标频率与用途 | MHz/kHz | 决定晶体/振荡器型号、负载电容、MCU 时钟树 | **阻断** |
| 晶体 CL | pF | 决定 C1/C2；CL 偏差直接变频率误差 | **阻断** |
| 晶体 ESR（max） | Ω | 负阻判据的第一主导项 | **阻断** |
| 晶体 C0（max） | pF | 影响 gmcrit 与可拉性 | 缺失时按同封装保守值估，标注 `[待核]` |
| 晶体 Cm 或 trim sensitivity | fF 或 ppm/pF | 把 CL 偏差换算成 ppm | 缺失时只能给量级，标注 `[待核]` |
| 晶体 DLmax | µW | 驱动电平判据 | 缺失时不做驱动判据，只做负阻 |
| MCU gm（min）或 Gm_crit_max | mA/V | 负阻判据 | **阻断**：不能用典型值或别的 MCU 代替 |
| 引脚/PCB 寄生 Cs | pF | CL 公式的一部分 | 先按 3–5 pF 估算，标注 `[构造]`；最终用叠层/封装核对 |
| 供电电压与 IO 电平 | V | 有源晶振输出摆幅、MCU VIH/VIL | **阻断**（有源方案） |
| 有源晶振负载 | pF | 输出边沿/幅度 | 未知时按 15 pF 保守设计 |
| OE/ST 极性 | — | 默认态、关断电流、启动 | **阻断**（有源方案） |
| 启动时间预算 | ms/s | 固件等待、复位释放 | **阻断**：LSE 按 1–5 s 预留 |
| ppm 预算 | ppm | 判断晶体/CL/温度是否够 | **阻断**：按协议/产品给，不能凭感觉 |
| 温度范围与热源 | °C | 频率-温度曲线、起振余量 | 先按 25 °C 算，标注高低温未测 |
| 湿度/涂覆 | — | 漏电会延长启动甚至不起振 | 高湿环境按三防漆评估 |
| 测量探头电容 | pF | 探头会改变 CL 和起振条件 | **阻断**：没有探头参数就不能解释“测了才坏” |

**阻断项：** 晶体 CL/ESR、MCU gm（或 Gm_crit_max）、供电/电平（有源方案）、启动预算、ppm 预算、探头电容。缺这些只能做“带条件的排序”，不能给“时钟通过”。

**必须区分 max 与 typ：**

| 参数 | 设计用哪个 | 原因 |
|---|---|---|
| ESR | **max** | 负阻判据用最坏晶体；typ 不能保证批次 |
| C0 | **max** | gmcrit 随 C0+CL 平方增长 |
| CL | 晶体标称值 + 电容容差 + Cs 误差 | CL 偏差直接变 ppm |
| gm | **min** | 增益裕度用最弱 MCU |
| DLmax | 晶体额定 max | 超过会加速老化/振裂 |
| 频率容差 | 含 25 °C 初始、温度、电压、负载、老化 | 只取 25 °C 初始值会低估 |
| 启动时间 | 最坏温度/最坏晶体 | 典型值不是保证值 |

**ppm 预算的例子（只用于说明方法，不是通用门限）：** ESP32-C3 检查表要求 40 MHz 晶体精度在 **±10 ppm** 内（`[原厂 MCU-S04]`，页面标注 “latest”，核对日期 2026-10-20）。这 10 ppm 是**该芯片/该参考设计**的要求，不能直接套到 STM32、RP2040 或 USB/CAN。USB、CAN、以太网的 ppm 门限必须查对应协议/器件手册；本稿没有读到这些规范的原文，`[待核]`。

**启动预算的例子：** HSE 晶体典型几 ms；32.768 kHz LSE 约 **1–5 s**（`[原厂 MCU-S02]`）。如果固件 HSE 就绪超时设 2 ms、LSE 等待设 100 ms，就会把“正常但慢”的晶体判成失败。固件等待应 ≥ 最坏启动时间，并在超时后回退到内部时钟且记录标志。

## 2. 最容易被忽略的机制

### 2.1 晶体模型：CL 不是“两颗电容的串联值”这么简单

晶体等效为**动生支路**（Cm–Lm–Rm 串联，Rm = ESR）与**静态电容 C0** 并联。标称频率是晶体在指定负载电容 CL 下的负载谐振频率；CL 不是晶体的自有参数，而是“外部电路希望晶体看到的电容”。

```text
CL = CL1·CL2/(CL1 + CL2) + Cs
```

- `CL1`、`CL2` 是两颗负载电容；`Cs` 是 MCU 引脚电容 + PCB 走线/焊盘寄生 + 探头电容。
- 取 `CL1 = CL2 = C` 时：`C = 2·(CL − Cs)`。
- `CL` 变大 → 频率变低（可拉性方向），同时 `gmcrit ∝ (C0+CL)²` 变大、负阻余量下降、启动变慢。
- `C0` 不决定标称频率，但决定 gmcrit 和可拉性；`C0` 越大，同样的 CL 下 gmcrit 越大、可拉性越低。
- `Cs` 不是“大概 5 pF”就永远成立：封装、焊盘、走线长度、是否探头、是否涂覆都会改变它。CL 公式里的 Cs 必须按实际叠层/封装估算，并在样机上用频率反推校正。

**工程含义：** 照抄参考板的 15 pF/18 pF/20 pF 是常见错误；参考板的晶体 CL、Cs、MCU 引脚电容和你的板不同。必须用**本板晶体**的 CL 和**本板**的 Cs 重算。

### 2.2 负阻不是“增益”，是环路能否补偿晶体损耗

Pierce 振荡器的小信号判据：

```text
gmcrit = 4 · ESR · (2πF)² · (C0 + CL)²
gain margin = gm / gmcrit        要求 > 5（HSE）
```

- `gm` 用 MCU 数据手册的 **min**；`ESR`、`C0` 用晶体的 **max**；`CL` 用实际最坏值。
- 若手册给的是 `Gm_crit_max`，则要求 `gmcrit < Gm_crit_max`，且通常 `Gm_crit_max = gm/5`。
- 实测 `Sf` 在 3–5 之间时，常见“样机起振、量产不起振”；`Sf < 3` 时连样机都可能不稳（AN2867 对 HSE 要求 ≥5，对 LSE 要求 ≥3）。
- **安全因子**（实测）：`Sf = (RADD + ESR)/ESR`。在晶体回路串可调电阻 `RADD`，每次改变后**重新冷启动**，找到刚好不能起振的边界；此时的 `RADD` 就是负阻。HSE 要求 `Sf ≥ 5`，LSE 要求 `Sf ≥ 3`。不能用“运行中把电阻调大直到停振”代替启动测试。
- **RExt 会吃掉负阻余量**：`gmcrit' = 4·(ESR+RExt)·(2πF)²·(C0+CL)²`。RExt 的初值公式 `RExt = 1/(2πF·CL2)` 只是“过驱动时”的起点，不是默认要装的值；AN2867 明确说，若晶体实际功耗低于额定 DL，不建议加 RExt（取 0 Ω）（`[原厂 MCU-S02]`）。
- **反馈电阻 RF**：多数 ST MCU 已内置；不要因为看到参考图上有 1 MΩ 就外加。外加会改变偏置点，甚至让振荡器停在错误的工作点。

### 2.3 驱动电平：测的是晶体里的电流，不是“输出幅度好看”

厂商判据：

```text
DL = ESR · IQ²
IQmax(RMS) = sqrt(DLmax / ESR)
IQmax(PP)  = 2√2 · sqrt(DLmax / ESR)
```

示波器法（AN2867）：

```text
DL = ESR · (πF·Ctot)² · Vpp² / 2
Ctot = CL1 + Cs/2 + Cprobe
```

- `Vpp` 是 **CL1 处**测到的峰峰值；`Cprobe` 是探头电容。测 LSE 建议用 **0.1 pF** 输入电容的探头（`[原厂 MCU-S02]`）。
- `DLmax` 是“不得超过”的额定，不是推荐工作点；长期接近额定会加速老化，超过可能振裂。
- 过驱动的表现：频率偏低/偏高、老化加快、晶体发热、波形削顶、长时间后不起振。仅看“波形幅度大”不能判断过驱动，必须按上式换算。
- **公式陷阱：** 计划书给的 `P = 2πf·CL·Vpp²` 若 `Vpp` 取峰峰值、`CL` 取负载电容，得到的是 CL 上无功功率的 **8 倍**（`Q = 2πfCL·Vrms² = 2πfCL·Vpp²/8`），**不是**晶体 ESR 上的损耗。用它和 `DLmax` 比较会把设计误判为超限。第 6.1 节用同一组数算出两个值，说明差异。判定必须用厂商的 ESR 公式。

**RExt 的正确用法：**

1. 先按厂商公式算实际 DL；若 DL ≤ DLmax，优先 **0 Ω**。
2. 若 DL 超限，才加 RExt；初值 `1/(2πF·CL2)`，然后**把 RExt 计入 ESR 重算 gmcrit**。
3. 加 RExt 后必须重新测 Vpp、DL、启动时间和负阻；RExt 太大 → 不起振，太小 → 仍过驱动。
4. RP2040 参考设计在 12 MHz/CL 10 pF 的晶体上串了 **1 kΩ**（R5），这是该参考设计在 3.3 V IOVDD 下的取值，不是通用规则；换晶体/换 IOVDD 必须重新测试（`[原厂 MCU-S05]`）。

### 2.4 启动时间：起振 ≠ 达到标称频率 ≠ 固件能等到

- HSE 晶体典型几 ms；LSE 32.768 kHz 约 **1–5 s**（`[原厂 MCU-S02]`）。这里的“启动”包括幅度建立到稳定、频率进入误差带。
- 低温、低电压、高湿/污染、CL 过大、ESR 过高都会延长启动；负阻余量不足时表现为“有时候起、有时候不起”。
- 固件等待必须覆盖**最坏**启动时间；如果超时后回退到内部 RC，必须把“本次启动用的是 HSI/LSI”记录到状态寄存器/日志，否则现场会把“能跑”误认为“HSE 正常”。
- 有源晶振的启动时间另算：SiT8008B `T_start ≤ 5 ms`（从 VDD 达到额定最小值算起），`T_oe ≤ 130 ns`（110 MHz；其它频率约 100 ns + 3 个周期）（`[原厂 MCU-S08]`）。固件 HSE 等待若设 2 ms，必然误判失败；建议 ≥10 ms 并留回退。

### 2.5 五种现象不是一回事

| 现象 | 时间尺度 | 主要嫌疑 | 第一检查 | 不能混用 |
|---|---|---|---|---|
| **完全不起振** | 上电即失败 | 焊接/开路/短路、晶体错、CL 错、负阻不足、OSC_OUT 被负载、旁路模式配置错 | 低电容探头看 OSC_IN/OSC_OUT 有无波形；查直流偏置；查固件时钟源 | 有波形但频率不对 ≠ 不起振 |
| **偶发起振/低温失败/批量失败** | 部分板、部分温度 | 实测 Sf 在 3–5、ESR max 偏高、CL 过大、湿度/污染、晶体批次 | 用 max ESR/min gm 重算；测 Sf；冷热循环；清洗/涂覆对比 | 样机通过 ≠ 量产通过 |
| **频偏** | 稳态、可重复 | CL 与标称不符、电容介质/容差、Cs 估错、晶体初始容差、温度、老化 | 频率计测 ppm；量 C1/C2；按 CL 公式反推；换 C0G | 频偏 ≠ 抖动；平均频率对不代表边沿干净 |
| **抖动/相位噪声** | 周期到周期 | 有源晶振本身、电源纹波、负载、缓冲器、PCB 耦合、探头 | 相位噪声/TIE；电池供电对比；测 VDD 纹波；换振荡器 | 频率计看不出抖动；ppm 合格 ≠ 抖动合格 |
| **测量扰动** | 探头接触时出现 | 探头 10 pF、长地线、1× 探头、LSE 高阻节点 | 探头在/不在对比；换 FET 探头/缓冲器；短地弹簧 | 探头造成的停振不是板子故障 |

### 2.6 测量本身会改变振荡条件

- 普通 10× 无源探头输入电容约 **10–15 pF**（`simulation-measurement.md §5.3`）。把它并在 XIN 或 XOUT 上，等于给 CL1 或 CL2 并联 10 pF；对 CL=8 pF 的设计，等效 CL 可能从 8 pF 变到 9.7 pF，频偏可达 **约 78–96 ppm**（第 6.3 节），负阻余量下降约 **19%**。
- 10 pF 在 8 MHz 的阻抗是 `1/(2π×8 MHz×10 pF) ≈ 1.99 kΩ`；在 32.768 kHz 是 `≈486 kΩ`。LSE 晶体 ESR 常在几十 kΩ 量级，10 pF 探头是重负载，可能直接停振；AN2867 建议 LSE 用 **0.1 pF** 探头。
- 探头地线夹的引线电感会引入振铃/假象；地线越长，这个假象越明显。具体机理与算例见 [simulation-measurement.md §5.3](../../simulation-measurement.md)，本文不重复。
- 正确做法：优先在**缓冲后的时钟输出**或 MCU 的 CLK_OUT 测频率；必须测 XIN/XOUT 时用低电容有源探头，短地，测完立即移除；把“探头在/不在”的频率差写进报告。

### 2.7 内部振荡器、外部时钟、旁路模式、模组

- **内部 RC（HSI/LSI）**：无外部元件、启动快、成本低；精度/温漂/老化必须查该型号数据手册。RP2040 文档明确：可以不接外部时钟，但频率不准，USB 等需要精确频率的应用必须外部时钟（`[原厂 MCU-S05]`）。ESP32-C3 检查表明确：固件只支持 **40 MHz 晶体**，精度应在 **±10 ppm** 内（`[原厂 MCU-S04]`）。STM32 的 HSI/LSI 具体 ppm 本稿没有读到，`[待核]`；不要把“内部 RC 能用”写成“精度够”。
- **外部时钟/旁路模式**：单端 CMOS 时钟直接进 OSC_IN/XIN，OSC_OUT/XOUT **空置**；固件必须选择“外部时钟/bypass”模式，不能仍按晶体模式配置。AN4488 §6（Figure 15）给出 STM32F4 HSE 外部时钟接法；RP2040 允许 IOVDD 电平的 CMOS 方波直接进 XIN（`[原厂 MCU-S01/MCU-S05]`）。电平判据：振荡器 `VOH(min) ≥ MCU VIH(max)`、`VOL(max) ≤ MCU VIL(min)`、输出不得超过 MCU 输入耐压；具体数值必须查两份手册。
- **有源晶振**：内部已经是一个完整振荡器，不需要 CL1/CL2、不需要负阻计算；要检查的是供电、输出电平、负载、OE/ST、启动、抖动。OSC_OUT 仍然空置。
- **模组内部已含晶体**：板级不再加晶体，但必须读模组数据手册的**参考电路**：模组可能仍要求外部 32.768 kHz 晶体、外部时钟或特定 load cap。不能因为“模组有晶振”就省略所有时钟检查；也不能因为“参考电路画了晶体”就给一个内部已含晶体的模组外加晶体（驱动冲突）。所有权表见 [module-integration.md §10](../../module-integration.md)。

### 3.2 负载电容的选择

1. 从晶体数据手册取 **CL**（不是“推荐 20 pF”）。
2. 估 **Cs**：MCU 引脚电容（查数据手册，未给则按同封装保守值）+ PCB 走线/焊盘（按叠层算，未算前按 3–5 pF 标注 `[构造]`）。
3. 取 `C1 = C2 = 2(CL − Cs)`；若算出的 C 小于器件可用值或为负，说明 CL 与 Cs 不匹配，换晶体或改布局。
4. 选 **C0G/NP0**，容差按 ppm 预算：以 C1=C2=10 pF 为例，1% 电容偏差 0.1 pF，两颗同向最坏折算到 CL 约 0.05–0.1 pF；10% 电容偏差 1 pF，折算到 CL 约 0.5 pF。按第 6.3 节，CL 变化 0.8 pF 可产生约 46 ppm——对 ±10 ppm 预算是灾难。
5. 电容电压系数/温度系数：C0G 基本可忽略；X7R/Y5V 的容值随电压/温度变化，不能用于 CL。
6. 把计算式写在原理图旁：`CL1=CL2=10 pF（CL=8 pF, Cs=3 pF）`，方便复核和改板。

### 3.3 RExt 与 RF

- **先算 DL，再决定 RExt**；不要默认装。
- 若装 RExt，位置按 AN2867：串在 OSC_OUT 与 CL2 之间（或按该 MCU 手册的推荐位置；不同 MCU 可能不同，`[待核]`）。
- RExt 会同时降低驱动和负阻余量；加后必须用 `ESR+RExt` 重算 gmcrit，并重测启动。
- **RF**：多数 ST MCU 内置；AN2867 Table 3 的分档范围（约 0.47–25 MΩ，按频率分档） 仅用于理解，不要据此在已有内部 RF 的芯片上外加。

### 3.4 LSE / RTC

- STM32F4 的 LSE 建议选 **CL ≤ 7 pF** 的谐振器；AN4488 明确“绝不要用 CL = 12.5 pF 的型号”。按 Cs=2 pF 的示例，`C = 2(12.5−2) = 21 pF`，超过 CL1/CL2 的 15 pF 上限（AN4488 的 CL 限制是 `[原厂 MCU-S01]`；Cs=2 pF 是 `[构造]` 示例）。
- LSE 启动 1–5 s；固件等待 ≥5 s，或改用有源 RTC/外部时钟。
- LSE 的 ESR 通常比 HSE 高得多；负阻判据用 LSE 的 `Sf ≥ 3`，不是 HSE 的 5。
- 32.768 kHz 晶体是音叉型，频率-温度曲线是抛物线；不要把它放在 LDO、功放、电机驱动旁边。顶点温度和曲线按具体晶体数据手册，`[待核]`。
- 若 OSC32_IN/OUT 兼作 GPIO，画跳线/0 Ω 选项并注明“不可同时使用”；同一应用里既做 RTC 又做 GPIO 是常见冲突。

### 3.5 有源晶振

- 确认 MCU 支持外部时钟/旁路模式；OSC_OUT 空置。
- 核对输出电平：SiT8008B 为 LVCMOS/HCMOS，供电可选 1.8/2.5/2.8/3.0 V 或 **1.62–3.63 V 连续范围**（Vdd_YY 选项）；20 MHz、无负载典型电流 **3.5–3.8 mA**（`[原厂 MCU-S08]`）。1.8 V 供电的振荡器能否直接驱动 3.3 V MCU 的 XIN，必须用两边的 VOH/VOL/VIH/VIL 判断，不能只看“都是 CMOS”。
- OE/ST/NC：OE 高=输出标称频率，低=输出高阻（内部振荡器仍跑）；ST 低=输出弱下拉、器件睡眠；NC=不连接。OE/ST 未被外部驱动时建议 **≤10 kΩ 上拉**；要悬空就选 NC 选项（`[原厂 MCU-S08]`）。
- 启动：`T_start ≤5 ms`；`T_oe ≤130 ns`（110 MHz）。固件等待 ≥10 ms 并留回退。
- 抖动：75 MHz、12 kHz–20 MHz 积分带宽下 RMS 相位抖动典型 **1.3 ps**、最大 **2 ps**；900 kHz–7.5 MHz 下典型 0.5 ps、最大 0.9 ps；RMS 周期抖动 1.8–3 ps 量级；启动/恢复期间无 runt 脉冲、无 glitch（`[原厂 MCU-S08]`）。这些是 SiT8008B 的条件值，不代表所有有源晶振。
- 负载：电气特性默认 **15 pF**；走线/引脚/探头都会加负载。超过 15 pF 查手册曲线或加缓冲；明显低于 15 pF 时边沿更快，关注振铃/EMI，可预留 22–33 Ω 串阻（DNP）。

### 3.6 旁路模式与模组

- **旁路模式**：外部 CMOS 时钟进 OSC_IN，OSC_OUT 空置，固件选择 HSE bypass（具体寄存器位按该型号参考手册）。不要把外部时钟同时接到 OSC_OUT，也不要在 OSC_OUT 上保留晶体负载电容。
- **模组**：先读模组数据手册的参考电路和“已集成”清单；确认模组内部是否含高频晶体、是否要求外部 32.768 kHz、是否允许外部时钟。板级原理图只画模组要求的外部器件，不重复画内部已有的晶体。
- **所有权冲突**：如果模组内部已有晶体，外部再加一颗，会出现两个振荡器/驱动冲突；如果模组参考电路要求外部 32.768 kHz，而板上没有，RTC/LFCLK 可能落在内部 RC 上，精度和功耗都会变。两种情况都要在原理图上写明“谁提供时钟”。

**读图教训：**

1. **邻近的电容不一定是晶体的负载电容。** Crazyflie 的 `C1 100n` 在 `STM_NRST` 上，`R3 10k` 在 `STM_BOOT0` 上；只看“晶体旁边有个电容”会得出错误结论。必须沿网络追到 MCU 引脚。
2. **有源晶振没有 CL1/CL2 是正常的。** iCEBreaker 的 `U7` 只需要 VDD 去耦、OE 上拉和输出走线；拿晶体负阻公式去套有源晶振是方法错误。
3. **板级没有晶体不等于系统没有晶体。** Feather Sense 的 32 MHz 晶体在模组内；32.768 kHz 则可能落在内部 RC。必须读模组参考电路，不能只看板级 BOM。
4. **“64 MHz”不是晶体频率。** nRF52840 的 CPU 64 MHz 由 32 MHz 晶体经时钟树倍频得到；把 64 MHz 当成晶体频率会选错器件。

### 3.8 BOM、DNP 与替代料

- 晶体/振荡器的完整料号、CL、ESR、C0、DL、温度范围、封装必须进 BOM；只写“8 MHz”不够。
- 替代晶体不能共用同一组 C1/C2：CL/ESR/C0 不同，必须重算 CL 与 gmcrit。
- RExt、串联端接、OE 上拉标 **DNP/0 Ω** 并注明装配条件；不要默认装。
- 有源晶振的 OE/ST/NC 选项要在料号里体现，不能只写“SiT8008”。
- 模组方案要在 BOM 里写清“模组内含 32 MHz；外部 32.768 kHz 是否装配”；否则生产会按不同版本装出不同 LFCLK。

**不要写“合理布局”就结束：** 评审必须给出实际走线长度、回路面积、参考平面是否连续、晶体地过孔数量/位置。没有这些数据，等于没有检查。

### 4.2 负载电容的地

- C1/C2 的接地端应就近回到 MCU 的 GND，而不是绕到远处的电源地/连接器地；否则回流路径长，容易把开关噪声耦合进振荡器。
- 两颗电容的地过孔尽量靠近焊盘；不要在电容地之间串长走线。
- 晶体下方的局部地平面要与 MCU 地低阻抗连接；不要形成“孤岛地”。
- 如果板上有多个地（模拟/数字/功率），按该板的接地策略处理；不要因为“晶振是模拟”就自动把晶体地接到 AGND 而远离 MCU 地。具体连接点按叠层/回流设计，不能套口号。

### 4.3 参考平面与串扰

- 时钟走线下方参考平面连续，不跨分割；跨分割会让回流绕路，边沿振铃/EMI 变差。
- 不要在晶体/时钟线下方走开关电源的 SW 节点、电机相线、射频功率线；这些是强 di/dt/dv/dt 源。
- 时钟线与相邻信号保持间距；具体间距按叠层/串扰预算，不能给一个万能 mm 数。
- 有源晶振的输出是单端 CMOS，不是差分；不需要 100 Ω 差分，但需要短走线、连续参考、必要时串阻。

### 4.4 有源晶振的 PCB

- 0.1 µF 去耦紧靠 VDD/GND；地过孔就近。
- 输出走线短，避免分支到多个负载；iCEBreaker 的 `FTDI_CLK` 同时到 FPGA 和 FT2232H，属于“共享时钟”，要检查分支长度/负载；必要时加缓冲器。
- OE/ST 上拉电阻靠近 pin 1；不要把它放在远离振荡器的位置。
- 远离天线、开关电源、电机驱动；有源晶振内部有振荡器，外部噪声会调制其输出。
- 如果输出边沿振铃/过冲，预留 22–33 Ω 串阻（DNP）；不要默认装 1 kΩ 把边沿变慢。

### 4.5 温度、机械与热路径

- 晶体的频率-温度特性是器件级的；音叉 32.768 kHz 通常是抛物线，HSE 晶体的转折点/斜率按切割/型号。不要把晶体放在 LDO、功放、电机驱动、电池充电器旁边；温度梯度会让 RTC/射频频率随负载变化。
- 有源晶振自身功耗 mW 级（SiT8008B 20 MHz 无负载 3.5–3.8 mA，按 3.3 V 约 12 mW，`[原厂 MCU-S08]`），自热不是主要问题；主要问题是电源纹波、负载和外部热源导致的频率漂移/抖动。
- 晶体封装对应力敏感；避免把晶体放在板边、螺钉孔、连接器插拔受力区；按器件手册的焊盘/回流要求，不要用外力压晶体。
- 热设计的一般方法见 [thermal/topic.md](../../thermal/topic.md)；本文只补充“温度如何变成频偏/启动失败”，不重复热阻公式。

### 4.6 EMC 与时钟走线

- 时钟线是辐射源：短、连续参考、少过孔、不跨分割；必要时串阻/屏蔽。
- 不要把时钟线走到板边/连接器附近；不要与电缆/天线平行长距离。
- 有源晶振的供电去耦不足会把电源噪声调制到时钟上，表现为抖动/杂散；先查 VDD 纹波，再换器件。
- DRC 通过只证明间距/连接性，不证明起振、频偏、抖动、EMC；这些必须计算/测量。

## 5. 方案与取舍

### 5.1 六种时钟来源比较

| 方案 | 典型器件/条件 | 频率精度 | 启动 | 静态电流 | 外部元件 | 设计难点 | 故障行为 | 适用条件 |
|---|---|---|---|---|---|---|---|---|
| **MCU 内部 RC（HSI/LSI）** | RP2040 内部振荡器；ESP32-C3 不用（只支持 40 MHz 晶体） | 精度/温漂按型号，RP2040 文档只说“频率不准”，未给 ppm `[待核]` | 快（按型号，本稿未给数值 `[待核]`） | 按型号/模式 `[待核]` | 无 | 精度无法保证；USB/CAN/射频可能失败 | 频偏、温漂、协议失败 | 无精确时钟要求、低成本、快速启动 |
| **HSE 无源晶体 + Pierce** | 8 MHz/12 MHz 等；CL 按晶体 | 初始容差按晶体型号：RP2040 推荐 ABM8 为 ±30 ppm（MCU-S05）、ESP32-C3 要求 ±10 ppm（MCU-S04）；再加 CL/温度/老化 | 几 ms（AN2867） | 按 MCU 数据手册 `[待核]` | 2 颗 CL + 可选 RExt | CL/ESR/负阻/布局；量产一致性 | 不起振、偶发、频偏、过驱动 | 成本敏感、需要 ppm 级、板上有空间 |
| **LSE 32.768 kHz 音叉晶体** | STM32F4 LSE；CL ≤7 pF | 初始容差按晶体型号 `[待核]` + 温度抛物线 + 老化 | **1–5 s**（AN2867） | 按 MCU 数据手册 `[待核]` | 2 颗 CL + 可选 RExt | 高阻、易受漏电/探头影响；CL1/CL2 ≤15 pF | 不起振、启动慢、RTC 漂移 | RTC/低功耗计时 |
| **有源晶振（XO）** | SiT8008B：1–110 MHz，±20/25/50 ppm，1.62–3.63 V 选项，15 pF 负载 | 总稳定度含初始/老化/温度/电压/负载 | **≤5 ms**（T_start） | 20 MHz 无负载 **3.5–3.8 mA** | 0.1 µF + 可选串阻 | 电平/负载/OE/抖动；供电噪声 | 无输出、电平不够、OE 悬空、抖动 | 启动确定、FPGA/USB、减少晶体布局风险 |
| **外部时钟/旁路** | 另一颗 MCU 的 CLK_OUT、时钟缓冲器、模组时钟 | 取决于源；要加源→负载的 ppm/抖动 | 取决于源 | 取决于源 | 视源而定 | 电平/耐压/负载/OSC_OUT 空置；固件 bypass | 无时钟、电平错、双驱动 | 板上已有可靠时钟、需要同步 |
| **模组内部晶体** | MDBT50Q：32 MHz 在模组内；32.768 kHz 默认参考电路外接 | 模组/晶体规格；32.768 kHz 若用内部 RC 则精度下降 | 模组启动 | 模组电流 | 按模组参考电路 | 读参考电路；所有权/版本 | 缺 32.768 kHz、LFCLK 走 RC、RTC 漂移 | 已认证模组、减少 RF/时钟设计 |

**取舍规则（`[推断]`）：**

- 需要 USB/CAN/射频/精确计时 → 不要只靠内部 RC；选晶体或有源晶振。
- 需要“上电后确定时间内一定有 clock” → 有源晶振的 `T_start ≤5 ms` 比晶体的负阻/启动更可控；代价是 mA 级电流和成本。
- 成本敏感、板上有空间、能控制 CL/布局 → 无源晶体；但必须做负阻/驱动/启动计算。
- 板上已有可靠时钟且电平匹配 → 外部时钟/旁路，省一颗晶体；但要确认源在复位/低功耗时的行为。
- 模组已认证 → 优先按模组参考电路；不要重复设计内部晶体，也不要漏掉模组要求的 32.768 kHz。

### 5.2 晶体、谐振器、有源晶振的失效行为

| 类型 | 频率精度 | 起振条件 | 外部元件 | 驱动电平 | 典型失败 | 适用 |
|---|---|---|---|---|---|---|
| 两端晶体 | 窄（ppm 级） | 需要 Pierce 反相器 + CL1/CL2 + 负阻余量 | 2 颗 CL、可选 RExt | 有 DLmax，需算 | 不起振、频偏、过驱动 | 精确时钟 |
| 三端谐振器（内置 CL） | 较宽（按型号） | 内置负载电容，外围简单 | 通常无 CL；可能有 RExt | 有额定 | 频偏、批次一致性 | 成本敏感、精度要求不高 |
| 有源晶振 | 窄（ppm 级，含总稳定度） | 内部振荡器，无需负阻 | 0.1 µF、可选串阻 | 输出驱动/负载 | 无输出、OE/电平、抖动 | 启动确定、FPGA/通信 |

**Crazyflie 的 `X1` 读图结论属于哪一种？** 符号有接地第三脚、且该页没有 CL1/CL2，最符合“三端谐振器（内置负载电容）”；但具体料号未在 PDF 中给出，必须查 BOM/KiCad 工程后才能定论。`[推断]`/`[待核]`。不要因为“Crazyflie 能飞”就认为“8 MHz 两端晶体不加电容也能起振”。

### 5.3 有源晶振 OE/ST/NC 的选择

| 模式 | Pin 1 行为 | 关断后电流 | 重新启动 | 适用 | 风险 |
|---|---|---|---|---|---|
| **OE（高有效）** | 高=输出标称频率；低=输出高阻，内部振荡器继续跑 | 仍耗内部振荡器电流（不是断电） | 快（T_oe ≤130 ns 量级） | 需要快速关断输出、保留振荡 | 低功耗产品误以为“OE 低=省电” |
| **ST（低有效）** | 低=输出弱下拉、器件睡眠 | 睡眠电流（按型号） | 需等 T_start（≤5 ms 量级） | 需要真正省电 | 唤醒后固件要等启动 |
| **NC** | 不连接；pin 1 接固定电平 | 按器件 | 按器件 | 不需要关断 | 悬空/误驱动；选 NC 选项并固定电平 |

- OE/ST 未被外部驱动时，SiT8008B 建议 **≤10 kΩ 上拉**；要悬空就选 NC 选项（`[原厂 MCU-S08]`）。
- OE 拉低只是输出高阻，不等于整颗器件断电；低功耗产品应选 ST 或断电，不要用 OE 当电源开关。
- 若用 MCU GPIO 控制 OE，确认复位期间 GPIO 的默认态不会让时钟意外关断；必要时加上拉。

## 6. 怎么判断：计算、仿真、测量、回读

### 6.1 完整算例 A：任务指定条件（CL=8 pF、Cs=3 pF）

**条件（写明假设）：**

- 目标 HSE：`F = 8.000 MHz`。
- 晶体：`C0 = 7 pF`、`CL = 8 pF`、`ESR(max) = 80 Ω`。这三个来自 AN2867 §3 的**教学算例值**（`[原厂 MCU-S02]`），不代表任何具体料号；实际设计必须换成所选晶体的 max 值。`DLmax = 100 µW` 是示例假设（`[构造]`），必须换成所选晶体的额定值。
- MCU：`gm(min) = 25 mA/V`。同样是 AN2867 教学值；实际必须用该 MCU 数据手册的 min。
- 寄生：`Cs = 3 pF`（`[构造]`，按本板封装/走线估算）。
- 测量假设：`Vpp = 1.0 V`（CL1 处，`[构造]`，必须实测）。
- 候选 RExt：`1 kΩ`（用于说明“加 RExt 会吃余量”）。

**步骤 1：负载电容。**

```text
C1 = C2 = 2·(CL − Cs) = 2 × (8 − 3) = 10 pF
校验：10×10/(10+10) + 3 = 5 + 3 = 8 pF
```

**步骤 2：临界跨导与增益裕度。**

```text
2πF = 2π × 8×10⁶ = 5.0265×10⁷ rad/s
(2πF)² = 2.5266×10¹⁵
C0 + CL = 7 + 8 = 15 pF = 15×10⁻¹² F
(C0+CL)² = 2.25×10⁻²² F²
gmcrit = 4 × 80 × 2.5266×10¹⁵ × 2.25×10⁻²²
       = 1.819×10⁻⁴ A/V = 0.182 mA/V
gain margin = 25 / 0.182 = 137.4 > 5  → 通过
```

**步骤 3：ESR max 与 gm min 的敏感性。** 固定 `C0=7 pF`、`CL=8 pF`，只改 ESR 和 gm：

| ESR(max) Ω | gmcrit mA/V | margin @ gm=25 mA/V | margin @ gm=10 mA/V | margin @ gm=5 mA/V |
|---:|---:|---:|---:|---:|
| 40 | 0.091 | 275 | 110 | 55 |
| 80 | 0.182 | 137 | 55 | 27.5 |
| 150 | 0.341 | 73.3 | 29.3 | 14.7 |
| 300 | 0.682 | 36.7 | 14.7 | 7.3 |

**读法：** ESR 从 80 Ω 升到 300 Ω，margin 从 137 降到 36.7（gm=25 时仍 >5）；但如果该 MCU 的 gm min 只有 5 mA/V，300 Ω 时 margin 7.3，已经接近门限。**不能只看 ESR，也不能用 gm 的典型值。**

**步骤 4：安全因子 Sf（实测判据）。**

```text
Sf = (RADD + ESR) / ESR
HSE 要求 Sf ≥ 5 → RADD ≥ 4×ESR
ESR = 80 Ω → RADD ≥ 320 Ω
若实测只能加到 RADD = 200 Ω 就不起振：Sf = (200+80)/80 = 3.5 < 5  → 不合格
```

这说明“纸面 margin 137”和“实测 Sf 3.5”可以同时存在：纸面用的是典型/教学值，实测包含布局、探头、批次、温度。两者都要做。

**步骤 5：RExt = 1 kΩ 的代价。**

```text
gmcrit' = 4 × (ESR + RExt) × (2πF)² × (C0+CL)²
        = 0.182 × (80 + 1000)/80
        = 2.46 mA/V
margin' = 25 / 2.46 = 10.2 > 5（gm=25）
若 gm(min) = 10 mA/V：margin' = 10/2.46 = 4.07 < 5 → 不合格
```

**结论：** 1 kΩ 不是“更稳”，而是用负阻余量换驱动电平；只有在实测 DL 超限、且用 gm min 复算仍 >5 时才装。

**步骤 6：驱动电平（厂商公式）。**

```text
Ctot = CL1 + Cs/2 + Cprobe = 10 + 1.5 + 0 = 11.5 pF
πF·Ctot = π × 8×10⁶ × 11.5×10⁻¹² = 2.890×10⁻⁴
(πF·Ctot)² = 8.352×10⁻⁸
DL = ESR · (πF·Ctot)² · Vpp² / 2
   = 80 × 8.352×10⁻⁸ × 1² / 2
   = 3.34×10⁻⁶ W = 3.34 µW
```

`3.34 µW < 100 µW` → 按厂商公式，**不需要 RExt**（与 AN2867 “DL 低于额定时不建议加 RExt”一致）。

**步骤 7：计划书公式 `P = 2πf·CL·Vpp²` 的对照。**

```text
P_plan = 2π × 8×10⁶ × 8×10⁻¹² × 1²
       = 4.021×10⁻⁴ W = 402 µW
```

这个 402 µW **不是**晶体 ESR 上的损耗：它是 CL 上无功功率（`Q = 2πfCL·Vpp²/8 = 50.3 µW`）的 8 倍。与厂商 DL 3.34 µW 的比值是 `402/3.34 = 120.4`（若 Ctot 取 CL=8 pF，比值约 249）。**若拿 402 µW 去比 100 µW，会把一个实际只有 3.34 µW 的好设计判成超限。** 判定必须用厂商式；计划书公式只能作为“CL 上无功功率量级”的旁证，不能直接对 DLmax。

**步骤 8：按 DLmax 反推允许的 Vpp（厂商式）。**

```text
Vpp(max) = sqrt( 2·DLmax / (ESR·(πF·Ctot)²) )
         = sqrt( 2×100×10⁻⁶ / (80×8.352×10⁻⁸) )
         = sqrt( 29.93 )
         = 5.47 V
```

按厂商式，Vpp 要到约 **5.47 V** 才达到 100 µW；按计划书公式，同样的 5.47 V 会算出 **12.0 mW**，差 120 倍。这个例子说明“公式选错”比“参数选错”更容易把设计带偏。

**结论与限制：**

- 满足：CL 配置、gain margin（教学值）、DL（假设 Vpp=1 V）、RExt 取舍均有量化依据。
- 仍待确认：`gm=25 mA/V`、`ESR=80 Ω`、`C0=7 pF`、`DLmax=100 µW` 都是教学值；必须换成该 MCU/该晶体的 min/max；`Cs=3 pF`、`Vpp=1 V` 是假设；`Sf` 未实测；温度/湿度/批次未测。
- **这个算例不能证明：** 实际起振、全温度余量、老化后频差、EMC、长期可靠性。

### 6.2 算例 B：RP2040 参考设计的实值核算

**条件（`[原厂 MCU-S05]`）：** RP2040 参考设计推荐 Abracon `ABM8-272-T3`：12 MHz、±30 ppm、`ESR(max)=50 Ω`、`CL=10 pF`、`C0=3.0 pF`、驱动电平 **10–200 µW**；两颗 **15 pF** 对地电容，串联 7.5 pF，加约 **3 pF** 寄生 → 10.5 pF；串 **1 kΩ**（R5）。假设 `Vpp=1.0 V`（CL1 处，`[构造]`，必须实测）。

**负载电容偏差：**

```text
CL_actual = 15×15/(15+15) + 3 = 7.5 + 3 = 10.5 pF
相对 10 pF：+0.5 pF（+5%）
```

**驱动电平（厂商式，Ctot = CL1 + Cs/2 = 15 + 1.5 = 16.5 pF）：**

```text
πF·Ctot = π × 12×10⁶ × 16.5×10⁻¹² = 6.220×10⁻⁴
(πF·Ctot)² = 3.869×10⁻⁷
DL = 50 × 3.869×10⁻⁷ × 1² / 2 = 9.67×10⁻⁶ W = 9.67 µW
```

按 Vpp=1 V 假设，9.67 µW 落在厂商给出的 10–200 µW 范围的**下沿附近**（略低于 10 µW）；Vpp 实测值决定它是否真的在范围内。1 kΩ 的作用是限制回路电流/驱动，不是“提高稳定性”；具体 Vpp 必须实测，不能把 1 V 当保证值。

**CL 偏差折成 ppm：** 用两种方法给出量级，实际必须用 ABM8 数据手册的 `Cm`/`C0` 重算：

- 按 AN2867 的示例可拉性 **45 ppm/pF**（`[原厂 MCU-S02]` 算例值）：`0.5 pF × 45 = 22.5 ppm`。
- 按 `Cm=26 fF`、`C0=3 pF`、`CL=10 pF` 的假设（26 fF 是由 AN2867 示例反推的教学值，不是 ABM8 的实测值）：`S = 0.026×10⁶/(2×(3+10)²) = 76.9 ppm/pF`；`0.5 pF × 76.9 = 38.5 ppm`。

**结论：** 5% 的 CL 偏差可以吃掉 22–39 ppm；对 ±30 ppm 的晶体，总误差可能接近/超过 50–70 ppm。对 tolerance 较宽的接口可能仍可，但对 ±10 ppm 的射频/协议预算不够。**具体协议门限 `[待核]`；本文不编造 USB/CAN 的 ppm 数。**

### 6.3 算例 C：CL 偏差 10% 与 10 pF 探头

**10% CL 偏差 → ppm。** 用 `S = Cm×10⁶/(2(C0+CL)²)`（Cm、C0、CL 均以 pF 计），取 `C0=7 pF`、`Cm=26 fF`（由 AN2867 示例 45 ppm/pF @ CL=10 pF 反推的教学值）：

| CL pF | 10% 偏差 pF | S ppm/pF | Δf ppm（幅值） |
|---:|---:|---:|---:|
| 8 | 0.8 | 57.8 | 46.2 |
| 10 | 1.0 | 45.0 | 45.0 |
| 12.5 | 1.25 | 34.2 | 42.7 |

**读法：** 10% 的 CL 偏差在 42–46 ppm 量级；这不是“几 ppm”的小事。实际晶体的 `Cm`/`C0` 必须查数据手册；上表的 26 fF/7 pF 是教学值，不能当保证值。频率方向：CL 增大 → 频率降低；表中给幅值。

**10 pF 探头加到 XIN：**

```text
原：CL1 = CL2 = 10 pF，Cs = 3 pF → CL = 10||10 + 3 = 5 + 3 = 8 pF
加探头后：CL1' = 20 pF → CL' = 20||10 + 3 = 6.667 + 3 = 9.667 pF
ΔCL = +1.667 pF
Δf ≈ 1.667 × (46.8…57.8 ppm/pF) ≈ 78…96 ppm
```

- 负阻余量：`gmcrit ∝ (C0+CL)²`，`(7+9.667)²/(7+8)² = 1.235`，margin 降到原来的 **81%**（下降约 19%）。原本 margin=5 的设计，探测时可能降到 4.05，低于 HSE 的 5 门限。
- 探头阻抗：8 MHz/10 pF 约 **1.99 kΩ**；32.768 kHz/10 pF 约 **486 kΩ**。LSE 晶体 ESR 常在几十 kΩ，10 pF 探头可能直接停振；AN2867 建议 LSE 用 **0.1 pF** 探头。
- 结论：**“探头一碰频率就变/就停”不是板子随机故障，而是探头成为 CL 的一部分。** 测频率优先在缓冲后的时钟输出；必须测 XIN 时用低电容有源探头，并记录探头在/不在的差值。

### 6.4 测量与回读计划

| 项目 | 仪器/接法 | 条件 | 判据 | 不能证明 |
|---|---|---|---|---|
| 频率 | 频率计，闸门 ≥1 s；32.768 kHz 用 ≥100 s 或倒数计数器 | 25 °C、标称 VDD、无探头/低电容探头 | `ppm = (f_meas−f_nom)/f_nom×10⁶` 在预算内 | 全温度、老化、抖动 |
| 启动时间 | 示波器单次触发，测 VDD/OSC 或固件时间戳 | 冷启动、最低/最高温度 | HSE 几 ms；LSE 1–5 s；固件等待覆盖 | 长期可靠性 |
| Vpp / DL | 低电容探头测 CL1 处 Vpp；按厂商式算 | 稳态、典型/最坏负载 | DL ≤ DLmax | 晶体内部温度/老化 |
| 负阻/Sf | 串 RADD，逐次冷启动找边界 | 室温 + 高低温 | HSE Sf ≥5；LSE Sf ≥3 | 批次分布（需多片） |
| 抖动 | 相位噪声分析仪/示波器 TIE | 规定带宽、电源、负载 | 按协议/器件预算；SiT8008B 1.3 ps typ/2 ps max（12 kHz–20 MHz） | 长期漂移 |
| 电流 | DMM/电流探头 | 有源晶振单独供电；睡眠模式 | 20 MHz 无负载 3.5–3.8 mA（SiT8008B） | 全部工作模式 |
| 回读 | MCU 时钟状态寄存器、RTC 计数、USB/CAN 状态、UART 误码 | 上电/复位/低功耗唤醒 | HSE/LSE ready 标志、时钟源、错误计数 | 模拟波形质量 |
| 温度 | 温箱/冷热风枪，记录温度 | 最低/最高/室温 | 起振、ppm、启动时间 | 湿度/振动 |

**频率计分辨率的具体例子：**

- 8 MHz：1 ppm = **8 Hz**；1 s 闸门 ±1 count = ±1 Hz = **±0.125 ppm**，足够看 1 ppm 级。
- 32.768 kHz：1 ppm = **0.032768 Hz**；1 s 闸门 ±1 Hz = **±30.5 ppm**，根本不够看 ppm 级；需要 ≥100 s 闸门（0.01 Hz ≈ 0.3 ppm）或倒数计数器。用 1 s 闸门测 32.768 kHz 然后宣称“在 ±20 ppm 内”是测量方法错误。

### 6.5 仿真

- 晶体起振仿真：用晶体等效模型（Cm/Lm/Rm/C0）+ MCU 反相器模型，观察起振时间、稳态幅度、负阻；通过标准是 margin >5 且幅度稳定。**本稿未执行** `[未执行]`。
- 有源晶振：用 IBIS 看输出振铃/过冲；通过标准由 MCU 输入绝对最大额定值给出。**本稿未执行** `[未执行]`。
- 仿真不能代替负阻实测、DL 实测、温度/湿度试验；不要用理想时钟源代替晶体模型。

### 6.6 通过标准

同时满足才算“时钟通过”：

1. HSE `gain margin > 5`（用 gm min/max ESR/max C0/实际 CL），或实测 `Sf ≥ 5`；LSE `Sf ≥ 3`。
2. `DL ≤ DLmax`（厂商式，Vpp 实测）。
3. 启动时间 + 固件等待 < 产品启动预算；LSE 按 1–5 s 预留。
4. 频率在 ppm 预算内（含温度/老化/CL 容差）；测量方法的分辨率优于预算的 1/3。
5. 有源晶振：VOH/VOL 满足 MCU VIH/VIL，T_start/T_oe 满足固件，抖动满足协议，OE/ST 默认态正确。
6. 模组：参考电路的外部 32.768 kHz/时钟要求已满足，LFCLK 来源已记录。
7. 以上都有证据（计算表、波形、频率记录、温度记录）；没有做的标 `[未执行]`。

## 7. 常见失败现象与排查顺序

**总顺序：** 先安全/无损（查原理图、BOM、固件配置、供电），再上电测量（低电容探头、频率计），最后侵入（拆焊、换晶体、串 RADD）。不要一上来就换晶体；先证明“是晶体/CL/负阻/配置”中的哪一个。

### 7.1 链 1：HSE 完全不起振

- **现象：** OSC_IN/OSC_OUT 无波形或幅度极小；固件从 HSI 跑；USB/CAN 失败；HSE ready 标志不置位。
- **候选：** H1 焊接开路/短路/晶体损坏；H2 晶体型号/CL 错；H3 负阻不足（ESR 高/CL 大/gm 小）；H4 OSC_OUT 被负载或旁路模式配置错；H5 供电/EN/复位异常。
- **区分检查：** ① 原理图/网表确认 OSC_IN/OUT 只接晶体和 CL；② 万用表测 OSC_IN/OUT 直流偏置（不应为 0 V 或 VDD 死点）；③ 低电容探头看有无微弱振荡；④ 量 C1/C2 实际值；⑤ 断电量晶体/查料号；⑥ 查固件时钟源（是否误配为 bypass/外部时钟）；⑦ 必要时串 RADD 测负阻。
- **证据：** 无波形 + 直流偏置异常 → 焊接/器件；有微弱波形但幅度不增长 → 负阻/CL；HSE 标志不置位但波形正常 → 固件/时钟树配置；换晶体后起振 → 晶体/批次。
- **修复：** 补焊/换晶体；按 CL 公式改 C1/C2；降低 CL/ESR；移除 OSC_OUT 负载；改固件时钟源。
- **复验：** 冷启动 ≥10 次；室温 + 高低温；频率 + 启动时间；HSE 标志。
- **新风险：** 换低 CL 晶体后可拉性变大、频偏对电容更敏感；拆焊可能损伤焊盘；探头仍可能让“修好”的板停振。

### 7.2 链 2：偶发不起振 / 低温失败 / 量产部分失败

- **现象：** 同一批板部分起振、部分不起；低温/高温失败；换晶体批次后比例变化；有时复位几次才起。
- **候选：** H1 实测 Sf 在 3–5；H2 ESR max 偏高/CL 偏大；H3 湿度/助焊剂残留漏电；H4 晶体批次/负载电容批次；H5 电源斜率/复位时序。
- **区分检查：** ① 用 max ESR/min gm/实际 CL 重算 margin；② 测 Sf（RADD 冷启动）；③ 冷热风枪/温箱复现；④ 清洗/烘干/涂覆前后对比；⑤ 换不同批次晶体/电容；⑥ 测 VDD 斜率/复位释放。
- **证据：** margin 计算 <5 或 Sf <5；低温才失败；清洗后恢复；批次相关性。
- **修复：** 换低 ESR/低 CL 晶体；改 C1/C2；加三防漆/清洗工艺；改布局缩短回路；必要时改有源晶振。
- **复验：** ≥10 块板，室温/最低/最高温度，冷启动多次；记录 Sf/启动时间/ppm。
- **新风险：** 降低 CL 会提高可拉性（频偏对电容更敏感）；三防漆可能改变 Cs；换晶体后要重算 DL/RExt。

### 7.3 链 3：频率偏（USB/CAN/RTC 超差）

- **现象：** 频率计读数偏离标称超过预算；USB/CAN 等协议错误或 RTC 走时偏；常温可重复。
- **候选：** H1 CL 与晶体标称不符；H2 C1/C2 用 X7R/容差大；H3 Cs 估错；H4 晶体初始容差/温度/老化；H5 探头负载；H6 晶体型号错（CL 不同）。
- **区分检查：** ① 频率计（足够闸门）测 ppm；② 量 C1/C2 实际容值/介质；③ 按 CL 公式反推实际 CL；④ 换 C0G 电容对比；⑤ 查晶体料号 CL/温度范围；⑥ 探头在/不在对比；⑦ 高低温测 ppm。
- **证据：** 换 C0G 后 ppm 改善 → 电容介质/容差；反推 CL 与标称差 → CL 错；温度曲线 → 晶体/温度；探头一碰就变 → 测量扰动。
- **修复：** 按 CL 公式改电容；换 C0G/1%；换正确 CL 的晶体；调整布局降 Cs；必要时选更低 ppm/TCXO。
- **复验：** 25 °C + 高低温 ppm；USB/CAN/RTC 功能；长期老化（未执行）。
- **新风险：** 改 CL 会改变负阻余量/启动时间；低 ppm 晶体可能 ESR 更高；TCXO 增加成本/电流。

### 7.4 链 4：抖动/相位噪声（射频/以太网/ADC 异常）

- **现象：** 平均频率正常，但射频灵敏度/吞吐下降、以太网误码、ADC SNR 差、时钟眼图抖动大。
- **候选：** H1 有源晶振本身抖动；H2 VDD 纹波/去耦不足；H3 输出负载/走线过长；H4 时钟缓冲器/电平转换；H5 PCB 耦合（SW/射频）；H6 探头/测量设置。
- **区分检查：** ① 相位噪声/TIE 测抖动；② 电池/线性电源 vs 板上 DC-DC 对比；③ 测 VDD 纹波；④ 缩短/端接输出；⑤ 换同频低抖动振荡器；⑥ 检查探头接地/带宽。
- **证据：** 换电源后抖动改善 → 电源；换振荡器改善 → 器件；加串阻/缩短走线改善 → 负载/振铃；探头在/不在变化 → 测量。
- **修复：** 低抖动振荡器；加强去耦/滤波；串阻/缓冲；改布局远离噪声源；必要时专用时钟芯片。
- **复验：** 协议误码/灵敏度/眼图；相位噪声；全温度。
- **新风险：** 串阻会减慢边沿；缓冲器增加功耗/抖动；低抖动器件可能电流更大。

### 7.5 链 5：测量扰动（探头一碰就停/频偏）

- **现象：** 探头接触 XIN/XOUT 时停振或频率跳变；移开恢复；LSE 尤其明显。
- **候选：** H1 10 pF 探头改变 CL；H2 长地线引入振铃/环路；H3 1× 探头高电容；H4 LSE 高阻节点；H5 探头供电/接地不良。
- **区分检查：** ① 探头在/不在对比频率/波形；② 换 FET/低电容探头；③ 用缓冲器/时钟输出测；④ 短地弹簧；⑤ 测探头电容（手册）。
- **证据：** 频率随探头变化量 ≈ 第 6.3 节计算；移开恢复；低电容探头改善。
- **修复：** 不在 XIN/XOUT 长期探测；用缓冲输出；LSE 用 0.1 pF 探头；短地。
- **复验：** 探头在/不在差异 < 预算；波形稳定。
- **新风险：** 缓冲器增加负载/抖动；探头仍可能改变起振条件。

### 7.6 链 6：有源晶振无输出/电平不对/OE 无效

- **现象：** 上电无时钟；或幅度远低于 MCU VIH；或 OE 拉低后仍输出/功耗不降。
- **候选：** H1 VDD 未上/去耦不良；H2 OE 悬空/极性错；H3 ST 极性/启动时间；H4 输出负载过大/短路；H5 OSC_OUT 未空置/双驱动；H6 电平不匹配（1.8 V 输出进 3.3 V MCU）。
- **区分检查：** ① 测 VDD/GND；② 测 OE/ST 电压与手册极性；③ 断开负载测输出；④ 查 OSC_OUT 网表；⑤ 查 MCU VIH/VIL 与振荡器 VOH/VOL；⑥ 测 T_start。
- **证据：** OE 悬空 → 随机；VDD 正常但无输出 → 器件/负载；VOH 不够 → 电平；OSC_OUT 有电容 → 双驱动。
- **修复：** 加 OE 上拉/选 NC；换匹配电平的振荡器/加时钟专用电平转换；清空 OSC_OUT；减小负载/加缓冲。
- **复验：** 冷启动、OE 开关、VOH/VOL、T_start、固件 HSE 标志。
- **新风险：** 上拉增加静态电流；电平转换增加抖动；ST 唤醒要等 T_start。

### 7.7 链 7：模组 LFCLK / 32.768 kHz 缺失

- **现象：** RTC 走时偏；低功耗唤醒时间不准；模组参考电路要求外部 32.768 kHz，但板上没有。
- **候选：** H1 模组默认 DC-DC 模式要求外部 X2；H2 固件用内部 RC；H3 模组版本不同；H4 X2 焊接/负载电容错；H5 32.768 kHz 被 GPIO 占用。
- **区分检查：** ① 读模组数据手册参考电路（MDBT50Q Ver.B 第 32 页）；② 板级找 X2/C12/C13；③ 读固件 LFCLK 源配置；④ 测 XL1/XL2 有无 32.768 kHz；⑤ 查模组版本/料号。
- **证据：** 板上无 X2 + 固件用 RC → LFCLK 精度下降；加 X2 后 RTC 改善；模组版本参考电路不同。
- **修复：** 按模组参考电路加 X2/C12/C13；或明确接受内部 RC 并写清 ppm/温度范围；改固件时钟源。
- **复验：** RTC 漂移（室温/高低温）；启动时间；功耗。
- **新风险：** X2 负载电容/ESR 选错会不起振；加晶体占板面积；内部 RC 省成本但精度/温度差。

### 8.3 停止条件

- 没有晶体 `ESR(max)`/`C0`/`CL` 或 MCU `gm(min)`：不能给“负阻通过”；只能给“待核”。

- 没有探头电容/测量设置：不能解释“探头一碰就坏”；先补测量条件。
- 没有温度/批次数据：不能给“量产通过”；只能给“样机通过”。
- 没有模组参考电路/版本：不能给“模组时钟通过”；先读手册。

### 10.2 适用范围

- **AN2867 的公式**（CL、gmcrit、DL、RExt、Sf）适用于 STM8/STM32 类 Pierce 振荡器；不能直接套到 ESP32-C3、RP2040 的内部振荡器/推荐晶体。RP2040 的 12 MHz/15 pF/1 kΩ 是参考设计值；ESP32-C3 的 40 MHz/±10 ppm/24 nH 是芯片检查表值；SiT8008B 的数值只属于该型号。
- **Crazyflie/iCEBreaker/Feather Sense** 是开源设计样本，用于观察“作者怎么画/怎么选”，不是正确性权威；作者修过的缺陷要按版本标注。Crazyflie 的 X1 料号未在 PDF 中给出；iCEBreaker 的 SiT2001 数据手册未读；Feather Sense 的模组版本/LFCLK 配置未读。
- **MDBT50Q Ver.B** 是 2018 年文档；新版本可能改参考电路/集成方式。引用时必须带版本/页码；不能把 Ver.B 的“必须外接 32.768 kHz”当成所有 MDBT50Q 变体的永久结论。
- **本稿没有做任何实物测量/仿真/温度/湿度/EMC/老化**；所有“通过”都是计算或读图层面的，不是本板实测。`[未执行]` 必须保留。

### 10.3 不能证明的事

- 不能证明某块具体板“起振可靠/频偏合格/抖动合格”，除非有该板的 Sf、Vpp、ppm、抖动、温度数据。
- 不能证明“照抄参考设计”就通过：CL/Cs/晶体批次/布局/探头都会变。
- 不能证明“有源晶振一定比晶体好”：功耗、成本、抖动、电平、OE 行为都是条件。
- 不能证明“模组有晶体就万事大吉”：32.768 kHz、LFCLK 源、参考电路版本都要核对。
- 不能把典型值/教学算例当保证值；不能把仿真当实测；不能把 DRC 当电气通过。

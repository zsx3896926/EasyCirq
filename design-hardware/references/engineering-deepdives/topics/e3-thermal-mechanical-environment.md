# E3 热设计与机械环境：外壳、气流、安装与邻近热源如何改变热路径

> **一句话用途：** 当热问题不是“芯片自身的 Rθ 不够”，而是装进外壳、压上导热垫、拧上散热器、旁边有 0.5 W 热源、风扇被滤网堵住，或者电池、触摸面、温度传感器靠近热源时，用本文把机械与环境变量落到位号、网络、页码和算例。
>
> **适用：** 密封/通风外壳、自然对流/强制风冷、导热垫/灌封/散热器安装、电池与触摸表面附近、温度传感器布置、连接器与线束的热耦合、海拔与安装方向、热循环/CTE 的边界判断。
>
> **不适用：** 具体电芯的热失控/滥用试验、安规认证、长期可靠性 qualification、液冷/热管/均温板设计、IC 内部热仿真、CFD/FEM 的结论签核。本文只给板级/系统级的一阶筛查和证据要求，不替代这些专门工作。
>
> **证据：** `【原厂】` 指原厂数据手册/应用笔记/官方文档（页码/章节来自 [thermal/sources.md](../../thermal/sources.md) 的已读记录，或文末列出的官方网页）；`【文件】` 指可直接复查的开源图纸位号/网络/行号；`【作者记录】` 指仓库 CHANGELOG/设计说明；`【构造算例】` 是为说明方法编造的条件，不对应具体板；`【推断】` 是工程推断，需实测；`【未执行】` 表示本次没有仿真或实测。
>
> **与现有内容的关系：** 不重复 [thermal/topic.md](../../thermal/topic.md) 的 Rθ 指标定义、JEDEC 测试板讨论和公式推导；不重复 [thermal/cases.md](../../thermal/cases.md) 的 C01–C11 算例。本文只补“机械/环境如何改变热路径”，并把每条结论落到位号、网络、页码或参数。器件级参数步骤仍看 [PWR-01](../../design-cards/power/p01-ldo.md)、[PWR-02](../../design-cards/power/p02-buck.md)、[DRV-05](../../design-cards/drive/d05-h-bridge.md)、[DRV-08](../../design-cards/drive/d08-heater.md)；组合接口看 [module-integration.md §12](../../module-integration.md)；测量方法看 [simulation-measurement.md §5/§8](../../simulation-measurement.md)。

## 0. 什么时候需要，什么时候不需要

### 0.1 必须做机械/环境热复核的触发条件

下表阈值是工程筛选值，不是标准条款；项目应按自身安全/可靠性要求调整。

| 触发条件 | 为什么不能只看器件 Rθ | 先交付什么 |
|---|---|---|
| 板子装进密封或半密封外壳，总功耗 > 1 W（示例阈值，不是标准） | 器件看到的是壳内空气/邻热源温度，不是外部环境；外壳表面又是一段附加热阻 | 壳内空气温度测点、外壳表面积、表面温升预算、最热器件清单 |
| 有电池，且充电器/功率管/电机驱动在电池附近 | 电芯的充放电温度窗口通常比芯片窄；NTC 贴在 PCB 上会滞后于电芯本体 | 电芯与热源距离、NTC 实际贴装位置、充电/放电温度门限 |
| 用户可触摸表面靠近功率器件 | 触摸限值按产品标准、材料、接触时间定义，不是 Tj；外壳不烫也可能内部超限 | 触摸面材料/面积/位置、表面温度实测计划、适用标准条款 |
| 温度传感器/热敏电阻靠近 MOSFET、LDO、电感、背光 | 传感器测到的是“局部板温 + 邻热源”，不是目标器件结温 | 传感器位号、网络、ADC 通道、热耦合路径、校准方法 |
| 使用导热垫、导热膏、相变材料、灌封胶、散热器或金属壳 | 界面热阻、压缩量、平面度、安装压力会主导结果；datasheet 的 RθJC 可能不是瓶颈 | TIM 型号/厚度/k/压缩率、接触面积、紧固方式、目标压力 |
| 有风扇、滤网、风道，或安装在密闭机箱/机柜内 | 风扇工作点由 PQ 曲线与系统阻抗交点决定；滤网/灰尘/海拔会让风量下降 | 风扇型号/PQ 曲线、进/出风口、滤网、海拔、堵转/失效状态 |
| 海拔 > 1000 m，或产品会经历高低温/热循环 | 空气密度下降使对流变差；热循环/CTE 失配会引入焊点/器件应力 | 海拔、安装方向、循环剖面、材料 CTE、验收准则 |
| 连接器/端子/线束承载 > 1 A，或靠近功率器件 | 接触电阻、端子降额、铜箔窄颈、邻近热源会叠加；额定电流不是单值 | 触点电流、接触电阻、线规、降额曲线、端子温度测点 |
| 使用铝基板/MCPCB、厚铜、埋铜块、press-fit 或大面积灌封 | 叠层/介电层/CTE 与 FR4 不同；热路径和机械应力都变了 | 叠层图、介电层热阻、铜厚、CTE、安装/紧固约束 |

### 0.2 可以不按本文展开的条件

- 板子在开放台面、自然对流、无外壳，且最热器件估算温升 < 20 K、对限值有 > 20 K 余量（示例值，按项目规定调整）。
- 总功耗 < 0.1 W，且没有电池/触摸/传感器/连接器热耦合。
- 只做封装比较或早期选型，不声称“实际板通过”；此时可按 [thermal/topic.md](../../thermal/topic.md) §2 使用 datasheet 指标，但结论只能写“有条件”。
- 器件有厂商完整系统热模型且已在本项目条件下校准；即便如此，也要保留测量复核点。

### 0.3 本文不能替代什么

- 不能替代电芯 datasheet、BMS 保护/热失控设计、UN38.3/IEC 62133-2 等电池安全试验。
- 不能替代 IEC 62368-1、ISO 13732-1、IEC 60601-1 等触摸/安规标准的条款判断；本文不给通用触摸温度数字。
- 不能替代 IPC-9701、JESD22-A104、IEC 60068-2-14 等热循环/温度变化试验；本文只给“什么时候需要做”和“需要哪些输入”。
- 不能替代 CFD/FEM 的网格无关性、收敛和边界条件校准；仿真通过不等于样机通过。
- 不能把“外壳不烫”“室温跑了 10 分钟”“DRC 通过”当作 Tj 证据。

### 0.4 阅读顺序

固定顺序：**机械包络（外壳/安装/风道）→ 总功耗与最坏工况 → 主热路径（板/壳/散热器）→ 界面材料与紧固 → 环境（海拔/方向/邻热源）→ 计算/仿真/测量 → 判定与未验证项**。反过来先选散热器或先加风扇，通常会在“界面没压紧”或“壳内空气已经 70 °C”上返工。

## 1. 必须先知道的条件

| 条件 | 为什么必须知道 | 缺失时怎么办 |
|---|---|---|
| 外壳外形尺寸、表面积、材料、表面处理、壁厚 | 表面温升按可换热面积算；涂装金属/非金属/未涂装铝的辐射特性不同 | 阻断表面预算；先按六面面积并扣除靠墙面，标“待按结构图核对” |
| 通风口位置/面积、滤网、防水防尘等级 | 自然对流需要进/出风口形成路径；滤网会随灰尘退化 | 无结构图则按密封壳保守算，标“未验证” |
| 安装方向、靠墙面、周围障碍物、太阳/热源辐射 | 自然对流方向影响 h；靠墙面不能按全表面积算 | 记录方向；按最差方向做敏感性 |
| 总功耗及分布（最坏同时工作） | 外壳表面温度和壳内空气温度由总功耗决定，不是单个器件 | 列热源表；缺最坏工况则不能判定 |
| 每个热源的 Tj/Tc/触摸/电池/传感器限值 | 这些不是同一个限值；混用会把“功能正常”当“安全” | 查具体型号/标准；缺失项标“待核” |
| 主热路径：PCB 铜/平面/热焊盘/过孔/TIM/散热器/外壳 | 选错路径会得到完全错误的 Tj；datasheet RθJA 可能不适用 | 读封装/布局指南；没有资料时按最保守路径并标“待核” |
| TIM 型号、厚度、k、压缩率、硬度、介电强度、老化 | `RθCS` 由厚度/面积/压力/接触热阻决定，不是只看 k | 阻断界面结论；按型号 datasheet 或实测 |
| 散热器 RθSA、安装压力、平面度、紧固扭矩 | 散热器数据手册的 RθSA 有测试条件；安装不好会使串联链失效 | 无数据则只用一阶筛查，标“待测” |
| 风扇 PQ 曲线、系统阻抗、转速/噪声、寿命、堵转检测 | 风扇不是“h=100”的同义词；工作点偏移会大幅改变风量 | 无 PQ 曲线则不能证明风冷足够 |
| 环境温度 Ta 的定义和测点（进风口/器件下方/壳外） | 不同标准的 Ta 测点不同；壳内 Ta 不是壳外 Ta | 写明测点；没有测点则结论只能“有条件” |
| 电池化学体系、容量、充放电温度窗口、NTC 曲线/位置 | 电芯窗口通常比芯片窄；NTC 贴 PCB 会滞后 | 查电芯 datasheet/BMS；缺失则阻断电池结论 |
| 触摸面材料、接触时间、适用产品标准 | 触摸限值随材料/时间/标准变化，不能用一个数字套所有产品 | 查标准条款；本次未取得正文的标“待核” |
| 温度传感器目标、安装方式、响应时间、自热 | 传感器测的是自身温度；安装位置/导热胶/气流决定读数 | 记录位号/网络/ADC；无数据则标“未验证” |
| 连接器/端子型号、触点电流、接触电阻、线规、插拔次数 | 额定电流是“电流+温升+环境+线规”的组合；多针同时通电要降额 | 查系列 datasheet；没有则按保守假设并实测 |
| 热循环剖面：温度范围、斜率、驻留、循环数、失效判据 | 没有剖面就没有“通过”的定义；CTE 失配只给边界 | 查产品标准/历史数据；缺失则标“未定义” |

**可以用带条件假设继续的：** 外壳 h（先按 5–10 W/m²K 做敏感性，标“构造假设”）、TIM 接触热阻（先按 0 并另做 +1/+2 K/W 敏感性）、邻热源耦合（先按共享铜 1D 估算，标“上界”）。**不能假设的：** 电芯温度窗口、触摸标准限值、连接器降额曲线、风扇 PQ 曲线、TIM 的 k/厚度/压缩率、散热器 RθSA 的测试条件。

## 2. 最容易被忽略的机制

### 2.1 外壳不是“环境”，而是一段串联热阻

密封外壳里，器件看到的不是外部 Ta，而是壳内空气/邻热源温度；热量还要从壳内空气到壳壁、再从壳壁到外部环境。外部表面预算只约束**外壳表面**，不含内部空气到壳壁的热阻、热点、通风、太阳负载和海拔。

一阶算例（`【构造算例】`，沿用 [thermal/topic.md](../../thermal/topic.md) §7.2 的表面模型，不重复推导）：`P=1 W`、`A=0.02 m²`、`h=5 W/m²K`：

```text
ΔT_surface = P/(h·A) = 1/(5×0.02) = 10 K
```

若外部 Ta=40 °C，则表面约 50 °C。这个 10 K 只是“壳壁到外部空气”的一段；壳内空气到壳壁、器件到壳内空气还会再加。`h=3` 时 16.7 K，`h=10` 时 5 K——h 的假设直接决定结果，所以必须写清外壳材料、方向、通风和海拔。`【原厂】` Cree 给出自然对流空气约 5–20 W/m²K、粗算可用 10 W/m²K，强制风冷可高到 100 W/m²K（S10 第 5 页）；这些是量级，不是你的外壳保证值。

`【原厂】` nVent 对密封电气柜的做法可以借方法、不能借数字：表面积按六个面计算，靠墙等不能换热的表面要扣除，不能用体积代替面积；示例 300 W/42 ft²/7.1 W/ft² 读得约 30 °F（16.7 °C）；建议保留 25% 安全裕量；内部循环风扇最多改善约 10%；图表是平均温升，局部热点可能更高（S22 第 1–2 页）。这些面向大型电气柜，不是小型 PCB 密封盒；但“扣除不可换热面、留裕量、热点高于平均”三条通用。

**判定纪律：** 外壳表面温度不是 Tj，也不是壳内空气温度；外壳不烫不能证明内部器件不超限。反之，外壳烫也不一定代表 Tj 超限，可能只是表面面积小/涂层辐射差。

### 2.2 气流：风扇工作点、风道和失效状态，不是“加个风扇”

风扇的风量由**风扇 PQ 曲线与系统阻抗曲线的交点**决定；滤网、百叶、狭窄风道、进出风口错位、热空气回流都会让工作点左移。风扇标称的“最大风量”是自由送风，不是装进你的外壳后的风量。

- `【原厂】` Advanced Energy 的自然对流电源指南：底板朝下或侧壁安装通常较好，侧壁因烟囱效应最佳，倒装应避免；密封盒内放置电源可能导致热失控，必须提供冷空气进入的通风；风扇常是首先失效的部件（S25 第 2–3 页）。这是电源产品经验，不是所有外壳的通用规则。
- `【原厂】` nVent：进风口宜在侧面靠近底部，出风口在对侧靠近顶部，出风口面积至少等于进风口；海拔升高使空气密度下降，应增加通过外壳的空气流量（S22 第 5 页）。
- `【原厂】` nVent 白皮书：所需风量可用 `V=3.1·Qv/ΔT`（m³/h、W、K）估算，但这只适用于其电气柜语境；表值是特定外壳在 ΔT=20 K 下的散热功率，不能跨产品套用（S23 第 3、6–12 页）。
- `【原厂】` ODrive 官方文档：FET 与电机是两个独立热区；温度超过 `temp_limit_lower` 后电流限制逐渐下降，到 `temp_limit_upper` 为 0 A；再高 5 °C 退出 `CLOSED_LOOP_CONTROL` 并报 `INVERTER_OVER_TEMP`/`MOTOR_OVER_TEMP`；`<fan>` 模块用滞环控制，且官方写明风扇模块是 ODrive Pro 的功能（ODRIVE-DOC）。这说明“风冷”在固件里是状态机，不是只装一个风扇。

**检查点：** 风扇是否有堵转/转速回读？滤网堵塞后是否有温度降额？风扇失效时负载是否降额/关断？进出风口是否被线束/电池/外壳筋挡住？风扇噪声/寿命/MTBF 是否可接受？这些都比“风扇尺寸”更常决定现场是否过热。

### 2.3 安装与界面：导热垫的 3.3 K/W 只是起点

`【构造算例】` 用 [thermal/topic.md](../../thermal/topic.md) §6.4 的 `RθCS≈t/(k·A)`（不重复推导）：导热垫厚 `t=1 mm`、面积 `A=1 cm²=1×10⁻⁴ m²`、`k=3 W/mK`：

```text
RθCS = 1×10⁻³/(3×1×10⁻⁴) = 3.33 K/W
```

同样面积下：0.5 mm → 1.67 K/W；2 mm → 6.67 K/W；k=1 W/mK、1 mm → 10 K/W；k=6 W/mK、1 mm → 1.67 K/W。这个公式**不含接触热阻**：实际界面有微观空气隙、表面粗糙度、平面度、压力不足、老化/泵出，都会在 3.33 K/W 上再加。若有效接触面积因翘曲只剩 50%，同一厚度下面积热阻翻倍到 6.67 K/W；若再加 1 K/W 接触热阻，1 W 下就是 4.33 K/W。

`【原厂】` MNT Reform 2 的官方手册写明：散热器是一块铣削铝件，通过导热垫接触 Processor Module 上 SoC 的 die，用四颗 M2×12 螺钉固定，螺钉下有四个金属或塑料垫柱（MNT-HW，Heatsink 节）。这四个螺钉/垫柱就是“安装压力/平面度/PCB 翘曲”的实际约束：拧紧顺序、垫柱高度、PCB 刚度都会改变导热垫压缩量。`【原厂】` MNT 的设计说明还明确：为 i.MX8M 开发了定制铝散热器，使 Reform 可以完全被动冷却，不需要风扇（MNT-BLOG）。所以 MNT Reform 2 的 stock 形态是**无风扇**；社区加装风扇是改装，不是原设计。

`【作者记录】` ODrive v3.5 CHANGELOG 也能看到机械对热路径的反向影响：v3.2 “Adjust heatsink holes”；v3.3 把 LDO 和 C29 翻到背面，理由是“为顶面留出 enclosure style heatsinking 的间隙”（CHANGELOG.md:70、:51）。这不是电气优化，而是为了让散热器/外壳能压到功率级上。`【文件】` ODrive v3.5 原理图第 4 页还有 `Thermal Pad`（U6 第 9 脚）标注（schematic_v3.5.txt:2524），说明热焊盘是原理图/封装契约的一部分，不是 PCB 事后补铜。

### 2.4 邻近热源：0.5 W 在 20 mm 处可以是几十 K

`【构造算例】` 用 [thermal/topic.md](../../thermal/topic.md) §6.5 的 `ΔT_local≈P_neighbor·R_path`，把共享铜皮当成 1D 导热条：`R_path=L/(k·W·t)`，铜 `k=385 W/mK`，`L=20 mm`，`W=20 mm`，`t=35 µm`（1 oz）：

```text
R_path = 0.02/(385×0.02×35×10⁻⁶) = 74.2 K/W
ΔT     = 0.5×74.2 = 37.1 K
```

同样 20 mm 距离：双层 1 oz 并联 → 18.5 K；双层 2 oz（70 µm/层）→ 9.3 K；单层 1 oz、铜宽 10 mm → 74.2 K；单层 1 oz、铜宽 50 mm → 14.8 K。这个 1D 条模型忽略横向扩散、对流和辐射，是“沿共享铜路径”的量级上界/筛查，不是精确温度；但它足以说明：**0.5 W 的邻热源在 20 mm 处可以产生几十 K 的局部温升，可能比 1 W 主热源的界面热阻更大。** 温度传感器、电芯、电解电容、晶体、高阻模拟节点不要放在这条共享铜路径上；如果必须靠近，要做开槽/隔离/独立铜岛，或实测。

`【原厂】` TI 也明确：多个热源共享铜/外壳时，各自的 Ta 不是外部环境，而是局部环境；把邻热源功耗计入（S01 第 12 页的 ambient 定义与第 10–11 页的 ΨJB 讨论）。`【文件】` ODrive 每个 MotorCell 用 12 颗 NTMFS4935NT1G（第 2–3 页各 12 颗），多颗功率管相邻布置，本身就会互相加热；第 2–4 页各有 `TEMP` 网络，三组 10 kΩ/3.3 kΩ 分压：R12/R13、R31/R35、R49/R50（schematic_v3.5.txt:1360-1361、:2036-2037、:2543-2544）；它读到的是该网络/板面附近温度，不是每颗 die 的结温。这也是为什么“壳内空气温度”与“器件结温”必须分开测。

### 2.5 灌封/三防漆：可能是散热，也可能是保温

灌封胶/三防漆改变三件事：导热路径、热容、机械应力。导热灌封胶可以把器件热量传到外壳/金属件，但低导热灌封胶也会把热“包”在局部，让原本靠空气对流的表面失去对流；灌封还会增加热质量、改变 CTE 失配、妨碍返修，并在热循环中把应力传到焊点/器件本体。

`【原厂/边界】` [thermal/topic.md](../../thermal/topic.md) §7.6 把 TIM/隔热材料、灌封、CTE/热机械列为超出板级一阶模型的主题：需要按具体材料核对 k、厚度、硬度/压缩率、介电强度、UL94、温度范围、可返修性、老化/泵出/干燥；隔热与导热是两类材料，不能混用。本文不重复这些参数，只给判断顺序：

1. 先问“灌封是为了导热、绝缘、防水还是机械固定？”四个目标的最优材料不同。
2. 若为了导热：确认热源到外壳的路径上没有低 k 厚胶层；必要时用导热垫/导热柱替代厚灌封。
3. 若为了防水/绝缘：接受热阻代价，重新算 Tj；不要用“灌封了就更可靠”跳过温度。
4. 若为了机械：评估 CTE/模量对焊点、连接器、大陶瓷电容的应力；热循环试验另行定义。
5. 任何灌封方案都要有返修/失效分析方案；否则现场无法定位。

### 2.6 连接器与线束：既是热桥，也是降额点

连接器的金属触点/外壳会把 PCB 的热传到线束，也会把线束/环境的热传回 PCB；触点接触电阻产生 `I²R` 热，塑料壳体在高温下软化/蠕变，端子保持力下降。`【文件】` MNT Reform 电池包 PCB 只有 4 个 Keystone 54 18650 支架和一个 5-pin Molex Pico-Lock 连接器，PCB 为 1.6 mm 双层、6 个网络（reform2-batterypack.kicad_pcb:4、:8–9、:1151/1206/1261/1316、:1451）；电池包本身没有温度传感器网络。`【文件】` [E4](e4-connector-long-term-reliability.md) §4.4 已核对 VESC `V_SUPPLY` 的走线宽度分档（5.08/2.286/1.27/1.016/0.635 mm 等），最窄段决定压降/温升；不要用最宽段代表整条路径。连接器/端子/铜箔窄颈的完整链路、降额算法和排查顺序见 E4，本文只补热耦合：**端子的温升 = 自身 I²R + PCB 铜传热 + 邻近器件/环境**，摸起来热不一定是接触电阻大。

### 2.7 海拔 2000 m：定性修正，不编造精确系数

`【原厂】` TI 的 RθJA 海拔倍率表：3000 ft 1.1、5000 ft 1.14、7000 ft 1.17、8350 ft 1.2（S01 第 5 页）；并说 8000 ft 约热 20%。2000 m ≈ 6562 ft，落在 5000–7000 ft 之间；按表线性插值约 `1.14 + (6562−5000)/2000×0.03 ≈ 1.16`。这只是把 TI 表的 RθJA 倍率借来做量级代理，**不是**对 h 的精确修正，也不是标准强制系数。

定性上，2000 m 的空气密度下降，自然对流 h 变差，风扇的质量流量下降（同样体积流量下冷却能力变差）；如果产品靠自然对流或滤网风扇，必须按厂商海拔降额/实测，不能直接用海平面曲线。海拔还涉及爬电距离/电气间隙/安规，和热是两条独立的检查线；不要用热结论替代安规。

### 2.8 电池、触摸表面、传感器附近的限制

**电池：** 电芯的充电/放电温度窗口通常比芯片窄；充电器/功率管/外壳要一起布置，不要把电池当散热器。`【原厂】` BQ2407x 的 NTC 例子：TS 脚偏置电流 75 µA（typ），高温门限 `VHOT=300 mV`（下降触发，迟滞 30 mV），低温门限 `VCOLD=2100 mV`（上升触发，迟滞 300 mV），TS 故障去抖 50 ms；配合 Vishay Type 2 曲线 NTC 时对应 0 °C/50 °C、3 °C 迟滞（PWR-S07，§6.5/§9.3.6）。这是**该充电器 + 该 NTC 曲线**的例子，不是所有电池的通用窗口；放电温度、倍率、热失控、冷充电要查电芯 datasheet/BMS 标准。NTC 应贴电芯本体/靠近电芯，不是贴在充电器 PCB 上；否则充电器自身发热会让 NTC 提前降流，而电芯实际还没热。

**触摸表面：** 按产品类型/地区/接触时间/材料查适用标准（例如 IEC 62368-1、ISO 13732-1、IEC 60601-1 等；本轮未取得正文）。本文不给通用温度限值，也不把“外壳 50 °C”直接判为合格/不合格；必须用实测表面温度 + 标准条款。`【原厂】` nVent 的“10 K 温升使元件寿命减半/失效率翻倍”是电气柜语境的经验说法（S23 第 3 页），不是触摸限值，也不能套到所有器件。

**传感器：** 温度传感器测的是自身温度，受安装位置、导热胶、气流、邻热源、自热影响；NTC/RTD 的激励、分压、自热和线性化见 [ANA-10](../../design-cards/analog/a10-rtd-thermistor.md)。`【文件】` VESC 原理图把 `TEMP_MOTOR` 与 `ADC_TEMP` 分成两个层次引脚（BLDC_4.sch:1246、:1266），说明电机温度与板载温度不是同一个测点；具体 NTC/分压在未包含的 `temp.sch` 中，待核对。`【原厂】` ODrive 官方文档把 inverter 与 motor 作为两个独立热区，分别限流（ODRIVE-DOC）；这也说明“一个温度传感器管全板”通常不成立。

### 2.9 热循环/CTE：只给边界，不冒充可靠性认证

热循环/CTE 失配的边界条件：

- **需要做**：大尺寸陶瓷电容、BGA/CSP、QFN 热焊盘、THT 大端子、press-fit、灌封、铝基板/厚铜、连接器与 PCB 的 CTE 差异大、温度循环跨度大/斜率快/循环数多。
- **需要输入**：温度范围、升温/降温斜率、驻留时间、循环数、通电/断电状态、失效判据（电阻漂移、空洞、裂纹、漏气、接触电阻）、样本数。
- **需要标准/方法**：IPC-9701（焊点热循环）、JESD22-A104（温度循环）、IEC 60068-2-14（温度变化）；本轮未取得正文，不引用具体条款/数值。
- **不能做**：用一次高低温“跑通”代替 qualification；用 datasheet 的 CTE 单值代替实际叠层/工艺；用仿真代替焊点疲劳试验；把“没裂”当“寿命足够”。

CTE 失配的一阶量级可以用 `Δε≈Δα·ΔT` 估算（`【构造算例】`，假设值仅演示）：若两种材料的面内 CTE 差 5 ppm/K、ΔT=100 K，则应变差约 `5×10⁻⁶×100=5×10⁻⁴`（0.05%）；差 15 ppm/K 则约 0.15%。这个数只说明“有失配”，不能直接判焊点寿命；实际焊点形状、IMC、空洞、循环剖面都会改变结果。本文不给“多少 ppm 一定可靠”的结论。

### 3.2 充电器 NTC/TS 的逐项检查

1. **NTC 曲线是否匹配门限**：BQ2407x 的 300/2100 mV 门限配 Vishay Type 2 时是 0/50 °C；换 NTC 曲线（beta/阻值）后，同样的电压门限对应不同温度。不能只抄“0/50 °C”而不核对曲线。
2. **偏置电流是否把 NTC 自热算进去**：75 µA 在 10 kΩ 上约 0.75 V，自热 `I²R` 约 56 µW——通常很小，但高阻 NTC/小珠径要核对。
3. **开/短路行为**：NTC 开路时 TS 被拉高/拉低，充电器是停充还是继续充？BQ2407x 的 TS 故障有 50 ms 去抖；具体行为查手册。不要假设“NTC 坏了会安全停充”。
4. **NTC 贴装位置**：贴电芯本体/电池包内，不是贴充电器 PCB；引线/导热胶/绝缘要固定，避免热滞后和开路。
5. **充电器热调节与 NTC 的交互**：BQ2407x 在 `TJ(REG)=125 °C` 减流、`TJ(OFF)=155 °C` 关断输入 FET；NTC 的 50 °C 门限可能先触发，也可能被充电器自身发热提前触发。要同时记录 TS 电压、充电电流、PCB 温度。

### 3.3 风扇/风道的原理图检查

- **默认态**：MCU 复位/掉电时风扇是开还是关？PWM 脚浮空是否导致全速/停转？TACH 上拉是否到正确电源？
- **供电**：风扇是 5 V/12 V/24 V？启动电流/堵转电流是否超过供电/驱动？是否有反接/浪涌保护？
- **控制**：PWM 频率是否在风扇允许范围？是否有最低占空比/启动占空比？滞环上下限是否可配置（ODrive `<fan>.upper/lower`）？
- **失效**：TACH 丢失/堵转时，固件是否降额/关断/报警？滤网堵塞是否只表现为转速正常但风量下降（TACH 测不到）？
- **结构**：风扇与散热器距离、进出风口、回流短路、线束阻挡；这些在原理图上看不到，必须看 3D/实物。

### 3.4 热焊盘/EPAD 的网络检查

- `【原厂】` TI 明确：裸露焊盘（EPAD/thermal pad）必须焊到 PCB 热焊盘；PowerPAD 不是设计成不焊接使用的（S02 第 3 页）。原理图上热焊盘不能浮空，通常接 GND/PGND 或专用散热网络；要确认 net tie/星点，避免把功率地噪声注入敏感地。
- ODrive `Thermal Pad` U6 第 9 脚是栅极驱动器的热焊盘，不是功率 MOSFET 的漏极；不要看到“Thermal Pad”就当成主功率热路径（schematic_v3.5.txt:2524）。
- 对 QFN/DFN，热焊盘下的过孔/铜区要在 PCB 上连续连接到内层/底层平面；原理图只能确认“接了什么网”，不能确认“焊了多少/有没有空洞”。后者看 PCB 和 X-ray。

### 3.5 状态表：正常/过热/传感器故障/风扇故障

| 状态 | 触发 | 期望行为 | 要验证的证据 |
|---|---|---|---|
| 正常 | 温度 < 降额门限 | 全性能；风扇按滞环启停 | 温度读数、风扇 TACH、负载电流 |
| 过热降额 | 温度 > `temp_limit_lower` | 电流逐渐下降，到 `temp_limit_upper` 为 0 A | 降额曲线、实际电流、温度 |
| 过温关断 | 温度 > `temp_limit_upper`+5 °C | 退出闭环，报 `INVERTER_OVER_TEMP`/`MOTOR_OVER_TEMP` | 故障码、恢复条件 |
| NTC 开路 | TS 电压越界 | 停充/降额/报警（按器件） | TS 电压、充电电流、故障标志 |
| NTC 短路 | TS 电压越界 | 同上 | 同上 |
| 风扇堵转 | TACH 丢失/电流异常 | 降额/关断/报警 | TACH、风扇电流、温度趋势 |

| 电池过温 | 电芯 NTC 超限 | 停充/放电限流 | 电芯温度、TS 电压、BMS 状态 |

### 3.6 加热器/热电制冷的边界

加热器控制（DRV-08）与本文的热路径是两件事：加热器是**故意**把热注入目标，不是“散热”。检查默认关断、看门狗、保险丝/热熔断、温度反馈独立性、传感器故障时的最大占空比。本文不重复 DRV-08 的拓扑和参数步骤；只提醒：加热器的热必须和电池/触摸/传感器限值一起看，不能只按“目标温度到了”判通过。

## 4. PCB 检查：回路、位置、参考平面、热路径

### 4.1 先画热路径，再谈铜面积

对每个热源画三条路径：

```text
路径 A（板主导）:   Tj → 封装/焊盘 → PCB 铜/平面 → 板面/空气
路径 B（壳/散热器）: Tj → RθJC → TIM/导热垫 → 外壳/散热器 → 外部空气
路径 C（邻热源）:   邻热源 → 共享铜/壳内空气 → 传感器/电池/连接器
```

先判断哪条是主路径：塑料封装无散热器通常板主导；有外露焊盘 + 散热器通常壳/散热器主导；密封小盒且没有 TIM 时，壳内空气可能主导。选错路径，后面算得再细也没用（见 [thermal/topic.md](../../thermal/topic.md) §2.5 的三电阻模型和 §4.1 的路径选择）。本文不重复 Rθ 指标定义。

- 铝基板/散热器问题：本仓库没有铝基板叠层证据，也没有散热器机械件；`【推断】` 某些 VESC 变体/第三方设计可能用 MCPCB 或铝散热器，但必须按具体版本/BOM/叠层/机械图核对（待按型号核对）。`【原厂】` Cree 的 MCPCB 对比（S11 第 3–4 页）说明铝/金属芯板在特定 LED 测试板上可把厚向热阻从 FR4 的约 30 °C/W 降到约 0.2 °C/W，但那是特定尺寸/热源/介质，不能直接套到 VESC 的 D2PAK/多层功率板。
- `【推断】` 如果某个 VESC 变体确实是铝基板/金属芯板，热路径会从“漏极焊盘 → FR4 铜/过孔 → 空气”变成“漏极焊盘 → 薄介电层 → 铝芯 → 散热器/外壳”；瓶颈随之转为介电层厚度/k、铜箔-铝芯的绝缘耐压、铝芯与散热器的接触/平面度。此时 `RθJC=0.40 K/W` 只描述 die 到封装壳，不能代表“die 到铝芯/环境”；必须按叠层图、介电层参数、TIM、安装压力和实测重新算。不能因为“铝基板”三个字就认为系统热阻自动变好。

### 4.3 热焊盘、过孔、焊接

- `【原厂】` TI PowerPAD：热焊盘必须焊；建议最小焊接面积 50% 封装热焊盘面积，标准工艺通常 >80%，X-ray 检查空洞（S02 第 3、12 页）。AN-1520 的 FEA：焊料覆盖从 100% 降到 50/20/10/5%，θJA 约增加 4/13/19/34%；10% 是临界点（S18 第 12 页）。这些是特定封装/模型，不是通用阈值，但说明“少量焊料”不能当满焊。
- `【原厂】` SLVAE85A 的 LDO 实测给出同一器件换板的量级：TPS745 WSON 从 1S0P 的 169.2 °C/W 降到热增强布局的 46.8 °C/W，TO-252 从 91.2 降到 26.8，SOT-23 从 227 降到 108（S05 第 8–10 页；4 层 9 in²、外层 2 oz/内层 1 oz、静止空气）。这说明“机械/铜/层数变了，datasheet 的 RθJA 就不再是同一个数”；具体比例不能套到你的板。
- 热过孔的数量/孔径/镀层/塞孔方式按具体 datasheet 和板厂；1D 孔壁热阻、扩散热阻、界面热阻的算法已在 [thermal/topic.md](../../thermal/topic.md) §6.2 和 [thermal/cases.md](../../thermal/cases.md) C06 给出，本文不重复。这里只补机械检查：过孔是否被焊料吸走、是否有空洞、热焊盘是否与内层平面连续连接、是否有 thermal relief（热过孔不应使用车轮连接）。
- 对 D2PAK/DPAK 等“漏极焊盘就是散热面”的封装，焊盘下方的铜面积/层数/铜厚比“过孔数量”更常是瓶颈；`【原厂】` Infineon D2PAK 测试：总漏极铜面积 <3S（202.35 mm²）时加层/加铜厚显著，>3S 后减弱；散热器只在铜面积 <2.7S（182.12 mm²）时才值得考虑（S19 第 12、19–21 页，特定 TO-263/0.3 A/自然对流条件）。这个阈值不能直接套 VESC/ODrive，但“先加铜、再考虑散热器”的顺序有参考价值。

### 4.4 布局与机械位置

- **温度传感器**：远离 MOSFET/LDO/电感/背光/电池充电器；不要放在共享散热铜上；必要时开槽/独立铜岛；传感器与目标表面之间用导热胶/金属面接触，不要隔空气隙。
- **电池**：远离充电器、功率管、DC/DC、发热连接器；不要放在散热器出风路径上；电池与外壳之间留隔热/缓冲；NTC 贴电芯。
- **连接器**：远离热源；大电流端子不要紧贴温度传感器；端子/线束的弯折半径和应力释放要留；密封连接器可能把热封在壳内。
- **风道**：进风口远离出风口/热空气回流；风扇前后留足够空间；滤网可拆换；线束不要挡风；风扇故障时是否有自然对流旁路。
- **安装/结构**：散热器螺钉/垫柱不要压在 PCB 薄区/连接器上；考虑 PCB 翘曲、螺钉扭矩、垫柱高度、导热垫压缩量；MNT 的四颗 M2×12 + 垫柱就是实例（MNT-HW）。ODrive 的 heatsink holes/顶面 clearance 说明结构件会反过来约束器件布局（CHANGELOG.md:70、:51）。
- **参考平面**：功率地 `PGND/DC_BUS` 与敏感 `AGND/GND` 按 ODrive v3.5 的分层处理（CHANGELOG.md:4–6）；散热铜如果接 PGND，不要把敏感模拟地/传感器地直接连上去；net tie 位置要在原理图/PCB 上可查。

## 5. 方案与取舍（至少 3 种）

### 5.1 热路径方案

| 方案 | 典型结构 | 优点 | 代价/限制 | 适用条件 | 故障行为 |
|---|---|---|---|---|---|
| PCB 铜/平面主导 | 热焊盘 + 多层铜/过孔，无散热器 | 成本低、无额外零件、可靠性高 | 受板面积/层数/铜厚限制，收益会饱和；datasheet RθJA 不适用 | 低功率、空间小、密封且热阻核算有余量（按项目） | 局部热点、板面变色、焊点热疲劳 |
| 导热垫/导热膏到金属壳 | 器件 → TIM → 铝壳/机壳 | 路径短、外壳兼作散热器、可密封 | 需要压力/平面度/绝缘；外壳触摸温度可能超限 | 手持/密封小盒、中低功率（按热阻核算） | 垫片压缩不足/老化 → 热阻上升 |
| 外置散热器 + TIM | 器件 → 热焊盘 → TIM → 铝挤/压铸散热器 | RθSA 可控、可更换、适合较高功率 | 体积/重量/成本；需要安装孔/压力；灰尘 | 中高功率、自然对流或风扇（按 RθSA 核算） | 螺钉松动/界面干涸 → 热点 |
| 铝基板/MCPCB | 器件直接贴金属芯/介电层 | 厚向热阻低、横向扩热好 | 单面/层数少、成本高、CTE/绝缘/加工限制 | LED/功率模块/简单大电流板 | 介电层击穿/热循环裂纹 |
| 强制风冷 | 散热器 + 风扇/风道 | h 可到 100 W/m²K 量级，功率密度高 | 噪声、灰尘、风扇寿命、海拔、滤网 | 高功率密度、可维护 | 风扇堵转/滤网堵 → 温度飙升 |
| 灌封/导热胶 | 器件/PCB 灌封到外壳 | 导热+绝缘+防水+机械固定 | 可能保温、CTE 应力、不可返修 | 户外/坚固/高湿 | 局部热点、开裂、无法维修 |

**选择顺序：** 先降功耗（拓扑/效率/降额）→ 再缩短热路径（热焊盘/铜/过孔/TIM）→ 再加大面积（散热器/外壳）→ 再加强制风/液冷。不要用风扇去补一个 10 K/W 的界面热阻；也不要用灌封去补一个没有金属外壳的散热路径。

### 5.2 界面材料方案

| 方案 | 典型厚度/特点 | 热阻/代价 | 适用 | 不能证明 |
|---|---|---|---|---|
| 导热垫（gap pad） | 厚度按型号（常见 0.5–3 mm，待核），可压缩，绝缘 | 1 mm/k=3/1 cm² = 3.33 K/W；厚垫热阻大；需压力 | 大间隙、需绝缘、返修 | 接触热阻/压缩量/老化未算 |
| 导热膏（paste） | 极薄，填微观空隙 | 界面热阻低，但会泵出/干涸/污染 | 平面度好、有夹紧 | 厚度/压力/长期稳定性未知 |
| 相变材料（PCM） | 常温固态，工作温度软化 | 薄、可重复，但需夹紧/温度循环 | 散热器、CPU/功率 | 循环寿命/泵出未验证 |
| 石墨/石墨烯片 | 面内扩热好，薄 | 面内导热高，厚向一般；导电需绝缘 | 热点扩散、薄空间 | 各向异性/电绝缘/接触 |
| 直接金属接触 | 金属-金属，必要时薄膏 | 最低界面热阻，但需平面度/压力/防腐 | 冷板/大散热器 | 实际接触面积/粗糙度未知 |
| 灌封胶 | 填充全部间隙 | 导热取决于填料；可能保温/CTE | 防水/绝缘/坚固 | 局部热点/返修/CTE |

**判定：** 先用 `RθCS≈t/(k·A)` 算一阶，再把接触热阻按 +0.5/+1/+2 K/W 做敏感性；如果界面热阻已经接近 RθJC 或 RθSA，先改界面，不要换更大风扇。

### 5.3 外壳/气流方案

| 方案 | 优点 | 代价 | 适用 | 失效行为 |
|---|---|---|---|---|
| 密封塑料壳 | 便宜、绝缘、IP 易做 | h 低、壳内空气热、无法对流 | 低功耗、室内、电池产品 | 壳内空气逐渐升温 → 降额/关断 |
| 通风塑料壳 | 自然对流好、成本低 | 灰尘/水汽/昆虫、EMI 泄漏 | 室内、非防水 | 滤网/百叶堵 → 过热 |
| 密封金属壳 | 横向扩热、辐射较好、屏蔽 | 触摸烫、重量、防腐/接地 | 中功率、需要屏蔽 | 表面烫/内部热点 |
| 金属壳 + 外置散热器 | RθSA 可控、可维修 | 体积/成本/安装 | 中高功率（按 RθSA 核算） | 界面/螺钉失效 |
| 风扇 + 风道 | 高功率密度 | 噪声、灰尘、寿命、海拔 | 高功率、可维护 | 风扇堵转/滤网堵 |
| 液冷/热管 | 极高功率密度、远距离传热 | 复杂度、泄漏、方向/重力 | 特殊/高功率 | 泄漏/干涸/泵故障 |

`【原厂】` Cree 的 h 量级（自然对流 5–20、强制风 100 W/m²K，S10 第 5 页）只能用于早期筛查；实际外壳的 h 必须由材料/方向/通风/海拔决定。nVent 的 25% 裕量、内部风扇 +10%、进出风口位置（S22 第 1–2、5 页）是电气柜经验，借方法不借数字。

## 6. 怎么判断：计算、仿真、测量、回读

### 6.1 四个层级各自能回答什么

| 层级 | 能回答 | 必要输入 | 不能证明 |
|---|---|---|---|
| datasheet 热阻 | 封装比较、早期筛查、RθJC/Ψ/Zθ 的量级 | 测试板/气流/参考面/功耗条件 | 你的板/外壳/邻热源下的实际 Tj |
| 一阶估算 | 主路径是否明显不够、灵敏度、方案排序 | P、面积、h、TIM、Rθ 链、假设 | 热点/多维扩散/接触热阻/长期 |
| 仿真（FEM/CFD） | 空间梯度、多热源耦合、风道/外壳内流场 | 几何、材料、叠层、TIM、h/辐射、边界条件、网格 | 边界条件正确性、批次/装配差异 |
| 实测 | 实际样机在约定工况下的温度 | 测点、仪器、校准、稳态判据、不确定度 | 全批次/全寿命/所有环境 |

`【原厂】` TI 的立场很清楚：RθJA 是特定测试板上的封装比较指标，静止空气 JEDEC 测量中 70%–95% 的功率从测试板散出；1s 与 2s2p 测试板可差最多 50%（S01 第 2 页）。所以 datasheet 值不能直接当实际板 Tj；要么用系统 `RθJA(effective)`，要么用 ΨJT/ΨJB + 实测，要么用散热器链 + 实测（S01 第 5–11 页）。本文不重复这些公式，只强调：**机械/环境改变的是“测试板条件”之外的路径，所以 datasheet 的适用性必须先判定。**

`【原厂】` 瞬态/脉冲还要看 ZθJC，而不是稳态 Rθ：S08 的 CSD19532Q5B 例子在 1 ms 单脉冲下归一化 Z≈0.17、1 ms/50% 占空比下 Z≈0.56，且 Tc=110 °C 时峰值电流显著低于 Tc=25 °C；文档明确说“Tc 恒为 25 °C”需要无限热沉，实际应按最高 PCB 温度（S08 第 4 页）。这对机械/环境的含义是：外壳/邻热源把 PCB 温度抬上去后，同一脉冲的可用电流会下降；不能拿 25 °C 的瞬态曲线做密封壳内的结论。

### 6.2 完整算例：1 W 密封盒 + 1 mm 导热垫 + 2000 m + 0.5 W 邻热源

`【构造算例】` 条件（全部为假设，不对应具体产品）：

| 输入 | 值 | 说明 |
|---|---:|---|
| 主热源功耗 P | 1 W | 最坏连续功耗 |
| 外壳可换热面积 A | 0.02 m² | 六面扣除靠墙面后的等效面积 |
| 外部自然对流 h | 5 W/m²K | 自然对流+辐射的等效值，构造假设 |
| 外部环境 Ta | 40 °C | 壳外空气 |
| 器件 RθJC | 2 K/W | 假设的封装结到壳 |
| 导热垫 | 1 mm、1 cm²、k=3 W/mK | 构造假设 |
| 接触热阻 | 0（先忽略） | 后续做 +1/+2 K/W 敏感性 |
| 邻热源 | 0.5 W，20 mm 外，共享 1 oz 铜 20 mm 宽 | 构造假设 |
| 海拔 | 2000 m | 定性修正 |

**步骤 1：外壳表面温升。** 沿用 [thermal/topic.md](../../thermal/topic.md) §7.2 的表面模型，不重复推导：

```text
ΔT_surface = P/(h·A) = 1/(5×0.02) = 10 K
T_surface  = 40 + 10 = 50 °C
```

本次实跑 `thermal_calc.py enclosure`（`power_W=1, area_m2=0.02, h_W_per_m2K=5, ta_C=40, limit_C=70`）输出 `surface_rise_K=10.0`、`surface_C=50.0`、`board_verified=false`；脚本只验证算式，不代表实测。

**步骤 2：导热垫热阻。** 用 [thermal/topic.md](../../thermal/topic.md) §6.4 的 `RθCS≈t/(k·A)`：

```text
RθCS = 1×10⁻³/(3×1×10⁻⁴) = 3.33 K/W
```

**步骤 3：结温。** 按 [thermal/topic.md](../../thermal/topic.md) §4.1 的散热器/外壳主导串联链（不重复公式），把外壳表面温度 50 °C 当作壳温参考（忽略壳壁厚度/横向扩散热阻，这是一个偏乐观的假设）：

```text
Tj = T_surface + P×(RθJC + RθCS)
   = 50 + 1×(2 + 3.33)
   = 55.33 °C
```

也可写成 `Tj = Ta + P×(RθJC+RθCS) + ΔT_surface = 40 + 5.33 + 10 = 55.33 °C`。与 `thermal_calc.py heatsink` 的输入 `P=1, Rth_jc=2, Rth_cs=3.333, Rth_sa=10, Ta=40` 输出 `tj_C=55.333` 一致（本次实跑，脚本输出 `board_verified=false`，只代表算式）。

**步骤 4：海拔 2000 m 的定性修正。** 2000 m≈6562 ft，TI 表 5000 ft 1.14、7000 ft 1.17，线性插值约 1.16（S01 第 5 页）。把 1.16 当作“对流侧热阻变差”的量级代理（不是精确修正）：

```text
ΔT_surface(2000 m) ≈ 10×1.16 = 11.6 K
Tj(2000 m) ≈ 40 + 5.33 + 11.6 = 56.9 °C
```

**步骤 5：0.5 W 邻热源在 20 mm 处的量级。** 用 [thermal/topic.md](../../thermal/topic.md) §6.5 的 `ΔT_local≈P_neighbor·R_path`，共享 1 oz 铜、20 mm 宽：

```text
R_path = 0.02/(385×0.02×35×10⁻⁶) = 74.2 K/W
ΔT_local = 0.5×74.2 = 37.1 K
```

若双层 1 oz 并联 → 18.5 K；双层 2 oz → 9.3 K；单层 1 oz、10 mm 宽 → 74.2 K；50 mm 宽 → 14.8 K。这个 37 K 是沿 1D 共享铜条的上界/量级，不是传感器实际读数；但它说明：**邻热源可以让传感器/电池看到的局部温度比主热源壳温高几十 K，远比 3.33 K/W 的导热垫更值得先处理。**

**步骤 6：判定。**

- 主热源 Tj：55–57 °C，对 125 °C 结温限值余量很大（若器件限值是 125 °C；具体型号待核）——`有条件通过`，因为 RθJC/TIM/接触热阻/壳内空气都是假设。
- 外壳表面：50 °C；触摸限值未查标准 → `待核`，不能判通过。
- 电池/传感器：若放在 20 mm 共享铜路径上，局部可能 +37 K → `不通过/需改布局`；若不在同一铜路径，需另算。
- `【未执行】` 没有实测壳内空气、热点、接触热阻、风扇/海拔；不能写“已验证”。

**步骤 7：敏感性。** 把关键假设扫一遍，比给一个“精确”数字更有用：

| 变量 | 取值 | 对结果的影响 |
|---|---|---|
| h | 3 / 5 / 10 W/m²K | 表面温升 16.7 / 10 / 5 K |
| 导热垫厚度 | 0.5 / 1 / 2 mm | RθCS 1.67 / 3.33 / 6.67 K/W |
| 导热垫 k | 1 / 3 / 6 W/mK | 1 mm、1 cm² 时 10 / 3.33 / 1.67 K/W |
| 接触热阻 | 0 / 1 / 2 K/W | Tj +0 / +1 / +2 K |
| 邻热源铜 | 单层 1 oz / 双层 1 oz / 双层 2 oz | +37 / +18.5 / +9.3 K（20 mm、20 mm 宽） |
| 海拔 | 0 / 2000 m | 表面温升 ×1 / ×~1.16（量级） |

**这个算例不能证明：** 壳内空气温度、局部热点、TIM 实际压缩/老化、电池/触摸标准限值、批次差异、长期可靠性。它只证明“在这些假设下，主路径余量很大，但邻热源/接触/外壳假设可以改变结论”。

### 6.3 仿真：什么时候值得做，输入是什么

值得从 1D 升级到 FEM/CFD 的条件：多热源强耦合、密封/狭小外壳、自然对流/辐射主导、风道/风扇工作点、各向异性铜/叠层、瞬态 >1 s、没有实测窗口、设计变更风险高。最小输入：功耗分布、叠层/铜占比、TIM/接触热阻、h/辐射、环境/邻热源、边界条件。检查：网格无关性、收敛、参数敏感性、与 1D/实测对比。`【原厂】` Infineon 的提醒也适用于板级：数据手册的 Foster 模型在特定散热器条件下测得，模块模型和散热器模型不能“无误差串联”；精确系统 Tj 需要实测整条路径的 Zth(j-a)（S27 第 9 页）。所以仿真模型也要用实测校准，不能拿厂商模型直接拼。

### 6.4 测量：测什么、怎么测、能证明什么

- **热电偶**：36–40 AWG、珠径 ≤2×2 mm、导热环氧、沿对角线走线并在 PCB 上贴 25 mm 以上；粗线可使温差低估 50% 以上，误差 5%–50%（S01 第 9 页）。测壳温用顶部中心 ±1 mm；测板温按 ΨJB/指南；测环境按定义的进风/器件下方位置。
- **红外**：读数依赖发射率；光亮金属/焊料/陶瓷/塑料发射率不同，必须修正；典型相机精度 ±2 °C 或读数 2% RSS，目标至少 10×10 像素，环境补偿不良可增加 10 °C 以上（S24）。红外测表面，不是 Tj。
- **电学 Tj**：用 TSP 标定后读结温；S12 只支持 **LED 的 Vf/Rth_JS**，二极管/MOSFET 体二极管 Vf 的 TSP 属于通用方法/`【推断】`，需要器件专用夹具/标定，不能拿通用温度系数套所有器件。
- **稳态判据**：固定负载/环境/方向下，温度在约定时间内变化小于约定值（例如 5 分钟 <1 K，实验室约定，不是标准）；记录判据。
- **记录**：板版本、器件完整型号、位号、输入/输出/负载、fsw、固件、Ta 测点、外壳/气流/方向、仪器型号/校准、测量时间、稳态判据。至少测目标器件附近、板面、外壳/环境；有邻热源时测其影响。
- **不能证明**：一次样机不烫 ≠ 全批次；外壳不烫 ≠ Tj 不超限；红外图漂亮 ≠ 发射率/测点正确；仿真通过 ≠ 边界条件正确（见 [simulation-measurement.md §8.3–§8.4](../../simulation-measurement.md)）。

### 6.5 回读：固件遥测与物理测量交叉

- **温度**：读 NTC ADC 计数/电压，换算成温度，与热电偶/红外在同一稳态点对比；检查分压电阻容差、NTC beta/曲线、ADC 基准、线阻。
- **风扇**：读 TACH/占空比/故障标志；与风量/压差（若有）对比；堵转测试要实际堵住风扇看固件反应。
- **充电器**：读 TS 电压、充电电流、热调节/故障标志；与电芯表面温度对比，确认 NTC 没有被 PCB 热源提前加热。
- **ODrive**：读 `temp_limit_lower/upper`、`INVERTER_OVER_TEMP`/`MOTOR_OVER_TEMP`、`<fan>.upper/lower`（ODRIVE-DOC）；确认热区映射到正确的传感器。
- **VESC**：读 `TEMP_MOTOR`/`ADC_TEMP` 两路（BLDC_4.sch:1246、:1266），确认电机温度与板温没有接反/共用一个分压。
- **回读不能替代物理测量**：传感器可能贴错位置、曲线错、ADC 饱和；必须至少一次交叉核对。

## 7. 常见失败现象与排查顺序

### 7.1 排查链 A：台面正常，装壳后过热/热关断

| 步骤 | 内容 |
|---|---|
| 现象 | 开放台面跑 30 分钟正常；装壳后 10–20 分钟降额/关断；外壳摸起来热/不热 |
| 候选原因 | 壳内空气温度高；外壳表面积不足/靠墙面未扣除；h 假设过高；邻热源；导热垫未压紧；风道短路/滤网堵；风扇失效 |
| 区分检查 | 开壳 vs 闭壳同一负载/环境；测壳内空气（器件上方/进风口/出风口）、外壳表面、器件壳温；记录风扇 TACH/占空比；红外看热点；检查导热垫压痕/螺钉扭矩/垫柱高度 |
| 证据 | 闭壳后壳内空气比外部高多少；表面温升 vs `P/(hA)`；导热垫压痕是否均匀；风扇风量/转速；邻热源功耗 |
| 修复 | 增加通风/散热器/外壳面积；改导热垫/压力；移走邻热源；降额/降功耗；风扇故障策略 |
| 复验 | 同一闭壳、同一负载、同一环境，重跑原失败时长；测 Tj/壳温/壳内空气；确认降额/关断不再触发 |
| 新风险 | 开通风孔破坏 IP/EMI；金属壳触摸烫；风扇噪声/灰尘；降额影响性能 |

### 7.2 排查链 B：器件很热，但 datasheet RθJA 说“没问题”

| 步骤 | 内容 |
|---|---|
| 现象 | LDO/MOSFET/驱动在满载时烫手/热关断；按 datasheet RθJA 计算却“余量很大” |
| 候选原因 | datasheet 是 JEDEC 测试板；实际铜面积/层数/气流/外壳差；热焊盘未焊/空洞；过孔不足/未连平面；Rds(on)/Vf 随温度恶化；邻热源；开关损耗被低估 |
| 区分检查 | 测壳温/板温/热焊盘温度；X-ray/显微镜看空洞/润湿；对比实际铜面积/层数与 datasheet 测试板；查 gate 波形/开关频率/电感；断电后看是否被邻热源加热；用 ΨJT/ΨJB 或散热器链反推 |
| 证据 | 实际板 RθJA(effective) 与 datasheet 差异；热焊盘覆盖率；过孔截面；壳温 vs 功耗；邻热源温升 |
| 修复 | 加铜/层/过孔/热焊盘焊接；换封装/散热器/TIM；降功耗/降频/改拓扑；移走邻热源 |
| 复验 | 同一负载/环境重跑；测 Tj（TSP/热电偶/红外交叉）；确认余量 > 不确定度 |
| 新风险 | 加铜/过孔可能改变回流/EMI；散热器增加高度/成本；降频影响性能 |

### 7.3 排查链 C：电池充电慢/停充，壳内很热

| 步骤 | 内容 |
|---|---|
| 现象 | 电池充不满/充电电流提前下降；外壳/电池仓热；NTC 读数与电芯表面不一致 |
| 候选原因 | NTC 贴 PCB 被充电器/功率管提前加热；NTC 曲线/分压错；电芯真的热；充电器热调节（BQ2407x 125 °C 减流/155 °C 关断）；邻热源；接触电阻/线束压降；散热不足 |
| 区分检查 | 同时测电芯表面、NTC 本体、TS 电压、充电电流、PCB 温度；开壳/闭壳对比；用外部热电偶对比 NTC 读数；查 NTC beta/分压；查充电器热调节标志 |
| 证据 | NTC 与电芯温差；TS 电压对应温度；充电电流 vs 温度；壳内空气温度；接触电阻/压降 |
| 修复 | NTC 移到电芯本体/加导热胶；隔离电池与充电器；增加通风/散热；降低充电电流/改充电策略；修正 NTC 曲线 |
| 复验 | 同一充电条件重跑；记录充电时间/电流/温度；确认不触发误保护 |
| 新风险 | 充电变慢；NTC 引线/绝缘/开路；电池仓结构变化 |

### 7.4 排查链 D：装了风扇/散热器，温升没改善

| 步骤 | 内容 |
|---|---|
| 现象 | 加风扇/散热器后温度只降一点，甚至更差；噪声大 |
| 候选原因 | 风扇工作点远离最佳效率（系统阻抗高/滤网堵/进出风口短路）；风向反/回流；散热器与器件接触不良；TIM 太厚/未压紧；风扇只吹到外壳不是散热器；海拔/滤网降额 |
| 区分检查 | 测风扇电压/电流/转速/TACH；测散热器进/出风温度；烟雾/纸条看流向；摸/测散热器与器件温差；堵转/拆滤网对比；查 PQ 曲线与系统阻抗 |
| 证据 | 风量/风速（若有）；散热器-器件温差；进出风温差；拆滤网/开壳对比 |
| 修复 | 改风道/进出风口；换高静压风扇；减小滤网阻力；改散热器安装/ TIM；加导风罩 |
| 复验 | 同一负载/环境重跑；测 Tj/壳温/噪声；确认风扇失效时仍有降额 |
| 新风险 | 噪声/振动/灰尘/风扇寿命；风道改变影响其他器件 |

### 7.5 排查链 E：端子/连接器发热（与 E4 交叉）

| 步骤 | 内容 |
|---|---|
| 现象 | 端子/连接器摸起来热，塑料壳变色/软化；压降变大 |
| 候选原因 | 接触电阻大（压接不良/氧化/微动）；端子额定未降额；多针同时通电；线径不足；邻近 MOSFET/加热器热耦合；铜箔窄颈 |
| 区分检查 | 同一电流下测端子-焊点/端子-线两端 mV 压降；断电后看是否仍被别处加热；红外看热点；查降额曲线/线规/压接高度 |
| 证据 | 接触电阻（四线）；端子温升；邻近器件温度；铜箔最窄段 |
| 修复 | 换端子/压接工具/线径；加应力释放；移走热源；加铜/过孔 |
| 复验 | 同一电流/环境测端子温升/压降；热循环/插拔后复测 |
| 新风险 | 端子尺寸/成本；压接工艺；振动/锁扣 |

## 9. 仍需型号资料/专家/实物确认

1. **VESC 铝基板/散热器版本**：本地 `BLDC_4.kicad_pcb` 是 1.6 mm 四层（F.Cu/GND/GND2/B.Cu），文件未注明基材，也没有铝基板/金属芯叠层证据；标题栏 4.6 与 `Power.sch` 4.11 混版。具体 VESC 版本的叠层/BOM/散热器机械件、导热垫/螺钉扭矩、相电流/温度实测，均 `待按型号核对`。
2. **MNT Reform 2 风扇/风道与电池 NTC**：官方手册/设计说明确认 stock 为铝散热器 + 导热垫、无风扇；本地仓库没有风扇/风道文件，电池包 PCB 没有温度网络，主板 `reform2-power.sch` 也没有 `TEMP/NTC` 网络名。若某配置有风扇/电芯 NTC，需按具体 revision/结构图核对；不能把社区改装当原设计。
3. **ODrive v3.5 风冷/散热器 RθSA**：本地 CHANGELOG 只给 heatsink holes/enclosure style heatsinking；官方风扇模块是 ODrive Pro，v3.5 没有板载风扇控制网络。v3.5 的散热器型号、RθSA、风扇风量/噪声、实际温度 `未执行/待测`。
4. **TIM/灌封材料**：导热垫/导热膏/相变/灌封胶的具体 k、厚度、压缩率、接触热阻、介电强度、UL94、老化/泵出、CTE/Tg，需按料号 datasheet/ASTM D5470 报告核对；本文只给 `t/(kA)` 一阶和敏感性。

8. **风扇/滤网/海拔**：风扇 PQ 曲线、系统阻抗、滤网压损、海拔降额、堵转/寿命数据未取得；2000 m 只用 TI 表做量级，不是精确修正。

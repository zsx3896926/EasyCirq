## 1. 设计意图与连接基线

本例要解决一个 12 V 标称输入、5 V/2 A 输出的集成开关同步 Buck 在原理图与 PCB 之间的三件事：

1. **输入电容到底围住哪条回路**：原理图上 `CIN` 接在 `VIN` 与 `GND` 之间看起来都对，PCB 上却可能把高 di/dt 回路拉成一个大环。
2. **反馈从哪里取**：从电感后、输出电容前取，还是从输出电容正端取，原理图的网表可能完全一样，调节效果不同。
3. **功率地与信号地怎么汇合**：图上都叫 `GND`，PCB 上却是两条不同的返回路径。

**给定条件（本分析假设，不是某个控制器的手册值）：**

| 项目 | 值 | 说明 |
|---|---|---|
| 输入范围 | 9–15 V | 12 V 标称；15 V 用于算最大占空比与峰值 |
| 输出 | 5.0 V / 2.0 A | 连续负载 |
| 开关频率 | 500 kHz（最小值） | 纹波计算用最小频率 |
| 效率估计 | η = 0.90 | 只用于初算，不能代替效率曲线 |
| 电感纹波目标 | ΔIL = 0.30 × IOUT = 0.60 A | PWR-S01 §3 的 0.2–0.4 倍范围 |
| 反馈基准 | VFB = 0.80 V | 示例假设，须换成本控制器手册值 |
| FB 偏置电流 | IFB = 100 nA | 示例假设，须换成本控制器手册值 |

**连接基线（分析用，不对应任何真实工程）：**

| 连接 | 基线 | 不能省的理由 |
|---|---|---|
| `VIN_12V` → 控制器 `VIN` | 经输入保护后进入功率块，`CIN` 就在 `VIN`/`PGND` 引脚旁 | `CIN` 要提供开关瞬间的脉冲电流，不能只从远端“同网”供电 |
| 控制器 `PGND` → 输入/输出电容负端 | 功率回流，短而宽 | 高 di/dt 回路和负载回流都走这里 |
| `SW` → 电感 `L1` → `COUT` → `VOUT_5V` | 局部功率路径 | 电感电流连续，但 `SW` 节点仍是高压摆率节点 |
| `COUT+` → `R1` → `FB` → `R2` → `AGND` | 反馈分压靠近 `FB` 脚 | 取样点错了，环路会调节错误的电压 |
| `BOOT` → `CBOOT` → `SW` | 自举电容靠近 `BOOT`/`SW` | 高侧驱动电流的回路不能绕远 |
| `EN`、`PG` | 可来自其它页/监控器 | 慢速状态信号，允许网名跨区 |

> 具体控制器的引脚名可能是 `VIN`/`SW`/`BOOT`/`FB`/`COMP`/`PGND`/`AGND`，也可能是别的命名；**引脚功能必须按所选型号手册逐脚核对**，不能按本例的名称直接套封装。

## 2. 原理图模块内部摆放

模块内部按“输入 → 开关 → 电感 → 输出 → 反馈”从左到右摆，功率器件和它们的电容作为一个完整局部块，不把 `CIN`、`COUT` 拆到页面边缘：

- `CIN` 画在 `VIN` 与 `PGND` 两个引脚之间的短支路上，而不是画在一条长电源总线的末端。
- 高侧/低侧开关（集成在控制器内时就是控制器符号）与 `SW`、电感、`COUT` 连续摆放；`BOOT` 电容紧贴 `BOOT` 与 `SW`。
- 反馈分压 `R1/R2` 紧靠 `FB` 脚，取样线从 `COUT+` 引出；`COMP`（若外补偿）也留在 `FB` 附近，不跨到功率区另一侧。
- `PGND` 与 `AGND` 使用可区分的符号或明确注释；如果控制器只有一个地脚，也要在注释里写清“功率回流与反馈回流在芯片地/输出电容地单点汇合”的 PCB 意图。
- `EN`、`PG` 放在控制器侧，`PG` 的上拉电阻画在它所指向的电压域旁，不能只写一个 `PG` 网名就认为已经有高电平。

```text
（分析草图，非 EDA 产物）

  VIN_12V ──┬──── CIN ────┬──── VIN
            │             │
            │           [HS]────────── SW ── L1 ──┬── COUT ──┬── VOUT_5V
            │             │                        │          │
            │           [LS]                       │          R1
            │             │                        │          │
           PGND ──────────┴────────────────────────┴──────────┴── FB
                                                                  │
                                                                 R2
                                                                  │
                                                                AGND

  BOOT ── CBOOT ── SW        （自举回路留在 SW/BOOT 引脚旁）
  EN  ── 来自监控器/其它页    PG ── 上拉到本域电源（开漏）
```

这样摆的理由不是“看起来整齐”，而是让读图的人一眼能回答：输入脉冲电流由哪颗电容闭合、`SW` 到电感再到输出是哪一段、反馈取样点在 `COUT` 之后还是之前、`PGND` 与 `AGND` 是否被画成同一条回流。

## 3. 局部短线与标签连接

| 连接 | 表达方式 | 理由 |
|---|---|---|
| `CIN` 到 `VIN`/`PGND` | **局部短线**，电容紧贴引脚 | 这是高 di/dt 回路；用网名拉到远处再回来，图上仍是同一个网，PCB 上却已经是大环 |
| `SW` 到 `L1`、`L1` 到 `COUT` | **局部短线** | `SW` 是高压摆率节点；走线越长，容性耦合和振铃越大 |
| `BOOT` 到 `CBOOT` 到 `SW` | **局部短线** | 高侧栅极驱动的脉冲电流只在自举电容—`BOOT`—`SW` 之间闭合 |
| `COUT+` 到 `R1`、`R1` 到 `FB`、`R2` 到 `AGND` | **局部短线**，分压靠近 `FB` | `FB` 是高阻小信号节点；用标签拆开会让取样点和回流无法跟读 |
| `COMP`（外补偿） | **局部短线** | 补偿网络与误差放大器之间的寄生会影响环路；不能当普通网名跨页 |
| `PGND` / `AGND` | **局部符号 + 注释**，不用一个全局 `GND` 掩盖回流 | 图上可以是一个网络，但必须写明 PCB 上在哪里单点汇合；不能把“同名”当成“同路径” |
| `VIN_12V` | **网名/端口**，从输入保护页进入本块 | 跨功能块，慢速直流；但进入本块后必须先到 `CIN`，不能先绕到别的负载 |
| `VOUT_5V` | **网名/端口**，从 `COUT+` 之后引出 | 跨页给负载；取样点必须在 `COUT` 之后，不能从连接器远端反推 |
| `EN_5V` | **网名/端口** | 慢速使能，允许跨区；但要核对默认态、门限和上拉域（SC14） |
| `PG_5V` | **网名/端口 + 本域上拉** | 开漏输出；没有上拉就不是有效高电平 |
| `SW` 测试点 | **短支路/测试焊盘**，不拉长网名 | 测试点本身也是天线；只留可探测的短支路，必要时 DNP |

**不能只用标签替代的连接：** `CIN` 回路、`BOOT` 回路、`FB` 分压、`COMP`、`PGND` 与 `AGND` 的汇合点。原因不是“标签不电气”，而是标签会把**物理距离和回路面积**从图上抹掉；DRC 只检查连接关系，不检查这些。

**标签命名与作用域：**

- 用 `VIN_12V`、`VOUT_5V`、`EN_5V`、`PG_5V` 标明电压域，避免把 5 V 逻辑的 `PG` 上拉到 12 V。
- `SW` 只在本页出现，不跨页；不要把它命名成 `VOUT` 或 `5V`。
- 层次页/重复模块要用页内网名，不能让两个实例的 `FB` 或 `SW` 因为同名而意外并联（SC41）。
- 如果工具把 `PGND`/`AGND` 当两个网络，必须在该控制器允许的单点连接处显式连接；如果工具只允许一个 `GND`，就在注释和 PCB 约束里写清回流分区，不能靠“改了网名”代替布局。

## 4. PCB 关键器件相对关系

以下是**离线布局草案**，只描述相对关系，不给坐标、间距、层数或叠层；这些必须在实际板框、封装和叠层确定后核对。

| 器件/区域 | 相对关系 | 检查点 |
|---|---|---|
| `CIN` | 紧贴控制器 `VIN` 与 `PGND` 引脚，电容—引脚—地过孔形成最小回路 | 电容端子到引脚不要经过长支路；地过孔靠近电容负端（PL10） |
| 控制器/开关 | 与 `CIN`、电感同侧；`SW` 铜满足载流与散热但不过度扩张 | `SW` 铜远离 `FB`、`EN`、时钟、模拟区及相邻层（PL11） |
| `L1` | 靠近 `SW`，输出端朝向 `COUT`；避免电感本体紧贴反馈走线 | 电感是磁场源；不要把它当“只是个储能件”随手转方向 |
| `COUT` | 在电感输出与 `PGND` 之间，输出取电点在 `COUT` 之后 | 负载电流先经 `COUT` 端子，再从取电点去连接器 |
| `R1/R2` | 靠近 `FB` 脚；取样线从 `COUT+` 单点引出 | 不从电感前、不从连接器远端、不从功率地取（PL12） |
| `CBOOT` | 紧贴 `BOOT`/`SW` | 自举回路面积最小（PL13） |
| `PGND` 铜 | 连续覆盖输入电容、低侧开关、输出电容的回路 | 不让 `CIN` 与 `COUT` 的回流在细颈处汇合（RT01） |
| `AGND`/`FB` 地 | 按控制器要求单点汇合，反馈分压地不穿过功率回流 | 图上同名不等于 PCB 同路径（RT06） |
| 散热 | 控制器散热焊盘/EPAD 接足够铜并与过孔配合 | 按具体封装与工艺核对，不凭封装名称推断（PL16、MF05） |
| 测试点 | `VIN`、`SW`（短支路）、`VOUT`、`PGND` 可探 | 测试点不被连接器/电感遮挡（MF15） |

```text
（分析草图，非 EDA 产物；只表示相对关系，不含坐标/间距/层数）

  输入保护 ── [CIN] ── [控制器 VIN/PGND]
                  │
               [HS/LS] ── SW ── [L1] ── [COUT] ──→ VOUT_5V
                  │                    │
                PGND ─────────────────┘
                  │
              [单点汇合] ── [R1/R2] ── FB

  检查对象：CIN 回路面积、SW 铜范围、FB 取样点、PGND/AGND 汇合点、EPAD 过孔
```

## 5. 电流路径、信号路径与返回路径

### 5.1 关键电流回路（按开关状态）

**导通状态（高侧开关开）：**

```text
VIN_12V → CIN+ → 高侧开关 → SW → L1 → COUT/负载 → PGND → CIN−
```

- `CIN` 提供开关瞬间的脉冲电流；电源只在平均电流层面供电。
- 电感电流从 `L1` 流向输出；输出电容与负载分享这部分电流。
- 回流从负载/`COUT` 负端经 `PGND` 回到 `CIN−`。

**关断状态（低侧开关开，同步整流）：**

```text
L1 → COUT/负载 → PGND → 低侧开关 → SW → L1
```

- 电感电流不能突变，低侧开关提供续流路径。
- 这条回路的电流是连续的（梯形波），但 `SW` 节点电压仍在跳变。

**真正需要最小化的是换流回路：**

```text
CIN+ → 高侧开关 → SW → 低侧开关 → PGND → CIN−
```

- 在开关切换的极短时间内，电流在这条回路里换向；回路面积越大，寄生电感越大，`SW` 振铃和输入电压尖峰越大。
- `CIN` 的放置不是为了“离芯片近好看”，而是为了让这条回路的面积最小（PL09、PL10）。

**本算例的电流量级（计算值，不是实测）：**

| 量 | 值 | 来源/条件 |
|---|---|---|
| 电感峰值 `ISW(max)` | 2.33 A | `IOUT + ΔIL/2 = 2 + 0.333` |
| 电感 RMS | 2.01 A | `√(IOUT² + ΔIL²/12)`，CCM 梯形近似 |
| 输入电容 RMS | 0.97 A | `IOUT·√(D(1−D))`，D = 0.370；D = 0.5 时约 1.0 A |
| 输出电容 RMS | 0.19 A | `ΔIL/√12` 的近似 |

这些值用于选电容的纹波电流额定和电感的饱和/RMS 额定；**实际波形、纹波和温升未测量**。

### 5.2 敏感信号路径

- **`FB` 取样路径**：从 `COUT+` 的取样点到 `R1`，再分压到 `FB`。这是高阻小信号，不能沿 `SW` 铜、电感下方或高 di/dt 过孔走。
- **`COMP` 路径（若外补偿）**：误差放大器输出到补偿网络，再到参考地；补偿件靠近 `FB`/误差放大器，不能拉长。
- **`EN`/`PG`**：慢速状态信号，允许跨区；但要核对门限、默认态、上拉域和失电行为（SC14）。`PG` 是开漏时，上拉电阻必须接到下游能接受的电压域。
- **电流采样（若控制器用）**：按具体控制器的采样方式核对；低侧采样要 Kelvin，避免功率电流共用采样段（RT07）。本例没有假设控制器一定用哪种采样。

### 5.3 返回路径与参考层

- `PGND` 走功率回流：`CIN−`、低侧开关源极、`COUT−`、负载回流。它上面有脉冲电流和地弹。
- `AGND` 走 `FB` 分压、`COMP`、`EN`/`PG` 的参考。它不能与 `PGND` 在任意点连在一起，否则功率回流会在反馈参考上产生压降。
- 汇合点按控制器手册：通常在芯片地或输出电容地单点汇合；**具体位置必须按所选控制器布局指南核对**，不能套一个“星形地”口号。
- 若使用地平面，检查 `FB`、`EN`、`PG` 下方参考是否连续，是否被 `SW` 铜、过孔或平面分割切断（RT04、RT06）。层数与叠层未定，不能声称参考已经连续。

### 5.4 原理图看得见与 PCB 必须查的分界

| 项目 | 原理图可见 | 只能在 PCB 上检查 |
|---|---|---|
| 连接关系 | `CIN` 是否接在 `VIN`/`PGND`，`FB` 分压比，`BOOT` 电容接法 | `CIN` 到引脚的实际回路面积、地过孔位置 |
| 器件值 | 电感值、电容标称值、分压电阻 | 电容有效容量、ESR、电感饱和电流随温度 |
| 电流路径 | 哪条支路属于功率、哪条属于反馈 | 回流是否真的走 `PGND`，`AGND` 是否被功率电流污染 |
| 开关节点 | `SW` 连到电感 | `SW` 铜面积、与 `FB`/时钟/模拟的耦合、测试支路 |
| 散热 | 哪个器件可能发热 | 铜面积、过孔、气流、实际温升 |
| 反馈取样 | 从 `COUT` 之后画 | 取样点是否真的在 `COUT+` 端子，而不是连接器远端 |

## 6. 常见错误及其后果

| 错误 | 图上表现 | 实际后果 | 为什么会通过 DRC/肉眼 |
|---|---|---|---|
| `CIN` 放在输入连接器旁，离控制器很远 | `CIN` 与 `VIN`/`PGND` 仍是同一个网，ERC 通过 | 高 di/dt 回路变大，`SW` 振铃、输入尖峰、EMI 变差；严重时高侧开关过压 | DRC 只查连接和间距，不查回路面积；肉眼看到“电容在电源入口”反而觉得合理 |
| 反馈从电感后、`COUT` 前取，或从负载连接器远端取 | `FB` 网仍连到分压，网表正确 | 输出纹波/负载压降被排除在环路外，稳态误差或振荡；远端取样还会把走线压降补进去 | DRC 不判断取样点位置；图上一条线连到 `FB` 看不出“从哪一点” |
| `FB` 分压地接到 `CIN` 与低侧开关之间的 `PGND` | 所有 `GND` 同名，ERC 通过 | 开关地弹叠加到 `FB`，输出抖动、占空比抖动，甚至环路不稳定 | 原理图只有一个地符号；DRC 不会区分回流路径 |
| `SW` 用长网名引到测试点/其它页 | 网表仍是 `SW`，连接正确 | `SW` 铜变成天线，耦合到 `FB`/时钟/接口；测试探头还会改变波形 | DRC 只看到一根合法网络；肉眼可能觉得“留个测试点很方便” |
| 自举电容离 `BOOT`/`SW` 远 | `CBOOT` 两端仍接对 | 高侧栅极驱动电流回路大，驱动电压跌落，开关损耗/发热增加，严重时高侧不能完全导通 | DRC 不查回路；电容值正确时图上完全正常 |
| 电感只按 2 A 平均电流选，没按 2.33 A 峰值和饱和电流选 | 电感值与计算值一致 | 峰值附近电感量下降、电流进一步上升，可能饱和/过热；限流可能误触发 | DRC 没有电感饱和模型；BOM 上“2 A 电感”看起来够 |
| 输出电容只写 10 µF，没算偏压/温度降容 | 原理图标称 10 µF | 有效容量不足，输出纹波/负载阶跃过冲超限；内补偿控制器可能不稳定 | DRC/ERC 不读电容偏压曲线；肉眼只看到标称值 |
| `PG` 上拉到 12 V 或未上拉 | `PG` 网名存在，ERC 可能通过 | 下游 3.3 V 逻辑过压；或开漏永远没有高电平，系统误判 | ERC 不检查上拉域和下游耐压；网名相同不代表电平兼容 |
| `PGND`/`AGND` 在图上合并，PCB 上却随意割地 | 图上只有一个 `GND` | 返回路径被切断，`FB` 参考跳动，辐射变差 | DRC 只查同一网络是否连通；割地后的“连通”可能经过长绕行 |

## 7. 改善后的方案与检查方法

### 7.1 改前/改后（分析上的方案，不对应真实工程改动）

| 项目 | 改前（常见草稿） | 改后（分析建议） |
|---|---|---|
| `CIN` | 放在输入连接器旁，靠网名连到控制器 | 移到 `VIN`/`PGND` 引脚旁，回路面积最小 |
| `FB` 取样 | 从电感后或负载连接器远端取 | 从 `COUT+` 端子取，分压靠近 `FB` |
| `FB` 地 | 与功率地共用一段回流 | 单独到 `AGND`，按控制器要求在单点汇合 |
| `SW` | 长网名 + 大测试焊盘 | 局部短铜，测试支路短且可 DNP |
| `CBOOT` | 放在控制器另一侧 | 紧贴 `BOOT`/`SW` |
| 电感选型 | 只按 2 A 平均电流 | 按 2.33 A 峰值 + 饱和/RMS + 温度降额 |
| `COUT` | 只写标称 10 µF | 按有效容量、ESR、负载阶跃过冲三者取最大 |
| `PG` | 网名直连下游 | 开漏 + 正确域上拉，核对下游耐压 |

### 7.2 电气复算顺序

1. **占空比**：`D = VOUT/(VIN(max)·η)`。本算例 `D = 5/(15×0.9) = 0.370`。用 `VIN(max)` 是因为它给出最大开关电流（PWR-S01 Eq.1）。
2. **电感**：先取 `ΔIL = 0.3×IOUT = 0.60 A`，`L = VOUT(VIN−VOUT)/(ΔIL·fS·VIN)`，得 11.1 µH；选 10 µH 后回算 `ΔIL = 0.667 A`。
3. **峰值与 RMS**：`ISW(max) = IOUT + ΔIL/2 = 2.33 A`；`IL,RMS ≈ √(2² + 0.667²/12) = 2.01 A`。
4. **限流反推**：`IMAXOUT = ILIM(min) − ΔIL/2`。要输出 2 A，`ILIM(min) ≥ 2.33 A`；候选 3.0 A 可给出约 2.67 A，候选 2.2 A 只能给出约 1.87 A，淘汰。
5. **输入电容**：`ICIN,RMS ≈ IOUT·√(D(1−D)) = 0.97 A`；D = 0.5 时约 1.0 A。按这个 RMS 选电容的纹波电流额定，不能只看容量。
6. **输出电容**：外补偿时 `COUT(min) = ΔIL/(8·fS·ΔVOUT)`；取 `ΔVOUT = 50 mV` 得 3.33 µF。ESR 附加纹波 `ESR·ΔIL`；负载阶跃过冲 `COUT ≥ ΔIOUT²·L/(2·VOUT·VOS)`，1 A 阶跃、100 mV 过冲时需 10 µF。三者取最大，并按有效容量折算标称值。
7. **反馈分压**：分压电流至少为 `IFB` 的 100 倍。本算例 `IFB = 100 nA`，取 10 µA；`R2 = 0.8/10 µA = 80 kΩ`，选 78.7 kΩ（10.17 µA）；`R1 = 78.7 k×(5/0.8−1) = 413 kΩ`，选 412 kΩ，回算 `VOUT ≈ 4.99 V`。电阻容差、VFB 容差和偏置电流误差未计入。
8. **自举电容**：按控制器手册取值，本算例不计算；耐压至少覆盖 `VIN(max)` 加振铃余量。

### 7.3 检查方法

- **网表回读（有 EDA 时）**：核对 `CIN` 是否同时连到 `VIN` 与 `PGND`、`COUT` 是否在电感之后、`FB` 节点是否只包含分压与 `FB` 脚、`BOOT` 电容是否只连 `BOOT`/`SW`。本例未做 EDA 回读。
- **几何检查**：量取 `CIN` 焊盘—引脚—地过孔的回路面积；检查 `SW` 铜是否延伸到 `FB`/时钟/模拟区；检查 `FB` 取样点是否在 `COUT+` 端子；检查 `PGND`/`AGND` 汇合点是否与控制器指南一致。
- **仿真（NOT RUN）**：若执行，用控制器厂商的平均/开关模型，激励为输入 9–15 V、负载 0.2–2 A 阶跃，观察 `VOUT` 跌落/过冲、电感电流峰值、`SW` 振铃；通过标准由控制器手册的纹波/瞬态限值给出。本例未运行任何 SPICE。
- **测量（未执行，方法见 MF29）**：`VIN`、`SW`、`VOUT` 用短地弹簧探头就近测量；电感电流用合适电流探头或分流器；负载用电子负载；热用热电偶/热像仪。停止条件：过流、器件异常发热、`SW` 振铃超过器件耐压即断电。具体带宽、探头和限值按实际器件手册，不在本例编造。
- **通过标准**：输出纹波、负载阶跃、电感峰值、开关应力、器件温升均在所选控制器/电感/电容手册限值内。**这些限值未在本例中核对**。

## 8. 必须保留的身份、连接和接口约束

- **器件身份**：控制器 `U1` 的完整订货型号、封装、引脚表、EPAD/散热焊盘定义；电感 `L1` 的完整型号、电感量、饱和电流、DCR、温度降额；`CIN`/`COUT`/`CBOOT` 的完整型号、标称值、耐压、ESR、介质；`R1/R2` 的阻值、精度、温度系数。本例没有给出具体料号，选型时必须补全。
- **Pin-pad 映射**：`VIN`、`SW`、`BOOT`、`FB`、`COMP`、`EN`、`PG`、`PGND`、`AGND`、EPAD 的物理脚号必须与封装焊盘逐项对照（SC02）。符号上的功能名不能代替物理脚号。
- **网络身份**：`VIN_12V`、`SW`、`VOUT_5V`、`PGND`、`AGND`、`FB`、`BOOT`、`EN_5V`、`PG_5V` 的名称和作用域不能因整理而改变；`SW` 不能改名为 `VOUT`，`FB` 不能与 `VOUT` 合并。
- **取样点**：`FB` 分压的取样点必须在 `COUT+` 端子；整理/改版时不能为了走线方便把取样点移到电感前或连接器远端。
- **默认态**：`EN` 的默认电平（上电、复位、MCU 未启动时）必须明确；`PG` 的上拉域和失电行为必须明确。
- **装配变体**：`SW` 测试支路、外补偿件、`PG` 上拉、DNP 的 0 Ω/跳线要标明默认装配；DNP 不等于无电气连接（SC08）。
- **接口**：本例没有外部连接器；若加入输入/输出连接器，必须保留板端视角、Pin-1、极性、额定电流和线缆压降约束（SC40）。

# 晶体振荡器：16 MHz HSE 的负载电容、负阻与驱动电平

> **类型：** 分析范例（未在 EDA 中执行）
> **关联设计卡：** [`../design-cards/mcu/m05-crystal.md`](../design-cards/mcu/m05-crystal.md)（MCU-05）；最小系统入口见 [`m01-bare-mcu.md`](../design-cards/mcu/m01-bare-mcu.md)（MCU-01）
> **是否实际修改工程：** 否
> **结论来源：** 电气计算 + 几何分析（无 EDA 回读、无实测）
> **引用来源：** MCU-S02（ST AN2867 Rev 24，§1–§3、§7.1）；MCU-S01（ST AN4488 Rev 7，§6）；MCU-S04（ESP32-C3 检查表，Clock Source）；MCU-S05（RP2040 硬件设计，§2.3）

## 1. 设计意图与连接基线

本例讨论一个 16 MHz HSE 皮尔斯晶体。它要回答的不是“晶振两脚有没有接上”，而是：

1. **负载电容配到多少**：晶体厂标称的 `CL` 是振荡到标称频率所需的负载，外部 `CL1/CL2` 要把 `CL` 配出来，并减去引脚/PCB 寄生 `Cs`。
2. **负阻余量够不够**：`gm/gmcrit > 5` 才算安全；余量不足会出现“样机起振、量产不起振”。
3. **驱动电平超不超**：`DL = ESR·IQ²`；超了会加速老化甚至振裂，必要时加 `RExt`，但 `RExt` 会吃掉负阻余量。
4. **布局能不能保持**：晶体、负载电容、`RExt` 必须是一个局部块；用网名拉远，pF 级节点就失去意义。

**给定条件（本分析假设，不是某个具体晶体/MCU 的手册值）：**

| 项目 | 值 | 说明 |
|---|---|---|
| 频率 | 16 MHz | HSE |
| 晶体 `CL` | 9 pF | 晶体手册值 |
| 晶体 `C0` | 7 pF | 晶体手册值 |
| 晶体 `ESR(max)` | 50 Ω | 用 max 设计 |
| 晶体 `DL(max)` | 100 µW | 示例假设；实际以晶体手册为准 |
| MCU `gm(min)` | 10 mA/V | 示例假设；实际以 MCU 手册 min 值为准 |
| 引脚/PCB 寄生 `Cs` | 4 pF | 估算值，须按封装/叠层核对 |
| 目标 | `gm/gmcrit > 5`（HSE） | MCU-S02 §3 |
| 测量假设 | `CL1` 处 `Vpp ≈ 1 V` | 仅用于驱动电平估算，须实测 |

**连接基线（分析用，不对应任何真实工程）：**

| 连接 | 基线 | 不能省的理由 |
|---|---|---|
| MCU `OSC_OUT` → `RExt`（可选）→ 晶体 → `OSC_IN` | 局部短线 | 这是振荡器回路；走线长度/寄生直接改变负载与负阻 |
| 晶体两端 → `CL1`/`CL2` → 地 | 局部短线，地就近 | 负载电容的地回归到 MCU 地，不穿过数字/功率区 |
| `RF`（反馈电阻） | 多数 ST MCU 已内置，不外加 | 外加会改变偏置/负阻；除非手册明确要求 |
| `RExt` | 0 Ω/DNP 或按计算值，串在 `OSC_OUT` 与 `CL2` 之间 | 只在驱动电平超限或需要抑制泛音时装；装了必须重算 `gmcrit` |
| 晶体外壳/guard ring | 按具体器件要求接地 | 金属封装晶体不要接振荡器地（MCU-S02 §7.1） |
| `OSC_IN`/`OSC_OUT` 测试点 | 不长期加支路；必要时短时探测 | 探头电容可能直接导致停振（RT24） |

> 具体晶体的 `CL`、`ESR`、`C0`、`DL` 和 MCU 的 `gm`/`Gm_crit_max` 必须查各自手册。本文的 16 MHz/9 pF/50 Ω/10 mA/V 只用于演示顺序，不代表任何料号。

## 2. 原理图模块内部摆放

晶体块画成一个完整的局部电路，紧邻 MCU 的 `OSC_IN`/`OSC_OUT`：

- 晶体符号在中间，`CL1` 从 `OSC_IN` 侧到地，`CL2` 从 `OSC_OUT` 侧到地；`RExt`（若装）串在 `OSC_OUT` 与 `CL2` 之间。
- `RF` 若芯片内置就不画；若芯片没有内置且手册要求，才画在 `OSC_IN`/`OSC_OUT` 之间。
- 负载电容标 C0G/NP0，值旁边写计算依据（如 `CL1=CL2=10 pF（CL=9 pF, Cs=4 pF）`），方便复核。
- `RExt` 标 `0 Ω` 或 `DNP`，并注明“仅当实测 DL 超限时装配”；不要默认画 1 kΩ。
- 晶体块下方/周围画局部地/guard ring 的意图注释；不要用一条长 `GND` 网名把负载电容的地拉到页面另一头。
- 若 LSE 与 HSE 共存，两个晶体块分开画，不能共用负载电容或地回路。

```text
（分析草图，非 EDA 产物）

        ┌──────────── MCU 内部 ────────────┐
        │        反相器 gm                  │
  OSC_IN ─┤▷o───────────────────────┬── OSC_OUT
        │                           │
        │          RF（多数内置）     │
        └───────────────────────────┘
             │                       │
            CL1                     RExt（0Ω/DNP）
             │                       │
            GND                     CL2
                                     │
                                    GND

  晶体接在 OSC_IN 与 OSC_OUT（经 RExt，若装）之间
  局部地/guard ring 回归到 MCU 地，不穿过数字/功率区
```

这样摆的理由：读图的人能直接看到“晶体两端、两颗负载电容、RExt 是否装、RF 是否内置”；不需要在页面另一头找一颗被网名拉走的电容。

## 3. 局部短线与标签连接

| 连接 | 表达方式 | 理由 |
|---|---|---|
| `OSC_IN`/`OSC_OUT` 到晶体 | **局部短线** | pF 级节点；走线电感/电容直接改变负载和负阻 |
| 晶体两端到 `CL1`/`CL2` | **局部短线** | 负载电容的回路面积影响寄生与串扰 |
| `CL1`/`CL2` 到地 | **局部短线 + 局部地** | 地回流要短，不能穿过数字/功率电流 |
| `RExt` | **局部串联**，0 Ω/DNP 可选 | 位置决定它限的是哪一段；不能放到另一页 |
| `RF` | **局部**，仅芯片未内置时 | 外加会改变偏置；不要把参考设计的 1 MΩ 直接搬来 |
| 晶体外壳/guard ring | **局部地符号 + 注释** | 金属封装晶体不要接振荡器地；guard ring 要有明确回归点 |
| `OSC_IN`/`OSC_OUT` 测试点 | **短支路/测试焊盘**，不拉长网名 | 探头电容可能停振；测试支路本身也是寄生 |
| LSE `OSC32_IN/OUT` | **独立局部块** | 32.768 kHz 晶体启动慢、阻抗高，不能用 HSE 的布局习惯 |
| 时钟使能/配置 | **网名/端口**（若需要） | 慢速控制信号可以跨区；不要把它与晶体节点混在一起 |

**不能只用标签替代的连接：** 晶体两端、`CL1`/`CL2`、`RExt`、`RF`、局部地。原因不是“标签不电气”，而是标签会把走线长度、回路面积和寄生电容从图上抹掉；DRC 只检查连接关系。

**标签命名与作用域：**

- `OSC_IN`/`OSC_OUT` 只在本页/本块出现，不跨页；不要用 `CLK`、`XTAL` 之类模糊网名把 HSE 和 LSE 混在一起。
- LSE 用 `OSC32_IN`/`OSC32_OUT`，与 HSE 分开；同一脚既做 RTC 又做 GPIO 时，要用跳线/0 Ω 明确互斥。
- 外部时钟输入（有源晶振/CMOS 时钟）是另一种接法，不能与晶体接法同时画在同一个输入网上（SC23）。
- 若保留测试点，命名要明确“测试用，DNP/短支路”，不要让后人把它当成正常负载。

## 4. PCB 关键器件相对关系

以下是**离线布局草案**，只描述相对关系，不给坐标、间距、层数或叠层。

| 器件/区域 | 相对关系 | 检查点 |
|---|---|---|
| 晶体 | 尽量靠近 MCU 的 `OSC_IN`/`OSC_OUT`，走线短且对称 | 不要跨到板边/连接器/高噪声区（PL19） |
| `CL1`/`CL2` | 紧贴晶体与地；地回归到 MCU 地附近 | 回路面积小，地过孔就近（PL19、RT24） |
| `RExt` | 若装，靠近 `OSC_OUT` 与 `CL2` | 不要把它放到远离晶体的位置 |
| 局部地/guard ring | 晶体周围按手册加 guard ring，局部地就近接 MCU 地 | 不是“随便铺一块铜”；guard ring 要有回归点（PL19） |
| 高噪声源 | `SW` 电感、DCDC、时钟/高速线远离晶体 | 不要从晶体下方穿过；相邻层也要看（RT24、RT04） |
| 机械 | 晶体避开分板线、按键、紧固应力区 | 机械应力会影响晶体/焊点（PL25） |
| 测试点 | 不长期并在 `OSC_OUT`；必要时短时探测 | 探头电容可能停振（MF15、MF29） |
| 三防漆 | 高湿环境按需涂覆，避免漏电 | 漏电会延长启动甚至不起振（MCU-S02 §7.1） |

## 5. 电流路径、信号路径与返回路径

### 5.1 振荡器电流路径

```text
OSC_OUT →（RExt，若装）→ 晶体 → OSC_IN → 内部反相器 → OSC_OUT
```

- 晶体支路里是交流驱动电流；`CL1`/`CL2` 为晶体两端提供交流回流到地。
- 驱动电流的回路是“反相器输出 → 晶体 → 反相器输入”，加上“晶体两端 → 负载电容 → 地 → 芯片地”的返回。
- `DL = ESR·IQ²` 里的 `IQ` 是流过晶体的 RMS 电流；`ESR` 是晶体串联电阻，不是负载电容的 ESR。
- `RExt` 串在回路里会降低驱动电流，但也会增加 `gmcrit` 的分母项（`ESR+RExt`），所以它不是“加了更安全”，而是“用负阻余量换驱动电平”。

### 5.2 信号路径

- 晶体输出是时钟信号，送到 MCU 内部时钟树；外部只看到 `OSC_IN`/`OSC_OUT` 两个节点。
- `OSC_OUT` 是驱动节点，幅度/波形对探头负载敏感；`OSC_IN` 是高阻输入节点，更容易受寄生/漏电影响。
- LSE 的 `OSC32_IN/OUT` 频率低、阻抗高，启动时间约 1–5 s；布局/漏电对它的影响比 HSE 更明显。

### 5.3 返回路径与参考层

- `CL1`/`CL2` 的地必须回到 MCU 地附近的局部地，不能穿过数字开关电流或功率回流。
- guard ring/局部地要有一个明确的回归点；不能只铺一圈铜但不接回 MCU 地。
- 晶体下方/相邻层的铜和走线要按具体振荡器/布局指南处理；不要套“晶振下方必须挖空”或“随便铺”的绝对口号（PL19）。
- 原理图只显示“电容接地”，看不见地回流是否绕远、guard ring 是否真的接到 MCU 地；这些必须在 PCB 上检查。

### 5.4 原理图看得见与 PCB 必须查的分界

| 项目 | 原理图可见 | 只能在 PCB 上检查 |
|---|---|---|
| 拓扑 | 晶体/外部时钟二选一，`CL1`/`CL2`/`RExt`/`RF` 是否装 | 走线长度、回路面积、寄生电容 |
| 负载电容 | 标称值、C0G/NP0、容差 | 实际 `Cs`、焊盘/走线寄生、地回归 |
| 负阻 | 晶体 `ESR`、MCU `gm` 是否记录 | 实际起振、负阻法 `Sf`、温度/批次余量 |
| 驱动电平 | `DL(max)`、`RExt` 是否装 | 实际 `Vpp`、`DL`、探头影响 |
| 地/guard | 局部地/guard ring 的意图 | guard ring 是否闭合、回归点、相邻层干扰 |
| 机械/环境 | 晶体位置、涂覆要求 | 分板应力、壳体应力、湿度/污染 |

## 6. 常见错误及其后果

| 错误 | 图上表现 | 实际后果 | 为什么会通过 DRC/肉眼 |
|---|---|---|---|
| 照抄 18 pF/20 pF 负载电容 | 电容值看起来“常见” | `CL` 与晶体不匹配，频率偏移；电容过大还会降低负阻余量、延长启动 | DRC 不检查 `CL`；肉眼看到“参考板也是这个值” |
| 用 X7R/Y5V 做负载电容 | 容值标称正确 | 容值随电压/温度变化，`CL` 被拉偏；频率漂移、起振余量下降 | DRC 不看介质；BOM 上只写容值 |
| 芯片已内置 `RF`，又外加 1 MΩ | 图上多一个反馈电阻 | 改变偏置/负阻，可能不起振或波形异常 | DRC 不检查内部 RF；肉眼觉得“加反馈更稳” |
| 默认串 1 kΩ `RExt` | 图上多一个电阻 | 负阻余量被吃掉；本算例 995 Ω 时 margin 约 0.93，直接不合格 | DRC 不计算 `gmcrit`；肉眼看到“限流电阻”以为保护 |
| 晶体走线拉到页面另一头/板边 | 网表正确，ERC 通过 | 走线电感和寄生电容改变负载；易受噪声耦合，起振/频率变差 | DRC 只查连接；图上一条线连过去看不出长度 |
| `OSC_OUT` 上长期挂测试点/探头 | 测试点是个合法焊盘 | 探头电容可能直接停振；测试点支路也是天线 | DRC 不检查寄生；肉眼觉得“留测试点方便调试” |
| 负载电容的地绕到数字/功率地 | 都叫 `GND`，ERC 通过 | 开关噪声叠加到振荡器，抖动/停振；LSE 更敏感 | 原理图只有一个地符号；DRC 不区分回流 |
| 金属封装晶体外壳接振荡器地 | 外壳画了地符号 | 外壳电容改变振荡条件；按 AN2867 §7.1 不应接振荡器地 | DRC 不检查器件外壳；肉眼看到“接地更安全” |
| LSE 选 `CL=12.5 pF` | 晶体参数看起来正常 | 外部电容需约 21 pF，超过 `CL1/CL2` 的 15 pF 上限；无法配到标称负载 | DRC 不检查晶体 `CL`；肉眼只看到“32.768 kHz” |
| 晶体与外部时钟同时接在 `OSC_IN` | 图上两个源都连到同一输入 | 两个源互相驱动/冲突，起振失败或时钟异常 | ERC 可能只报多个驱动，未必阻断；肉眼看到“都接时钟脚” |
| 高湿环境未涂覆/guard ring 不闭合 | 图上有 guard ring 意图 | 漏电延长启动甚至不起振；量产/现场失效 | DRC 不检查湿度/污染；肉眼看到一圈铜以为完成 |

## 7. 改善后的方案与检查方法

### 7.1 改前/改后（分析上的方案，不对应真实工程改动）

| 项目 | 改前（常见草稿） | 改后（分析建议） |
|---|---|---|
| 负载电容 | 照抄 18 pF/20 pF，X7R | 按 `C = 2(CL−Cs)` 算（本算例 10 pF），选 C0G/NP0、1% 或更高 |
| `RF` | 外加 1 MΩ | 查芯片是否内置；内置则不外加 |
| `RExt` | 默认 1 kΩ | 先算 `DL`；不超限则 0 Ω/DNP；超限再选值并重算 `gmcrit` |
| 布局 | 晶体放板边，走线长 | 晶体紧邻 MCU，短/对称，局部地/guard ring |
| 测试点 | `OSC_OUT` 长期挂测试点 | 不长期加；必要时短时探测，测完移除 |
| LSE | 用 12.5 pF 晶体 | 选 `CL ≤ 7 pF`；外部电容不超过 15 pF 上限 |
| 地 | 负载电容随便接 `GND` | 局部地就近回 MCU 地，不穿过数字/功率区 |

### 7.2 电气复算

1. **负载电容**：`CL = CL1·CL2/(CL1+CL2) + Cs`。取 `CL1 = CL2 = C`，`C = 2(CL−Cs) = 2×(9−4) = 10 pF`。校验：`10×10/(10+10)+4 = 5+4 = 9 pF`。
2. **临界跨导**：`gmcrit = 4·ESR·(2πF)²·(C0+CL)²`。
   `2πF = 1.0053×10⁸ rad/s`，平方 `1.0107×10¹⁶`；
   `(C0+CL) = 16 pF`，平方 `2.56×10⁻²² F²`；
   `gmcrit = 4×50×1.0107×10¹⁶×2.56×10⁻²² = 5.17×10⁻⁴ A/V = 0.517 mA/V`。
3. **负阻余量**：`gm/gmcrit = 10/0.517 = 19.3 > 5`，按本例假设通过。若 `gm` 换成手册 min 值、`ESR` 换成 max 值后余量仍 >5 才算设计通过。
4. **驱动电平**：`DL = ESR·(πF·Ctot)²·Vpp²/2`，`Ctot = CL1 + Cs/2 + Cprobe = 10+2+0 = 12 pF`。
   `πF·Ctot = 6.032×10⁻⁴`，平方 `3.638×10⁻⁷`；
   `DL = 50×3.638×10⁻⁷×1²/2 = 9.1×10⁻⁶ W = 9.1 µW`。
   若晶体 `DL(max)=100 µW`，余量足够，不需要 `RExt`。若 `DL(max)=10 µW`，9.1 µW 只剩约 1.1 倍余量，应考虑 `RExt` 或更低 ESR/更低 Vpp 的晶体。
5. **`RExt` 初值**：`RExt = 1/(2πF·CL2) = 1/(1.0053×10⁸×10×10⁻¹²) ≈ 995 Ω`。若直接装 995 Ω：
   `gmcrit' = 4×(50+995)×1.0107×10¹⁶×2.56×10⁻²² = 10.8 mA/V`；
   `margin = 10/10.8 = 0.93 < 5`，**不合格**。这说明“初值公式”是过驱动时的起点，不是默认要装的值。
6. **折中 `RExt`**：若装 100 Ω，`gmcrit' = 0.517×(150/50) = 1.55 mA/V`，`margin = 10/1.55 = 6.45 > 5`；驱动电平按串联分压粗略降到约 1/3（约 3 µW，实际以 Vpp 实测为准）。若装 470 Ω，`gmcrit' = 0.517×(520/50) = 5.38 mA/V`，`margin = 1.86 < 5`，不合格。
7. **LSE 校验**：32.768 kHz 晶体取 `CL=7 pF`、`Cs=2 pF`，`C = 2(7−2) = 10 pF`，在 `CL1/CL2` 的 15 pF 上限内（MCU-S01 §6）。若用 `CL=12.5 pF`，`C = 2(12.5−2) = 21 pF > 15 pF`，不可用——这正是 AN4488 明确“不要用 CL=12.5 pF”的原因。
8. **频率误差**：负载电容容差会变成频率误差。10 pF、1% 的 `CL1/CL2` 各 ±0.1 pF，串联后约 ±0.05 pF；若换成 5% X7R，各 ±0.5 pF，串联后约 ±0.25 pF。具体 ppm 需要该晶体的 `Cm`/可拉性，本文没有给 `Cm`，因此不能把“0.05 pF 等于多少 ppm”写成结论。可拉性公式为 `Pullability (ppm/pF) = Cm×10⁶/(2(C0+CL)²)`（MCU-S02 §3），须用所选晶体数据计算。
9. **启动时间**：MHz 级晶体典型几 ms；32.768 kHz 约 1–5 s（MCU-S02 §3）。固件等待时间必须覆盖；LSE 不能用 HSE 的“几 ms”经验。

### 7.3 不同芯片的参考值不能照抄

- **RP2040 参考设计**用 12 MHz 晶体、两颗 15 pF 对地电容、1 kΩ 串联电阻，并明确说明换晶体参数或 IOVDD 必须重新测试（MCU-S05 §2.3）。这组值只适用于该参考设计与 3.3 V IOVDD，不是通用 16 MHz 方案。
- **ESP32-C3** 只支持 40 MHz 晶体，精度 ±10 ppm，XTAL_P 初值串 24 nH，C1/C2 按晶体 `CL` 计算并整体测试微调（MCU-S04）。不能把 STM32 的 8/16 MHz 负载电容直接套过去。
- 这两条不是本例 16 MHz 设计的取值依据，只用于提醒“同一种‘晶振电路’在不同芯片上不是同一套参数”。

### 7.4 检查方法

- **网表回读（有 EDA 时）**：确认 `OSC_IN`/`OSC_OUT` 只连晶体网络（或外部时钟，二选一）；`CL1`/`CL2` 值、`RExt` 装配、`RF` 是否误加；LSE 与 HSE 是否分开。本例未做 EDA 回读。
- **几何检查**：晶体到 MCU 的走线长度/对称性；`CL1`/`CL2` 的地回路；guard ring 是否闭合、回归点是否到 MCU 地；晶体附近是否有 `SW`/DCDC/高速线；测试支路是否存在。
- **仿真（NOT RUN）**：若执行，用晶体等效模型 + MCU 反相器模型做起振仿真，观察起振时间与稳态幅度；通过标准为 `margin > 5` 且幅度稳定。本例未运行仿真。
- **测量（未执行）**：负阻法串可调电阻 `RADD` 测停振点，`Sf = (RADD+ESR)/ESR`；HSE 要求 `Sf ≥ 5`，LSE 要求 `Sf ≥ 3`（MCU-S02 §3）。驱动电平用高阻/低电容探头测 `Vpp` 后按公式算；LSE 建议 0.1 pF 输入电容探头。频率用频率计；启动时间用示波器单次触发。探测本身会改变振荡条件，测完移除。
- **通过标准**：`Sf` 满足 HSE ≥5/LSE ≥3；`DL ≤ 晶体额定`；启动时间在固件等待内；频率误差在系统预算内。具体限值查晶体/MCU 手册。

## 8. 必须保留的身份、连接和接口约束

- **器件身份**：晶体 `Y1` 的完整型号、频率、`CL`、`ESR(max)`、`C0`、`DL(max)`、精度/温度范围、封装；`CL1`/`CL2` 的容值、精度、C0G/NP0、耐压；`RExt`/`RF` 的阻值与装配状态。本文没有给出具体料号。
- **Pin-pad 映射**：`OSC_IN`/`OSC_OUT`（或 `OSC32_IN`/`OSC32_OUT`）的物理脚号与封装焊盘必须核对（SC02）；不能为了走线方便交换。
- **网络身份**：`OSC_IN`、`OSC_OUT`、`OSC32_IN`、`OSC32_OUT` 分开命名；HSE 与 LSE 不能共用负载电容/地；晶体网络不能与外部时钟输入混为同一个网。
- **装配状态**：`RExt` 是 0 Ω、DNP 还是计算值；`RF` 是否内置；LSE 是否兼作 GPIO（跳线/0 Ω 互斥）；这些不能因整理/BOM 替代而丢失（SC08）。
- **布局约束**：晶体紧邻 MCU、短/对称走线、局部地/guard ring、远离 `SW`/DCDC/高速线、测试支路不长期存在；这些是 PCB 约束，不是原理图网名能表达的（PL19、RT24）。
- **机械/环境**：晶体避开分板线/紧固应力区；高湿环境按需三防漆；金属封装外壳不接振荡器地（PL25、MCU-S02 §7.1）。
- **接口**：若使用外部时钟/有源晶振，必须保留其供电、输出电平、OE/ST 极性、启动时间与负载约束；不能与晶体接法同时装（SC23）。

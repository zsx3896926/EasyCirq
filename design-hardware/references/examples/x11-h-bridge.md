## 1. 设计意图与连接基线

这个局部要解决的是：用四个 N 沟道 MOSFET 组成 24 V 有刷电机的 H 桥，20 kHz PWM，额定 1.5 A、堵转 3 A，正转/反转/制动/滑行四种状态都要有明确的电流回路；栅极由两个带自举的半桥驱动器控制；低侧公共回流放一颗采样电阻，用于电流观测与限流。环境 60 °C，目标结温按器件手册另算。

本文按**分立四管 + 两个半桥栅驱**分析，因为这样能把自举、死区、栅极回路、采样地这几个真正决定成败的连接逐项拆开；集成 H 桥（例如 DRV8871 一类）把其中大部分收进芯片，但“母线电容回路、电机连接器、默认态、回生”仍然要在板上处理。器件型号未定；文中出现的 DRV8871 数值只作为“器件实例（条件限定）”，不是本文的选型结论。

必须保持的连接基线：

| 连接 | 从 | 到 | 必须保持的性质 |
|---|---|---|---|
| 母线 | `VM` | 两个高侧漏极 + `C_bulk` 正端 | 换流回路最短，去耦电容与半桥同区 |
| 高侧/低侧中点 | `HS1`/`HS2` | 对应低侧漏极、电机 `OUT1`/`OUT2`、自举电容负端 | 开关节点是 dv/dt 节点，不得被长线/标签拉远 |
| 低侧源 | `LS1`/`LS2` 源极 | 采样电阻 → `PGND` | 功率回流与采样 Kelvin 分开 |
| 自举 | `VDD` → `Rboot` → `Dboot` → `HB` | `Cboot` 跨 `HB`–`HS` | 自举电容紧贴驱动 `HB`/`HS` 脚 |
| 栅极 | `HO`/`LO` | 栅极电阻 → 栅极 | 栅极回路短，源极返回独立 |
| 控制 | MCU PWM/IN | 驱动器输入 | 默认态可定义，复位/bootloader 期间不误导通 |
| 电机 | `OUT1`/`OUT2` | 电机端子 | 极性、连接器视角、线缆固定 |

接口边界：`VM` 与 `PGND`、电机端子 `OUT1`/`OUT2`、MCU 侧 PWM/EN/故障、采样输出到 ADC、栅极驱动供电。H 桥的“地”不是单一地：功率回流、栅极返回、采样参考、逻辑地各自有路径，只在规定点相交。

## 2. 原理图模块内部摆放

按“母线—半桥—电机”的功率流从左到右排：`C_bulk` 放在两个半桥之间靠上，两个半桥各自把高侧与低侧上下对齐，`OUT1`/`OUT2` 向右到电机端子；每个半桥的栅极驱动器放在对应半桥左侧或下方，自举二极管/电阻/电容紧贴驱动器的 `HB`/`HS` 脚；采样电阻画在两条低侧源极汇合之后、`PGND` 之前，`K+`/`K−` 单独引出。

不要把四个 MOSFET 画成“整齐的矩阵”再把栅极线绕到页面另一侧；H 桥的读图重点是每个半桥的上下管、开关节点和自举回路，功率器件的物理邻近关系必须在图上就能看出来。

```text
（分析草图，非 EDA 产物）

          VM ──┬───────────────┬───────────────┐
               │               │               │
            [C_bulk]        ┌──┴──┐         ┌──┴──┐
               │            │ HS1 │         │ HS2 │
               │            └──┬──┘         └──┬──┘
               │          OUT1 │               │ OUT2
               │            ┌──┴──┐         ┌──┴──┐
               │            │ LS1 │         │ LS2 │
               │            └──┬──┘         └──┬──┘
               │               └──────┬────────┘
               │                   [R_SH]
               │                      │
              PGND ───────────────────┘

  每半桥一套栅驱：
    VDD ──[Rboot]──[Dboot]── HB ── Cboot ── HS
    HO ──[Rg]── HS 栅极
    LO ──[Rg]── LS 栅极
    COM ─────── LS 源极
  注释：HS 节点、Cboot、COM 返回必须局部短接；OUT1/OUT2 到电机端子
```

这样摆的理由：自举电容的负端就是开关节点 `HS`，它的充电路径和放电路径都只在“驱动器 `HB`/`HS`—电容—低侧源极”这个小回路里；一旦把 `Cboot` 画到页面另一侧或用网名连接，读图阶段就看不出这个回路的面积，布局阶段也容易把它当成普通去耦。

## 3. 局部短线与标签连接

**必须保留局部短线：**

- `C_bulk` 到两个半桥高侧漏极/低侧源极：这是高 di/dt 换流回路，必须画成连续、短、可读的功率路径；不能用一个 `VM` 标签把电容和半桥分开。
- 自举网络 `VDD → Rboot → Dboot → HB` 与 `Cboot` 跨 `HB`–`HS`：这是高侧栅极偏置的全部能量来源；必须局部、紧贴驱动器引脚。
- 栅极电阻到栅极、源极返回 `COM`/`HS`：栅极回路与功率回路分开，源极返回要独立；不能把栅极线拉成跨页长线。
- 采样电阻 `R_SH` 的 `K+`/`K−` 到采样放大器：Kelvin 对，成对短走。
- 驱动器 `VDD` 旁路电容到 `COM`：去耦回路决定驱动抗扰度。
- 电机端子到 `OUT1`/`OUT2`：若同页，保留短线并标注极性；跨页时用端口而不是长标签。
- 控制输入的默认下拉/上拉：必须画在驱动器输入旁，不能只靠 MCU 内部上拉。

**适合用网络标签/端口：**

- MCU 到驱动器的 `PWM_H1`/`PWM_L1`/`PWM_H2`/`PWM_L2`（或 `IN1`/`IN2`）、`nSLEEP`、`nFAULT`：跨页时用标签，注明有效电平与默认态。
- `VM`、`PGND`：用电源/地符号分配，但必须能追到入口与 `C_bulk`；不能把 `PGND` 与逻辑 `GND` 混成同名。
- 采样输出 `ISENSE_BRG` 到 ADC：用有语义的名字，两端短引线。
- 电机端子：用连接器端口，标注 `OUT1`/`OUT2` 与板端视角。
- 故障/诊断：`nFAULT` 开漏上拉，注明上拉域。

**不能用标签替代：**

- 不能用标签连接 `HB`/`HS` 与自举电容。标签会把“必须紧贴引脚的小回路”变成任意长度的连接，图上失去回路面积的提示。
- 不能把 `VM` 和 `PGND` 只画成两个全局符号而省略半桥之间的功率路径；读图者需要看到电流从哪个管进出。
- 不能把 `OUT1`/`OUT2` 命名为 `M+`/`M−` 后就当成固定极性；H 桥的转向由开关状态决定，名字应表达“桥臂输出”，方向由注释/固件说明。
- 不能把两条低侧源极都直接标 `PGND` 而把采样电阻“旁路”掉；采样电阻必须在回流路径上，图上要能看出电流经过它。
- 不能用全局 `GND` 同时表示功率地、栅极返回和逻辑地；三者若在不同点相交，必须分开画。
- 不能用标签跨过栅极电阻或自举二极管；那会在网表层面短接它们。

**命名与作用域：** `VM`、`PGND`、`BRG_OUT1`/`BRG_OUT2`、`HB1`/`HS1`、`ISENSE_BRG`、`nFAULT`、`PWM_H1`/`PWM_L1` 等；自举网络用页内名，不作为跨页端口；电机连接器端口单独命名，注明板端/线端视角。方向用箭头或 `OUT1→电机→OUT2` 注释。

## 4. PCB 关键器件相对关系

以下是**草案**，只给相对关系，不给坐标、层数、线宽、铜厚或热阻；未实际摆放。

- `C_bulk` 放在两个半桥之间、靠近高侧漏极与低侧源极的换流路径；电容正端到高侧漏极、负端到低侧源极的回路要短而宽。
- 每个半桥的高侧与低侧相邻放置，开关节点 `HS` 的铜面积满足载流/散热但不过度扩张；不要为了整齐把低侧管放到板的另一侧。
- 栅极驱动器紧贴对应半桥，`HB`/`HS`/`HO`/`LO`/`COM` 到 MOSFET 的连线短；自举二极管/电阻/电容贴在驱动器引脚旁。
- 栅极电阻靠近栅极；每个管独立栅极电阻，不共用。
- 采样电阻放在两条低侧源极汇合后的回流路径上，Kelvin 对从本体引出，采样放大器靠近但远离开关节点；采样地不与低侧源极的大电流铜共用。
- 电机端子放在板边，`OUT1`/`OUT2` 成对走、足够宽；端子附近留电机线固定/应力释放。
- 功率地与逻辑地分区，在控制器/采样放大器处单点相交；不要让数字回流穿过功率地铜。
- 热：MOSFET 的散热铜/过孔按器件与板级热阻评估；采样电阻远离热源，避免热电动势。
- 默认下拉、`nFAULT` 上拉、`nSLEEP` 电阻靠近驱动器输入，不要放在 MCU 页远端。

```text
（分析草图，非 EDA 产物，仅表示相对关系，不代表坐标）

 [电机端子]
     │
   OUT1 ──[HS1/LS1]──┬──[C_bulk]──┬──[HS2/LS2]── OUT2
                     │             │
                  [栅驱1]       [栅驱2]
                     │             │
                  [R_SH + 采样] ── PGND
 关键：C_bulk 到两个半桥的换流回路最短；栅驱贴半桥；采样远离开关节点
```

## 5. 电流路径、信号路径与返回路径

**按开关状态的关键电流回路：**

- **正转（HS1 + LS2 导通）：** `VM → HS1 → OUT1 → 电机 → OUT2 → LS2 → R_SH → PGND → C_bulk 负端`。
- **反转（HS2 + LS1 导通）：** `VM → HS2 → OUT2 → 电机 → OUT1 → LS1 → R_SH → PGND`。
- **制动/慢衰减（LS1 + LS2 导通）：** 电机电流在 `电机 → LS2 → 公共源极节点 → LS1 → 电机` 内循环，母线不参与。**如果采样电阻在公共源极节点之下，制动电流不经过它**；这是单电阻采样的观测盲区，不是布局能修的。
- **滑行/快衰减（四管全关）：** 电机电感维持电流，经体二极管回到 `VM`，母线被顶高；反向电压约为 `VM + 两个体二极管压降`（DRV-S10 §2.2）。
- **高频换流回路：** 每个半桥的 `C_bulk → 高侧 → 开关节点 → 低侧 → 回电容`，这是布局最关键的回路；`V_DS` 尖峰近似 `L_s × di/dt`，回路越大尖峰越高（DRV-S05 §9）。
- **自举刷新回路：** 低侧导通时 `VDD → Rboot → Dboot → Cboot → HS → LS → COM`；高侧导通时 `Cboot → HB → HO → 高侧栅极 → HS`。

**敏感信号路径：** `R_SH` 的 `K+`/`K−` → 采样放大器 → ADC；栅极驱动 `HO`/`LO` → 栅极电阻 → 栅极；`nFAULT`、PWM 输入。栅极回路与采样回路都不能与功率换流回路共用返回段。

**返回路径：** 功率回流从低侧源极 → `R_SH` → `PGND` → `C_bulk` 负端；栅极返回从栅极源极 → `COM`/`HS` → 驱动器；采样返回从 `K−` → 采样放大器地；逻辑返回回到控制器地。四者在单点相交，不能各自找“最近的地”。

**原理图上看不出来的：**

| 项目 | 原理图能表达 | 必须在 PCB 核对 |
|---|---|---|
| 换流回路面积 | 只能表达连接 | `C_bulk`—高侧—低侧—回电容的实际铜回路与过孔 |
| 自举回路 | 能表达 `HB`/`HS`/`Cboot` | 电容是否贴引脚、回路是否被拉长、是否与功率回流共用 |
| 栅极回路 | 能表达串联电阻 | 栅极—源极环路面积、源极返回是否独立、是否被功率铜分割 |
| 死区/直通 | 只能靠注释与驱动配置 | 实际驱动时序、关断延迟差、体二极管导通窗口 |
| 采样是否经过制动电流 | 能表达拓扑 | 采样电阻在公共源极节点之上/之下，制动回路的实际铜 |
| 回生路径 | 能表达钳位/斩波 | 母线电容、TVS/制动斩波的位置与回路，线缆电感 |
| 默认态 | 能表达下拉/上拉 | 复位/bootloader 期间驱动器输入的实际电平与电机状态 |
| 热 | 只能表达散热铜 | 实际铜面积、过孔、气流、结温 |

## 6. 常见错误及其后果

| 错误 | 图上表现 | 实际后果 | 为什么会通过 DRC/肉眼 |
|---|---|---|---|
| 自举电容放在驱动器远处，`HB`–`HS` 用长线/标签 | 网表连接正确 | 自举回路电感大，高侧栅极驱动振铃/欠压，高占空比时掉出 UVLO | DRC 只查连通与间距，不查回路面积；视觉上“连接正确” |
| `Cboot` 只按“ reference 值”随手取小 | 图上有一个电容 | 高侧栅极电荷不足，`V_HB` 跌落触发 UVLO，高侧提前关断；严重时丢脉冲 | ERC 不检查自举容量；肉眼无法从符号看出容值是否够 |
| `Rboot` 取 0 Ω 或过小 | 图上只是一个电阻 | 启动/刷新时二极管峰值电流大（`Ipk=(VDD−Vf)/Rboot`），二极管/驱动受冲击；`dv/dt` 干扰 LO/HO | DRC 不检查峰值电流；0 Ω 看起来“最强” |
| 死区不足或只靠软件互补 | 互补 PWM 看起来正确 | 上下管直通，`V_DS` 尖峰与 SOA 应力，可能瞬时损坏 | DRC 不检查时序；原理图无法表达 ns 级死区 |
| 制动时两低侧导通，但采样电阻在公共源极节点之下 | 图上“采样电阻在回流里” | 制动电流在 `LS2→LS1` 内循环，不经过 `R_SH`；控制器以为电流为零 | 连接正确；只有按状态画电流回路才发现观测盲区 |
| 采样 Kelvin 与低侧源极大电流铜共用 | 图上仍是两条网络 | 源极回流在采样段产生压降，增益误差/振铃；低侧开关噪声进入放大器 | DRC 不区分“同网络铜皮上流什么电流” |
| `C_bulk` 放在板子入口，远离半桥 | 图上电源连接正确 | 换流回路大，`V_DS` 尖峰高，EMI 差；电容纹波电流被长铜分摊 | DRC 只查间距；视觉上“电容在电源入口很合理” |
| 栅极电阻省略或四个管共用 | 图上栅极直接连 | 栅极振铃、误开通、直通；并联/共用时开关不同步 | ERC 不检查栅极网络；短路连接看起来更简单 |
| 控制输入在复位时悬空 | 图上只连到 MCU | 电机在复位/bootloader/程序崩溃时意外动作 | ERC 不检查默认态；MCU 内部上拉不一定在复位期间有效 |
| 电机端子 `M−` 被当成地接到 `PGND` | 图上像“回路” | 低侧管导通时电源经高侧/低侧短路，或制动时电流路径错误 | 网表连接正确；丝印/视觉上看不出“这是桥臂输出不是地” |
| 回生/减速没有钳位或制动斩波 | 图上没有额外器件 | 母线被电机能量顶高，超过电容/器件耐压；`ΔV ≈ I×t/C` | DRC 不检查能量；空载/轻载测试可能不触发 |
| 单电阻采样在 PWM 关断期间采样 | 图上没有采样时序 | 读到的是续流/零电流而不是相电流，控制环失真 | 原理图不表达采样时刻；DRC 不检查固件时序 |

共同点：**H 桥的很多失效是“时间 + 回路面积 + 电流方向”的问题。** DRC 保证的是几何间距和连通性；ERC 保证的是引脚/网络语义。它们都不会告诉你自举电容的回路有多大、死区是多少 ns、制动电流走哪条铜。

## 7. 改善后的方案与检查方法

**改前/改后（分析层面，不是实际工程改动）：**

- 改前：`C_bulk` 在板入口；自举件散放在驱动页；栅极线跨区；采样电阻在两条低侧源极之前；控制输入只靠 MCU 内部上拉；无回生钳位。
- 改后：`C_bulk` 移到两个半桥之间；自举件贴 `HB`/`HS`；每管独立栅极电阻；采样电阻放在公共回流并做 Kelvin；驱动器输入加默认下拉；按最坏回生加母线电容/钳位/制动斩波；明确制动/滑行默认态。
- 连接是否保持：若真在工程执行，应比较整理前后的 MOSFET 引脚—网络成员、自举件连接、采样 Kelvin 对、连接器极性；本范例没有工程，无法回读。

**哪些结论来自几何：** `C_bulk` 与半桥的相对位置、自举件到 `HB`/`HS` 的距离、栅极回路面积、采样电阻在回流中的位置、功率地/信号地分区、散热铜。这些只能看实际布局与铜皮。

**哪些结论来自电气计算（示例假设，不是器件保证）：**

- 自举电容：设 `Qg = 20 nC`（假设）、`VDD = 12 V`、`Vf_boot = 0.7 V`、允许 `ΔVHB = 1.0 V`。
  - `Cg = Qg/(VDD − Vf) = 20 nC/11.3 V = 1.77 nF`
  - `Cboot ≥ 10 × Cg = 17.7 nF`（DRV-S01 的经验规则）
  - 电荷判据 `Cboot ≥ Qtotal/ΔVHB ≈ 20 nC/1 V = 20 nF`
  - 候选 47 nF，必须用实际 `Qg`、自举二极管压降、UVLO 与最小占空比重算。
- `Rboot` 峰值：`Ipk = (12 − 0.7)/Rboot`；2.2 Ω → 5.14 A，10 Ω → 1.13 A。要核对二极管峰值额定与驱动耐流；`τ = Rboot × Cboot/duty`，10 Ω/47 nF 在 duty = 1 时约 0.47 µs，低占空比下充电窗口按比例变长，但可用于充电的时间更短，必须一起核对。
- `CVDD ≥ 10 × Cboot = 470 nF`；候选 1 µF，仍需按驱动手册。
- 死区损耗：设 `Vf = 1.5 V`、`I = 1.5 A`、`t_dead = 300 ns`、`fsw = 20 kHz` → `P ≈ 1.5 × 1.5 × 300 ns × 20 kHz = 13.5 mW`，量级很小，但死区期间体二极管导通与电流畸变要在控制上接受。
- 回生：设 `I = 3 A`、`t = 1 ms`、`C_bus = 470 µF` → `ΔV = I×t/C = 6.38 V`，24 V 母线抬到约 30.4 V；吸收能量 `½C(V²−V0²) ≈ 0.082 J`。若器件按 40 V 级选型，这个抬升已吃掉相当一部分余量；实际必须按负载惯量、减速时间与线缆电感重算，不能只用这组假设。
- 器件实例（条件限定）：若改用集成 H 桥 DRV8871（SLVSCY9B），手册典型 `R_DS(on)` 高低侧合计 565 mΩ、`RθJA = 41.1 °C/W`（JEDEC 条件）、内部死区典型 220 ns、`tOFF` 典型 25 µs；1.5 A 时 `P ≈ 1.27 W`、`ΔT ≈ 52.3 °C`，60 °C 环境结温约 112 °C；2 A 时已超过 150 °C 绝对最大。这说明“峰值 3.6 A”不等于可连续 3.6 A，热与封装才是连续电流的边界（DRV-S02 §6.1、§6.4、§6.5、§7.3.4）。

**复验方法：**

- 上电前：检查四个管的方向/引脚、母线电容极性、栅极电阻、默认下拉、电机端子极性；限流电源先小电流上电。
- 栅极波形：用差分探头看 `V_GS`（高侧相对 `HS`），确认死区、振铃、米勒平台；不要用普通接地示波器直接碰高侧浮动节点。
- 自举：看 `V_HB−V_HS` 在低侧导通窗口内的充电与高侧导通时的跌落；确认不低于驱动 UVLO。
- 采样：在 PWM 导通中点触发采样，分别看正转/反转/制动/滑行；确认制动时采样是否真的为零（由此判断观测盲区）。
- 回生：受控减速，测母线电压峰值与电容纹波；必要时加钳位/制动斩波后再测。
- 热：按 MF28 渐进加载，记录壳温/结温估算与环境；停止条件为超 SOA、超结温、母线过压、直通。
- 测量记录按 MF29：探头地线、带宽、接地点、负载、温度、PWM 条件都要写清。

**未执行/未验证：** 未做 EDA 回读、未做仿真、未做双脉冲/热/回生实测；`Qg`、`Vf`、`C_bus`、`Rboot`、死区均为假设或候选值；MOSFET 的 SOA、体二极管反向恢复、栅极电荷、热阻、封装寄生均未按具体型号核对。相关检查项见 SC21、SC39、SC09、SC18、PL09、PL11、PL13、PL14、PL16、RT01、RT02、RT06、RT07、RT09、RT23、MF28、MF29。

## 8. 必须保留的身份、连接和接口约束

| 项目 | 必须保留 | 丢失/改动后的后果 |
|---|---|---|
| 四个 MOSFET 完整型号/封装 | `V_DS`、`R_DS(on)`@`T_J`、`Q_g`、SOA、体二极管、热阻 | 换管后自举电容、死区、热预算全部要重算 |
| 栅极驱动器完整型号 | `VDD` 范围、UVLO、死区/interlock、`HB`/`HS`/`HO`/`LO`/`COM` 定义 | 只换后缀可能改变 UVLO 或自举方式 |
| 自举二极管 | 耐压、正向压降、结电容、反向恢复、峰值电流 | 慢恢复会在 `HB`–`HS` 产生过冲，触发 UVLO |
| `Cboot`/`Rboot`/`CVDD` | 容值、耐压、介质、封装、`Rboot` 阻值 | 容值不足高侧掉电；`Rboot` 过小峰值电流过大 |
| 栅极电阻 | 每管独立、阻值、功率、封装 | 共用/省略导致振铃、误开通、直通 |
| 采样电阻 | 阻值、功率、容差、TCR、四端/Kelvin | 换成两端件会失去 Kelvin；功率不足会漂移 |
| 电机端子 | 位号、Pin-1、`OUT1`/`OUT2`、板端/线端视角 | 接反/把输出当会导致电机反转或桥臂短路 |
| 网络名与作用域 | `VM`、`PGND`、`HB1`/`HS1`、`ISENSE_BRG`、`nFAULT` | 改名/全局化会把功率地、逻辑地、隔离地混在一起 |
| 默认态 | 输入下拉、`nSLEEP`、`nFAULT` 上拉、复位/bootloader 行为 | 电机在复位/下载时意外动作，违反安全默认态 |
| 保护/钳位 | TVS、制动斩波、母线电容、保险的装配状态 | DNP 不等于无连接；漏装会让回生/浪涌无去处 |
| 变体 | 集成/分立方案、单电阻/双电阻采样、制动方式 | 不同变体不能共用同一 PCB 丝印与 BOM 而不标注 |

不得在未核对的情况下改动 MOSFET 引脚（G/D/S 依封装与型号）、驱动器 `HB`/`HS` 定义、自举二极管方向、电机端子极性。本文不给具体栅极电阻、死区 ns、线宽或铜厚：它们必须按器件手册、开关频率、栅极电荷与实际叠层确定。

# F01 ODrive 电流采样寄生电阻导致比例误差

> **证据等级：** `A`。ODrive 硬件作者在 v3 CHANGELOG 中把 v3.4 的缺陷直接写为“额外的表观分流电阻导致电流测量比例误差”，并在 v3.5 把 Kelvin 连接净距用 net-tie 固化。作者确认的是原因与修复，没有给出误差百分比、波形或测试条件；本案例不填这些数字。TI SSZT805 只用于解释误差机理（式 2），不替代 ODrive 的作者记录。
>
> **适用边界：** 只适用于低侧分流、运放或电流检测放大器差分取压、功率电流与感测线可能共用铜皮的布局。高侧/在线采样、集成分流电阻的器件、四端分流器不直接套用。
>
> **关联：** 设计卡 [ANA-06 低侧电流采样](../design-cards/analog/a06-low-side-sense.md)、[ANA-07 高侧电流采样](../design-cards/analog/a07-high-side-sense.md)；范例 [x09 低侧 Kelvin 电流采样](../examples/x09-current-sense.md)；检查项 [SC36](../schematic-details.md)、[PL14](../pcb-placement-details.md)、[RT07、RT21](../pcb-routing-details.md)、[DM19](../domain-design-details.md)。

## 现象

电流环在整段量程上偏高或偏低一个近似固定的比例：10% 额定电流与 80% 额定电流的相对误差接近，零电流附近又能回到零。表现为“增益错”而不是“零点漂移”：

- 力矩常数标定后仍然偏，电流限幅、力矩估算和过流保护阈值都按错误比例工作。
- 同一固件换一块板，误差比例改变；同一块板改布局后整批改变。
- 用外部钳形表、串联分流表或电源读数交叉核对时，读数比值不随电流大小明显变化。
- 发生阶段通常在样机功能测试或电流环整定时；不是上电即死机，因此容易被误判为“固件标定问题”。

## 工况

- 板卡：ODrive v3 类低侧采样电机驱动板；按 CHANGELOG 时间线，缺陷存在于 v3.4（2017-11-04）之前的板版。具体板号、装配变体和分流电阻料号必须按实际工程记录填写，本案例不代填。
- 功率级：24 V 母线、三相半桥、低侧分流；PWM 连续输出；电机台架或堵转加载。
- 采样链：分流电阻两端经差分放大器/电流检测放大器送入控制器 ADC；放大器增益由外部电阻或内部固定增益决定。
- 环境：室温台架；未做高低温与批量统计。测量仪器、量程、探头接法和校准日期需在工程记录中写明。
- 装配变体：分流电阻是否手焊、是否换过料号、是否使用四端封装，都会改变寄生占比。

## 原因假设

- **H1 分流电阻本身超差或温漂过大。** 若成立：误差应落在电阻容差/温漂范围内，换料号才变化；不会因为改版布局而整批改变；四线测量电阻体可证实。
- **H2 采样走线与功率走线共用一段铜，寄生电阻 `R_STRAY` 与 `R_SHUNT` 串联。** 若成立：输出按 `(R_SHUNT + R_STRAY) / R_SHUNT` 成比例放大，零电流仍为零；误差比例与电流大小近似无关；把感测点移到分流器焊盘内侧后误差变小。
- **H3 放大器增益电阻失配或增益设置错。** 若成立：也是比例误差，但与布局无关，从首版就存在；换增益电阻或改增益配置才变化。
- **H4 放大器 `R_G` 的地与分流电阻的地之间存在地平面电位差。** 若成立：主要是偏移误差（零电流不为零），不是纯比例；式 3 的 `V_GND_OS` 项会随功率电流变化。
- **H5 ADC 基准或分压错误。** 若成立：会同时影响母线电压、温度等其他通道，不是单通道比例误差。
- **H6 固件标定系数错。** 若成立：所有同版板表现一致，改固件即变；与板版和布局无关。

## 区分假设的检查

按“先安全、再无损、再侵入”的顺序：

**安全（不上电、不拆焊）**

1. 读原理图与 PCB：分流器两端到放大器/控制器的两条 sense 线是否从焊盘内侧引出；功率铜是否从同一焊盘外侧进出；两条 sense 线是否彼此成对、是否穿过功率铜。可支持或排除 H2。
2. 查 BOM 与换料记录：分流器阻值、容差、温漂、封装、是否四端；增益电阻型号与容差。支持或排除 H1、H3。
3. 查原理图的取样参考点：`R_G` 的地是否回到分流器低端，还是回到远处的系统地。支持或排除 H4。

**无损（上电测量，不改变硬件）**

4. 零电流下读采样输出。若明显偏离零点，优先指向 H4/H5，而不是 H2。
5. 在两个相差较大的电流点（例如 20% 与 80% 额定）用外部表对比，计算两点的相对误差。比例接近 → H2 或 H3；随电流明显变化 → 先查 H4/H5。
6. 用示波器看 PWM 开关沿时 sense 线上的共模与尖峰。它只能说明是否叠加了动态误差，不能单独证明比例误差来自哪里。

**侵入（拆焊、飞线、注入；仅在安全限流和热管理下进行）**

7. 从分流器焊盘内侧直接飞线到放大器输入，临时做 Kelvin 连接，重测同两个电流点。误差显著减小 → 证实 H2。飞线只用于证实，不能作为量产修复。
8. 拆下分流器，用四线法测电阻体实际值。排除 H1。
9. 用已知电流源或短接放大器输入，分离“放大器/增益”与“布局寄生”。大电流注入必须限流并监控温升。

## 根因证据

- **作者已证实（A）：** ODrive v3 CHANGELOG（仓库 `v3/CHANGELOG.md`，master 分支，核对日期 2026-10-20；条目自带版本号与日期，仓库未提供 commit SHA，本文不杜撰）：
  - `## [3.4] - 2017-11-04` 的 Changed：`Fixed extra apparent shunt resistance, which caused a current measurement scale error`。
  - `## [3.5] - 2018-04-24` 的 Fixed：`Clearance of shunt resistor kelvin connections now enforced with net-tie`。
  这两条把“额外的表观分流电阻 → 电流测量比例误差”和“用 net-tie 固化 Kelvin 净距”直接写成设计修订，属于硬件作者对根因与修复的确认。
- **原厂机理（B，仅解释机理）：** TI SSZT805 式 2：`V_out = I_LOAD × (R_SHUNT + R_STRAY) × Gain`，明确把未做 Kelvin 时的杂散电阻写成增益误差；式 3 把地平面电位差写成偏移误差。它说明“为什么是比例误差”，不证明 ODrive 的具体寄生值。
- **合理推断（C）：** 具体这块板的 `R_STRAY` 大小、误差百分比、两个通道是否同时出现，CHANGELOG 没有给出。若要用比例误差反推 `R_STRAY`，需要该板实际 `R_SHUNT` 与两点电流标定数据；本案例不填数字。
- **仍待验证：** 哪一段铜（焊盘、过孔、连接器、地回流）贡献了主要寄生；需要拆焊四线测量或改版前后对比。CHANGELOG 没有给出测量波形或批量数据。

## 修复

- **布局（主修复）：** sense 线从分流器焊盘内侧的专用取样点引出，功率电流从焊盘外侧进出；两条 sense 线成对走、不穿过功率铜；放大器 `R_G` 的地单点回到分流器低端。对应 [RT07](../pcb-routing-details.md) 与 [PL14](../pcb-placement-details.md)。
- **原理图/库：** 用 net-tie 或明确的四端符号把“功率端”和“感测端”分开表达，避免 EDA 把两者当成同一节点。net-tie 只在工具支持且版图能落实净距时使用，这正是 v3.5 记录的做法。
- **BOM：** 这个缺陷不要求换分流器；除非四线测量证明电阻体本身超差，否则换料号会掩盖问题。
- **封装：** 若分流器封装没有独立 sense 焊盘，换四端封装或调整焊盘引出方式；这属于封装/布局变更，需要重新做热与载流核算。
- **固件：** 可以临时用增益系数补偿让台架可用，但不能修复随电流、温度和装配变化的寄生；正式版不应以固件标定掩盖布局缺陷。
- **装配变体：** 手焊/返修板必须与量产采用同一取样方式，否则标定系数不可移植。

## 复验

- **条件：** 同一板版、同一固件、同一分流器料号；记录母线电压、温度、PWM 频率与占空比；外部表精度应优于待测误差的 1/3；在 20% 与 80% 额定电流、正反两个方向取点；连续 PWM 输出，不用单次脉冲。
- **通过标准：** 两点相对误差的差异落在项目给定的误差预算内（预算本案例不代填）；零电流偏移不超过预算；改版前后同一电流点的读数一致性优于预算；不再出现“误差随电流成固定比例”的现象。
- **实际结果：** 未执行。没有这块板改版前后的测量数据，也没有波形；CHANGELOG 只是作者修订记录。

## 适用边界

- **适用：** 低侧分流、运放/电流检测放大器差分取压、功率铜与感测线可分离的布局；尤其是大电流、小阻值分流，寄生占比大。
- **需要重新分析：** 高侧/在线采样（共模与 PWM 瞬态主导，见 ANA-07）；集成分流电阻的器件（内部已做 Kelvin）；四端分流器（寄生主要在焊盘/过孔而不是电阻体）；多相或并联分流。
- **不能证明：** 不能证明所有电流比例误差都来自寄生电阻；不能给出 ODrive 的具体误差百分比；不能把 net-tie 当成所有 EDA 都支持的修复；不能替代改版后的实测。

# 嘉立创业务：从图纸到实物的正确衔接

打板/贴片任务同时执行 [生产规则接入](jlc-production.md)，由Agent按当前工艺/渠道建立 [生产档案](../assets/manufacturing-profile.md)。PCB能力、SMT装配和EDA实际规则分别核对；依 [PCB生产规则](jlc-pcb-rules.md) 与 [SMT生产规则](jlc-smt-rules.md) 选择适用项，不等到导出时才查制造要求。

## 按用户想收到什么选择路线
| 用户想要的结果 | 主要业务与交付 |
|---|---|
| 先看方案/图纸 | 嘉立创EDA中可编辑原理图/PCB与检查；不自动购料 |
| 买零件自己焊/做接线实验 | 立创商城购料清单，按需PCB/钢网等；明确用户所需工具与装配工作 |
| 收到工厂焊好的板 | 嘉立创PCB + SMT独立选料/报价/工艺核对，BOM/坐标与变体一致 |
| 已有元件或特殊来料 | 按当前服务是否接受、包装/备损/交付规则核对，不承诺所有物料都能代贴 |
| 产品需外壳/面板/机械件 | 只在真实需要时对接面板、FA、3D打印/CNC等当前服务；依据机械尺寸与装配，不强推额外业务 |

## 业务边界
立创商城采购与嘉立创SMT下单的元件选购是独立流程，库存/价格独立核对。商城有货、EDA有库、SMT能贴、已经备料、已经下单是不同状态。
基础库/扩展库等标签以当前SMT渠道与服务类型核对，费用、活动、适用工艺/数量随实际订单确认。不要把旧优惠、固定换料费、账号福利或“商城买过”当成自动免料费/免换料费或可贴证明。
不要混用国内与海外站点的币种、库存和费用规则；按用户地区与实际订单路线选择，不能将JLCPCB/LCSC海外数据直接作为国内结算承诺。
商城购料不是SMT私有库存自动入库，也不代表SMT单已选中该物料。若实际服务存在备料/预订/客户自有料流程，读取当前指引并单独核对状态。

## 设计阶段提前考虑制造
关键器件选型时就检查目标装配路线的封装/供应/贴装条件。手焊新手优先考虑可焊性、工具和可返修性；工厂装配则按实际工艺和成本比较，不能为基础库强行更换不等价器件。
在可行方案中比较总成本、板层/尺寸/工艺、物料种类、交期与返修；不单看某颗芯片单价，避免便宜替代导致封装/固件/工艺成本增加。
涉及安装孔/接口/壳体时先锁定机械条件，再准备其他业务文件，保持一套工程版本与尺寸基准。

## 交付清单按路线裁剪
- EDA：实际工程身份/版本、保存状态、必要导图，关键未决问题。
- PCB：实际Gerber/钻孔/板框/层叠与工艺说明，确认板厂能力与现有检查覆盖。
- 商城：按装配数量与变体整理的采购BOM、真实商品链接/C号、价格/库存来源时间、缺料/未核及分项预算。
- SMT：以同一版本生成BOM与坐标，核对位号/面/旋转/原点/单位/极性、DNP和装配数量；匹配料、可贴/库存/费用另核。
- 如有：外壳/面板图、接口/孔位置、装配与后续烧录/测试计划。
用户未要求的服务不自动开单；不能把文件导出、平台上传、匹配完成、报价、下单、支付和生产分别跳步说成“交付完成”。

## BOM C 号审计

`zhigou bom export --type csv` 默认会用执行器的 `standard-parts.json` 按 MPN 回填
Supplier Part；项目专用料通常不在该表里，结果为 0/N 匹配。把本项目实际使用的
MPN→C 号整理成 `project-standard-parts.json`，再用 `--parts` 重导出，最后用
`bom_cnumber_check.py` 做确定性核对：

```bash
zhigou bom export --type csv --parts evidence/project-standard-parts.json
python scripts/bom_cnumber_check.py evidence/photo-led-bom.csv \
  --parts evidence/project-standard-parts.json \
  --expect-designator RV1=10kΩ --out bom-check.json
```

脚本检查数量、位号、MPN、`C<数字>`、空 Supplier Part 的本地映射回填、映射冲突、
重复位号、同 MPN 不同 C 号和指定位号的值；不访问网络。PASS 只代表 BOM/映射内部一致，
**不代表库存、价格、MOQ、SMT 可贴或封装与符号一致**，这些仍按立创商城/嘉立创实时核对。
2026-10-26 photo-led 实测：本地映射 15/15 回填；RV1=`10kΩ`/`3296W-1-103`/
`C56237`（库身份实测，库存/价格未核对）。

## Agent执行与用户接手
可用官方当前工具/连接器/页面完成的已授权步骤由Agent处理。若当前无商城/SMT账号通道，先完成真实图纸和购料/制造文件，明确给出剩余一步，不让用户从头重做。
用户需要作出的重要决定用“自己焊还是工厂焊好”“成本与交期更看重哪个”等解释；技术文件映射和检查由Agent负责，用户不需要懂坐标格式或SMT库类别。
若用户已明确委托订购，在实际授权预算和宿主规则内推进；准备具体可审阅结果后再处理必要的交易确认，不额外制造多轮审批。

## 制造后不默认结束完整设备任务
保留PCB/SMT与商城的独立业务核对。在当前服务范围内进一步核实烧录、检查/测试和成品装配是否适用，需要什么程序版本/格式、治具与测试说明；不从“贴片完成”推断“应用功能已通过”。
对完整idea，Agent继续准备程序、配置/使用说明和联调；实物到达后按原始场景收集实际证据。工厂的AOI/飞针等检查报告不能代替用户手机实际收到通知或目标负载正确动作。

三条具体交付路线（商城购料自己焊、嘉立创 PCB+SMT、电子板+固件/配置+外壳/线束+整机验收）的必需文件、真实字段、装配变体和对账步骤见 [制造与交付路线](manufacturing-routes.md)。

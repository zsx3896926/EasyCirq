# 嘉立创PCB生产规则与条件快照

用途：设计准备、设置DRC、制造复核。按 [生产规则流程](jlc-production.md) 应用。本页不是通用默认规则或板厂实时数据库；生产前重新查实际渠道/订单。核对日期：2026-10-20；以下数值仅来自当日读取的官方正文，不适用于未注明的HDI、FPC、金属基板或特殊工艺。

## 可用于核对的少量数值

同表“mm”和“mil”可能为近似并列；项目中保留原文精度/单位，按EDA单位准确换算，不累计四舍五入误差。以下不是已加载进用户工程的配置。

| 对象与条件 | 官方能力快照（PCB-A） | Agent如何使用 |
|---|---|---|
| 1oz成品铜，单双面线路 | 最小线宽/线距0.10/0.10mm | 常规布线优先留制造余量；载流、压降与隔离所需更大值另外满足 |
| 1oz成品铜，多层线路 | 0.09/0.09mm | 不把BGA局部特例放宽成全板普通规则 |
| 2oz成品铜，双面/多层线路 | 分别0.16/0.16mm、0.15/0.15mm | 变铜厚必须重新检查；不能沿用1oz间距 |
| 双面/多层非常规通孔via | 内径/外径0.15/0.25mm为表列能力；表内推荐孔径≥0.2mm | 小孔有费用/工艺条件，不能当默认；环宽、孔距、板厚与可靠性再核对 |
| 常规锣边与V割处铜边 | 走线/焊盘距锣边/槽≥0.2mm；V割≥0.4mm | 区分真实加工边/中心线与铜边定义；旧PCB-B的锣边值为0.3mm，订单未确认前保留冲突 |
| 插件成品孔/NPTH公差 | 插件孔+0.13/-0.08mm；NPTH ±0.1mm | 配合实物引脚最大尺寸和结构公差，不以via孔径当精密安装孔 |

未列数值的其他铜厚、盲埋孔/微孔、槽宽/长、压接孔、半孔/包边、板厚/尺寸、公差与阻焊桥，应从当前专项条件提取到项目档案。不能把表列最大尺寸、最小孔和最厚铜分别拼成一个未经支持的工艺组合。

## 必须落实的PCB检查

| 检查对象 | 实际动作与证据 | 不能用来替代的证据 |
|---|---|---|
| 层叠/阻抗 | 绑定实际层叠及材料/铜厚；确定目标网络、参考层、几何和订单管控选项，读取可用报告 | 默认90/100Ω、软件计算结果、工具入口链接不等于板厂已管控 |
| 孔类型与环宽 | 分开处理PTH插件孔、via、NPTH、槽、压接孔；量各层环宽与到孔/铜的距离，查最小/最大孔及处理范围 | 只量孔中心距离，或只看顶层焊盘 |
| 塞孔与盘中孔 | 依据PCB-D确定哪些孔需填实/盖帽、哪面开窗及适用孔径；匹配实际订单选项和生产稿 | 盖油不证明填平；树脂与铜浆也不能由网名/备注自动推断已选 |
| 阻焊 | 核对铜焊盘、Mask开窗与桥宽、铜厚/油墨颜色、相邻开窗和孔处理；复核厂方对开窗的调整 | 最小铜间距通过不等于可保阻焊桥；Paste不是Mask |
| 钢网接口 | 将焊膏分窗、DNP、散热焊盘和孔处理与SMT一起核对，参照器件原厂焊盘要求 | PCB可加工不证明贴装/回流可行 |
| 外形/孔槽/分板 | 识别唯一加工外形来源及合法内切口/槽；按锣边/V割/邮票孔检查全层铜、应力与外形公差 | 不把备注层线或3D挖空当已输出加工；也不禁止所有内轮廓 |
| 接触/特殊区域 | 核对金手指、半孔、按键触点、RF、隔离、精密安装等的表面处理、禁铜和加工要求 | 不能因常规OSP便宜就覆盖接触区的适用工艺 |
| 丝印与生产标记 | 可识别的位号/极性/版本，查文字到露铜、板边、孔和装后可见性；关键标记采用更严格的适用SMT要求 | 源文件里有文字不保证厂方掏字后仍完整可读 |

## 已发现的冲突与使用办法

- A的阻焊栏目明确包含2025年LDI升级说明；B仍保留不同的开窗扩展与塞孔表述。新单/返单可能采用不同生产稿，必须核对实际处理，不按旧经验批量改开窗。
- A提供不同材料、层数、铜厚及特种孔的能力；B某些范围更窄。保留条件和值，不据此声称其中一页整体失效。对无法确认的项目使用兼容候选并标缺口；不能为小孔可做而自动开通收费工艺。
- 工厂能加工的线宽不保证载流/温升/阻抗/安全间距，尺寸公差也要回到外壳、连接器与实际装配验证。工艺上更保守但破坏RF/电源回路的修改不自动合理。

最终按 [制造细节](manufacturing-details.md) 做同版文件复核，按 [SMT生产规则](jlc-smt-rules.md) 查装配可行性。实际工厂审核未发生时，只能报告设计/文件检查范围。

# 嘉立创SMT生产规则：服务、装配和数据一起核对

用于工厂焊好板、混合贴片/插件、来料、拼板、制造准备。核对日期2026-10-20。按 [生产流程](jlc-production.md) 建立订单档案；不能把国内SMT规则套用海外JLCPCB，不能以立创商城C号现货替代工厂供料/工艺确认。

## 官方来源与服务条件

当日读取 [SMT规范目录](https://www.jlc.com/portal/q7i64042.html)（页面标注2026-10-13），其P0/P1/P2分别组织准入、良率和成本问题，但正文声明须结合正式文本、器件和工程审核。以下是适用检查的独立归纳，不把目录中的每个数字提升成全行业强制规则。

[工艺总表](https://www.jlc.com/portal/vtechnology.html)当日显示：经济型与标准型在贴装面、板材/尺寸、工艺边和Mark、最小封装与检测服务上有差异。Agent必须查当前订单能选的具体路线；若存在其他新服务名称，重新核对，不强行映射老类别。标准型的工艺边/Mark要求不能取消，也不能给手焊任务或经济型强加所有标准型约束。

总表提供X-ray、AOI、FCT等服务项目不等于本单已经购买、全部执行或具备所需程序/治具。烧录与功能测试逐项确认范围、文件、接口、条件和报告。

## 工艺边、Mark与拼板

| 项目 | 官方快照与范围 | 实际设计/核查动作 |
|---|---|---|
| 标准型硬板工艺边 | [专项规范](https://www.jlc.com/portal/q7i62681.html)：常规宽5–8mm，3mm为不建议采用的极限；定位孔一般直径2mm、4个 | 按传送方向、夹持面、高度、薄板/小板支撑做候选；器件本体/伸出脚不得侵占夹持区。生产边与成品外形分开，不能擅改用户安装尺寸 |
| 光学定位 | [Mark专项规范](https://www.jlc.com/portal/q7i62691.html)：至少3个、不对称；铜点直径1mm、开窗直径2mm、中心距边≥3.85mm，周围3mm无干扰 | 检查实际铜/Mask/丝印和轨道遮挡，确认全局/局部及单双面需要，Mark不当作需采购贴装的元件；“周围3mm”的具体几何有歧义时保留范围并查图/厂方，不能猜成硬DRC |
| V割 | [V-cut专项规范](https://www.jlc.com/portal/q7i62703.html) | 检查贯通直线、两侧铜和器件避让、板厚/残厚、外伸器件与分板应力；不同方向的轮廓不能硬拼成任意V割 |
| 邮票孔/异形/镂空 | 当前拼板专项和订单工程条件 | 核对连接强度、毛刺/断口落在何处、连接筋与敏感件、单元间隙、分板工具和治具支撑；不因空间紧自动删除加强筋 |
| FPC及特殊材料 | [FPC目录](https://www.jlc.com/portal/q7i64084.html)、[FPC工艺边](https://www.jlc.com/portal/q7i64063.html) | 单独核对补强、四边夹持、材料/耐温/治具和拼板；FPC当日总表存在尺寸描述差异，未取得订单条件前不自动给最终尺寸，也不套FR4拼板模板 |

旧 [可接受工艺边设计](https://www.jlc.com/portal/server_guide_22406.html)提及符合条件可取消工艺边，而标准型专项要求必须设置。不要用旧条件自动豁免当前标准型；把实际单板/拼板/代加生产边责任写明，核对厂方生产稿后关闭问题。

## 封装、布局与可焊性

| 问题 | Agent要落实的检查 | 来源/条件与冲突处理 |
|---|---|---|
| 本体间隔与返修 | 查实际本体/高度/吸嘴通道，而非中心距或单看焊盘。小阻容/二三极管、IC、发热与热敏器件分别处理 | [器件间隔专项](https://www.jlc.com/portal/q7i62744.html)提供1/3/5mm等类型化参考，针对本体间距；若近端去耦或高密度布局不兼容，保留电气意图并提出局部装配评估，不无依据挪远去耦或直接判全板不能生产 |
| 引脚/焊盘几何 | 对齐完整型号、原厂推荐焊盘、脚距、Mask/Paste及实际服务；密脚/特殊封装单独检查 | [相邻引脚/焊盘专项](https://www.jlc.com/portal/q7i62694.html)。脚距、铜边间隙、本体间距不是同一个参数，不能把参考间距强行改进原厂焊盘 |
| 焊盘内孔 | 检查焊膏吸入、孔填实/盖帽与平整、EPAD锡量/分窗；与PCB订单联动 | [焊盘上的过孔](https://www.jlc.com/portal/q7i62741.html)及PCB孔处理；不把普通盖油当解决盘中孔，也不禁止所有已采用合适填孔的盘中孔 |
| 热不平衡 | 核对小件两端铜量/回流与散热焊盘、载流瓶颈和钢网 | SMT目录有热阻连接建议，需和电源载流/器件要求共同满足；不能给所有大电流/散热焊盘盲套同一细支条 |
| 高重件/穿板固定脚 | 检查二次回流掉件、双面穿脚互顶、钢网/治具/吸嘴干涉与后焊顺序 | 以实际器件重量、脚长、装配面、板厚及厂方工艺确认；不要自行决定胶水或削脚 |
| 极性与Pin-1 | 对照原厂标识、实际焊盘、丝印和装配图；底面角度约定单独查 | [极性专项](https://www.jlc.com/portal/q7i62705.html)。不凭LED缺角、二极管色带或库缩略图推定所有器件极性 |
| 温度、潮湿与清洗 | 核对回流曲线/次数、MSL/开封时长、包装/烘烤限制、MEMS/光学/传感器禁清洗区域和后焊需求 | 目录相关专题和具体原厂资料；不把通用烘烤温度/时长强用于所有器件及包装，不把低温回流当无代价替代 |
| 来料与追溯 | 核实可贴料/私有库存或来料权限、包装、最小上机量、备损、批次/可焊性和替代批准 | 依当前服务与具体物料；不把目录备损百分比当每种料必须统一购买数，更不能把高价料“0损耗”当厂方保证 |

## BOM与坐标要能进入真实生产

读取 [坐标格式说明](https://www.jlc.com/portal/server_guide_53182.html)、[文件标准](https://www.jlc.com/portal/server_guide_4071.html) 与当前上传模板。前者页面当前有“所有角度总和不超过360°”等歧义措辞，不实现为全板角度求和校验；查每器件角度的当前字段约定，必要时提交格式问题。

1. 从同一保存版本和装配变体导出。最终BOM每个装配位号只对应一个确定型号/封装；DNP与后焊分别列明，不把未选定替代料放进最终装配表。
2. 按当前模板提供位号、型号/规格、封装等字段，C号/SMT料号按真实匹配保存。坐标核心字段为`Designator`、`Mid X`、`Mid Y`、`Layer`、`Rotation`；一位号一行，不能将同料多个位号的BOM聚合格式复制进坐标。
3. 明确mm/mil和原点/轴向/旋转，优先采用模板支持的mm；该格式说明中mil需在数值标注、标题不附单位，上传前按当前模板再核对。旋转以器件中心，不能拿Pin-1坐标冒充中心。Top/Bottom按器件本体所在面，插件/特殊装配核对例外。
4. 保留工程物理身份，建立导出映射，检查重复/缺失/多余位号和BOM、坐标、PCB集合；Mark/孔、DNP、后焊等排除项有明确理由。[官方问题说明](https://www.jlc.com/portal/server_guide_17103.html)提示多件拼成一个封装仍需各实物独立位号/坐标；成品模块与现场贴装多件区别处理。
5. 分开单板坐标与工厂拼板坐标；核对倍率、重复位号策略、上下表面变换、坐标尺度和实际外形。最大最小坐标差只提示明显单位/尺度错误，不证明每个器件位于合法轮廓或可贴。
6. 核对料匹配/极性/装配仿真及正式DFM修正图；保存原始与修订对应。旧帮助说厂方可能调整方向/坐标，不代表可以忽略疑似错件/反贴；异常应在投产前有明确处理与证据，不能自行假定稍后会修。

## 交付与回读

完成实际PCB/SCH对应、适用生产规则、文件、位号/坐标/变体、厂方工艺与DFM意见闭环。分别留下已覆盖、已证实缺陷、待确认及需实测项目。未取得报告标“厂方审核未执行”，未核库存/报价标“未核”，未下单标“未下单”；不以本地0错误替代工厂审核或焊后功能验证。

# 选型、BOM与装配变体

## 商城优先，但保持工程适配
中国大陆任务优先检索立创商城候选，用户指定供应商/自有库存/指定料除外。按 lcsc-sourcing.md 做C号、完整MPN/封装与实际EDA身份映射；不能以可购买或基础库标签替代电气、机械和pin-pad核验。
先检查关键料是否能按目标数量/时间取得，再将供货和总成本纳入可行候选比较。报价缺失不填0；商城和SMT供货独立核对，流程见 jlc-handoff.md。

## 选型顺序
1. 优先核对用户指定器件，但仍检查完整型号/封装、电气能力、生命周期与应用条件；冲突时提出替代或设计调整。
2. 采用适用参考设计中的外围选型方法，核对改动的输入/负载、实际额定和layout前提。
3. 比较功能、工作范围、温度/容差、封装/可制造、软件生态、供应与成本；按项目需要提供备选，不强制每个稀有/指定器件都凑一个未经验证备选。

## 先定装配方式，再选封装

封装的第一约束是“谁来装”，不是库里有什么。开工时按 [G0 需求门禁](design-gates.md) 的 `assembly` 先定路线，再选具体封装：

| 装配方式 | 默认封装 | 边界 |
|---|---|---|
| 手焊（新手/无返修经验） | 0603 阻容、SOT-23 三脚、直插件 | 0402 不进入手焊清单；细间距/多脚封装不靠手焊 |
| 嘉立创 SMT | 0402/0603、SOT-23-5、SMA、USB-C 等按工艺核对 | 仍要核对基础库/扩展库、可贴状态与换料费 |
| 直插 THT | 明确按手焊处理 | 记录 `assembly: tht`，核对孔径、脚距、方向与装配空间 |

G0 的 `assembly` 是整板路线（如 `self-solder` / `jlc-smt` / `mixed`）；下方零件表的 `assembly` 是逐器件字段（`smt` / `hand` / `tht` / `dnp`），两者不要混用。

- 手焊默认 0603，0402/1005 只用于 SMT（本轮任务书口径）。这与 [制造与交付路线](manufacturing-routes.md)、[无源件选型](selection/passives.md) 中“有经验可手焊 0402”的能力描述不矛盾：后者是能力上限，不是默认路线。任何 0402 手焊例外都要在 G0 装配字段显式记录返修能力与验收标准，不能只写一句“小心焊”。
- SOT-23-5、SMA、USB-C 细间距默认需要装配能力（SMT 或有经验的返修工位）；USB-C 还要先定 power-only 6P/16P 与插拔空间。
- 封装与 footprint 分开：封装是本体/引脚形式（0603、SOT-23-5、SMA），footprint 是 EDA land pattern 名；两者不能互相替代。
- 机械/热条件在选封装时一起核对：蜂鸣器声孔、电位器螺丝刀空间、NTC 热隔离，见 [机械约束](../assets/docs/mechanical.md) 与 [热敏电阻布置](../assets/docs/thermal-sensor.md)。

## 关键器件的记录

每个采购/装配相关器件按一行一料记录下列字段，不合并成一列“型号/封装/C号”：

| 字段 | 内容 | 不能用什么代替 |
|---|---|---|
| `role` | 功能角色（比较器、NTC 测温、报警驱动） | 位号；位号随改版变 |
| `designators` | 当前位号 | 功能角色 |
| `mpn` | 完整原厂 MPN（含后缀/封装代码） | 系列名/通用名 |
| `manufacturer` | 制造商；空值写 `待核` | 供应商 |
| `package` | 本体/引脚形式（0603、SOT-23-5、SMA、直插 Ø9.5） | footprint |
| `footprint` | EDA land pattern 名与库身份 | package |
| `lcsc` | LCSC C 号；没有就写非立创渠道或 `待核` | 库存/价格 |
| `stock` | 库存状态、数量、核对日期；未核对写 `unchecked` | C 号 |
| `smt_class` | `basic` / `extended` / `consigned` / `pending` | 装配方式 |
| `assembly` | `smt` / `hand` / `tht` / `dnp` | 可贴状态 |
| `datasheet` | 手册路径/链接与版本 | 商品页摘要 |
| `alternates` | 替代 MPN、差异、C 号状态 | 主料 |

- 空厂家/空 MPN 不留空，统一写 `待核`；采购前必须补实，不能靠 BOM 看起来齐全过关。
- C 号是身份，不是可得性：有 C 号不代表有库存、能贴、价格合适。库存、MOQ/包装、SMT 可贴状态分别核对，见 [立创商城](lcsc-sourcing.md)。
- 原始 BOM 先导出并保留：`easyeda bom export --type csv --enrich=false`；富化失败不阻断设计，处理流程见 [立创商城](lcsc-sourcing.md)。
- 字段模板与检查：[parts.example.json](../assets/parts.example.json)，运行 `python scripts/bom_check.py <parts.json>` 检查缺字段、手焊 0402、DNP 分类等结构问题；脚本通过不等于库存/封装/电气已核。

C号/供应商编号服务采购与匹配，不证明引脚、封装或电气等价；非立创供应链不因缺C号阻断设计。
“基础库/扩展库”、库存、单价、换料费/工艺优惠随实际订单核对，不写成永久承诺。无源件在满足性能/温度/布局后尽量统一值和封装。
替代料分别检查pin-to-pin、footprint、额定/动态、时序/启动、驱动/固件与工艺；例如主控家族或USB桥同功能不能自动认定可直接替换。

## 降额与计算
按器件手册、环境、任务标准和实际工况核对容差/温度/偏压/浪涌。经验倍率可作为候选初筛，必须注明条件，不能替代应力计算。
MLCC关注有效容量，电阻关注封装降额与脉冲，电感同时核对饱和/RMS与损耗，MOSFET核对实际Vgs/温度/SOA，连接器核对接触额定与升温。
指定器件不合适时给出“保留它需要改变什么”和“替代方案改变什么”，不要偷偷换型号。

需要可直接填写的核算表时用 [设计核算表](../assets/design-calc.md)；通用公式与算例库见 [计算手册](calculations/README.md)，本文不重复。

## DNP与变体
DNP表示不装配，不是NC，也不是从原理图删除。明确默认装配变体、可选端接/配置、互斥选件和各变体下的连接/启动条件。
BOM和坐标依明确变体生成，DNP不出现在该变体的装配清单；原理图/PCB源数据保留，并列出DNP表。装配状态未知的关键配置保持待核。
可选终端用额定/阻值正确的器件加DNP、跳线或开关控制；不要把0Ω当作总线终端本体。

替代料分级（直接替换 / 需改阻容或固件 / 需改原理图封装PCB / 资料不足）、逐项核对和检索顺序见 [替代分类](selection/replacement-classes.md) 与 [器件选型资料](selection/README.md)。

需要完整功耗/结温、热阻指标、瞬态及PCB/外壳测量方法时，按需读 [板级热专题](thermal/topic.md)，不以其一阶算例替代实际工艺/器件验证。

## C01 LDO 12 V→3.3 V/150 mA，小封装假设 θJA=250 K/W

**类型：** 离线计算 + 反例（说明“小封装 + 高压差”为什么经常不可行）。
**关联：** topic.md 3.1、4.1、4.2。

**输入（假设，不是某型号保证值）：**

| 输入 | 值 | 来源/说明 |
|---|---:|---|
| Vin | 12 V | 假设 |
| Vout | 3.3 V | 假设 |
| Iout | 0.15 A | 假设 |
| Iq | 5 mA | 假设 |
| θJA | 250 K/W | 教学假设：小封装、低铜面积、静止空气；实际必须查具体 datasheet/板条件 |
| Ta | 40°C | 假设 |
| Tj,max | 125°C | 假设；具体器件查 datasheet |

**公式（离线计算）：**

```text
P = (Vin − Vout)·Iout + Vin·Iq
  = (12 − 3.3)·0.15 + 12·0.005
  = 1.305 + 0.06 = 1.365 W
Tj = Ta + P·θJA = 40 + 1.365·250 = 381.25°C
所需 θJA = (Tj,max − Ta)/P = (125 − 40)/1.365 = 62.27 K/W
该 θJA 下允许的最大 P = (125 − 40)/250 = 0.34 W
```

**结果（`thermal_calc.py ldo`）：** `status=exceeds_tj_max`，`power_W=1.365`，`tj_C=381.25`，`margin_K=−256.25`，`required_theta_ja_K_per_W=62.27`，`max_power_at_theta_ja_W=0.34`。

**判定：** 不通过。381°C 已超出模型/器件有效范围，只能当“失败信号”，不能当真实温度。

**可行方向（按优先级）：**

1. 改 Buck：P 从 1.365 W 降到约 0.1–0.2 W 量级（取决于效率/负载），热问题大幅缓解。
2. 降 Vin：如果后级允许，降到 5 V 可把 P 降到约 0.28 W。
3. 换大封装/热焊盘/更多铜：把 θJA 降到 ≤62 K/W（最好 ≤50 K/W 留余量）。
4. 降 Iout / 加串联电阻分担：串联电阻会降低 PSRR/瞬态余量，需重新验证（TI SSZT950 只提了电阻额定功率，未展开这个代价）。[S07]
5. 加散热器/风扇：对小封装 LDO 通常不划算，先考虑 1–3。

**不能证明：** 实际板 θJA、热关断行为、瞬态/启动、长期可靠性；这些要测量或查具体器件。

## C02 同一 LDO，θJA=60 和 50 K/W 的边界

**类型：** 离线计算（说明“算出来没超”不等于“有工程余量”）。
**关联：** topic.md 4.3。

**输入：** 同 C01，只改 θJA。

| θJA | Tj | 对 125°C 的余量 | 判定 |
|---:|---:|---:|---|
| 60 K/W | 121.9°C | 3.1 K | 名义通过，但余量小于模型/测量不确定度；按项目 20 K 余量要求仍不通过 |
| 50 K/W | 108.25°C | 16.75 K | 有条件通过；仍需确认实际板 θJA ≤50 K/W，且不确定度上界仍有余量 |

**结果（`thermal_calc.py ldo`）：** 60 K/W → `tj_C=121.9`，`margin_K=3.1`；50 K/W → `tj_C=108.25`，`margin_K=16.75`。带 `min_margin_K=20` 时，60 K/W 返回 `status=tight`；不带时 `status=calculated` 只表示“未超限”，不是工程通过。

**判定：** 60 K/W 只能算“贴线”，不能当通过；50 K/W 也只能算“有条件通过”。如果项目要求 20 K 余量，需要 θJA ≤约 47.6 K/W。

**不能证明：** θJA=60/50 是否真实；必须查具体封装/板/气流，或实测。数据手册的 JEDEC 值不能直接当这两个数。[S01][S05]

## C03 MOSFET 24 V/5 A/100 kHz：一阶通过例

**类型：** 离线计算（说明损耗分项 + Rds(on) 温度迭代）。
**关联：** topic.md 3.2/3.3、4.2。

**输入（假设）：**

| 输入 | 值 |
|---|---:|
| Vin | 24 V |
| Iout | 5 A |
| Duty | 0.4 |
| Rds(on) @25°C | 10 mΩ |
| Rds 温度系数 | 0.004 /°C（线性近似，仅局部有效） |
| θJA | 50 K/W（假设板/封装条件） |
| Ta | 40°C |
| Tj,max | 125°C |
| fsw | 100 kHz |
| tr = tf | 20 ns |
| Qg | 20 nC |
| Vgs | 10 V |

**公式与迭代（离线计算）：**

```text
P_sw = 0.5·Vin·Iout·(tr+tf)·fsw
     = 0.5·24·5·40e-9·100e3 = 0.24 W
P_gate = Qg·Vgs·fsw = 20e-9·10·100e3 = 0.02 W
迭代 Rds(on)(Tj) 与 Tj：
  Tj ≈ 58.67°C，Rds(on) ≈ 11.35 mΩ
  P_cond = 5²·0.01135·0.4 = 0.1135 W
P_total = 0.1135 + 0.24 + 0.02 = 0.3735 W
Tj = 40 + 0.3735·50 = 58.67°C
余量 = 125 − 58.67 = 66.33 K
```

**结果（`thermal_calc.py mosfet`）：** `conduction_loss_W=0.11347`，`switching_loss_W=0.24`，`gate_loss_W=0.02`，`power_W=0.37347`，`rds_on_at_tj_ohm=0.01135`，`tj_C=58.67`，`margin_K=66.33`，`status=calculated`。

**判定：** 在该组假设下通过，余量较大。

**不能证明：** θJA=50 是否真实；开关损耗是否是实际上界（感性负载开通可能更小，关断可能不同；Coss/死区/体二极管未计）；实际波形/EMI/布局。要用 datasheet 的 Eon/Eoff 和实测校准。[S09]

## C04 MOSFET 48 V/10 A/200 kHz：高温失效反例（Rds(on) 正反馈）

**类型：** 离线计算 + 反例（说明 Rds(on) 正反馈把 Tj 推到远超限值；该线性模型仍收敛，但不是真实热失控）。
**关联：** topic.md 3.2/3.3、4.2。

**输入（假设）：** Vin=48 V，Iout=10 A，D=0.5，Rds(on)@25°C=20 mΩ，温度系数 0.005/°C，θJA=40 K/W，Ta=40°C，Tj,max=125°C，fsw=200 kHz，tr=tf=50 ns，Qg=50 nC，Vgs=10 V。

**计算：**

```text
P_sw = 0.5·48·10·100e-9·200e3 = 4.8 W
P_gate = 50e-9·10·200e3 = 0.1 W
迭代结果：Tj ≈ 338.75°C，Rds(on) ≈ 51.375 mΩ（≈51.4）
P_cond = 10²·0.0514·0.5 = 2.56875 W
P_total = 2.56875 + 4.8 + 0.1 = 7.46875 W
Tj = 40 + 7.46875·40 = 338.75°C
余量 = 125 − 338.75 = −213.75 K
```

**结果（`thermal_calc.py mosfet`）：** `power_W=7.46875`，`conduction_loss_W=2.56875`，`switching_loss_W=4.8`，`gate_loss_W=0.1`，`tj_C=338.75`，`margin_K=−213.75`，`status=exceeds_tj_max`。

**判定：** 不通过。338.75°C 超出线性 Rds(on) 模型/器件有效范围，只能当“高温失效/模型外”信号，不能当真实温度。该模型在此例仍收敛（Rds–Tj 定点增益约 0.2），所以不要把它说成“热失控”；真正的热失控需要增益 ≥1 或负阻行为，需另算/实测。

**可行方向：** 降 fsw（开关损耗与 fsw 成正比）、选更低 Qg/Rds(on) 的器件、加散热器/降低 θJA、检查是否是硬开关（软开关/ZCS 可显著降损耗）、降低电流/提高效率。改完后必须重跑迭代，确认收敛且有余量。

**不能证明：** 真实器件在 338°C 的行为、热关断/损坏阈值、实际开关波形、SOA/雪崩。

## C05 LED 6 串/350 mA：Rth_JS 与 Rth_SA 的分界

**类型：** 离线计算（说明LED热阻链与real/electrical口径）；假设相同LED共用近似等温焊点节点，不求解局部扩散与热耦合，不能直接推广长条灯板。
**关联：** topic.md 3.5、6.2、8.3。

**输入（假设）：**

| 输入 | 值 | 说明 |
|---|---:|---|
| 串联数 | 6 | 假设 |
| Vf（每颗） | 3.0 V | 假设；实际随电流/温度变 |
| If | 0.35 A | 假设 |
| 光学效率 η_opt | 0.30 | 假设；OSRAM 说典型 25%–50%，具体查 datasheet [S12] |
| Rth_JS_real | 5 K/W（每颗） | 假设；必须用“real”口径 [S12] |
| Rth_SA | 15 K/W（或 10 K/W） | 假设：PCB + TIM + 散热器到环境 |
| Ta | 40°C | 假设 |
| Tj,max | 125°C | 假设；Cree XLamp 常见 150°C，但具体型号查 datasheet [S10] |

**计算：**

```text
P_elec = 6·3.0·0.35 = 6.3 W
P_heat = 6.3·(1 − 0.30) = 4.41 W
Rth_SA=15: T_solder = 40 + 4.41·15 = 106.15°C
           每颗Q=4.41/6=0.735W；Tj = 106.15 + 0.735·5 = 109.825°C
           余量 = 125 − 109.825 = 15.175 K
所需 Rth_SA = (125 − 40 − 0.735·5)/4.41 = 18.441 K/W
Rth_SA=10: T_solder = 84.1°C
           Tj = 84.1 + 3.675 = 87.775°C
           余量 = 37.225 K
```

**结果（`thermal_calc.py led`）：** Rth_SA=15 → `heat_power_W=4.41`，`solder_point_C=106.15`，`tj_C=109.825`，`margin_K=15.175`，`required_rth_sa_K_per_W=18.441`，`status=calculated`；Rth_SA=10 → `tj_C=87.775`，`margin_K=37.225`，`status=calculated`。

**判定：** 两者都只在模型条件内留有余量；不是实物通过。允许Rth_SA上限为18.441K/W，但为了余量应显著低于它。

**口径检查：** 如果 datasheet 给的是 **electrical Rth_JS**（用全部电功率），则应用每颗 `P_elec=1.05W` 算其结到焊点的温升，而不是每颗 `P_heat=0.735W`；混用会低估或高估。OSRAM 明确区分两套定义。[S12] 工具默认 `rth_js_basis=real`；若用手册的 electrical Rth，传 `rth_js_basis=electrical`，工具会用每颗 `P_elec` 乘 `Rth_JS`、但仍用 `P_heat` 乘 `Rth_SA`（板/TIM/散热器带走的是热，不是光功率）。如果光学效率未知，用 0（全部电功率当热）做保守估算，Tj 会更高。

**不能证明：** 实际 LED 的光效、Rth_JS、T_solder 测点、PCB/TIM/散热器热阻；这些要按具体 datasheet 和实测。

## C06 热过孔：9 个 0.3 mm 孔够不够？

**类型：** 离线计算（1D 孔壁模型）+ 反例（“加孔”不是万能）。
**关联：** topic.md 6.2、附录 A。

**输入（假设）：** 钻孔 0.3 mm，镀层 25 µm，板厚 1.6 mm，孔数 9，铜导热率 385 W/m·K。

**计算：**

```text
A_one = π/4·(D_out² − D_in²)
      = π/4·((0.3e-3)² − (0.25e-3)²)
      = 2.1598e-8 m²
R_one = L/(k·A) = 1.6e-3/(385·2.1598e-8) ≈ 192.4 K/W
R_9 = R_one/9 ≈ 21.38 K/W
R_39 = R_one/39 ≈ 4.93 K/W
```

**结果（`thermal_calc.py via`）：** 9 孔 → `resistance_K_per_W=21.379`；39 孔 → `resistance_K_per_W=4.934`。

**判定：** 如果目标是 5 K/W，单看孔壁需要约 39 个；但这只是 1D 孔壁，**不含**焊盘到孔的扩散热阻、界面热阻、目的地铜层热阻。实际中这些可能比孔壁更大，所以“39 个孔”不等于“5 K/W”。

**资料对照：**

- TI PowerPAD：小 die 通常 5–9 个 0.33 mm 孔对多数应用足够；继续加孔收益递减。[S02]
- AN-1520：FEA中特定dog-bone区域过孔从0增到24个只降低θJA约0.5%，不是DAP热焊盘下过孔结论；5% 的改善主要来自铜面积。[S18]
- SLVAE85：铜面积/过孔增加到一定程度后饱和；热焊盘封装获益更大，SOT-23 更依赖顶层/底层铜。[S05]
- Cree：0.6 mm 填充孔单孔约 96.8 K/W；只适用于热源正对过孔，否则扩散热阻增加。[S11]

**不能证明：** 实际板的扩散/界面热阻、焊接空洞、铜层连接；这些要 FEM 或实测。

## C07 密封外壳：4 W、0.02 m²、h=5/8/10

**类型：** 离线计算 + 灵敏度（说明 h 的假设主导结果）。
**关联：** topic.md 7.2、附录 A。

**输入（假设）：** P=4 W，A=0.02 m²，Ta=30°C，表面限值 `limit_C`=70°C（这是外壳表面限值，不是 Tj；仅用于示例）；h_eff=5/8/10 W/m²K。

**计算：**

```text
T_surface = Ta + P/(h·A)
h=8:  30 + 4/(8·0.02) = 30 + 25 = 55°C，余量 15 K
h=5:  30 + 4/(5·0.02) = 30 + 40 = 70°C，余量 0 K
h=10: 30 + 4/(10·0.02) = 30 + 20 = 50°C，余量 20 K
所需 A（h=8，limit_C=70）= 4/(8·40) = 0.0125 m²
```

**结果（`thermal_calc.py enclosure`）：** h=8 → `surface_C=55`，`surface_rise_K=25`，`margin_to_limit_K=15`，`status=calculated`；h=5 → `surface_C=70`，`margin=0`，`status=tight`；h=10 → `surface_C=50`，`margin=20`，`status=calculated`。`limit_C` 是外壳表面限值，不是 Tj。

**判定：** h=5 时贴线/不通过；h=8 有 15 K 表面余量，但 nVent 建议保留 25% 安全裕量（相对允许温升 40 K 即 10 K），15 K 刚超过；h=10 有 20 K。实际 h 必须由外壳材料/方向/通风/海拔决定，不能拍脑袋。

**资料对照：**

- Cree：自然对流空气 h 约 5–20 W/m²K，粗算可用 10；强制风冷可到 100。[S10]
- nVent：密封电气柜表面积按六面计算，靠墙面扣除；建议 25% 裕量；内部循环风扇最多改善约 10%；进风口底部/出风口对侧顶部；海拔升高增加 airflow。[S22]
- nVent 白皮书：`(Ti−Tu)=Qv/(k·A)` 等关系；10 K 温升寿命减半；+35°C 内部平均是常规值；这些面向电气柜，不是小型 PCB 盒。[S23]

**不能证明：** 内部空气到壳壁的热阻、热点、太阳负载、通风/海拔、器件 Tj；表面模型只约束外壳表面。

## C08 散热器链：10 W、Rth_jc=2、Rth_cs=0.5、Rth_sa=3

**类型：** 离线计算（串联链 + 所需散热器）。
**关联：** topic.md 2.3、4.1、6.4。

**输入（假设）：** P=10 W，Rth_jc=2 K/W，Rth_cs=0.5 K/W，Rth_sa=3 K/W，Ta=40°C，Tj,max=125°C。

**计算：**

```text
Rth_total = 2 + 0.5 + 3 = 5.5 K/W
Tj = 40 + 10·5.5 = 95°C
余量 = 125 − 95 = 30 K
所需 Rth_sa = (125 − 40)/10 − 2 − 0.5 = 8.5 − 2.5 = 6.0 K/W
```

**结果（`thermal_calc.py heatsink`）：** `total_rth_K_per_W=5.5`，`tj_C=95`，`margin_K=30`，`required_rth_sa_K_per_W=6.0`，`status=calculated`。

**判定：** 在该组假设下通过。Rth_sa=3 K/W 的散热器足够；如果实际 Rth_cs 因 TIM/压力/面积变差，余量会被吃掉。

**适用条件：** 串联链最适合“散热器主导、Rth_jc 远小于 Rth_ja”的情况；否则用 TI Eq.6 或实测。[S01] Rth_cs 最好实测/按 TIM 厂商数据，`t/(kA)` 只是估算。[S01]

**不能证明：** 实际 TIM/安装压力/气流/方向/海拔；散热器数据手册的 Rth_sa 通常有测试条件，不能直接当机箱内值。

## C09 测量反例：粗热电偶把壳温测低了

**类型：** 资料结论 + 算术反例（不是实测）。
**关联：** topic.md 8.1、8.5。

**资料结论：** TI 说用 线径粗于36 AWG的热电偶测封装顶面，会把热量导走，使 ambient-surface 温差减小 50% 以上；错误线径可造成 5%–50% 的测量误差。[S01]

**构造反例（假设）：** 真实 `Tc−Ta=60 K`，粗热电偶只读到 30 K；ΨJT=1°C/W，P=1 W，Ta=40°C。

```text
真实 Tj ≈ 40 + 60 + 1·1 = 101°C
按测得的 Tc 估算：Tj ≈ 40 + 30 + 1 = 71°C
低估 30 K
```

**判定：** 如果 Tj,max=125°C，两种估算都“没超”，但真实值已经接近；如果真实 Tc−Ta=90 K，粗线读 45 K，估算 86°C，真实 131°C，就会漏判超限。

**正确做法：** 36–40 AWG（TI 建议 36–40 AWG J/K 型）、珠径 ≤2×2 mm、导热环氧、沿对角线走线并在 PCB 上贴 25 mm 以上；记录线径/贴装/走线。[S01] 红外交叉核对时注意发射率/反射环境。[S24]

**不能证明：** 这个 60→30 K 的具体比例不是实测；它只说明“粗线会低读”这一方向。实际误差取决于线径、贴装、气流、表面。

## C10 反例：把 datasheet 的 JEDEC RθJA 直接当实际板

**类型：** 资料结论 + 算术反例。
**关联：** topic.md 2.2、2.6、4.1。

**资料结论：** TI 说 RθJA 是在特定测试板上测的，PCB 设计对它的影响最强；仅 1s vs 2s2p 测试板就可造成最多 50% 的差异；静止空气 JEDEC 测量中 70%–95% 的热从测试板走。[S01]

**构造反例（假设）：** datasheet RθJA=40 K/W（JEDEC 2s2p），实际板是 1s/低铜，假设实际 RθJA=60 K/W（+50%，仅为示例，不是实测）；P=1.25 W，Ta=50°C，Tj,max=125°C。

```text
按 datasheet：Tj = 50 + 1.25·40 = 100°C，余量 25 K → 看起来通过
按假设实际：Tj = 50 + 1.25·60 = 125°C，余量 0 K → 贴线/不通过
```

**判定：** datasheet-only 估算不能作为通过证据；必须用实际板/外壳/气流的 `RθJA(effective)`、ΨJT/ΨJB + 实测，或至少按最差板条件做敏感性。

**不能证明：** 60 K/W 是假设；50% 是 TI 对 1s vs 2s2p 的“最多”描述，不是你板上必然发生。它只说明误差量级可以大到改变结论。

## C11 反例：焊料覆盖不足

**类型：** 资料结论 + 算术反例。
**关联：** topic.md 6.4。

**资料结论：** AN-1520 的 FEA：焊料覆盖从 100% 降到 50/20/10/5%，θJA 约增加 4/13/19/34%；10% 是临界点；>50% 时变化 <5%。[S18] TI PowerPAD 建议最小焊接面积 50%。[S02]

**构造反例（假设）：** 满焊 θJA=25 K/W，P=2 W，Ta=50°C，Tj,max=125°C。

```text
100% 覆盖：Tj = 50 + 2·25 = 100°C，余量 25 K
50% 覆盖：θJA ≈ 25·1.04 = 26 K/W，Tj = 102°C，余量 23 K
20% 覆盖：θJA ≈ 25·1.13 = 28.25 K/W，Tj = 106.5°C，余量 18.5 K
10% 覆盖：θJA ≈ 25·1.19 = 29.75 K/W，Tj = 109.5°C，余量 15.5 K
5% 覆盖：θJA ≈ 25·1.34 = 33.5 K/W，Tj = 117°C，余量 8 K
```

**判定：** 即使 5% 覆盖仍“没超”，余量已从 25 K 降到 8 K；再叠加器件/环境/测量不确定度就可能超。50% 是 TI 的最低建议，不是“50% 就够”的保证；工艺上应争取 >80% 并用 X-ray 检查。[S02]

**不能证明：** 这些 θJA 比例是 AN-1520 特定封装/模型的 FEA，不是你的板；实际空洞形状/位置也影响结果。

# Agent先定位，再给用户一个具体下一步

先读当前目标、工程/设备/版本、最近改动和实际日志。只收集当前问题需要的证据，不要求用户跑整套检查；不要凭某个报错词直接改线、改网名或替换器件。深层执行协议服从已配置EDA工具当前文档。

## 连接和执行问题

| 现象 | Agent先查 | 按证据采取的动作 |
|---|---|---|
| 找不到CLI/窗口 | Agent所在电脑是否是EDA那台，命令发现/安装与实际进程，health结果 | 能代查就代查；需要用户操作时仅给当前一步，菜单/路径现场核对 |
| daemon/connector断开 | 启动状态、版本对齐、外部交互权限、窗口及最近日志 | 按当前工具说明重连/修配置；端口占用先确认进程归属，不能让用户随便杀进程/重启电脑 |
| 超时/部分成功 | 当前对象与网络、队列/日志、源数据与计划差异 | 先判已生效/未生效/部分生效，再补缺失；禁止整批盲重试 |
| 检查命令不支持 | 当前help/动作目录与目标EDA版本 | 换已支持的等价检查或明确未覆盖，不用历史命令或临时JS假装通过 |
| 保存状态不清楚 | 当前文档身份、修改标记、显式保存响应与适用回读 | 不要求所有版本都有同一个`saved:true`字段；未取得保存证据不能宣称已保存 |

## 电路连接与图面问题

| 现象 | 避免误判 | 复核与处理 |
|---|---|---|
| 单脚网络 | 不自动等于漏连，可能是测试点/有意外部接口 | 查电气意图、真实物理脚、端口作用域和对端；确定缺陷后才补线 |
| 悬空/NC冲突 | 不把所有未用或未读脚都标NC | 查原厂脚含义，区分必须接、可悬空、DNC与未知 |
| 网名相似/大小写不同 | 不自动认定是同一个网 | 对照源数据/意图/实际成员；未经证实不得合并电源域或信号 |
| 线看起来接上 | 接近像素、同网名或动作成功都不证明导通 | 回读端点/pin-net/跨页连接；保持身份后修源数据与受影响对象 |
| 图很乱 | 不把所有局部拓扑拆成标签，也不交换脚号 | 模块几何→页面组合→实际回读→整页/局部导图，必要时用离线几何提示 |
| PCB未布线/短路 | 飞线、同网铜属性和真实接触分别看 | 查焊盘/层/铜区填充，修受影响网络再重铺铜/检查 |
| DRC间距/孔/丝印 | 规则可能来自实际工艺、绝缘或机械，不随手放宽 | 对照约束来源，处理真实对象；不为0报错缩小安全边界 |

## 制造、程序和实物问题

| 现象 | 分层定位 | 下一步 |
|---|---|---|
| BOM/坐标不一致 | DNP/插件/测试点/装配变体、导出版本和CSV编码 | 明确当前实际要贴的位号集合，再重导/对账；不直接删BOM行掩盖差异 |
| 制造包疑似缺层 | 核对实际层叠、输出角色、X2属性/格式与独立查看器 | 不只靠文件名猜层，不强制无孔板必须有钻孔或所有板必须两面阻焊 |
| 料号缺货/匹配不同 | 区分商城、SMT、缓存与实时订单渠道 | 工程审查替代后更新图纸/BOM/固件等影响；下单匹配不自动优先于完整MPN/封装 |
| 烧录失败 | 目标芯片/板版、数据线/接口、实际设备识别、供电/BOOT/复位及工具日志 | 先定位连接/启动/工具条件，不用统一按键组合处理所有芯片 |
| 上电重启/发热 | 供电/焊接/短路/额定、复位原因与实测波形 | 异常先停止受影响供电；适用限流与测量，不让新手摸热芯片试温或套固定100mA |
| 读数异常 | 电源/引脚/地址/原始数据、参考/校准、安装与环境 | 同时考虑硬件、固件和真实被测物，不只调阈值让数值“好看” |
| 通知收不到 | 采集→判断→网络→服务响应→手机实际收到逐段核对 | 发包成功不等于送达；不要求用户在聊天粘贴私钥/token |
| 续航差 | 实测整板输入侧各状态、弱网重试、睡眠外设与电源静态 | 以实际电池/截止和状态更新预算；不能先断言“睡眠一定占最大头” |

每次只改变能解释因果的部分，记录假设、实际观测、改动和受影响复验。安全可控的飞线/返修仅用于证实方案，不能把临时修复当正式生产版本；不以软件掩盖硬件额定/保护缺陷。

## 演练暴露、随后修掉的问题（1.2.4）

**「有引脚或网络没有接上」没有说是哪一个** —— 已修。

现在卡片显示：

```
❌ 还不能打样

必须修的问题：
  · 有引脚或网络没有接上：BB_VIN
    → 把它连到该连的地方，或显式标成不接（NC）
```

链路：`sch_connectivity_metrics` 的 finding 带 `net` 字段 → `sch_kpi` 按
`reads[].check` 找到对应 check，把名字附到阻断项括号里 → Go 的 card 提取括号
内容接在白话标签后。

上一轮失败的原因是读错了字段（用 `reads[].source`，实际是 `reads[].check`）。
没有名字的阻断项不会渲染多余冒号（有测试覆盖）。

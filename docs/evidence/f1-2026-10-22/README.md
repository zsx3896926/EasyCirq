# F1 USB 供电 MCU 小板：真实 EDA 原理图证据（2026-10-22）

## 结论先行

- 本轮在嘉立创EDA专业版 4.1.78 的真实工程副本上，完成了 **16 个器件、27 个电源标记、16 个网络端口、44 段导线**的原理图；`apply` 逐项回读 `verified`，`save` 返回 true，关闭重开后稳定身份/连接 `match`。
- 导出 Protel 网表核对了物理脚-网络：5V、3V3、GND、CC1/CC2、EN、RST、IO0、TXD、RXD、LED_A 均符合计划。
- **未完成**：PCB、DRC/ERC、制造、样机、固件；图面仍偏拥挤，未达到“工程师可直接接管”的排版质量；部分电气边界（ESD、保险、LDO 热/压差、ESP 峰值电流）未核算。不得把本页当成可生产板。

## 需求与边界

- 5V USB-C 供电，AMS1117-3.3 降到 3.3V。
- ESP-01S（ESP8266 模块）作为主控；复位键、GPIO0 启动键、3.3V 电源指示灯。
- 4 针 UART 排针：3V3、TXD、RXD、GND，用于下载/调试。
- USB-C CC1/CC2 各 5.1k 下拉，作为 sink 申请 5V。
- 本页只验证原理图连接与保存/重开；不验证 USB 兼容性、ESD、浪涌、LDO 热、ESP 峰值电流、射频/天线、结构或固件。

## 执行与验证

1. 先放置 16 个真实库器件，回读 `designator/component/supplier_id/footprint`。
2. 读取每个器件的物理引脚坐标；按引脚端点放电源标记/网络端口，串联器件只用单段直线，避免多段线被编辑器重排。
3. `apply --save`：93 个动作逐项回读 `verified`；`saved:true`。
4. 导出 PNG（1600 宽）与 Protel 网表；核对上述网络。
5. `reopen-check`：关闭后重新打开工程，16 器件/34 个归一化导线段 `match`。

证据文件：`apply-result.json`（逐项动作与验证）、`reopen-check.json`、`snapshot.json`（回读快照）、`plan.json`（可复现计划）、`schematic.png`、`schematic.net`。

## 图面现状与未完成

**图面**：功能关系可读，但 J101 左侧的电源/CC 标记与连接器脚名拥挤，J102 右侧的 3V3/TXD/RXD/GND 标记贴近排针，U101 周边上拉/按键较密。它通过了连接与网表验收，但**没有**通过“工程师看图舒适、可直接接管”的排版验收。下一轮应优先重排这三个局部，保持网表不变。

**电气未验证**：
- USB-C 仅做 5V sink；未做 ESD、浪涌、保险、反接保护，未核对连接器耐流/温升。
- AMS1117 的压差、功耗、结温、输入/输出电容稳定性未算；5V→3.3V 在 ESP 峰值电流下的掉压未测。
- ESP-01S 的启动脚上下拉、复位时序、射频净空/天线条件未核对；模块峰值电流与 LDO 能力未验证。
- C101/C103 的“10µF”来自库器件名，未逐项核对原厂料号/容差/电压降额。
- 未运行原理图DRC/ERC，未做PCB、BOM/坐标、DFM、打样/SMT、烧录或功能实测。

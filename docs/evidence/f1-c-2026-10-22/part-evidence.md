## C2 电源稳定性（U102 = YONGYUTAI AMS1117-3.3）

- 输入：VBUS 5V（经 D102 TVS、C101/C106 10µF 陶瓷入）；输出 3.3V。
- 压差：LCSC 标称 dropout 1.2V@1A。实际负载按 ESP-01S TX 峰值 170mA + LED/上拉 ≈ ≤250mA
  估：dropout ≈ 1.2V×0.25 ≈ 0.3V → 5V−3.3V=1.7V ≫ 0.3V，**压差裕量充足**（独立复算，非抄结论）。
- 功耗/热：P=(5−3.3)V×0.25A ≈ 0.43W；SOT-223 θJA 典型 90–110°C/W（小板无额外铜）→ ΔT ≈ 39–47°C。
  环境 40°C 时结温 ≈ 80–87°C，**可接受但需首板实测温升**（M2 项）。
- 电容网络（网表逐脚复核）：输入 5V 侧 C101 10µF；输出 3V3 侧 **C107 22µF/35V 钽
  （CA45-E035K226T）+ C106 10µF 陶瓷 + C102 100nF**。AMS1117 家族经典稳定条件为输出钽电容
  ≥10µF、ESR 约 0.2–1Ω；本设计满足类型与容量要求，并联陶瓷电容不改变钽的 ESR 主导。
- **未闭环**：YONGYUTAI 原厂手册 PDF 未取得（LCSC 页仅给 dropout/额定）；其 ESR 稳定窗口与
  AMS（原厂）手册的差异未核。状态 PARTIAL：计算成立、类型匹配，原厂正文待取；若取不到，
  G/H 阶段给出「换有完整手册的 1117 兼容料」比较（不擅自宣布现方案通过）。
- 纹波/启动/负载瞬态测试方案：列入 M2 首板表（限流上电→3V3 纹波 ≤50mVpp 判据、TX 峰值瞬态 ≤100mV 跌落判据）。

## C3 USB-C 与 UART

- CC（网表复核）：CC1={J101-A5, R101-2}、CC2={J101-B5, R102-2}，R101-1/R102-1 同在 GND 网
  → **两路独立的 5.1kΩ 1% Rd 下拉**（非并联），符合 USB-C UFP sink 规范。
- VBUS 保护：D102 SMBJ5.0A（Vrwm 5V）位于 VBUS 入口、LDO 之前；钳位约 9V 级，承受对象为 LDO 输入
  （AMS1117 输入耐压 ≥15V 级），**协调成立**；ESP-01S 不直接见 VBUS。
- J102 职责：4P = 3V3/GND/RXD/TXD → **调试口兼 3V3 输出**。外接 USB-TTL 时若其 3V3 也供电，
  与板载 LDO 并联反灌。推荐接线：USB-TTL 只接 GND/RXD/TXD；禁止：USB-TTL 3V3 与板 3V3 同接。
  首板测试先断 J102-3V3 再上电。
- 未用数据脚：DP1/DN1/DP2/DN2/SBU1/SBU2 悬空（设计意图），见 B 包处置表与图面注记。

## C4 启动与复位（ESP8266 ESP-01S，网表逐脚复核）

- EN(CH_PD)：R103 10k 上拉 3V3 + C104 100nF（EN={U101-6, R103-2, C104-1}）→ RC ≈ 1ms。
- RST：R104 10k 上拉 + C105 100nF + SW101 到 GND（RST={U101-7, R104-2, SW101-1, C105-1}）
  → 复位按键。
- IO0：R105 10k 上拉 + SW102 到 GND（IO0={U101-3, R105-2, SW102-1}）→ 下载模式按键。
- IO2：R107 10k 上拉（IO2={U101-2, R107-2}, R107-1→3V3），启动时保持高。
- 四个启动相关脚（EN/RST/IO0/IO2）**均有外部 10k 上拉**；ESP8266 裸芯片无内部强上拉，
  这些上拉是必要的，不是无依据重复添加。
- 模组内部已有：ESP-01S 板载 SPI flash 与天线；无需外部晶振/flash。
- 待实测：上电复位窗口、按键复位、下载时序（M2）。

# PCB 预布局审题：独立盲测记录（三轮，2026-10-29）

> 对象：[exercises-pcb 盲测题面](../../../easycirq/references/engineering-deepdives/exercises-pcb/blind-prompts.md) 的 20 题（X01–X20）。当前为 **v3 题面**（v1 → v2 → v3 修订链见 §4）。
>
> 一句话：**三轮都跑通了；机制/证据/行动/未知四维稳定在 93–100%，但结论类型维始终是短板（50–72%）。** 第三轮证明 v3 全局规则让 X01/X02 的标记位移明显下降（0/6 → 5–6/6 正确），但 X13 的成对翻转识别仍为 0/3；同时暴露出「条件簇」答案与成对案例表口径冲突，导致整体结论率反而下降——这是口径问题，不是内容退步。

## 1. 三轮总览

| 轮次 | 题面 | 试答 | 评审 | 结论类型 ✓ | 机制 | 证据 | 行动 | 未知 |
|---|---|---|---|---|---|---|---|---|
| 第一轮 | v1（含 PL/verdict 提示） | 3 Agent | 1 人 | **43/60 = 71.7%** | 95.0% | 100%（泄题） | 96.7% | 96.7% |
| 第二轮 | v2（去提示；X01 补软检查） | 3 Agent | **2 人交叉** | **A 61.7% / B 60.0%** | 96.7/95.0 | 95.0/100 | 100/96.7 | 93.3/90.0 |
| 第三轮 | v3（+主标记落层规则 2b） | 3 Agent | **2 人交叉** | **A 53.3% / B 50.0%** | 100/98.3 | 95.0/98.3 | 98.3/93.3 | 96.7/95.0 |

- 三轮不可直接比较（题面/答案键/评审/作答者都不同）。**内容层稳定，结论类型维是唯一主要失分维度**。
- 跨评审一致率：第二轮 278/300 = 92.7%；第三轮 **277/300 = 92.3%**，但结论维一致率从 86.7% 降到 **76.7%**（“条件簇”分歧，见 §3）。

## 2. 第三轮重点结论（v3 要验证的四件事）

| 题 | 第二轮 | 第三轮 | 结论 |
|---|---|---|---|
| X01 | 三人全 △（`条件`） | 6/6 `可确认` + `review`（仅 T1 漏子问） | **明显下降** ✔ |
| X02 | 三人全 △（`条件`） | 6/6 `可确认` + `review`（全 ✓） | **明显下降** ✔ |
| X10 | 答案 `条件`，两评审冲突 | 3/3 `待补`（与 v3 答案一致） | 一致；**答案键同时改过，不能单独归因** |
| X11 | 三人全 △（`条件` 争议） | 3/3 `可确认`（条件副注仅 1/3 完整） | 目标达成但副注不齐；**答案键同时改过** |
| **X13** | 两人 ✗（未识别翻转） | **3/3 未识别翻转（0/3）**，两评审都判错 | **没有改善，反而更差** ✘ |

**X13 根因（两评审独立指出）**：题面没给“原布局的 `ck-analog` 距离检查失败（22.8 mm > 14 mm）”这个基线，三人只围绕 HPWL 推理；而同一对案例在 **X07** 三人都答对（知道会 `review → acceptable` 翻转）→ 属**题面缺基线**，不是内容能力退步。

## 3. 整体结论率下降的归因（重要）

第三轮结论维 53.3% / 50.0%，低于第二轮，但**不是内容退步**：

- 机制/证据/行动/未知四维与上一轮持平（93–100%）。
- 下降集中在「条件簇」：逐题 answers 标 `条件`，但成对案例表 PC01/PC02/PC04 对同一对案例标 `可确认`；试答者按 v3 规则 0（判分器判定层）写 `可确认`，被两评审分别判 △/✗，且两评审彼此也不一致（X08：A `ppp` vs B `nnn`；X18 同）。
- 结论维跨评审一致率因此从 86.7% 降到 76.7%。

→ 结论：**v3 规则 0 解决了它针对的问题（X01/X02），但条件簇的答案与成对表未同步统一**，造成新的口径噪声。v4 建议见 [round3-evaluation.md](round3-evaluation.md) §5（统一条件簇、给 X13 补基线、明确规则 0 适用范围、争议单元单列）。

## 4. 方法与限制

| 项 | 做法 |
|---|---|
| 试答者 | 每轮 3 名独立 Agent；输入只有放在仓库外的题目副本；禁止读仓库/答案/案例、禁止联网/运行命令；每人自报“读过文件”，均只有副本路径 |
| 评审 | 第一轮 1 名；第二/三轮 2 名独立评审（互不可见、未读前轮评分），各自输出 60 行评分 CSV |
| 评分 | 结论类型/机制/证据/行动/未知，`✓ / △ / ✗`；每轮对重点题做专项 |
| 一致性 | 60×5 单元脚本逐格比对，冲突由 Lead 记录并裁决 |

**限制**：每轮 3 个样本、约束式隔离（非容器/权限强隔离）、作答同源同构可能、结论类型评分主观空间大（第三轮结论维一致率仅 76.7%）；**不证明模型能力**，不作为认证；v1/v2/v3 分数不可直接比较；条件簇口径未定前，结论类型比例不宜对外引用。

## 7. 能证明 / 不能证明

**能**：题面足以支撑机制解释与修复动作；"不臆造 code、不补默认坐标、不整板重排"可复现；v3 规则对 X01/X02 的标记位移有效；双评审能把“答案口径问题”和“作答问题”分开（X13 vs X08）。

**不能**：三轮样本各 3 个、约束式隔离、同源作答、条件簇口径未统一、结论维评审一致率仅 76.7%——不能推断模型能力；不能作为认证或对外能力声明；第三轮之后未跑第四轮。

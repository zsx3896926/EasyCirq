## 3. 方法

| 项 | 做法 |
|---|---|
| 试答者 | 每轮 3 名独立 Agent；输入只有放在仓库外的题目副本；禁止读仓库/答案/案例、禁止联网/运行命令；每人自报“读过文件”，均只有副本路径 |
| 评审 | 第一轮 1 名；第二至七轮各 2 名独立评审（互不可见、未读前轮评分），各自输出 60 行评分 CSV |
| 评分 | 结论类型/机制/证据/行动/未知，`✓ / △ / ✗`；标准侧冲突单列、不混入作答错 |
| 一致性 | 60×5 单元脚本逐格比对；冲突由 Lead 记录并裁决 |

**限制**：每轮 3 个样本、约束式隔离（同一文件系统、指令约束，非容器/权限强隔离）、作答同源同构可能；七轮题面/答案键/评审/作答者均不同，分数不可跨轮直接比较；**不证明模型能力**，不作为认证或对外能力声明；只覆盖离线几何/网表代理判断。

## 4. 能证明 / 不能证明

**能**：盲测流程可复现；内容层稳定；题面/答案口径变化能显著改变结论类型得分（v4 后 88.3%，v6 后 96.7–100%）；X13 的 0/3→3/3 可归因到题面补基线；X20 的 verdict 层 0/3→3/3 可归因到题面补硬/软属性；两评审能独立定位标准侧缺陷。

**不能**：不能推断模型能力或作为认证；不能证明真实工程判断力；不能比较不同轮次分数高低（条件不同）；约束式隔离无法排除训练语料记忆。

## 7. 复跑方式（下一轮）

1. 使用当前 `blind-prompts.md`（v6）复制到仓库外；
2. 起 2–3 个新会话，只给该文件，禁止读仓库/答案/联网/运行命令；
3. 用当前 `answers.md`（v6.1）+ 五维口径，**至少 2 名评审交叉评分**，各自保留原始分数与 60 行 CSV；
4. 逐格比对一致率；标准侧冲突单列，不混入作答得分；记录“读过文件”声明；
5. 若确实要开下一轮：**先定“子结论是否单独计分”的评分协议**；按本轮收口判断，建议不再开第八轮。不要覆盖既有证据。

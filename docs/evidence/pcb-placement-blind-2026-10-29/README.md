>
> 一句话：**四轮盲测把「题面/答案口径」的问题逐轮收敛掉了**。结论类型维从 71.7% → 61.7% → 53.3% → **88.3%**（第三轮的低点是口径冲突，不是退步）；跨评审一致率从 92.7% → 92.3% → **98.3%**（结论维 100%）。X13 翻转识别从 0/3 → **3/3**，归因是题面补基线。内容层（机制/证据/行动/未知）始终 93–100%。

## 3. 方法

| 项 | 做法 |
|---|---|
| 试答者 | 每轮 3 名独立 Agent；输入只有放在仓库外的题目副本；禁止读仓库/答案/案例、禁止联网/运行命令；每人自报“读过文件”，均只有副本路径 |
| 评审 | 第一轮 1 名；第二/三/四轮各 2 名独立评审（互不可见、未读前轮评分），各自输出 60 行评分 CSV |
| 评分 | 结论类型/机制/证据/行动/未知，`✓ / △ / ✗`；每轮对重点题做专项，标准侧冲突单列、不混入作答错 |
| 一致性 | 60×5 单元脚本逐格比对；冲突由 Lead 记录并裁决 |

**限制**：每轮 3 个样本、约束式隔离（同一文件系统、指令约束，非容器/权限强隔离）、作答同源同构可能；四轮题面/答案键/评审/作答者均不同，分数不可跨轮直接比较；**不证明模型能力**，不作为认证或对外能力声明；只覆盖离线几何/网表代理判断。

## 4. 能证明 / 不能证明

**能**：盲测流程可复现；内容层（机制/证据/行动/未知）稳定在 93–100%；题面与答案口径的变化能显著改变结论类型得分（v4 后 88.3%，跨评审结论维 100%）；X13 的 0/3→3/3 可归因到题面补基线；两评审能独立定位标准侧缺陷（X05/X20）。

**不能**：不能推断模型能力或作为认证；不能证明真实工程判断力；不能比较不同轮次的分数高低（条件不同）；约束式隔离无法排除训练语料记忆。

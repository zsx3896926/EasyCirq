# PCB 预布局审题：独立盲测记录（两轮，2026-10-29）

> 对象：[exercises-pcb 盲测题面](../../../easycirq/references/engineering-deepdives/exercises-pcb/blind-prompts.md) 的 20 题（X01–X20）。当前为 **v3 题面**（v1 → v2 → v3 修订链见 §4）。
>
> 结论先说：**两轮盲测可跑、机制/证据/行动维达标，且“不臆造、不补数据、不整板重排”纪律可复现；但结论类型维两轮都只有 60–72%，失分几乎全是“可确认/条件/待补”标记位移。**第二轮用双评审交叉评分（300 单元一致率 92.7%），据此定位并修订了 X05/X10/X11 的答案口径与“主标记落层”规则。

## 2. 方法与限制

| 项 | 做法 |
|---|---|
| 试答者 | 每轮 3 名独立 Agent；输入只有放在仓库外的题目副本；禁止读仓库/答案/案例、禁止联网/运行命令；每人自报“读过文件”，均只有副本路径 |
| 评审 | 第一轮 1 名；第二轮 2 名独立评审（互不可见、未见第一轮评审），各自输出 60 行评分 CSV |
| 评分 | 结论类型/机制/证据/行动/未知，`✓ / △ / ✗`；X05、X11 专项判断答案本身是否站得住 |
| 一致性 | 第二轮的 60×5 单元用脚本逐格比对，冲突由 Lead 逐条裁决 |

**限制**：每轮 3 个样本、约束式隔离（同一文件系统，靠指令约束，非容器/权限强隔离）、作答同源同构可能、结论类型评分仍有主观空间；**不证明模型能力**，不作为认证或对外能力声明。

## 5. 能证明 / 不能证明

**能**：题面足以支撑回路/耦合/热/机械层面的机制解释与修复动作；"不臆造 code、不补默认坐标、不整板重排"在盲测下可复现；双评审能把“答案口径问题”和“作答问题”分开（X11 vs X13）。

**不能**：3 个样本、约束式隔离、评分主观性、同源作答——不能推断模型能力；v1/v2/v3 分数不可直接比较；第二轮之后未再跑第三轮。

## 6. 复跑方式（下一轮）

1. 使用当前 `blind-prompts.md`（v3）复制到仓库外；
2. 起 2–3 个新会话，只给该文件，明确禁止读仓库/答案/联网/运行命令；
3. 用当前 `answers.md`（v3 口径）+ 五维口径，**至少 2 名评审交叉评分**，各自保留原始分数与 60 行 CSV；
4. 逐格比对一致率，冲突由 Lead 裁决；记录“读过文件”声明；
5. 在本目录新增 `round3-*.md`，不要覆盖既有证据。

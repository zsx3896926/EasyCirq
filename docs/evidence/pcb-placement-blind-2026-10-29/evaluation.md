## 1. 方法与口径

每题按 **结论类型 / 机制 / 证据 / 行动 / 未知** 五维各给一个符号：`✓` = 正确且完整；`△` = 方向对但缺关键项、标记位移或表述混淆；`✗` = 明确错误（与答案相反）。**结论类型**维以答案标记（可确认/条件/待补/过度）为准，并同时检查三件事：是否把 `review` 软检查说成 `blocking` 硬错误、是否把数据缺口说成可确认、是否漏 `NOT RUN`。

判定一律"仅凭题面可判"：题面未给 code 名时，写"题面未给名、不臆造"记 `✓`，臆造不存在 code 记 `△`；只有题面确实无法判断才归因题面。

## 4. 发现（现象 → 归因 → 建议动作）

**① 三人共弱题只有 X11，责任在答案口径。** 三人一致标 `待补`（答案 `条件`），但机制、证据、行动全部正确。→ 属**答案问题**（X11 未拆"可确认的几何事实"与"条件性的等价判断"）叠加**题面问题**（未要求标记落在被问对象上）。→ 已落实：题面加"结论类型须落在被问的那件事上"；答案口径建议留给 Lead/后续轮。

**② X01 的 verdict 是题面缺陷，不是作答错误。** B1 报 `fail`、B2 报 `blocking`、B3 报 `review`；案例与答案均为 `review`。题面只说"checks 用引脚对计算距离，超阈值失败"，**没说这是软检查、也没说无硬检查命中**（X02 却写了）。严格按"仅凭题面可判"，X01 的 review/blocking 不可判，B1/B2 的 `✗` 不计入判断力证据。→ 已落实：题面补"该检查为软检查、本案例无硬检查命中"。

**③ X03/X04 的 code 名：三人全部正确地"不臆造"，但题面把可得分项藏起来了。** 答案要求 `keepout_violation`/`body_overlap`，题面均未给；三人写"题面未给名"是正确行为。→ 属**题面问题**：要么给枚举，要么明确"未给名时写 check_id、不新造 code"。→ 本轮选择**保留"不臆造"训练目标**，在 v2 题面注明该口径。

**④ 证据维 100% 饱和，题面确有泄题。** 每题都写"场景来源：`P1-MCU-MIN`…；PL17、PL18"；X05 直接写"期望 `blocking`，codes 只有 `connector_off_edge`"，X12/X13/X14/X17 写"从 review 翻到 acceptable"——verdict 答案写在题面里。→ 属**题面问题**。→ 已落实 v2：场景来源只留案例 id，删除 PL 编号与 verdict/codes 提示。

**⑤ B3 的"可确认+待补"是系统性偏置。** 答案标 `条件` 的 X09/X14/X16/X18，B3 全部写成"可确认+待补"。→ 属**作答问题**（把"其中几何部分可确认"当成整题结论类型）。→ 建议：题面/评分口径明确"结论类型只写一个主标记 + 一句附加说明"（v2 已在题面开头注明）。

**⑥ X05 的"代理压缩"混淆是三人共同机制弱项。** 三人均写"被压进贴边代理"，答案要求"是案例数据只声明了这一个硬检查"。→ 属**作答问题**，同时暴露题面把两个选项并排给出、缺少区分标志。→ 建议保留该辨析题，答案侧补"二选一且选后者"。

**⑦ 无人做过度修改，但两处漏答"过度例"。** 60 份作答中没有"整板重排/删电容/改判据"的建议（正面结果）；缺口是 X01 B1、X08 B2 未答"过度动作"子问。→ 属**作答问题**。→ 已落实：X01/X08 把"过度例"标为必答项。

**⑧ 结论类型维低分集中在"标记位移"，不是判断错。** 15 个 △ 中 12 个是标记选错；真正的内容错误只有 X01 的 review→blocking。→ 属**口径问题**：复合标记如何计分未定义。→ 建议答案侧加"标记粒度规则"。

## 5. 结论

**这轮盲测能证明什么**：只看题面的约束下，3 名 Agent 在机制、证据、行动、未知四维的 ✓ 比例分别为 95%、100%、96.7%、96.7%，说明题面足以支撑回路/耦合/热/机械层面的机制解释与修复动作选择；60 份作答中没有出现"过度修改""臆造 code""补默认坐标"的越界行为，说明"不臆造、不补数据"的纪律在盲测下可复现；结论类型维 71.7% 且失分几乎全是标记位移，说明主要噪声源是**标记口径**而不是判断力。

**不能证明什么**：3 个样本、单评审人、无第二评分人交叉校验；隔离是**约束式**的（只读题面副本、禁读仓库/答案/联网/运行命令），不是强隔离，无法排除对训练语料的记忆；三份作答高度同构，**不能**据此推断模型能力，也不作为认证或对外能力声明；X01 这类题面信息不足的题，其失分不能归因于作答者。

**修订结论：题面需要修订，且已修订（v2）。** 已落实：X01 软检查声明；移除 PL 编号与 verdict/codes 提示；X11 标记落点要求；X01/X08 过度例必答；README 盲测状态与限制。未落实（建议后续轮）：答案侧"标记粒度规则"、X05 答案"二选一"表述、X03/X04 code 枚举方案。

> 注：本轮作答基于**修订前**的 v1 题面；v2 题面用于下一轮盲测，两轮的分数不可直接比较。

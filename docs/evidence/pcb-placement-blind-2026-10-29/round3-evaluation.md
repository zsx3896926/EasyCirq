## 3. 重点问题对照（本轮要看的 5 题）

符号：`y`=✓、`p`=△、`n`=✗；每格是 3 名试答者的结论类型序列；`A/B` 为两评审。

| 题 | 第二轮（R1–R3） | 第三轮（T1–T3） | 结论 |
|---|---|---|---|
| **X01** | A `ppp` / B `ppp`（三人全 △） | A `pyy` / B `pyy` | **明显下降**：主标记全部 `可确认`、判定全部 `review`；仅 T1 漏答“只比中心距会怎样” |
| **X02** | A `ppp` / B `ppp`（三人全 △） | A `yyy` / B `yyy` | **明显下降**：主标记 `可确认`、判定 `review`，两评审全 ✓ |
| **X10** | A `yyy` / B `ppp`（答案 `条件`，两评审冲突） | A `yyy` / B `yyy`（答案已改 `待补`） | 与 v3 口径一致；**但答案键本轮同时改过，不能单独归因于题面** |
| **X11** | A `ppp` / B `ppp` | A `pyy` / B `ppy` | 主标记 3/3 `可确认`（目标达成）；条件副注只有 T3 完整 → 部分 ✓。**答案键同时改过，不可单独归因** |
| **X13** | A `ynn` / B `ypp` | A `nnn` / B `pnn` | **没有改善，反而更差**：三人全部答“两份 verdict 相同/不翻转”，都漏掉 `P3-ANALOG`（review）→ `P3b-ANALOG-PAIR`（acceptable）的翻转 |

### 3.1 X01/X02 为什么能干净归因

这两题的 answers 与第二轮完全相同（`可确认`），只有题面 v3 加了全局规则 2b。第二轮三人全写 `条件`（把“真实板耦合条件”当主标记），第三轮 6/6 写 `可确认`（判分器 verdict 层）→ **规则 2b 生效**，标记位移确实下降。

### 3.2 X10/X11 的归因限制

本轮 answers 同时把 X10 主标记改为 `待补`、X11 改为 `可确认`。作答与答案一致，但**题面规则与答案键同时变化**，无法区分是哪一项起作用。下一轮若要干净测量，应先固定答案键、只改题面（或相反）。

### 3.3 X13 为什么没改善（专项诊断）

- 三人作答都只围绕 **HPWL** 推理（“HPWL 是全局阈值，未超阈所以不翻转”），没有人指出**软检查 `ck-analog` 本身会翻转**。
- 关键证据：`P3-ANALOG` 的 `ck-analog` 实测 22.76 mm > 14 mm 阈值（失败，review）；`P3b-ANALOG-PAIR` 只把模拟链整体挪远，实测 12.70 mm ≤ 14 mm（通过，acceptable）。这是**距离检查的翻转**，与 HPWL 无关。
- 题面 v3 只写“某模拟链案例…把它整体挪远…HPWL 变差”，**没有给出原布局的软检查失败基线**；三人因此把问题当成“HPWL 变差会不会降低 verdict”。
- 反证：三人在 **X07（同一对案例）** 都答对了“贴功率级 → review、挪远 → acceptable”，说明他们知道这对案例会翻转，只是 X13 的题面没有把“哪一项检查翻转”说清。→ **题面问题，不是内容能力退步**。

## 4. 结论类型整体下降的归因（重要）

结论类型 ✓ 从第二轮 61.7%/60.0% 降到 53.3%/50.0%，**主要不是内容退步**，而是「条件簇」的答案口径内部冲突：

| 现象 | 证据 |
|---|---|
| 逐题 answers 标 `条件`，但成对案例表对同一对案例标 `可确认` | X12 vs PC02、X14 vs PC04、X15 vs PC01；三人都按“判分器判定层”写 `可确认` → 被判 △/✗ |
| 两评审对同一批单元分歧最大 | X08：A `ppp`、B `nnn`；X18：A `ppp`、B `nnn`；X07/X17：A `yyn`、B `yy` 系列差异 |
| 机制/证据/行动/未知四维稳定 | 98.3%–100% / 93.3%–98.3% / 95%–96.7%，与上一轮持平 |

也就是说：v3 规则 0 解决了 X01/X02 那类“题面诱导”，但**没有同步把 conditions-cluster 的答案与成对表统一**，导致评审各自按不同读法打分——这是本轮结论维下降与跨评审一致率下降的主因。

## 5. 裁决与 v4 建议（本轮**未**修改产物，保持证据可复现）

> 本轮分数按当前 v3 口径计算；以下为下一轮（v4）的修订建议，**未**回写、未追溯。

1. **统一条件簇口径**：X07/X08/X12/X14/X15/X18 与成对表 PC01/PC02/PC04 必须一致。建议规则：
   - 题目问“两份布局各判什么 verdict / 会不会翻转”→ 主标记 `可确认`（判分器判定层），工程条件写副注 + `NOT RUN`；
   - 题目问“这个取舍在真实工程里可不可接受 / 真实后果”→ 主标记 `条件`。
2. **X13 题面补基线**：明确“原布局的 `ck-analog` 距离检查失败（22.8 mm > 14 mm 阈值），只挪远后通过（12.7 mm）”，或直接问“哪一项检查发生了翻转”。
3. **规则 0 的适用范围**写进题面试答要求（目前只在 answers/side 有），避免评审各按一套读法。
4. **评审分歧太大的单元**（X08/X18 等）应单列“标准争议”，不混入作答得分；本轮两评审对 16 个单元给出不同判级。
5. 若下一轮结论维仍 < 70%，建议把“结论类型”拆成两维：**判分器判定层**（verdict/check）与**工程结论层**（真实板后果），避免一个符号承载两种问题。

## 6. 能证明 / 不能证明

**能**：v3 规则对 X01/X02 的标记位移有效（同答案键、只改题面）；X10/X11 的作答与 v3 口径一致；X13 的翻转识别没有改善，且根因定位到题面缺基线（X07 反证）；条件簇的答案-成对表冲突被两评审独立发现。

**不能**：三轮的作答者、答案键、题面版本都不同，**分数不可跨轮直接比较**；每轮 3 样本、约束式隔离、双评审对条件簇本身分歧大（结论维一致率 76.7%）；**不证明模型能力**，不作为认证；条件簇口径未定前，结论类型比例不宜对外引用。第四轮（v4 题面 + 统一口径）未运行。

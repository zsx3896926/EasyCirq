### 1.3 五维判定规则（本轮执行细则，先定规则再打分）

| 维度 | ✓ | △ | ✗ |
|---|---|---|---|
| 结论类型 | 主标记与 v5 一致、单主标记、落在**规则 0 第一问句所在层**，且核心 verdict 不冲突 | 主标记正确，但核心 verdict 与答案冲突（硬检查说成 `review`、应 `blocking` 说成"不可判"） | 主标记错（含把 `条件`/`待补` 位移、把软代理超阈值说成"已证实失效"） |
| 机制 | 给出物理/判分语义机制：回路与回流、耦合路径、热路径、机械干涉、判分器语义边界 | 只复述结论或 code，机制靠"因为题面说…"代替 | 机制缺或与答案反向 |
| 证据 | 指到案例 id、finding code、check_id 或**具体规则描述**（题面未给 code 名时写规则描述即算 ✓，不要求猜名） | 只复述题面前提、无对象定位 | 证据错误或编造 code |
| 行动 | 修复动作与结论匹配；X01「过度例」、X08「过度例 + 改对但分数不变」两必答项齐全 | 方向对但缺必答项，或只给"还要看什么"不给动作 | 动作与结论矛盾（把 `review` 当整板重排、把 `blocking` 当微调） |
| 未知 | 列出离线不可判项并标 `NOT RUN`/未做/未知 | 只写"真实还要看…"作为建议、不给状态；或缺关键项 | 整题无缺口意识，或声称已确认不可判项 |

补充约定：

1. **结论维只比主标记**（题面要求「只写一个主标记」），复合写法按主标记计；verdict 级细节按 §1.3 的 △ 规则处理。
2. **`条件` 两段检查**：主标记 `条件` 的题（X05/X08/X09/X17/X18）要求"可确认的几何/判分事实 + 尚缺的条件"两段；三段式按主标记计，缺一段记机制 △。
3. **读法宽严**：证据维按"规则描述可选"宽口径（因为 v4 题面刻意不泄 code 名）；`NOT RUN` 允许等价写法（"未做""全未知"）。

### 1.4 标准侧与作答错分离

- 先把答案-vs-规则 0 的冲突单列（§4.5），不计入作答错；
- 答案要求在题面未给前提下无法推出的（如某 finding 的硬/软属性），单列为**前提缺口**；
- `benchmarks.json` 的 `expected` 用于核对 verdict/codes 事实，不用来倒推试答者应知的内容。

1. **v5 两处修订在作答侧归零。** X05 三人 3/3 `条件`、X20 三人 3/3 `可确认`，20/20 题主标记三人一致（60/60 单元）。第四轮结论维 88.3% 的低点归因（条件簇 + X05/X20 标准侧冲突）在本轮不再出现：结论维 93.3%，扣 S1 后 100%。
2. **X20 是唯一残留的"标准侧前提缺口"，且 3/3 同向。** 无人写 `blocking`，说明题面对"缺失类 finding 的硬度"信息不足；三人都在"不得通过"的安全侧，未出现假通过。建议答案给 X20 补一句"题面未声明硬度时，判分层可确认的是'数据不完整→不得判 acceptable'；`blocking` 需契约硬度"，或题面直接标注该 finding 为硬检查。
3. **X14/V1 是唯一一处结论维"主标记对、verdict 错"的作答错。** 把 P8-MULTI 的 `blocking` 写成 `review`，随后"翻转"叙述仍成立，属推断不足而非口径问题；V2/V3 用"两条检查失败→通过"回避了 verdict 词，未被判错——需注意这是**未写**而非**写错**，若下轮要求显式 verdict，V2/V3 在 X03/X04/X14 可能各降一档。

## 6 限制

- **单评审**：本轮只有我一人打分，无跨评审一致率；300 单元中 11 个非 ✓ 的 △/✗ 边界（尤其"未知"与"机制"两维）带主观性，换评审可能 ±3–5 单元。
- **3 个样本、同一模型族**：三人作答高度同构（V2≡V3），统计上不能推断总体能力，也不能外推真实工程判断。
- **未读 round2/3/4 记录**（按要求保持独立），因此不做跨轮严格对比；文中对"第四轮 88.3%"的引用只来自 README 的公开摘要。
- **不可知项**：作答者看不到案例 `expected`、code 名、契约硬度；X20 的 `blocking`、X14 的 P8-MULTI 原 verdict 都属"题面未直给"，本报告对二者的归属（作答错 vs 前提缺口）是判断而非事实。
- **口径选择**：证据维取宽口径（规则描述即可）；结论维把"verdict 级误述"计入 △（沿用 README"不把 review 说成 acceptable"的精神）。若改严/改宽，结论维会在 93.3%–100% 间移动。
- **未做的检查**：未复算 P8/P3 的几何数值（只读 `expected` 与 rationale），未运行判分脚本；真实工程检查（DRC/布线/阻抗/热/装配）一律 `NOT RUN`。

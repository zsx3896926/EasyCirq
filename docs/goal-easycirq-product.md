## 一、定位：我们不是又一个 EDA

| | 他们解决什么 | 他们不解决 |
|---|---|---|
| 嘉立创 EDA / KiCad / Altium | **画出**原理图和 PCB | 画完之后呢？能不能下单？漏了什么？ |
| 立创商城 / 华秋 | **买到**器件、**做出**板 | 设计阶段的问题到不了这里就被埋了 |
| 各路 AI 画板工具 | 生成一版图 | **它说得对不对，没人验证** |

> **EasyCirq 在 EDA 之上加一层「交付保证」：**
> 每一步都要有证据，没有证据就推不动，推不动就明确告诉你缺什么。

**一句话：把「我觉得画完了」变成「有证据证明可以下单」。**

这也是为什么它必须是 harness 形态——**不是让 AI 更会画图，是让人和 AI 都没法假装做完了。**

## 二、用户与场景

| 用户 | 他现在怎么活 | 我们要给他什么 |
|---|---|---|
| **电子工程师**（主） | 画完靠经验自查，漏了到打样才发现 | 一道能替他兜底的网，且**说得出依据** |
| **硬件创业者**（主） | 没有专职硬件，找外包又验不了 | 把"能不能投产"变成一个**看得懂的判词** |
| **学生 / 转行新手**（次） | 不会用 EDA，教程看完还是不会 | **30 分钟内做出一块能下单的板** |
| **企业硬件团队**（次） | 公司规范靠人盯，新人踩老坑 | 规范变成**可执行、会拦人**的规则 |

**不做谁**：不做纯学术仿真、不做机械结构、不做量产测试设备。

## 三、体验原则（"国内顶尖产品的风格"落成规则）

参考的不是某一家的皮肤，是**这一类产品做对的事情**：

| 参考 | 学什么 |
|---|---|
| **剪映** | 打开就能干活，不需要教程；每个按钮点下去都有即时反馈 |
| **WPS** | 本地优先、离线可用；格式兼容认真对待 |
| **飞书 / 语雀** | 中文排版讲究；信息密度高但不挤；克制的留白 |
| **微信开发者工具** | 本地 IDE 形态的开发者体验；错误信息带上下文、能复制 |
| **即时设计 / MasterGo** | 国产设计工具的界面精度；深浅色都对得起眼睛 |
| **DeepSeek** | 中文 AI 产品的交互语言：不卖弄、说人话 |

### 3.1 视觉规则（可检查，不是审美评价）

| 项 | 规则 |
|---|---|
| 字体 | 系统中文黑体；**数字与英文用等宽**，中英混排不跳动 |
| 字号阶梯 | 仅 `12 / 14 / 16 / 20 / 28`，行高 `1.6` |
| 主色 | **只有一个**；语义色只有四种（成功/警告/失败/中性），**禁止彩虹** |
| 状态标识 | **颜色 + 文字 + 图标**三者同时给（色盲友好，也是中文产品习惯） |
| 圆角 / 阴影 | 圆角 `6px`；阴影只有两档（浮起 / 弹层） |
| 空状态 | **必须写"下一步做什么"**，不许只有"暂无数据" |
| 数字 | 所有 KPI/计数**右对齐、等宽**，一眼能比大小 |

### 3.2 交互规则

| 规则 | 判据 |
|---|---|
| **三秒可判** | 打开面板 3 秒内能说出"这块板能不能交付" |
| **一键** | 跑门、推进、导出、诊断，各一个按钮，不藏在菜单里 |
| **可取消** | 任何超过 3 秒的操作都有进度和取消 |
| **不打断** | 不用模态框；用侧滑抽屉 |
| **键盘优先** | `Ctrl+K` 命令面板，常用操作有快捷键 |
| **能复制** | 每条错误都有"复制诊断信息"，粘给支持就能定位 |
| **可恢复** | 中断后续跑（已有能力），界面要体现"上次停在哪" |

### 3.3 文案规则

- **说人话**：不写"操作失败"，写"这块板还差 2 个引脚没连，点这里看是哪两个"
- **每条错误三问齐备**：发生了什么 / 为什么 / 下一步做什么
- **不用感叹号**，不卖萌，不甩专业术语解释基本概念
- **数字必须可追溯**：界面上的每个数字，点开能看到它来自哪条命令

## 四、产品面

### S1 面板（产品门面）

> **不是状态显示器，是工作台。**

**① 概览**
- 大判词：`可以下单` / `还不能下单` / `还没检查过`（三态，绝不模糊）
- 一行对账：`必查 14/15 · 缺证据 2 · 提醒 3`
- 一张板缩略图 + 工程名 + 页面

**② 相位与证据**（核心）
- S0–DELIVER 相位条，五态：`pass / fail / blocked / pending / stale`
- 点一格 → 缺什么、怎么补（`howToFix`）、上次跑的时间
- **`pending` 和 `stale` 有自己的颜色，永不为绿**

**③ Agent 工作面**
- 对话流：模型想做什么 → 允许 / 拒绝 → 为什么
- **拒绝高亮**（这是 harness 的全部意义所在）
- 可停止、可续跑，显示"上次停在哪"
- 每轮可展开看原始 JSON

**④ 历史与产物**
- 时间线：谁在何时推进了相位、跑了什么门、结果如何
- 产物：交付包、BOM、报告 —— 可打开、可导出、可"在文件夹中显示"

**⑤ 工程与连接器**
- 工程列表、当前窗口/页面
- 连接器版本必须 `v1.0.22`，不符要**醒目且可点**直达修复步骤
- daemon 健康度

### S2 上手（首次运行）

**目标是 30 分钟首次价值**，路径固定：

```
1. 启动 → 自动体检（EDA 装了吗、连接器导了吗、Python 在吗）
2. 每项红 → 一条可执行命令 + 一个"帮我做"按钮
3. 选工程 → 选板子
4. 面板解释"相位是什么"（一次，不啰嗦）
5. 跟着相位条走 → 第一张交付卡
```

每一步可跳过、可回来、可重看。

### S3 诊断与支持

- **一键诊断包**（脱敏）：版本、doctor、日志尾部、环境、相位证据
- 面板内 doctor 可视化，每个红项配修复命令
- "复制诊断信息"一键到剪贴板
- 明确告诉用户**诊断包里有什么、没有什么**

### S4 交付与生命周期

- 签名安装包（Windows Authenticode）
- **离线安装包**（无网可装，参考 WPS 的做法）
- 自更新走面板（已有 `easycirq update`，包一层）
- **兼容性矩阵显式化**：CLI / 连接器 / 技能 三者版本对应关系
- 一键卸载（不留垃圾）

## 五、质量门槛（全是数字）

| 维度 | 门槛 | 怎么验 |
|---|---|---|
| **首次价值** | 新人 ≤ **30 分钟**拿到 `可以下单` 的卡，全程只用面板 | 真人实测录像计时，**不接受自评** |
| **三秒可判** | 打开 ≤ 3 s 能说出能否交付 | 5 人盲测，≥4 人说对 |
| **失败可解释** | 每条错误答齐三问 | 自动扫描全量错误文案 |
| **不假装完成** | 五态 × 每个显示面，`pending/blocked/stale` **永不呈现为通过** | 光谱测试 |
| **性能** | 首屏 < **800 ms**（4 年前笔记本）；交互 < **100 ms** | 基准脚本进 CI |
| **可访问性** | WCAG 2.1 AA；axe **0 critical**；**全键盘可用** | axe + 键盘走查清单 |
| **韧性** | 面板崩了 CLI 照常；daemon 挂了显示 degraded 不是白屏 | 杀进程测试 |
| **安全** | 只监听 `127.0.0.1`；CSP 拒外链；日志不含密钥/网表 | netstat + 头断言 + 日志扫描 |
| **可复现** | 同输入 → 逐字节相同产物 | 已有 plan SHA / selftest 扩到交付包 |
| **无遥测** | 默认**零外连**；开启要显式勾选并显示发送内容 | 抓包验证 |

> 每一项都要有命令输出或测试。**不接受"体验很好""很专业"这类回答。**

## 六、工程约束（不可协商）

| 约束 | 理由 |
|---|---|
| 面板**内嵌单一二进制**，无构建步骤 | 客户机不该装 node |
| 面板**只监听 `127.0.0.1`** | 与 `llm-proxy` 同一条纪律 |
| 面板**零判定逻辑**，只渲染 CLI 的 JSON | 否则出现第二个真相来源 |
| 面板与 CLI **互不依赖** | 面板崩了不能影响干活 |
| 所有数据来自 `--json` 或证据文件 | 单一真相来源 |
| 中文文案**集中放**，不散落硬编码 | 成本几乎为零的预留 |

**铁律：面板是渲染器，不是第二套逻辑。** 任何判定差异都是 bug，用测试钉死。

## 七、验收判据（20 条）

### A. 面板（10 条）

1. `easycirq panel` 起得来，打印确切 URL，可用浏览器打开
2. **只监听 `127.0.0.1`**（`netstat` 证明不是 `0.0.0.0`）
3. 相位条五态颜色与证据**一一对应**
4. `pending`（门没跑）**不显示为绿**
5. `card` exit=2 → 显示"还没检查过"，不是"通过"
6. 改板后证据变 `stale`，面板标出且**不让推进**
7. 任意一次拒绝，面板说清：**哪个相位、想做什么、为什么不行**
8. 连接器版本不符有醒目提示且可点
9. 杀掉面板进程，`easycirq phase` 照常
10. 干净安装后打开面板**无任何构建步骤**

### B. 质量（6 条）

11. axe **0 critical**；键盘可走完主流程
12. 首屏 < 800 ms，交互 < 100 ms（CI 跑基准）
13. 空 / 错 / 离线三种状态**都有设计**，不是白屏
14. 深色 / 浅色都可用
15. 默认抓包**零外连**
16. 每条用户可见错误答齐"发生了什么 / 为什么 / 下一步"

### C. 交付（4 条）

17. 签名安装包可装
18. 离线安装包可用
19. 诊断包可导出且**已脱敏**（断言不含网表/密钥）
20. `inspect-bundle` verdict `ok`，且包内含面板

**做法上只有一个选择**：面板不自己实现判定，而是 `exec` **它自己这个二进制**跑同一条命令。
只有这样"面板跑出来的门"和"人敲出来的门"才可能是同一份字节。参数是服务端查表得到的
**白名单键**（`gate` / `phase-advance` / `phase-run-s5` / `card`），前端传不了任意命令行。

**故意不放进白名单**：任何删除/清空类命令。面板是给人看进度的，不该成为一把能毁掉画布的按钮。

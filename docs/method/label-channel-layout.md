# 标签通道布局法（Label-Channel Layout）

> 沉淀于 2026-10-30。C 板 scratch 重排连续失败 5 轮后总结的**根因级**方法，
> 不是"再试一次"的补丁。适用于任何"用程序把整页原理图写进 EDA"的场景。

## 1. 问题现象与误判

| 现象 | 误判 | 真因 |
|---|---|---|
| 连线被拒 `SCHEMATIC_GEOMETRY_INVALID` | 以为 EDA 慢/连接器坏，重试方向 | 标签框与已有线/器件/标签重叠 |
| 块间距放大后仍被拒 | 以为"挤" | 同一器件同侧引脚间距 10 < 标签高 12，**必须分层** |
| 连接器 `degraded` 后全线失败 | 以为纯 EDA 问题 | 失败率超阈值（10%）触发降级；失败源是上面两条 |
| 清空重建后又乱 | 以为"自动连线就这样" | 没有在**布局阶段**为标签预留通道 |

**一句话**：几何校验不是障碍，是**布局欠账的账单**。

## 2. 方法：四层闭环

```
① 分组（电气角色） → ② 通道预留（布局） → ③ 离线桩线规划（预测） → ④ 引擎写入（执行）
```

### ① 分组：`tools/subdivide.py`
- 每个核心器件（U/MK/Q/Y）与其"共享非电源网络"的被动器件成一组；
- 只接电源/地的被动器件 → "去耦/滤波"组；
- 无核心器件的组按参考号族拆：J→排针、TP→测试点、D→ESD；
- 单器件碎组自动并入最大兄弟组，避免碎片卡片。

### ② 通道预留：`tools/channel_layout.py`
- 每个器件每侧需要：`桩线 20 + 该侧最宽标签宽`（上下为 `20 + 标签高`）；
- 排布时相邻器件的通道**不相邻共享**；
- 卡片尺寸 = 器件并集 + 通道 + 4；再从标签实际位置**迭代回灌**（冲突 → 该侧 +40），直到 0 冲突。

### ③ 离线桩线规划：`tools/stub_planner.py`
- 建模：器件框 + 桩线段 + 标签框；
- 每根 pin 首选"沿引脚朝向 + 20 单位"；冲突则换方向；再冲突进入**同侧分层**：
  - 同侧两个标签若 y 重叠，只能在 x 方向分开 → `offset = 20 + shelf × (标签宽 + 6)`；
- 全失败才标记"布局让位"（此时**不允许写 EDA**）。

**关键量化结论**：109 引脚中 92 根在 20 单位可连，17 根需要第二层；间距放大 3 倍不改变这个结论。

### ④ 写入引擎：`tools/apply_engine.py`
- 写前 `verify`（计划器件/引脚 vs 页面实际，缺件 fail fast）；
- 写前 `preflight`（桩线端点越界/零长度拒绝）；
- 坏线清理：`sch check` 提取 `zero-length-wire` id → `prim-delete`；
- 自适应批量 10→5→2，每批 `doc reload` + `health`；`degraded` 立即停；
- 失败分类 `ok/geometry/plan/effect/degraded`，`plan` 永不重试；
- JSONL journal 断点续跑。

## 3. 分页方法（2026-10-30 补充）

1. 卡片 = **union(器件, 标签) + 2** → 标签出框在几何上不可能；
2. **同一模块的所有卡片不跨页**（块亲和）；
3. 块按面积降序做"装入最轻一页"的负载均衡；页内按高度分两列平衡；
4. 行满换行、行满换页：首卡必落第 1 页，永不出现空白页；
5. 验收指标：`labels_outside_cards=0`、`card_overlaps=0`、`block_split_pages=0`、
   `page_parts` 两页差值 ≤ 10%。

C 板实测：2 页、43 器件、109 标签、0 出框、0 重叠、块不跨页、页负载 23/20。

## 4. 验收清单（缺一不可）

- [ ] `stub_planner` 预测 `shrunk == 0`
- [ ] 卡片 `labels_outside_cards == 0`、`card_overlaps == 0`
- [ ] 分页 `block_split_pages == 0`、页负载均匀
- [ ] `apply_engine` 写前 verify 无缺件
- [ ] 写后 `sch check` 零长度 = 0、`ace review` 通过
- [ ] 导出 PNG 与预览逐页对比，差异逐条记录

## 5. 反模式（禁止）

- ❌ 在 EDA 上"换方向重试"直到通过（把路由决策交给校验器）；
- ❌ `degraded` 状态下的批量重试；
- ❌ 手工分组不核对器件总数（漏 C1/R7/R8 导致 65 次注定失败）；
- ❌ 卡片尺寸与标签位置分开计算（必然重叠或出框）。

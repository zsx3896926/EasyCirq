## 00:20–01:40 第一轮：布局规划器

### 发现的问题（用户反馈：画得太垃圾）

1. 落点前没有量块尺寸：器件顶出图纸、压标题栏。
2. 分区框按“看着差不多”画：块比框大、框内大片空白。
3. 分区标题与块内网络标签打架（同一高度）。
4. 块自动连线部分失败后没有量化记录。
5. `standard-parts.json` 的 deviceUuid 是 lceda.cn 站点的，当前 EasyEDA 是 easyeda.com → 所有块落块失败；必须先用 `lib search`/`lib by-lcsc` 按站点解析。

### 本轮产出

- `easycirq/scripts/sch_layout_plan.py`：
  - 输入 `easycirq-sch-layout-plan/v1`（page、titleBlock、blocks[envelope{w,h}]）；
  - 可用区 = 页面 - 边距 - 标题栏（上方整条 + 左下角）；
  - 货架排布（按高度/宽度降序）；
  - 分区 = 块包络 + padding，标题在块上方留 titleGap；
  - 输出 frames + placements（bbox/at）+ metrics（fits/zones/overlaps/area_usage）；
  - 分区互相重叠时自动裁剪（frame apply 拒绝重叠分区）。
- 测试 `tests/test_sch_layout_plan.py` 5 个用例：三块落位避开标题栏、分区含块且标题留白、块太多 blocked、无标题栏用满页、非法输入 blocked。

### 实测（EasyEDA Pro 4.1.78，easyeda.com）

- 音频板三块实测包络：ES8311 560×340、MEMS 460×220、AW8737 560×340。
- 规划后落点：三块全部在页内、互不重叠、无越界（`fits=3, overlaps=0`）。
- 分区框正确显示、标题在块上方；标题栏区域未被侵占。

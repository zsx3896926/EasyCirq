## 七、诚实记录：五次误诊

这一轮最有价值的产出之一，是**证伪了我自己记的五条"产品缺陷"**：

| # | 我当时的结论 | 代码里的事实 |
|---|---|---|
| #22 | 缺块级能力 | 39 个已验证块 |
| #29 | `--replace` 顺序错 | 就是先删后连 |
| #30 | `group-move --ids` 静默断网 | 有完整电气自检并报错 |
| #32 | 缺布局手段 | `autolayout`，且明确要求布线前跑 |
| #33 | check/clusters 级别不一致 | 两者测的几何不同，零交集 |

**唯一站得住的那条（#35），恰恰是我去翻了数据本身。**

**纪律（已写进账本）**：在把任何现象记成"产品缺陷"之前，先找到**处理这件事的那个函数**读一遍；
只有"代码里确实没有这段逻辑"才算缺陷。

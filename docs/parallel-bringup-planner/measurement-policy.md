# 测量方法纪律（measurement-policy）

适用对象：首板上电/功能测试计划生成器产出的任何"测量动作"与"通过/失败判据"。
约束来源：本文件与 `docs/parallel-bringup-planner/source-register.md`（SRC-001…SRC-011）、`benchmarks/bringup-planner/sources/device-facts.json`（F-001…F-154）配套使用。

标注约定：
- `[SRC-xxx pN / F-xxx]` = 有官方依据（原厂文档，附印刷页码与 fact 编号）。
- `[工程纪律]` = 行业通行做法，**不是原厂要求**，不得在计划里写成"原厂规定"。
- `BLOCKED` = 缺少官方依据或缺少仪器能力，此时必须输出"无法判定/需人工确认"，不得给通过结论。

---

## 1. 断电电阻档 / 二极管档

**1.1 前置条件（强制，有官方依据）**
1. 必须断电、放电、断开外部供电路径：Fluke 87 手册原文与页码——"Turn off power on the test circuit and discharge all capacitors before attempting in-circuit resistance measurements…" `[SRC-007 p20 / F-075]`。电容测量同样要求断电并放电 `[SRC-007 p22 / F-138]`。
2. 必须确认被测网络没有第二条供电路径（USB、调试器、电池、反灌二极管、上拉电源域、外部模块）。断不干净时读数只反映"多路径并联结果"。
3. 放电后仍需等读数稳定：仪表用**已知电流给电容充电**，电容电压可达 **1.2 V** `[SRC-007 p22 / F-138]`，所以容性节点读数会持续漂移；**必须等稳定，或把漂移过程作为数据记录**（起始值、稳定时间、终值）。

**1.2 读数解释（官方依据 + 边界）**
4. 在路电阻读数 = **所有可能路径的总电阻**：手册原文"This explains why in-circuit measurement of resistors does not often yield the ohms value indicated by the resistor's color code" `[SRC-007 p20 / F-136]`。因此**低阻不必然是短路**；高阻也不必然等于开路（可能有反向并联结）。
5. 量程本身会改变被测电路：40 MΩ 以下量程不会正向偏置硅结，但 **40 MΩ 量程会**让二极管/三极管结导通 `[SRC-007 p21 / F-137]`。判据必须写明量程。
6. 二极管档读数是"整条串联路径结电压之和"：仪表单一 0…+3.000 V 量程、最多覆盖**五只硅结** `[SRC-007 p23 / F-073, F-074]`；1.2 V 不一定是一个"坏结"。
7. 通断蜂鸣不是精确电阻判据：蜂鸣阈值是**型号/量程相关**的典型值（例如 400 Ω 档 <40 Ω 才响），且接近阈值时 EMI 会造成乱响 `[SRC-007 p20 / F-140]`。
8. **没有给定判据时，不得输出通用欧姆阈值**。`[SRC-007 全篇未给"短路"欧姆阈值]` 判据只能来自：该网络设计阻抗（原理图/数据手册推算）、同板良品对照值、或目标器件官方限值（如 `[F-001 VDS 30 V][F-002 VGS ±20 V]` 只用于应力边界，不用于电阻阈值）。
9. 若必须给数值，写成"对照判据"：`参考板 = X Ω @ 条件`，并注明是**相对比较**而非绝对短路判据 `[工程纪律]`。

**1.3 不能证明什么**
- 不能证明"器件未损坏"（内部开路/弱连接在断电电阻档可能完全正常）。
- 不能证明"没有潜在短路"（并联路径会掩盖）。
- 不能覆盖全温、长期漂移与 EMC/ESD 后的退化；单点、单温、单样品结论不得外推 `[SRC-008 / F-076–F-078 的测量条件纪律]`。

## 2. 带电电压 / 纹波 / 噪声

**2.1 DC 电压合格 ≠ 纹波/瞬态合格（强制分离）**
10. 万用表 DC 电压读数正常，**不能**作为纹波、噪声、瞬态跌落、上电过冲合格的证据。`[SRC-008 / F-076, F-077：噪声按 10 Hz–100 kHz 频带规定；DC 表不覆盖该频带]`
11. 任何纹波/噪声数值必须同时声明：**测量带宽**、耦合方式、探头倍率、量程、测点与参考地。缺任一项，该数值不得进入判据。`[SRC-008 / F-076–F-078；SRC-010 p53 / F-144]`
12. p-p 与 RMS 不可互换：高斯假设下 RMS ≈ 1/6 p-p `[SRC-008 / F-078, F-079, F-080]`。把示波器 p-p 直接当 RMS 报出 = 证据无效。

**2.2 示波器设置必须声明的项（缺一即判据无效）**
- **有效带宽** = min(示波器模拟带宽, 探头带宽, 是否开 20 MHz 限制)。DS1054Z 为 **DC–50 MHz**、计算上升时间 **7 ns** `[SRC-011 p6/p7 / F-150, F-151]`；20 MHz 带宽限制会衰减 20 MHz 以上分量 `[SRC-011 p7 / F-154；SRC-010 p53 / F-144]`。
- **探头补偿**：未补偿/补偿不良的探头会造成测量不准确或错误，测量前必须做补偿检查 `[SRC-010 p32 / F-143；p31 / F-147]`。
- **探头比率**：通道比率默认 10X，可选 0.01X–1000X，必须与物理探头一致，否则幅值错误 `[SRC-010 p53 / F-145；p253 / F-146]`。
- **探头负载**：示波器模拟输入为 **1 MΩ±1% ∥ 15 pF±3 pF** `[SRC-011 p6 / F-148]`；ESP32-C3 引脚电容仅 **2 pF typ** `[SRC-009 p55 / F-122]`，即探头电容远大于引脚本身——高阻/弱驱动节点（晶振、复位 RC、strapping、高阻分压）接入探头即被改变。
- **采样率**：DS1054Z 为 1 GSa/s 单通道、500 MSa/s 双通道、**250 MSa/s 三/四通道** `[SRC-011 p6 / F-153]`；四通道同时用会悄悄降采样。
- **精度**：DS1054Z DC 增益精度 ≥10 mV/div 时 **±3% 满量程**（<10 mV 时 ±4%）`[SRC-011 p7 / F-152]`；据此**不能**判 1% 级的 3.3 V 电压合格。
- **耦合**：DC / AC / GND（DS1000Z 支持）`[SRC-011 p6]`；AC 耦合隐藏 DC 偏置与慢漂移。

**2.3 接地与差分（硬性 BLOCKED 条件，有官方依据）**
13. 官方安全条款：**探头地线必须接大地（earth ground），不得接地线到高压**；仪器经电源线保护地接地，地夹**不是浮地** `[SRC-010 p4（安全页 II）/ F-142；p31 / F-147]`。因此地夹**只能接电路地（保护地/参考地）**，不能夹在浮地节点、非地参考节点、半桥中点或 BTL 输出任一端。
14. 非地参考测量（高边采样、半桥开关节点、BTL/H 桥输出、隔离侧、市电热地）**必须用差分测法**（差分探头/隔离通道）。`[SRC-010 手册未提供浮地/差分测量程序，仅规定地线必须接大地]` 若计划缺少差分能力，必须输出 **BLOCKED：缺少差分测量能力**，不得用单端探头"大概看一下" `[工程纪律]`。
15. 探头接地回路本身会引入振铃/误差：地夹引线越长，回路电感越大，快速边沿测量误差越大 `[工程纪律；SRC-010 未给地线长度指标]`。

## 3. 时钟 / 复位 / 启动脚（波形判据的边界）

16. 探头负载会改变或掩盖波形：晶振脚、CHIP_EN 复位脚、strapping 脚属高阻/弱驱动节点 `[SRC-011 p6 / F-148 的 15 pF 输入电容；SRC-009 p55 / F-122 的 2 pF 引脚电容]`；ESP32-C3 还明确要求晶振幅度 >500 mV 且需在整体测试中调整负载电容 `[SRC-004 / F-054, F-052, F-053]`。
17. **缺少带宽/探头参数时，不得宣称"波形测量可完成"**：若计划未给出示波器带宽、探头倍率/负载、采样率，该项只能输出 BLOCKED 或"仅做存在性观察（不判定）"`[工程纪律]`。以 DS1054Z 为例：50 MHz 带宽 / 7 ns 上升时间 `[F-150, F-151]`，不能分辨 TPS62130 2.5 MHz 开关节点的边沿谐波 `[F-026]`。
18. 时序判据只用官方时序值：ESP32-C3 **tSTBL ≥50 µs、tRST ≥50 µs** `[SRC-009 p28 / F-124, F-125；SRC-004 / F-045, F-046]`、**strapping tH ≥3 ms** `[SRC-009 p30 / F-127；SRC-004 / F-051]`、复位门限 **VIL_nRST ≤0.25×VDD / VIH_nRST ≥0.75×VDD** `[SRC-009 p55 / F-130；SRC-004 / F-049]`。
19. 上电毛刺必须按官方表核对：GPIO18 上电高电平毛刺典型 **50 µs** `[SRC-004 / F-059]`、MTCK/MTDO/GPIO10/U0RXD 典型 5 ns 低毛刺 `[SRC-004 原表]`。下游使能若对这些毛刺敏感，判据应写成"毛刺不得触发下游动作"。
20. strapping 判据必须**同时检查 GPIO2/GPIO8/GPIO9**：下载模式 GPIO9=0 且 GPIO8=1（GPIO2=1）`[SRC-009 p31 / F-129；SRC-005 / F-062, F-063]`；GPIO8=0 且 GPIO9=0 非法 `[SRC-005 / F-068]`；GPIO9 内部上拉默认 1 且内部约 **45 kΩ** `[SRC-009 p30/p55 / F-128, F-123]`，弱下拉会被内部上拉压过 `[SRC-005 / F-064, F-065]`。

## 4. 电流 / 限流

21. 限流值必须由三样东西推导，缺一不可：**已知启动电流/浪涌**、**运行电流与负载**、**保护策略**。可用的官方量级依据：TPS62130 IQ 17 µA typ / 30 µA max、ISD 1.5 µA typ / 25 µA max、静态限流 4.2 A typ（3.6–4.9 A）、启动期 VOUT<0.5 V 限流约 1.6 A `[SRC-002 p5/p9 / F-024, F-089, F-025, F-090, F-097, F-094]`；ESP32-C3 建议供电能力 **≥0.5 A** `[SRC-009 p54 / F-116；SRC-004 / F-044]`；比较器 0.225 mA/ch `[F-037]`。**限流的具体数值属工程推导**，不得写成原厂要求。
22. 限流过小会造成**反复重启/打嗝**：需确认限流 > 启动峰值，且电源不会在启动/负载跳变瞬间掉出 MCU 工作下限（ESP32-C3 推荐下限 **3.0 V**，绝对最大 3.6 V）`[SRC-009 p54 / F-113, F-110；工程推导]`。TPS62130 的 UVLO 约 2.7 V（迟滞 200 mV），若用 3.0 V 轨给 buck 供电，余量很小，可能进入打嗝 `[SRC-002 p5 / F-091, F-092]`。
23. **低限流不等于安全**：限流只限制能量，不能替代短路保护、反接保护、热设计；限流下的长时间热积累仍可损坏器件 `[工程纪律]`。
24. 电流测量本身必须记录：量程、分流电阻/探头类型、带宽（若有）、测点；并修正**burden voltage**——A 档 ×0.03 V、mA 档 ×1.8 mV、µA 档 ×100 µV `[SRC-007 p20 / F-141]`。低压轨上 1 A 读数即可掉约 30 mV，可能把 3.3 V 拉到 MCU 下限附近。

## 5. ADC / 传感链路

25. **读到数值不等于量程/精度已验证**：ESP32-C3 ADC1 在 ATTEN=0 时有效范围 0–750 mV、误差 ±10 mV；ATTEN=3 时 0–2500 mV、误差 ±35 mV `[SRC-004 / F-055–F-058]`。判据必须写明量程档位与允许误差，否则"读数在范围内"没有意义。
26. ADC 判据必须使用**标定后**条件，并注明是否做过硬件+软件校准 `[SRC-004 / F-055–F-058]`；未标定的裸读数只能作趋势观察。
27. 数字接口电平要按官方表判：ESP32-C3 **VIH ≥0.75×VDD、VIL ≤0.25×VDD**（3.3 V 时约 2.475 V / 0.825 V）`[SRC-009 p55 / F-117, F-118]`，因此 1.8 V 器件无法直接驱动其输入；输出 **VOH ≥0.8×VDD、VOL ≤0.1×VDD**（高阻负载）`[F-119]`，IOH/IOL 只是典型 40/28 mA `[F-120, F-121]`，且累计 IO 输出电流绝对最大 1000 mA `[F-111]`。
28. NTC/分压传感链路要把**输入偏置电流**计入误差：LM393 输入偏置最大 50 nA、VOS 最大 5 mV@25 °C `[SRC-003 / F-036, F-039]`，在数十 kΩ 以上分压上会产生可测偏差；比较器判据不得把 ±5 mV 内的偏差当故障。比较器为开集输出，**必须外接上拉**（产品页特性原文）。
29. **单点测量不覆盖全温/长期漂移**：任何"温度读数正确"结论只在该温度、该时刻、该样品成立；全温区、长期漂移、自热效应必须单列为未覆盖项 `[工程纪律]`。

## 6. 证据记录（缺证据 = 未测量）

30. 每条测量记录至少包含：**仪器型号 + 序列号（若可得）**、**设置/量程/耦合/带宽/探头倍率**、**测点与参考地**（net 名/位号/引脚）、**时间戳**、**原始读数或原始文件**（截图/CSV/波形文件路径）。`[工程纪律；SRC-008 要求噪声数值必须带频带；SRC-007 要求说明断电/放电前提；SRC-010 要求记录探头比率并先做补偿]`
31. **人工声明不等于真实测量**：没有原始文件/截图的"已测量，正常"不得作为通过证据；生成器不得接受纯文字断言作为 PASS 依据。`[工程纪律]`
32. 判据必须写清"用哪台仪器、哪个档位、什么带宽、什么条件"，并且**典型值不得写成门限**：`typical:true` 的 fact 只能用于量级判断（如 TPS62130 IQ 17 µA、CSD RDS(on) 8.2 mΩ、DS1054Z 单通道 1 GSa/s）、门限只取 min/max 列或实测基线 `[SRC-002 / F-024；SRC-001 / F-009–F-012；SRC-011 / F-153]`。
33. 绝对最大额定值只能用于"是否越界"的安全判断，不能当工作目标 `[SRC-002 p4 / F-082；SRC-009 p54 / F-110；SRC-001 / F-001, F-002]`；LM393/TLV700 的绝对最大额定值表**未核实**，涉及这些器件的"会不会打坏"判据必须标 BLOCKED（见 source-register §4）。

## 8. 判据输出模板（生成器应遵守）

```text
measurement_id: M-xxx
目标: <测什么>            引用: SRC-xxx pN / F-xxx
前置条件: <断电/放电/断开外部供电/限流/环境>
仪器: 型号 | 档位/量程 | 带宽 | 耦合 | 探头倍率 | 采样率
测点: <net/位号/引脚>    参考地: <net/GND 位置>
判据: <min/max 或对照值>  数据性质: guaranteed | typical | engineering-derived
证据: <原始文件路径/截图>  时间: <ISO8601>
结论: PASS | FAIL | BLOCKED(<原因>)
未覆盖: 全温 | 长期漂移 | EMC/ESD | <其他>
```

**BLOCKED 触发条件（任一即触发）**：缺官方依据；缺差分/隔离测量能力（非地参考测量）；缺仪器带宽/探头参数却要判定波形；无限流/启动电流依据却要判定"能安全上电"；只有人工声明而无原始数据；仪器精度不足以支撑判据（如用 ±3% FS 判 1%）。

## 9. 本文件的依据边界

- 有官方依据的条目：1.1(1)、1.2(4,5,6,7)、2.1(10–12)、2.2（带宽/补偿/比率/负载/采样率/精度/耦合）、2.3(13)、3(16 的晶振与探头负载、18–20)、4(21 的量级部分、22 的 UVLO 部分、24)、5(25–28)、6(29–30 的引用部分)、7（仪器门槛）。
- 属工程纪律、不得冒充原厂要求的条目：通用欧姆阈值禁令、地线长度、差分/BLOCKED 判定、限流下限推导、证据字段、全温/EMC 未覆盖声明。
- **明确缺口**：Rigol 手册未提供浮地/差分测量程序（因此差分测量按 BLOCKED）；Fluke 87V 专用手册未取得（现有为 87/83/85 手册）；LM393/TLV700 的页码级规格表未核实。

# 智构 v1.0.0 发布说明

状态：正式发布候选，尚未打标签或发布 GitHub Release。

智构是硬件设计协作 Skill，配合能够执行本机命令的 AI 客户端、嘉立创 EDA
专业版及独立安装的 easyeda-agent/Connector 工作。它提供工作方法、工程工具与
验收纪律，不承诺任意复杂工程一键完成。

## 获取与安装

正式发布后，从本仓库 Releases 下载 design-hardware-installer-1.0.0.zip。
完整解压后，Windows 双击 Manage-Skill.cmd，选择一个客户端安装。
需要 Python 3.10+；不需要 Git。macOS/Linux 可使用包内 skill_update.py。
保留发布包与 SHA256SUMS，核对文件来源。目录中 release.json 的 archive_sha256
校验 Skill ZIP；SHA256SUMS 校验所有发布资产。哈希用于完整性，不是数字签名。

命令行示例（在解压后的目录）：

```bash
python skill_update.py install --client claude --package design-hardware-1.0.0.zip --manifest release.json
python skill_update.py status --client claude
python skill_update.py rollback --client claude
```

Codex 使用 --client codex，WorkBuddy 使用 --client workbuddy。
已有手动安装需显式 --adopt，先备份再迁移；本地有修改时不静默覆盖。
安装后重新装载 Skill，并确认客户端能够读取完整目录。文件健康不代表 EDA 已连通。

## 支持范围

- 原理图/PCB 的需求、设计、检查、局部修改和交付流程。
- 模块分区、图纸预算、文字几何、器件身份与连接核对。
- 电源路径、走廊离线候选、PCB 证据门禁及模块放置合批。
- 安装、版本检查、更新、备份、回滚与中断恢复。

## 实验能力与已知限制

- feedback_loop：最终收紧代码的真机写入尚未验证；已有旧代码真机证据仅证明
  当时的执行与失败识别。unknown/BLOCKED 不等于 PASS。
- compose：复杂副本案例在 strict gate 停止，之后局部修正并独立保存重开；
  不代表完整 playbook 或 strict 通过。无基线警告的小工程完整闭环仍待补测。
- WorkBuddy 全流程、最终发布包驱动的 EDA 写入未验证；跨平台 CI 检查包级逻辑，
  不代表 macOS/Linux/各客户端的 EDA 图形宿主验收。
- 离线电源/几何工具有覆盖限制；不会证明阻抗、SI、热、EMC 或制造可行性。
- 未用打样、上电或实物测试验证本版本；制造导出按当前执行器能力逐项报告。
- 外部执行器独立版本管理；已记录的 EDA 4.1.78 / easyeda-agent 1.15.0 是
  历史已测组合，不是对所有后续版本的兼容承诺。

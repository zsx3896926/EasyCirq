# 智构 v1.0.1

首个完整交付的 v1.0 稳定版补丁，采用 Apache License 2.0。

## 修复

v1.0.0 标签已发布，但打包前的全量 Python 3.10 测试发现旧代码使用了
Python 3.12 才支持的 f-string 语法，导致发布资产没有生成。该版本修复了
兼容性，并将完整测试扩展到 Python 3.10 和 3.13；保持文本对象 ID 生成行为不变。
原 v1.0.0 标签保留，不移动、不覆盖。

## 下载与安装

下载 design-hardware-installer-1.0.1.zip，完整解压后运行 Manage-Skill.cmd，
选择一个客户端。Python 3.10+；不需要 Git。已有本地修改不会被静默覆盖。
使用 SHA256SUMS 校验下载，release.json 绑定内部 Skill ZIP 及文件清单。
安装后重新装载 Skill，再核对 EDA 连接。客户端实际装载与真实 EDA 写入并非包级测试。

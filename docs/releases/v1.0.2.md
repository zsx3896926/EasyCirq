# 智构 · EasyCirq v1.0.2

EasyCirq 品牌的第一个稳定版：仓库、Skill、离线审计模块与安装器产物从
`design-hardware` / `zhigou_mcp` 更名为 `easycirq` / `easycirq_mcp`（PR #77、#101）。
相对 v1.0.1 的变更跨了多轮并行任务的合并，本说明只陈述可复核的高层变化与边界。

## 主要变更

- **更名与统一工具链**：工程/Skill 更名 EasyCirq；集成 EDA 工具链合入 main
  （runtime、connector `.eext`、daemon），发布产物包含统一工具链 bundle 与
  EasyCirq Skill 安装器（`easycirq-toolchain-<v>.zip` / `easycirq-<v>.zip`、
  `Manage-Skill`、`SHA256SUMS` 等）。
- **B1 任务启动器**（PR #74 及 follow-up）：本机 sidecar，用固定 argv 受控启动
  Claude Code headless，构建 Skill 插件、注入 routing.md、挂离线审计 MCP，并提供
  版本握手、事件轮询、超时/取消/并发与只读任务契约。
- **B1-Bound 只读绑定层**（PR #121）：能力面收窄（仅 Read/Glob/Grep/Skill +
  `mcp__zhigou_bound__*`）、任务状态机、HMAC-SHA256 签名回执链、supervisor 生成
  最终报告；launcher 通过 `--bound` 挂载 supervisor，并要求真实 Agent 任务产出
  `FINALIZED` 报告，防止“跳步/伪造证据/直连审计工具绕过流程”。
- **多轮并行能力与闭环任务合并**：标注/布局、机械布局、电气审查、回流路径审计、
  变更影响、电路模块、采购规划、交付审计、bringup 规划、布局意图、四层板闭环、
  DRC 摘要等，随各自 PR 合入；详见仓库 `git log v1.0.1..main` 与各 `docs/parallel-*`。

## 下载与安装

下载 `easycirq` 安装器产物（`easycirq-toolchain-<version>.zip` 或
`easycirq-<version>.zip`），完整解压后运行 `Manage-Skill.cmd` 选择客户端。Python
3.10+；用 `SHA256SUMS` 校验，`release.json` 绑定内部 Skill ZIP 与文件清单。

## 能力与边界（不夸大）

- 离线审计/DRC 结果代表“已声明的输入与规则范围内未发现问题”，不代表制造、信号
  完整性、温升、EMC 或实物功能通过。
- 真实 EDA 写入、真实 Anthropic Claude 模型、硬件实测均保持 **NOT RUN**（本仓库
  交付的是流程/证据链与离线能力，不伪造运行结果）。
- 许可证 Apache-2.0；随包 MIT schema 保留原许可与归因。

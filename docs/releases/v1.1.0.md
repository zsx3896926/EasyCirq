# 智构 · EasyCirq v1.1.0

这是**破坏性重命名**版本：全项目统一为中文名「智构」、英文名「EasyCirq」，
废弃旧英文名 `zhigou`、`design-hardware`、`hardware-design-skill`。

## 破坏性变更

- 仓库：`hardware-design-skill` → **`EasyCirq`**（旧 URL 自动跳转）
- Skill：`design-hardware` → **`easycirq`**（客户端命令 `/easycirq`）
- 运行时 CLI / 二进制：`zhigou` → **`easycirq`**，`zhigou.exe` → **`easycirq.exe`**
- 环境变量：`ZHIGOU_*` → **`EASYCIRQ_*`**
- 状态目录：`~/.zhigou` → **`~/.easycirq`**
- 协议服务：`zhigou-agent` → **`easycirq-agent`**
- MCP 服务：`zhigou-offline-audit` → **`easycirq-offline-audit`**
- 连接器：`zhigou-connector` → **`easycirq-connector`**（UUID 不变）
- 工具链包：`zhigou-toolchain-*` → **`easycirq-toolchain-*`**

**升级说明见 [docs/migration-easycirq.md](../migration-easycirq.md)。**
不保留 `zhigou` 命令别名，也不保留旧协议服务名。

## 下载与安装

推荐新用户（一句话安装）：

```text
请从 https://github.com/zsx3896926/EasyCirq 的 Releases 下载并安装 EasyCirq（智构）。
```

完整工具链资产：

- `easycirq-toolchain-installer-1.1.0.zip`（解压后运行 `Install-EasyCirq.cmd` / `.ps1`）
- `easycirq-toolchain-1.1.0.zip` + `toolchain-release.json`
- `easycirq-1.1.0.zip` + `release.json`（仅更新 Skill）
- `easycirq_<os>_<arch>[.exe]`（CLI，供 `easycirq update` 自更新）
- `skills.tar.gz`、`checksums.txt`（`easycirq update` 校验用）
- `Manage-Skill.*`、`skill_update.py`、`companion_update.py`、`INSTALL.md`、`SHA256SUMS`

## 更新

- 已安装用户运行：`easycirq update`（CLI + Skill），或 `Manage-Skill` 仅更新 Skill。
- 连接器：扩展广场版随商店更新；手动导入的 `.eext` 需在 EDA 里卸载旧版、导入新版、重新授权并完全重启。

## 能力与边界

本版本延续 v1.0.x 的原理图/PCB 读写、DRC、BOM、Gerber/钻孔/CPL（GUI 导出）、
3D 导出、离线审查、首板上电计划、变更影响、标注排版、电路块库、MCP 离线审计。

- 真实 EDA 全流程需本机连接嘉立创 EDA 专业版（v4.1.60+，验证版 4.1.78）并导入连接器。
- 离线工具 `real_eda = NOT RUN`；`pass_with_scope` 只代表声明范围内未发现问题，不是整板/硬件通过。
- 制造、信号完整性、温升、EMC、实物功能需实测；不承诺全自动交付。
- 扩展广场上架状态以嘉立创商店为准；未上架时用仓库内 `.eext` 手动导入（无商店自动更新）。

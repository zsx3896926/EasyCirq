# 开工确认：超温报警板

> 这是客户说「做一个能测温度、超温就响的板子」之后，**第一眼该看到的东西**。
> 目标是「一句确认：能不能做、大概多少钱、多久」。本文件就是那句确认。
> 器件编号与价格为**估算**，下单前必须以立创商城实时库存与价格为准。

## 一句话回答

**能做。** 单板成本约 **¥8–15**（不含 PCB 与贴片），打样 5 片约 **¥50–80** 全包，
**3–5 天**出板（含 24h 加急 PCB + 48h 贴片）。

## 三个方案

| 方案 | 器件 | 成本 | 难度 | 适合 |
|---|---|---|---|---|
| A 纯模拟（比较器） | NTC + 比较器 + 蜂鸣器 | ¥6–10 | 低 | 功能单一、要便宜 |
| B 小 MCU | NTC + MCU + 蜂鸣器 + LED | ¥10–18 | 中 | 要可调阈值、要显示、要扩展 |
| C 现成模块拼装 | 模块 + 底板 | ¥15–25 | 最低 | 只要验证想法 |

**推荐 B**：同一块板既能做「超温就响」，以后加显示/联网不用重开板；成本只比 A 高几块。

## 方案 B 的构成（推荐）

| 功能块 | 器件 | 备注 |
|---|---|---|
| 感温 | NTC 10K B=3950（0603/0805） | 分压后进 ADC |
| 主控 | 8 位/32 位小 MCU（SOP-8/SOP-16） | 阈值可调、蜂鸣节奏可控 |
| 报警 | 有源蜂鸣器 5V（或 3V 经三极管） | 有源 = 给电就响，省事 |
| 指示 | 0805 LED + 1K 限流 | 电源与报警各一 |
| 电源 | 5V USB 输入 + LDO 3.3V（如需） | 或直接 3.3V 供电 |
| 保护 | 100nF×3 去耦、10uF 储能 | |

> LCSC 编号在选型时逐个核实（`easycirq lib search` 可直接查 C 号）。
> 本文件**不写死编号**，避免过期误导。

## 三个必须先问清的问题

1. **供电**：USB 5V / 电池 / 12V？——决定电源拓扑，是最影响成本的一项。
2. **阈值**：固定（如 60°C）还是可调（旋钮/按键）？——固定可去掉 MCU 走方案 A。
3. **声音要求**：要「嘀嘀」可区分报警还是「一直响」？——决定要不要 MCU 做节奏。

这三个问题不回答，方案只能停在「大概」。

## 成本估算（单板，5 片小批）

| 项 | 估算 |
|---|---|
| 元器件 | ¥8–15 |
| PCB（5 片，10×10cm 内，双层） | ¥5–20（嘉立创打样价） |
| SMT 贴片（5 片，单面，~10 点） | ¥30–50（含工程费） |
| 快递 | ¥10–15 |
| **合计** | **约 ¥50–80** |

数量上到 100 片时，单板元器件成本约降 30%，SMT 工程费摊薄。

## 工期

| 阶段 | 时间 |
|---|---|
| 原理图（含检查） | 0.5 天 |
| PCB 布局布线（含 DRC） | 0.5 天 |
| 打样 + 贴片 | 3–5 天（加急 24h PCB + 48h SMT） |
| 验收（焊接/上电/功能） | 收货当天 |

## 风险（先说清）

| 风险 | 影响 | 应对 |
|---|---|---|
| NTC 批次差异 | 阈值偏移几度 | 用 1% 精度件；固件留校准 |
| 蜂鸣器驱动电流 | 直接驱动烧 MCU 口 | 加三极管或选低电流有源蜂鸣器 |
| 阈值点抖动 | 温度在阈值附近反复报警 | 固件加 2°C 回差 |
| 单片打样价高 | 小批成本不划算 | 一次拼板多款 |

## 这份确认的边界

- 器件与价格为**估算**，下单前以立创商城实时数据为准。
- 「能做」指的是**技术上可行**，不等于「已通过离线检查」——那是出图之后的事。
- 没有承诺「量产可用」；5 片打样与 1000 片生产是两件事。

Import an EasyEDA Pro project archive (.epro2, .epro, or a .zip packaging) as a new
project through the official @beta importer. The command never writes into an
existing project and does not open the result. The archive is checked for ZIP
integrity first; .epro2 must contain .epru data. Import success proves only
that a project was created: open it and read back schematic, PCB and DRC.
A timeout leaves the outcome unknown; run 'zhigou project find' before retrying.

Usage:
  zhigou project import [flags]

Examples:
  zhigou project import --window <id> --file design.epro2 --name blink-import

Flags:
      --extract-libraries   also extract embedded libraries into the team library
      --file string         project archive to import (required)
  -h, --help                help for import
      --name string         friendly name of the new project (required)
      --team-uuid string    owner team UUID (default: active project's team)

Global Flags:
      --doc string                pin every mutating action to this schematic page / PCB (uuid or name): the CLI switches to it and confirms via live document.current before editing, refusing rather than land the edit on whatever page is foreground — removes the doc-switch race
      --force-stale-read string   deprecated compatibility option; stale PCB reads now continue with staleRisk and authoritative workflows still save, reload, then read back
      --host string               daemon host (default "127.0.0.1")
      --ports string              daemon port range (start-end) (default "23111-23120")
      --project string            route by project name/uuid instead of --window (survives windowId churn)
      --skip-version-check        deprecated compatibility option; version differences are diagnostic and no longer block actions
      --window string             EasyEDA window ID

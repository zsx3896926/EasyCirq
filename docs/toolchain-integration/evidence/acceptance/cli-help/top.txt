easycirq — AI-native EasyEDA Pro automation layer

Usage:
  easycirq [command]

Available Commands:
  actions      Print the typed action catalog as JSON
  api          Discover the official eda.* API surface (search / list, offline)
  apply        Replay a declarative step file (playbook) against EasyEDA
  audit        Inspect the action audit log
  blocks       Query the embedded circuit-block library (电路块库) — offline, no daemon
  board        Manage Boards (板子/组合) — the schematic↔PCB binding
  bom          BOM export and enrichment
  call         Generic escape hatch: call any typed action directly
  capabilities Negotiate capabilities item by item (supported/unsupported/unknown + reason)
  completion   Generate the autocompletion script for the specified shell
  connector    Locate, inspect and verify the EasyCirq connector .eext
  daemon       Manage the easycirq-agent background daemon
  debug        Debug escape hatches (confirmation-gated)
  doc          Discover and open/switch EasyEDA documents (schematic pages / PCBs)
  doctor       Diagnose the integrated toolchain (skill, runtime, daemon, connector, protocol)
  editor       Editor UI around the canvas (side panels); never changes the project
  health       Check daemon health across the port range (alias of `daemon health`)
  help         Help about any command
  lib          EasyEDA device library operations
  notify       Show a toast inside the EasyEDA window (design-flow step notification)
  pcb          PCB operations
  project      Read EasyEDA project and document context
  sch          Schematic operations
  skill        Inspect and update the locally-installed easycirq-agent skill dirs
  spec         Validate and inspect the S0 design proposal (S0 spec)
  version      Print version information
  view         Editor canvas view shortcuts (zoom / fit) for schematic & PCB
  web          Control the connected EasyEDA Web editor page
  workflow     Deprecated project checklist: init / status / advance / confirm / reset / pages

Flags:
      --doc string                pin every mutating action to this schematic page / PCB (uuid or name): the CLI switches to it and confirms via live document.current before editing, refusing rather than land the edit on whatever page is foreground — removes the doc-switch race
      --force-stale-read string   deprecated compatibility option; stale PCB reads now continue with staleRisk and authoritative workflows still save, reload, then read back
  -h, --help                      help for easycirq
      --host string               daemon host (default "127.0.0.1")
      --ports string              daemon port range (start-end) (default "23111-23120")
      --project string            route by project name/uuid instead of --window (survives windowId churn)
      --skip-version-check        deprecated compatibility option; version differences are diagnostic and no longer block actions
  -v, --version                   print version and exit

Use "easycirq [command] --help" for more information about a command.

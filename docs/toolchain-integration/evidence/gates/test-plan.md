## 3. 上电步骤
1. 断电测 `+5V`–`GND` 阻抗，异常先查短路，**不上电**。
2. 限流电源 5.0 V / 100 mA，首次不要用 USB 直供。
3. 上电只看电流与温度；异常立即断电并保留现场。
4. 逐项测 V3–V10，每次只改一个变量。
5. 证据写文件名+sha256；口头"正常"不算证据。

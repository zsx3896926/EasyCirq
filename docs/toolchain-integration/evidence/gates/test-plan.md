## 3. 上电步骤
1. 断电测 `+5V`–`GND` 阻抗，异常先查短路，**不上电**。
2. 限流电源 5.0 V / 100 mA，首次不要用 USB 直供。
3. 上电只看电流与温度；异常立即断电并保留现场。
4. 逐项测 V3–V10，每次只改一个变量。
5. 证据写文件名+sha256；口头"正常"不算证据。

## 7. 到货后执行步骤（照做即可）

1. **先别上电**：目视 V2（极性/漏件/连锡）→ 拍照；
2. 万用表 V3：`+5V`–`GND`、`VIN`–`GND` 阻抗，记录读数；若 <1 kΩ 先查短路；
3. 限流电源 **5.0 V / 限流 100 mA**，空载上电 → V4 记录静态电流与温度；
4. 按 SW1 → V5 记录 `V_R1` 与电流；按 SW2 → V6 同样；
5. 交替/同时按 → V7；
6. 边界：反接（V8）、短路 LED（V9）、缓降 5→3 V（V10）——每步只改一个变量，异常立即断电；
7. 照片/读数落证据目录，回填本计划"实测"列与状态（PASS/FAIL/NOT RUN）；
8. 复核人不能与测试人相同。

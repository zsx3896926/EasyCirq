# 模块复用合同（Agent 填写，用户不填）

> 用途：把一个已做过的电路块/模块复用到新项目时，逐条写清边界、不可变项、必须重算项、兼容证据与退役条件。用户只确认目标与偏好，不填本表。
> 证据规则：没有目标板回读或实测时，`status` 不得写 `reusable`；`待查` 不当作通过。

## 5. 决定与条件
- 决定（四选一）：`reusable` / `accepted-with-conditions` / `rejected` / `not-a-module`
- 条件（必须可测试，写对象、条件、判据）：待查
- 拒绝条款（逐条写证据与是否可降级）：待查
- 复评触发：目标负载、环境、产量、来源版本、许可、PCN/EOL 变化

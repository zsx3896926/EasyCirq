# 丝印与装配标识（模板）

用于布局冻结前的丝印评审、打样前的装配图交付。由 Agent 起草并在每次改板后复核；用户只看“装的时候会不会装反/装错/找不到标记”，不逐项确认。未知写 `待确认`，没有实际看图或回读证据的“已检查”不算通过。

丝印是给装配、测试和维修看的，不是装饰：极性、1 脚、方向、板名/版本和 DNP 必须在不拆件的情况下可读。底层丝印按底面视角正确可读（EDA 中镜像），装配图分别出 Top/Bottom 视图。最小线宽/字高、到焊盘和板边距离以当次板厂与 [生产档案](../manufacturing-profile.md) 为准，未知写 `待确认`。极性与方向规则另见 [制造细节](../../references/manufacturing-details.md) 与 [嘉立创 SMT 规则](../../references/jlc-smt-rules.md)。

## 2. 位号与文字放置规则

- 位号优先放在器件长边或丝印框外，方向统一（0°/90°），避免倒置。
- 不压焊盘、阻焊开窗、过孔、光学定位点和板边；不覆盖连接器插拔区、声孔、导光柱。
- 密度高时用引线或分组标注，不能缩小到工艺最小字高以下；宁可移到空白区，不压在焊盘上。
- 底层文字镜像，过孔/测试点不盖文字；双面贴装时两面分别检查。
- `pcb silk-align` 只重排位号并做碰撞规避，不生成极性、1 脚或功能标记；运行后必须复核这些标记是否被移动、遮挡或覆盖。
- 自动避让后检查文字是否落入外壳遮挡区、插头空间或声孔；这些区域以 [机械约束模板](mechanical.md) 为准。

## 3. 装配图检查清单

- [ ] 板名、版本、日期与当前制造包、图签一致。
- [ ] Top/Bottom 视图齐全，装配面标注正确，底层文字镜像正确。
- [ ] 每颗极性器件有方向标记：LED、二极管、电解/钽电容、蜂鸣器。
- [ ] 每个 IC/模块与连接器有 1 脚标记和插入方向。
- [ ] DNP 位号在丝印、装配图、BOM、CPL 四处一致，坐标文件排除 DNP 或明确标不贴。
- [ ] 位号不压焊盘/开窗/板边，无重叠；最小字高符合当次工艺。
- [ ] 每个测试点有 TP 编号 + 功能/电压，装配后可接触。
- [ ] LED/蜂鸣器/按键有功能标签，颜色与位置可区分。
- [ ] 连接器方向、插头空间与机械模板一致。
- [ ] BOM/CPL/装配图的位号集合一致，旋转与面别已抽查（重点：极性器件、连接器）。
- [ ] 丝印在装配后仍可见，不被外壳、电池或线束遮挡。
- [ ] 导出图/截图来自当前保存版本，附回读、哈希或 `silk-align` 回执。

## 5. 工具与证据边界

- `easyeda pcb silk-align`：只重排位号，带碰撞规避与写入后测量；不添加或校验极性/功能文字。
- `easyeda pcb silk-add`：添加自由丝印字符串，可用于板名、版本、警告语。
- `easyeda pcb silk-label-pads`：给焊盘标脚号/网名；`silk-netnames`：在指定区域自动生成网名标签；`silk-zone-outline`：绘制功能分区框。
- `easyeda pcb view-side` + `pcb snapshot`：分别取 Top/Bottom 视图；`snapshot` 需要前台 PCB 窗口，截图只是辅助证据。
- v1.14.0 没有丝印内容（极性、1 脚、可读性）的自动检查；`pcb check` 覆盖铜/孔/铺铜 DFM，不替代丝印检查。必须人工看导出视图并核对装配图。
- 证据落盘：`silk-align` 回执、导出图/截图、装配图文件、BOM/CPL 对应行；在 `design-state.json` 的 `routing.silk_align` 与 `manufacturing.artifacts` 记录路径。

## 6. 门禁与状态

- G5 前：位号、极性、1 脚可读，`silk-align` 回执保存；未确认项标 `待确认`，不得默认可接受。
- G6 前：装配图、DNP 表、BOM、CPL 一致；缺一项或相互矛盾按 `BLOCKED` 处理。制造包清单见 [制造包清单](manufacturing-package.md)，首件装配与功能验证按 [实物验证记录](verification.md) 执行。
- 每条 `已验证` 必须写明看图/回读的方法、对象与版本；只有计划或模板不算证据。

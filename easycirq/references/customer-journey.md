# 客户旅程：从一句话到一块能用的板

> 这份文档描述**客户看到什么**，不是工具怎么实现。每一幕都给出：客户可能说的话、
> agent 要跑的命令、客户会看到的输出、这一幕算不算通过。
> 所有命令都在本机 `easycirq` 里，客户不需要知道 daemon、connector、KPI、通行证。

## 第 1 幕：开工

**客户说**：「做一个能测温度、超温就响的板子」

**agent 做**：

```bash
easycirq setup            # 装好了没有？差哪一步？
```

**客户看到**：

```
EasyCirq 安装检查
  ✓ 运行时            easycirq 1.2.1
  ✓ 守护进程           运行中（端口 23111）
  ✓ EasyEDA 连接器    已连接（EasyEDA Pro 4.1.78）
  ✓ 技能             已安装
一切就绪。下一步：说清你要做什么板子，或者运行 easycirq status 看当前状态。
```

然后 agent 用日常语言回一句确认：**能不能做、大概多少钱、多久**。

**通过条件**：四行全 ✓，客户拿到一句人话的答复，没有看到任何工具概念。

## 第 2 幕：设计

**客户说**：「好，开始吧」

**agent 做**（客户看不到）：

1. 写需求与模块清单、电源树、引脚表（`spec.json`）
2. 冻结快照：`sch connectivity` / `sch list` / 导出 SVG 测文字 / `sch drc --json` / `bom export`
3. 跑离线门禁：`python scripts/sch_offline_pipeline.py --snapshot-dir <快照> --project <P> --page <P>`

**客户看到**：原理图 + BOM。关键部分高亮，术语点开有白话解释（低压网络、去耦电容、限流电阻）。

**通过条件**：客户能指着图说「这块是电源、这块是报警」，不需要读 KPI 报告。

## 第 3 幕：上机前

**客户说**：「这张图行不行？能打样吗？」

**agent 做**：

```bash
easycirq status --kpi-report <报告>   # 现在能不能写
easycirq card   --kpi-report <报告>   # 能不能打样
```

**客户看到**（两种可能）：

```
❌ 还不能打样

必须修的问题：
  · 有引脚或网络没有接上
    → 把它连到该连的地方，或显式标成不接（NC）

还没检查的项目（补上资料即可）：
  · 引脚复用冲突

检查结果：必查 11/14 通过 · 缺证据 2 · 不适用 0 · 提醒 1
下一步：按下面的建议逐条修，修完重新测量
```

或者：

```
✅ 可以打样

检查结果：必查 13/13 通过 · 缺证据 0 · 不适用 1 · 提醒 1
下一步：导出制造文件；打样回来后做验收
```

**通过条件**：客户只看到一张卡；「必须修」与「还没检查」分开；**只有 PASS + 有效通行证才说可以打样**。

## 第 4 幕：打样后

**客户说**：「板子回来了，焊好了」

**agent 做**：把实测填进 `.easycirq/acceptance.json`，然后

```bash
easycirq acceptance
```

**客户看到**：

```
✅ 这块板可以交付使用

工程 RetroCam-02  板号 retrocam-01
  ✓ 焊接       照片 IMG_001.jpg（2026-10-31）
  ✓ 上电       3.3V 轨实测 3.28V
  ✓ 功能       加热至 56℃ 时蜂鸣器响，与设计阈值 55℃ 一致
下一步：把这张卡和实测记录一起归档；有问题照上面的证据追溯
```

写了「通过」但没有实测证据的项会变成 `?`，整张卡降为「还差实测证据」。

**通过条件**：三项（焊接/上电/功能）都有实测证据；没有证据的项不能算过。

## 四幕之外：客户永远不需要知道的东西

daemon、connector、typed action、KPI、gate token、快照、回读、DRC、ERC、LVS。
它们都在上面四幕里被使用，但一次都不出现在客户面前。

## 失败时客户看到什么

任何一步出错，输出都带「下一步做什么」：

| 客户遇到 | 看到什么 |
|---|---|
| 没装好 | `easycirq setup` 给出编号的最短路径 |
| 图有问题 | 卡片列出必须修的问题 + 每条一句建议 |
| 资料没给全 | 「还没检查的项目（补上资料即可）」 |
| 打样后有坏件 | 验收卡标 ✗ + 返修建议 |
| 写入被拦 | 「这次写入被拦下了：还没有这一页通过离线检查的通行证」+ 怎么拿到 |

## 这份剧本的边界

- 它描述的是**工具已经支持**的流程；真实打样与实测需要客户完成。
- 「大概多少钱、多久」由 agent 依据 BOM 与工艺给出，本剧本不代替报价。
- 图面可读性的「拓扑电路必须直连」仍需人工/导图复核，工具只给页级代理指标。

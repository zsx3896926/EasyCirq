# I²C 总线

> **一句话用途：** 在给定电源容差、器件数量和总线几何下，算出唯一可用的上拉电阻区间，并判断"再加一个器件/再并一块板"之后这条总线是否还成立；同时把地址、并联上拉、掉电钳位和串阻代价一次说清。
>
> **证据等级：**
> - `E1` 本次已打开并核对原厂资料/作者记录，关键公式、条件或数值可定位到章节/页码。
> - `E2` 通用工程方法，关键结论有来源入口，但具体器件值/脚号/封装仍须按当前型号手册核对。
> - `E3` 仅有离线分析或工程推断，缺少可核对来源；不得当作保证值。
>
> **本卡结论：** 上拉区间公式、0.3/0.7×VDD 门限、`tr`/`Cb` 上限、灌电流与漏电约束、串联电阻 `Rs` 的代价，已按 NXP UM10204 Rev.7.0 §6.1/§7.1–§7.5（p.43–54）与 TI SLVA689A §2/§4（p.3、p.5）核对。**每个具体器件的 `VOL`/`IOL`/`Ci`/漏电仍是手册值，本卡只用规范上限做算例，不能替代你手上器件的数据手册。**
>
> **不能替代：** 具体器件数据手册、实际叠层的 `Cb` 场求解或实测、上电/掉电时序验证、示波器边沿测量、EMC 与多主仲裁测试。

## 1. 用途与适用范围

I²C 是开漏、线与的总线：任何器件都只能把线拉低，高电平完全由上拉电阻对总线电容充电建立。因此一条总线能否工作只由两个数决定——**低电平时谁有能力灌走全部电流，高电平时谁有能力在规范时间内把电容充到门限以上**。本卡解决五类决定：

1. **上拉区间**：`Rp(min)` 由灌电流决定，`Rp(max)` 由上升时间与输入漏电决定；两者必须有交集，没有交集时"换个阻值"永远无解。
2. **总线电容**：`Cb` 由哪些项构成、怎么在布局前估、超了以后的四条出路（降速、Fm+、分段、开关上拉）。
3. **边沿与灌电流**：`VOL`/`IOL` 是保证值不是典型值；总线上最弱的那个器件决定下限。
4. **地址与并联上拉**：多板/多页同名网络会自动并联上拉，地址的 7 位/8 位表示法会让"地址冲突"在图上查不出来。
5. **串阻 `Rs` 的代价**：它能压尖峰，但必须并入 `Rp` 与容性负载重新计算，且受低电平噪声容限限制。

适用：Standard-mode（100 kbit/s）、Fast-mode（400 kbit/s）、Fast-mode Plus（1 Mbit/s）的双向 I²C/SMBus，单主或多主，板内或短排线互联。

### 不能使用的条件

- **Hs-mode（3.4 Mbit/s）与 Ultra Fast-mode（5 Mbit/s，单向）**：本次只读了摘要中的速率档位，Table 12–15 未读，本卡不对其电平、时序与上拉给任何结论。
- **长线/电缆传输**：规范只约束总线电容与边沿，不约束传输线效应、地弹与共模。超过约 1 m 或带屏蔽双绞的场合要另做信号完整性分析，不能靠"加大上拉"解决。
- **隔离总线**：数字隔离器的双向性、传播延时与默认态要单独评估，本卡不覆盖。
- **多主仲裁与时钟同步**：本卡只算电气窗口，不证明仲裁过程、时钟拉伸与总线恢复。
- **器件手册只给 typical `VOL`/`IOL`**：无法做下限计算，必须先换有 min/max 保证值的器件或按最坏情况留足余量并标注"待核"。
- **总线上有推挽器件**：推挽输出与开漏总线的线与前提冲突，不适用本卡。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 上拉电源范围 | `VDD` min/max，V | 电源树、稳压器容差 | **阻断**：`Rp(min)` 与漏电上限都依赖它 |
| 目标速率档 | kbit/s | 系统需求 | **阻断**：决定 `tr` 与 `Cb` 上限 |
| 总线上每个器件的 `IOL(min)` | mA | 各器件数据手册保证值 | **阻断**：取全总线最小值 |
| 每个器件的 `VOL(max)` 及其测试电流 | V、mA | 数据手册（注意测试条件） | **阻断**：`VOL` 只在指定灌电流下保证 |
| 每个器件的引脚电容 `Ci` | pF | 数据手册（规范给 10 pF 上限） | 可用 10 pF/脚先估，标注待核 |
| 总线几何与叠层 | mm、εr、线宽 | PCB 叠层/布线草案 | 先用几何估算，布局后复算 |
| 连接器与保护器件电容 | pF | 器件手册 | 先按 2–5 pF 量级预留，标注待核 |
| 上拉电阻容差与温漂 | ±%、ppm/°C | 电阻手册 | 先按 ±1% 薄膜估算 |
| 器件数量与地址表 | 个、7 位地址 | 原理图/BOM | **阻断**：决定并联上拉与地址冲突 |
| 每块板/每个页面的上拉数量 | 个 | 各板原理图 | 未知时按"每块板各一个"最坏情况算 |
| 输入漏电 `Ii` | µA | 数据手册（规范给 ±10 µA 上限） | 用 10 µA/脚做上限，标注待核 |
| 是否使用串联电阻 `Rs` | Ω | 设计意图 | 未定时先按 0 Ω 算，再单独校核 `Rs` 上限 |

**阻断项**是前四项：没有它们，`Rp` 区间无从计算。其余项可以先用规范上限或几何估算推进，但必须在卡片或设计记录里写明"这是估算值，布局后复算"。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

        VDD ──┬───────────────┬──────────────┬── …
              │ Rp1           │ Rp2          │
  SDA ────────┴───────┬───────┴───────┬──────┴── …
                      │               │
                 ┌────┴────┐     ┌────┴────┐
                 │ 器件 A  │     │ 器件 B  │   ← 都只有开漏下拉
                 │  + Ci   │     │  + Ci   │
                 └────┬────┘     └────┬────┘
                     GND              GND

  集中电容模型：Cb = ΣCi + 走线电容 + 连接器 + 保护器件
  上升沿：V(t) 从 0.3×VDD 充到 0.7×VDD，t = ln(0.7/0.3)·Rp·Cb = 0.8473·Rp·Cb
  下降沿：由最强/最弱下拉器件的 IOL 与 VOL 决定，不由 Rp 决定
```

三个关键点：

- **常数 0.8473 的来源**：上升时间定义为从 `0.3×VDD` 到 `0.7×VDD`，RC 充电解出 `ln(0.7/0.3)=0.8473`，所以 `tr = 0.8473·Rp·Cb`（IF-S01 §7.1 p.50；IF-S02 §2 p.3）。
- **门限**：`VIL(max)=0.3×VDD`、`VIH(min)=0.7×VDD`；Fm/Fm+ 有 `0.05×VDD` 的施密特迟滞；Fm/Fm+ 输入滤波器抑制 ≤50 ns 尖峰（IF-S01 §6.1、Table 10，p.43–45）。这三个数一起决定了"边沿慢到什么程度会被当成毛刺或被误判"。
- **线与**：所有器件共用一个节点，任一器件拉低即为低。因此下限必须按**最弱**的 `IOL(min)` 算，而不是按典型值或主控的值算。

## 4. 参数确定步骤

顺序理由：`Rp(min)` 只依赖器件与电源，不依赖布局，先算；`Rp(max)` 依赖 `Cb`，而 `Cb` 是全卡最不确定的输入，必须最后算并在布局后复算。先算 `Rp(max)` 会得到一个"看起来能选"的阻值，再发现下限把它顶掉，白算一轮。

1. **判据：确定速率档与对应的规范上限。**
   **取值（IF-S01 Table 11，§6.1 p.43–45）：** `tr(max)` = 1000 / 300 / 120 ns，`Cb(max)` = 400 / 400 / 550 pF，对应 Standard / Fast / Fast-mode Plus。`tf(max)` = 300 / 300 / 120 ns。
   **注意：** 这是**规范允许的上限**，不是任何具体板卡的实测值；`Cb` 允许值本身还随供电电压和频率变化（Table 11 注 [9]），换档位必须整行重取。

2. **判据：`Rp` 下限——灌电流。**
   **公式（IF-S01 §7.1 p.50；IF-S02 §2 p.3）：** `Rp(min) = (VDD − VOL(max)) / IOL(min)`。
   **保守写法（本卡建议）：** 若器件手册没有给出 `VOL(min)`，取 `Rp(min) = VDD(max) / IOL(min)`。理由：低电平电流实际是 `(VDD − VOL)/Rp`，最坏情况出现在电源最高、`VOL` 最低时；用 `VOL=0` 可以把"`VOL` 随电流下降"这一未保证的自由度消掉。
   **数值示例（IF-S01 §7.2.4，位于 §7.2–§7.5 的 p.51–54 区间）：** VDD=5 V±10%、`VOL(max)=0.4 V@3 mA` 时 `Rp(min)=(5.5−0.4)/3 mA=1.7 kΩ`；该阻值本身又把 `Cb` 限制在约 200 pF 才能满足 300 ns。

3. **判据：估算 `Cb`。**
   **构成：** `Cb = ΣCi(所有器件引脚) + 走线 + 连接器 + ESD/TVS + 测试点`。
   **器件项：** 规范给每脚 `Ci=10 pF`（IF-S01 §6.1、Table 10，p.43–45），可作为上限先估。
   **走线项：** 按实际叠层用场求解器或阻抗/电容计算器得出 pF/cm，不要用固定常数签核；布局草案阶段可用"线宽 + 介质厚度 + 参考层距离"粗算，并注明待复算。
   **测试点项：** 预留测试焊盘和探针本身都是电容，必须计入——这是"样机好好的，插上探头就通信失败"的常见原因。

4. **判据：`Rp` 上限——上升时间。**
   **公式：** `Rp(max) = tr(max) / (0.8473 · Cb)`（IF-S01 §7.1；IF-S02 §2）。
   **含义：** `Cb` 每增加 10%，`Rp(max)` 就下降约 9%；`Cb` 翻倍则 `Rp(max)` 减半。所以"再加一个传感器"不是加一个地址，是把上限砍掉一截。

5. **判据：`Rp` 上限——输入漏电。**
   **公式（由 IF-S01 §7.4 的输入漏电与噪声容限条件推导）：** 每个引脚最多 `Ii=±10 µA`，高电平噪声容限 `VnH=0.2×VDD`，因此
   `Rp ≤ VnH / (n · Ii) = 0.2·VDD(min) / (n · 10 µA)`。
   **含义：** `n` 取该网络上的引脚总数（含主控）。这条约束通常比上升时间宽松得多，但在"几十个器件 + 大电阻"的背板上会先失效。手册用 Figure 47 按 VDD 给曲线，本次未读图，只用上述代数形式。

6. **判据：区间是否有交集。**
   **判定：** 若 `Rp(min) > Rp(max)`，该总线在当前速率、当前 `Cb` 下**无解**，任何阻值都不行。
   **出路（按代价排序，IF-S01 §7.2 给出的四种）：**
   - 降 `fSCL`：换到更慢的档位，`tr(max)` 变大，`Rp(max)` 上升；
   - 换更高驱动能力的器件（Fm+，`IOL` 20 mA）；
   - 用缓冲器/多路开关把总线分段，每段各 400 pF（见 [I²C 缓冲](i02-i2c-buffer.md)）；
   - 用开关式上拉（只在边沿期间接入低阻上拉）。
   **注意：** 手册明确提醒，加缓冲一定增加延时（缓冲器传播延时 + 每个边沿的额外转换时间），且可能带来特殊的 `VIL`/`VOL` 问题。

7. **判据：串联电阻 `Rs` 是否可用、最大多少。**
   **作用（IF-S01 §7.3）：** 抑制高压尖峰，例如 300 Ω 量级；用了 `Rs` 必须把它并入 `Rp` 与容性负载计算；`Rs` 还影响输出下降时间。
   **上限推导：** 驱动器把引脚拉到 `VOL` 时，总线侧电压被 `Rs` 抬高为
   `Vbus = VOL + (VDD − VOL)·Rs/(Rp + Rs)`。
   低电平噪声容限为 `0.1×VDD`，故要求 `(VDD − VOL)·Rs/(Rp + Rs) ≤ 0.1·VDD`。
   **结论：** `Rs/Rp` 大致不能超过 0.1 量级；`Rp=3.3 kΩ`、`VDD=3.3 V`、`VOL=0.4 V` 时 `Rs ≤ 424 Ω`。这与手册"约 300 Ω"的示例一致，但上限随 `Rp` 变化，不能当固定值。

8. **判据：地址与并联上拉。**
   **地址：** 先确认手册写的是 7 位地址还是含 R/W 的 8 位写法（SC27）。把 7 位地址左移一位当 8 位用，会造成"两个器件地址不同"的错觉。
   **并联：** 每块板各装一个上拉时，等效 `Rp = Rp1 ∥ Rp2 ∥ …`。必须用并联后的值重跑第 2、4、5 步，不能只看单板。

## 5. 完整算例

**给定条件（算例假设，非任何具体器件规格）：**

- 上拉电源 3.3 V ±5% → `VDD(min)=3.135 V`、`VDD(max)=3.465 V`。
- 目标 Fast-mode 400 kbit/s → `tr(max)=300 ns`、`Cb(max)=400 pF`（IF-S01 Table 11）。
- 总线：1 个主控 + 4 个从器件，共 5 个引脚/线；每脚按规范上限 `Ci=10 pF`。
- 几何：12 cm 走线，按 1.5 pF/cm 估 → 18 pF；连接器 4 pF；ESD 阵列 2 pF。
- 全总线最弱 `IOL(min)=3 mA`、`VOL(max)=0.4 V`（Fast-mode 规范条件）。
- 每个引脚漏电按 `±10 µA` 上限；单板一个上拉，电阻 ±1%。

**计算：**

1. **总线电容：**
   `Cb = 5×10 pF + 18 pF + 4 pF + 2 pF = 74 pF`。
   低于 400 pF 上限，余量很大——本例的瓶颈不在电容总量，而在上拉区间。

2. **`Rp` 下限（保守取 `VOL=0`）：**
   `Rp(min) = 3.465 V / 3 mA = 1155 Ω`。
   （按手册原式 `(3.465−0.4)/3 mA = 1022 Ω`；两者都算出来，取更严的 1155 Ω。）

3. **`Rp` 上限（上升时间）：**
   `Rp(max) = 300 ns / (0.8473 × 74 pF) = 300e−9 / 6.270e−11 = 4785 Ω`。

4. **`Rp` 上限（漏电，n=5）：**
   `Rp ≤ 0.2 × 3.135 V / (5 × 10 µA) = 0.627 V / 50 µA = 12.54 kΩ`。
   比上升时间宽松，不构成约束。

5. **区间：1155 Ω – 4785 Ω**，宽度约 4.1 倍，属于"能选但要挑"的区间。

6. **候选比较：**

   | 候选 | `tr`（74 pF） | 低电平电流（3.465 V） | 判定 |
   |---|---|---|---|
   | 1.5 kΩ | 94 ns | 2.31 mA（77%） | 通过，但功耗与电流是 3.3 kΩ 的 2.2 倍，无必要 |
   | **3.3 kΩ** | **207 ns（69% 上限）** | **1.05 mA（35%）** | **入选** |
   | 4.7 kΩ | 295 ns（98%） | 0.74 mA | 通过，但只剩 5 ns 余量 |
   | 10 kΩ | 627 ns | 0.35 mA | 淘汰：超过 300 ns |

   4.7 kΩ 的实际余量可以换算成电容：`Cb(max) = 300 ns/(0.8473×4.7 kΩ) = 75.3 pF`，也就是**只剩约 1.3 pF**。一个连接器、半个 ESD 阵列或一段走线就能吃掉。这就是"默认 4.7 k"在样机上能通、加一个器件就失败的原因。

7. **串阻校核（`Rp=3.3 kΩ`，`Rs=300 Ω`）：**
   低电平抬升 `= (3.465−0.4)×300/(3300+300) = 3.065×0.0833 = 0.255 V`。
   允许值 `0.1×VDD = 0.33 V`，余量 0.075 V（约 23%）。
   若改 `Rs=1 kΩ`：`3.065×1000/4300 = 0.713 V`，远超 0.33 V，会把"低"抬到 `VIL` 附近——淘汰。

8. **并联上拉复核（多板同名网络）：**
   - 2 块板各 4.7 kΩ → 2.35 kΩ：`tr=147 ns`、电流 1.47 mA，通过。
   - 4 块板各 4.7 kΩ → 1.175 kΩ：电流 `3.465/1175 = 2.95 mA`，达到 3 mA 上限的 98%，实际不可接受。
   - 5 块板 → 0.94 kΩ：电流 3.69 mA，**超过 `IOL` 上限**，器件无法把线拉到 `VOL`。
   - 若原设计是 10 kΩ 并两块板 → 5 kΩ：`tr = 313 ns > 300 ns`，**已经失败**。

**候选选择：**

- **3.3 kΩ ±1% 薄膜**入选：同时满足下限（35% 电流）、上限（69% 边沿）、漏电（远低于 12.5 kΩ）；两块板各装一个时并联为 1.65 kΩ，边沿仍有 104 ns 的余量。
- 4.7 kΩ 被淘汰的理由不是"不通过"，而是**没有余量**：`Cb` 估算本身有 ±20% 不确定度，1.3 pF 的余量小于估算误差。
- 10 kΩ 在单板就不通过，淘汰。
- 1.5 kΩ 通过但电流翻倍，且多板并联时会直接超 `IOL`，淘汰。

**结论与限制：**

满足：`Rp` 区间非空；低电平电流、上升时间、漏电三条约束均有余量；串阻抬升在噪声容限内；4 块板并联的边界已算出。

仍待确认：`Cb=74 pF` 是几何估算，必须用实际叠层复算或实测；`VOL=0.4 V@3 mA` 是 Fast-mode 规范条件，具体器件在 1.05 mA 下的 `VOL` 要查其 `VOL-IOL` 曲线；上拉电阻的温漂（±100 ppm/°C 量级）在 −40…+85 °C 内会带来约 1% 的阻值变化，需纳入最坏情况；`Rs` 若实际装配，必须重跑第 2 步（因为低电平电流路径变成 `Rp+Rs`）。

> 算例中的 5 个器件、74 pF、3.3 kΩ、300 Ω 只适用于本算例条件，不能推广到其他芯片或板。

**这个算例不能证明：** 多主仲裁与时钟拉伸是否正常、总线在 EMC 干扰下的误码率、器件在低温下的实际 `VOL`、实际连接器与线缆的电容、上电/掉电瞬间的钳位行为。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 上拉电阻 | 阻值、容差、温漂、额定功率 | 只给 ±5% 且 `Cb` 余量 <10%；功率不足 | 0402/0603，按 `VDD²/R` 核功率 | 每网络每板一个；多板并联必须复算 |
| 串联电阻 `Rs` | 阻值、容差、寄生电感 | 使低电平抬升超过 `0.1×VDD` | 0402，靠近驱动端 | 不是"防振铃万能件"，见 RT20 |
| ESD/TVS | 工作电压、电容、钳位电压 | 电容过大吃掉 `Cb` 预算；钳位高于器件耐压 | 靠近连接器 | 见 PL15 |
| 连接器 | 针数、间距、插拔次数、电容 | 无地针或地针过少 | 按结构 | 布线顺序见 §9 |
| 缓冲/中继 | 侧别、静态偏移、`tPD`、EN 时序 | 需要 B-B 级联；带上升沿加速器 | — | 见 [IF-02](i02-i2c-buffer.md) |
| 上拉电源 | 与器件 I/O 同域、掉电顺序 | 上拉域比器件先掉电 | — | 掉电时上拉消失会导致总线浮空 |

**推荐工作条件与绝对最大额定值分开写：** `IOL` 是推荐工作条件下的保证值，不是绝对最大值；绝不能"按绝对最大灌电流设计"。**`VOL` 的测试电流必须与实际电流同量级**——手册给 `VOL@3 mA` 而实际只灌 1 mA 时，`VOL` 通常更低，但这是"通常"，不是保证；若手册有 `VOL-IOL` 曲线，按实际电流取值。

## 8. 原理图表达

- **上拉画在"所有权明确"的位置**：单板设计画在主控或连接器旁，并在注释里写 `Rp=3.3k ×1（本板）`；多板系统在每块板上注明"本板上拉 4.7k，与底板并联后 2.35k"。
- **不要用全局网络名把 SDA/SCL 跨页连到多个子模块而不核对上拉数量**（SC41）。层次化设计里最容易出现"每个子页各画一个上拉"。
- **地址脚局部画全**：`A0/A1` 的上下拉、DNP 选项、默认装配组合写在同一处，并注明地址是 7 位还是 8 位（例如 `0x48 (7-bit)`）。
- **串阻标为可选件**：画成 `Rs (DNP, 0R default)` 并在旁边写"装配后须重算低电平抬升与上升时间"，避免后人当成固定值。
- **注释写判据而不是结论**：写 `tr ≤ 300 ns @ Cb ≤ 74 pF`，不要只写"4.7k 上拉"。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 上电 | 器件未就绪时可能拉低总线；上拉域未建立时总线浮空 | 核对器件上电复位期间的引脚状态；上拉域与 I/O 同域 | 慢斜坡上电，示波器看 SDA/SCL |
| 掉电 | 先掉电器件的 I/O 通过 ESD 二极管把总线钳到其电源轨 | 选 `Ioff` 器件、串阻限流、或加隔离 | 分别给各器件断电，测总线电平与漏电流 |
| 单器件卡低 | 总线永久为低，主控报"bus busy" | 预留分段/跳线；固件做总线恢复（打时钟） | 人为短接 SDA 到地，观察恢复流程 |
| 地址冲突 | 两个器件同时应答，读到错误数据 | 地址表 + 上电扫描；地址脚用 DNP 选项 | 上电扫描全部地址，比对 BOM |
| 多板并联上拉 | 等效 `Rp` 过小，`VOL` 抬高或器件灌不动 | 只在一处装上拉；或每板用大阻值 | 并联后测低电平与上升时间 |
| 热插拔 | 插入瞬间总线被拉低/尖峰 | 连接器地针先接触；串阻；ESD | 带电插拔多次，观察误码 |
| 短路到电源 | 器件灌电流超限 | 串阻限流；核对 `IOL` 绝对最大 | 逐线短接测试（仅样机） |
| 长线/高容 | 边沿超 `tr(max)`，采样错误 | 降速、分段、Fm+ | 在最远端测 `tr` |

## 11. 验证办法

- **工具检查：** ERC/网表确认每条 SDA/SCL 只有一个上拉（或已知数量的并联）；BOM 核对阻值与容差；地址表与器件手册逐条比对（SC27、SC45）。
- **计算复核：** 用 `VDD(max)` 复算 `Rp(min)`，用 `Cb` 估算上限 +20% 复算 `Rp(max)`，用全总线最小 `IOL` 复算电流；再用 `VDD(min)` 复算漏电上限。四个角落都要跑。
- **仿真：** 未执行。若做：用集中 `Cb` + 理想开漏的 SPICE 模型，观察 `0.3/0.7×VDD` 之间的边沿时间与最坏器件的 `VOL`；通过标准为 `tr ≤ tr(max)` 且 `VOL ≤ VOL(max)`。集中模型不能反映传输线效应与地弹。
- **测量：** 示波器带宽 ≥200 MHz，10× 探头（探头电容 10–15 pF **必须计入 `Cb`**），使用短地弹簧而非长地线；测点选**最远端器件**的引脚而非主控端；分别测 SDA 与 SCL 的上升/下降沿，触发在起始条件上；在最高工作温度和最低 `VDD` 下各测一次。
- **通过标准：** 最远端 `tr` 不超过所选档位上限；`VOL` 在 ACK 位期间不超过 `VOL(max)`；无低于 −0.3 V 的过冲；连续读写 ≥10⁶ 帧无 NACK/错误。
- **不能证明：** 多主仲裁、时钟拉伸、EMC 抗扰、长期可靠性、器件在寿命末期的 `IOL` 退化。

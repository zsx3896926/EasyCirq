# Buck 降压变换器

> **一句话用途：** 在选定 Buck 拓扑后，用一组有顺序的公式把占空比、电感、峰值/RMS 电流、输入/输出电容、开关与二极管应力、反馈分压一次算清，并用器件的最小限流值反推“这颗芯片实际能给出多少输出电流”。它回答的是“2 A 的芯片能不能带 2 A 负载”，而不是“照着参考电路抄”。
>
> **证据等级：** `E1`。占空比按 `VIN(max)` 计算、纹波与电感公式、`IMAXOUT = ILIM(min) − ΔIL/2`、`ISW(max) = IOUT(max) + ΔIL/2`、二极管平均电流、反馈分压 100× 规则、输出电容与 ESR 纹波/过冲公式，均已按 TI SLVA477C（Revision C）§1–§7 核对；热与 `θJA` 的初估方法按 SLVA118A §3–§5 核对。**本卡不覆盖环路补偿、DCM/BCM、轻载 PFM、最小导通/关断时间、多相与耦合电感**，这些必须查具体控制器手册；SLVA477C 明确不涉及补偿与稳定性。
>
> **不能替代：** 具体 Buck 控制器的数据手册（限流 min/max、最小 on/off 时间、内部补偿推荐的 L/C、θJA）、效率曲线、环路仿真/波特图、EMI 与热实测。

## 1. 用途与适用范围

解决六类决策：

1. **占空比与工作点**：用最大输入电压算 D，因为它给出最大开关电流；用最小输入电压检查是否进入 dropout/最大占空比。
2. **电感选型**：先定纹波比例（`0.2–0.4×IOUT`），再算 L，再回算峰值与 RMS；饱和电流必须高于峰值并留裕量。
3. **芯片能不能带这个负载**：数据手册的“2 A”通常是开关限流或热限制下的条件值；用 `ILIM(min)` 反推实际最大输出。
4. **输入/输出电容**：输入电容按数据手册最小值与 RMS 纹波电流选；输出电容按纹波、ESR、负载阶跃过冲三者取最大。
5. **开关/二极管应力**：峰值电流、反向电压、平均电流与功耗。
6. **反馈分压**：分压电流至少为 FB 偏置电流的 100 倍，才能把偏置误差压到 <1%。

适用：集成开关、**CCM** 的降压功率级；同步整流把续流二极管换成低侧 MOS 时，除二极管功耗公式外其余公式仍适用（SLVA477C §1）。

### 不能使用的条件

- **DCM/BCM 或轻载 PFM**：本卡公式建立在 CCM 梯形波上；轻载进入 DCM 后纹波与峰值关系改变。
- **需要环路补偿设计**：SLVA477C 明确不涉及补偿与稳定性；本卡不能给相位裕度、斜率补偿、补偿网络。
- **输入接近输出、需要 100% 占空比**：受最小关断时间与高侧 FET 压降限制，公式会给出接近 1 的 D，但器件可能无法维持。
- **最小导通时间受限**：高输入、低输出时 `tON` 可能小于器件最小值，导致跳周期或纹波失控；本卡只给 `tON` 计算，判据查手册。
- **多相、耦合电感、GaN、隔离拓扑**：不在来源范围。
- **效率用公式代替曲线**：η 只是估算；轻载/高低温/不同 Vin 下的效率必须查曲线或实测。
- **内部补偿转换器随意改 L/C**：SLVA477C §7 指出内补偿器件必须用推荐 L 与 C，或按数据手册的 L×C 比例调整，**不能只加大输出电容**。

## 2. 必要输入

| 输入 | 符号/单位 | 如何取得 | 缺失时怎么办 |
|---|---|---|---|
| 输入电压范围 | `VIN(min/max)` V | 上游电源树/适配器/电池 | **阻断**：D、L、应力都依赖 |
| 输出电压与容差 | `VOUT`、±% | 负载要求 | **阻断** |
| 输出电流（连续/峰值） | `IOUT(max)` A | 负载预算 | **阻断** |
| 开关频率最小值 | `fS(min)` Hz | 控制器手册（固定或可编程） | **阻断**：纹波按最小 fS 算 |
| 开关限流最小值 | `ILIM(min)` A | 控制器数据手册电气表 | **阻断**：决定实际可输出电流 |
| 目标纹波比例 | `ΔIL/IOUT` | 设计选择（常用 0.2–0.4） | 可用 0.3 先算，标注假设 |
| 效率估计 | `η` | 手册曲线/同类实测 | 先用 0.9 估算，标注未核 |
| 反馈电压与 FB 偏置电流 | `VFB` V、`IFB` A | 控制器手册 | **阻断**：分压计算依赖 |
| 输出纹波/瞬态要求 | `ΔVOUT` mV、`ΔIOUT` A、`VOS` mV | 负载手册/系统预算 | 用 1% VOUT 与 5% 过冲先算，标注假设 |
| 环境温度与 θJA | `TA` °C、°C/W | 产品规格/控制器热信息 | 未知时按最坏环境与手册 θJA 上限 |
| 最小 on/off 时间 | ns | 控制器手册 | 未知时算出 tON/tOFF 并标注待核 |
| 内部/外部补偿 | — | 控制器手册 | 内补偿时只能用推荐 L/C |

**阻断项：** `VIN`、`VOUT`、`IOUT`、`fS(min)`、`ILIM(min)`、`VFB`。缺 `ILIM(min)` 时不能回答“能不能带这个负载”，只能算功率级元件。

## 3. 拓扑及工作原理

```text
（分析草图，非 EDA 产物）

        ┌──────── HS FET ────────┐
  VIN ──┤                         ├── SW ──[ L ]──┬──── VOUT
        │                         │               │
       CIN                        │              COUT
        │                    LS FET / 二极管      │
       GND                        │              GND
                                  └──── PGND ─────┘

  高 di/dt 回路（开关导通时）：CIN → HS FET → L → COUT/负载 → PGND → CIN
  高 di/dt 回路（开关关断时）：PGND → LS FET/二极管 → L → COUT/负载 → PGND
```

- **控制量**：占空比 `D ≈ VOUT/(VIN·η)`。D 随 Vin 下降而上升，所以**最大开关电流出现在 Vin(max)**（SLVA477C §1：用 VIN(max) 算 D 与纹波）。
- **电感**：在开关导通期间承受 `VIN−VOUT`，关断期间承受 `VOUT`；纹波 `ΔIL` 与 L、fS 成反比。
- **输入电容**：承受脉冲电流，RMS 最大；它决定输入电压纹波与 EMI。
- **输出电容**：承受电感电流的交流分量，决定输出纹波与负载阶跃过冲。
- **反馈**：从输出（最好在输出电容之后）取分压，进 FB 与内部基准比较；FB 是高阻节点，易受 SW 节点耦合。
- **隔离边界**：本拓扑非隔离；若需要隔离，必须另加变压器拓扑，不能仅靠“地分开”。

## 4. 参数确定步骤

顺序理由：**先用 VIN(max) 定 D 与峰值，再定 L，再用 L 回算纹波与峰值，最后选电容与反馈**。反过来先选电感再算峰值，容易得到“饱和电流刚好不够”的结果。限流校核放在峰值之后，因为它决定“芯片能不能带这个负载”。

1. **判据：占空比（最坏开关电流点）。**
   **公式：** `D = VOUT / (VIN(max) · η)`
   **依据：** SLVA477C Eq.1；文中 η 举例 90%。用 VIN(max) 是因为它给出最大开关电流。
   **假设：** CCM；η 为估计值。
   **注意：** 另用 `VIN(min)` 算 `Dmax = VOUT/(VIN(min)·η)`，检查是否超过器件最大占空比或最小关断时间。

2. **判据：电感纹波与电感量。**
   **公式：** `ΔIL = (VIN(max) − VOUT) · D / (fS(min) · L)`；无推荐值时 `L = VOUT · (VIN − VOUT) / (ΔIL · fS · VIN)`
   **依据：** SLVA477C Eq.2、Eq.5–6；纹波先按 `ΔIL = (0.2…0.4)·IOUT(max)` 估；fS 取转换器**最小**开关频率。
   **假设：** 理想电感、无 DCR；实际电感量随直流偏置下降，额定电流必须高于峰值。
   **口径提醒：** Eq.1 的 D 含 η，Eq.5 的 L 不含 η；同一组数代入两式会得到略有差异的 ΔIL。算例中按**较大**的 ΔIL 做应力校核，并写明口径。

3. **判据：峰值与 RMS 电流。**
   **公式：** `ISW(max) = IOUT(max) + ΔIL/2`；`IL,rms ≈ √(IOUT² + ΔIL²/12)`
   **依据：** SLVA477C Eq.4；RMS 为梯形波近似（本卡推导，假设线性纹波）。
   **用途：** 电感饱和电流、开关峰值、输入/输出电容纹波电流都从这里取。

4. **判据：芯片实际可输出电流。**
   **公式：** `IMAXOUT = ILIM(min) − ΔIL/2`
   **依据：** SLVA477C Eq.3；ILIM(min) 为数据手册给出的开关限流最小值。
   **选择：** 若 `IMAXOUT < IOUT(max)`，这颗芯片在**最小**限流样片下带不动，不能靠“典型限流”放行。

5. **判据：二极管（非同步）或低侧 FET（同步）。**
   **公式（非同步）：** `IF(avg) = IOUT(max)·(1−D)`；S01 记录的功耗式为 `PD = IF·VF·D`
   **口径说明：** 按平均电流定义，导通损耗应为 `VF·IF`（IF 已含 `1−D`）；S01 记录式多乘了一个 D。算例按两者中较大的 `VF·IF` 取值，避免低估。
   **同步整流：** 低侧 FET 导通损耗约 `IOUT²·(1−D)·RDS(ON)`，RDS(ON) 用**结温下**的最大值；二极管功耗公式不再适用。
   **假设：** VF 取实际电流/温度下的值；反向恢复与开关损耗未计。

6. **判据：输入电容。**
   **依据：** SLVA477C §6：输入电容最小值通常由数据手册给定；必须用低 ESR 陶瓷、X5R 或更好，否则直流偏压/温度会损失大量容量。
   **计算（本卡推导，理想梯形波）：** `ICIN,rms ≈ IOUT·√(D·(1−D))`；输入纹波 `ΔVIN ≈ IOUT·D·(1−D)/(fS·CIN) + ESR·ΔI`。
   **选择：** 先满足数据手册最小值，再按 RMS 电流与纹波加并联；按实际偏压降容折算。

7. **判据：输出电容（纹波 + ESR + 过冲）。**
   **公式：** `COUT(min) = ΔIL / (8·fS·ΔVOUT)`；`ΔVOUT(ESR) = ESR·ΔIL`；`COUT(min),OS = ΔIOUT²·L / (2·VOUT·VOS)`
   **依据：** SLVA477C §7。**注意：** 该式在**外补偿**时成立；内补偿转换器必须用推荐 L/C，不能只加大 COUT。
   **选择：** 三者取最大，再按有效容量折算标称值。

8. **判据：反馈分压。**
   **公式：** 分压电流 `Idiv ≥ 100·IFB`；`R2 = VFB/Idiv`；`R1 = R2·(VOUT/VFB − 1)`
   **依据：** SLVA477C Eq.9–11：分压电流至少为反馈偏置电流的 100 倍，引入 <1% 误差。
   **选择：** 先定 Idiv，再选标准阻值，回算 VOUT 与误差；VFB 容差通常主导精度。

## 5. 完整算例

**给定条件：**

- 输入：**10–14 V**（标称 12 V），目标输出 **5 V ±3%**（4.85–5.15 V）。
- 负载：**2 A** 连续；负载阶跃 **1 A**（10–90%）。
- 开关频率：**fS(min) = 500 kHz**。
- 目标：输出纹波 **≤50 mV**；阶跃过冲 **≤100 mV**；η 估计 **0.9**。
- 环境：`TA = 50 °C`，目标壳内温升 ≤60 °C（自定目标）。
- 假设（须按具体控制器核对）：`VFB = 0.8 V`、`IFB = 1 µA`、`ILIM(min) = 3.0 A`、内部补偿、推荐 L/C 待查。

**计算：**

1. **占空比：**
   - `D = 5 / (14 × 0.9) = 5 / 12.6 = 0.3968`
   - 最小输入：`Dmax = 5 / (10 × 0.9) = 0.5556`
   - 最大输入时导通时间：`tON = 0.3968 / 500 kHz = 0.794 µs`
   - 最小输入时关断时间：`tOFF = (1 − 0.5556) / 500 kHz = 0.889 µs`
   - **待核：** 器件最小 on/off 时间是否小于这两个值。

2. **电感：**
   - 目标纹波：`ΔIL = 0.3 × 2 A = 0.6 A`
   - `L = 5 × (14 − 5) / (0.6 × 500 kHz × 14) = 45 / 4.2×10⁶ = 10.71 µH`
   - 选标准值 **10 µH**。
   - 回算（按 Eq.2，D 含 η）：`ΔIL = (14 − 5) × 0.3968 / (500 kHz × 10 µH) = 3.571 / 5 = 0.714 A`
   - 若按理想 `D = VOUT/VIN = 0.3571`，则 `ΔIL = 9 × 0.3571 / 5 = 0.643 A`。两者差 11%，**应力校核取 0.714 A**。

3. **峰值与 RMS：**
   - `ISW(max) = 2 + 0.714/2 = 2.357 A`
   - `IL,rms = √(2² + 0.714²/12) = √(4 + 0.0425) = 2.011 A`
   - 电感饱和电流必须 **>2.36 A**，并按高温/直流偏置下的电感量下降留裕量（具体裕量按电感厂商曲线，本组来源未给通用系数）。

4. **限流校核：**
   - `IMAXOUT = 3.0 − 0.714/2 = 3.0 − 0.357 = 2.643 A`，大于 2 A，通过。
   - 若器件 `ILIM(min) = 2.5 A`：`2.5 − 0.357 = 2.143 A`，仅 7% 余量，临界。
   - 若 `ILIM(min) = 2.3 A`：`1.943 A < 2 A`，**最小样片带不动，淘汰**。

5. **二极管（若非同步，仅作对照）：**
   - `IF = 2 × (1 − 0.3968) = 1.206 A`
   - `PD = IF × VF`，取 `VF = 0.5 V`（示例，须查实际器件在 1.2 A/高温下的值）：`PD = 0.603 W`
   - S01 记录式 `PD = IF·VF·D = 0.239 W`；按较大值 0.603 W 做热评估。
   - 反向电压 ≥ `VIN(max) = 14 V` 再加振铃裕量。
   - **对照同步整流：** 低侧 FET 若 `RDS(ON) = 20 mΩ`（示例）：`P = 2² × (1−0.3968) × 0.02 = 48.3 mW`，远低于肖特基的 0.6 W；这就是同步 Buck 在大电流下的优势。

6. **输入电容：**
   - `ICIN,rms ≈ 2 × √(0.3968 × 0.6032) = 2 × 0.4892 = 0.978 A`
   - 选 2×10 µF X5R/X7R、25 V，按偏压降容后有效约 8–10 µF；每颗的纹波电流额定须大于分担值（约 0.49 A），并留温度降额。
   - 输入纹波估算（C=10 µF）：`ΔVIN ≈ 2 × 0.3968 × 0.6032 / (500 kHz × 10 µF) = 0.4787 / 5 = 95.7 mV`，再加 ESR 项；若要求更小，加并联或降低 ESL。

7. **输出电容：**
   - 纹波判据：`COUT = 0.714 / (8 × 500 kHz × 0.05) = 0.714 / 200000 = 3.57 µF`
   - ESR 判据：取 ESR=5 mΩ → `ΔV = 5 mΩ × 0.714 A = 3.6 mV`，可忽略。
   - 过冲判据：`COUT = 1² × 10 µH / (2 × 5 × 0.1) = 10 µH / 1 = 10 µF`
   - 取三者最大 10 µF（有效）。选 2×22 µF 标称、按 50% 降额约 22 µF 有效；纹波 `0.714/(8×500k×22µ) = 8.1 mV`，过冲 `1×10µ/(2×5×22µ) = 45 mV`。
   - **但内补偿器件必须用数据手册推荐的 L/C 组合**；2×22 µF 只有在推荐范围内才能用，否则按推荐值重选。

8. **反馈分压：**
   - `Idiv ≥ 100 × 1 µA = 100 µA`
   - `R2 = 0.8 V / 100 µA = 8 kΩ`，选 **8.06 kΩ**（Idiv = 99.3 µA）
   - `R1 = 8.06 kΩ × (5/0.8 − 1) = 8.06 kΩ × 5.25 = 42.32 kΩ`，选 **42.2 kΩ**
   - 回算：`VOUT = 0.8 × (1 + 42.2/8.06) = 4.989 V`，误差 −0.23%。
   - 实际精度由 VFB 容差（常为 ±1% 或更好）、电阻容差与温漂共同决定；上例只证明分压比，不证明总精度。

9. **损耗/热一致性检查：**
   - `POUT = 5 × 2 = 10 W`；按 η=0.9，`PIN = 11.11 W`，总损耗 **1.11 W**。
   - 若允许 60 °C 温升，所需 `θJA ≤ 60/1.11 = 54 °C/W`；控制器+电感+电容的实际热分布必须另行分配。
   - 这只是一个“总量级”检查，不能替代开关损耗、栅极损耗、电感铜损/铁损的分项计算。

**候选选择：**

- 选 **3 A 级、500 kHz 以上、内部补偿的同步 Buck**：峰值 2.36 A、限流 3.0 A 下 `IMAXOUT 2.64 A`，满足 2 A；同步整流避免 0.6 W 的二极管损耗。
- 淘汰 2 A 额定开关：峰值 2.36 A 已超过额定，最小限流样片更不够。
- 淘汰 100 kHz 级方案：L 需约为 10 µH 的 5 倍，体积/成本不合算，且瞬态变差。
- 淘汰非同步方案（若效率/热是硬指标）：0.6 W 二极管损耗在 50 °C 壳内需要额外散热。
- 淘汰“只按典型限流选”的方案：必须用 `ILIM(min)` 复算。

**结论与限制：**

满足：占空比、电感量、峰值/RMS、限流（3.0 A 假设下）、输入/输出电容的纹波与过冲判据、反馈分压比。
待确认：控制器真实 `ILIM(min)`、`VFB`、`IFB`、最小 on/off 时间、内部补偿推荐的 L/C、θJA 与效率曲线；电感的饱和电流与直流偏置曲线；电容的实际降额与 ESR；SW 节点振铃与 EMI。

> 算例中的 10–14 V/5 V/2 A/500 kHz/10 µH/2×22 µF 只适用于本算例；`VFB=0.8 V`、`IFB=1 µA`、`ILIM(min)=3.0 A` 是假设值，不代表任何具体型号。

**这个算例不能证明：** 环路稳定性与相位裕度、轻载 DCM/PFM 行为、最小导通时间下的跳周期、EMI、实际壳内温升、电感在高温下的饱和余量、长期可靠性。

## 6. 器件选择依据

| 器件/类别 | 必看参数 | 淘汰条件 | 封装/热/装配约束 | 备注 |
|---|---|---|---|---|
| 集成同步 Buck | `VIN` 范围、`ILIM(min)`、`fS`、最小 on/off、内部补偿推荐 L/C、θJA | 只有 typical 限流；无最小 on/off；推荐 L/C 与目标不符 | QFN 带 EPAD，需散热铜/过孔 | 首选；注意轻载模式 |
| 非同步 Buck + 二极管 | 同上 + 二极管 VF/VR/热 | 大电流下二极管损耗过高 | 二极管需散热 | 低成本，效率低 |
| 控制器 + 外部 FET | 栅驱、死区、补偿、电流采样 | 无补偿资料/无 SOA | 占板大，散热可控 | 大电流/高压 |
| 功率电感 | 电感量、Isat、Irms、DCR、直流偏置曲线 | 只给 Isat 不给偏置曲线；DCR 过大 | 屏蔽式，注意高度与漏磁 | 饱和电流 > 峰值并留裕量 |
| 输入电容 | 有效容量、ESR、RMS 电流、耐压 | 只用 Y5V/低耐压 | 0805/1206，靠近开关回路 | X5R/X7R |
| 输出电容 | 有效容量、ESR、RMS 电流 | 超出内补偿推荐范围 | 多颗并联 | 不能只加大容量 |
| 反馈电阻 | 容差、温漂、分压电流 | 分压电流 <100×IFB | 0402 | 精度由 VFB 主导 |

**推荐工作条件 vs 绝对最大额定值：** `VIN` 绝对最大只用于“不得超出”；`ILIM(min)`、`fS(min)`、`VFB`、`θJA` 都取自推荐工作条件/电气表。**不能用 typical 限流、typical 效率、typical θJA 做设计判据。**

## 8. 原理图表达

- **功率级局部画全**：VIN、CIN、HS/LS FET（或芯片 SW）、电感、COUT、PGND 在同一块内用真实导线连接；SW、BOOT 不用长网络标签跨页。
- **反馈分压画在 FB 脚旁**：R1/R2、前馈电容（若有）靠近 FB；取样点用一个小圆点标在输出电容之后，注明“sense at COUT”。
- **输入电容画成一组**：不要把 2×10 µF 分散到不同页；注明“close to VIN/PGND, loop < …”。
- **注释写工作点**：`VIN 10–14 V, VOUT 5 V/2 A, fS 500 kHz, L 10 µH, ΔIL 0.71 A, ISW 2.36 A, ILIM(min) 3.0 A`。
- **标注补偿类型**：`internal comp — use datasheet L/C` 或 `external comp — see COMP network`；避免后人误以为可以随意改 COUT。
- **EN/PG 域**：EN 分压来源、PG 上拉域显式画出；PG 不要只留网名。
- **装配选项**：不同 L/C 组合的 DNP 选项要标清“本变体不装”，并写可装组合（SC08）。

## 10. 异常状态

| 状态 | 预期行为/风险 | 设计对策 | 验证方法 |
|---|---|---|---|
| 启动 | 输出电容充电浪涌；预偏置输出可能反向电流 | 软启动/限流；查 pre-bias 能力 | 不同输入斜率上电，测 IIN/VOUT |
| 掉电 | 输入塌陷，输出电容经电感/高侧 FET 倒灌 | 查高侧 FET 体二极管方向；必要时加阻断 | 切断输入，测 VIN/VOUT 反向电流 |
| 输出短路 | 限流/打嗝；电感与开关承受大电流 | 核对限流与热；必要时外部保险 | 短时短路，测电流与温度 |
| 轻载 | 进入 DCM/PFM，纹波与频率变化 | 查轻载模式与最小负载要求 | 10 mA/100 mA 负载下测纹波 |
| 输入低于设定输出 | 100% 占空比/dropout，输出跟随输入 | 核对最大占空比与 UVLO | 可调电源扫输入 |
| 输入瞬态 | 超过绝对最大/触发 OVP | TVS/钳位；核对推荐上限 | 热插拔/浪涌注入 |
| 过热 | 热关断/限流降额 | 按 θJA 与损耗降额 | 热箱/热像仪 |
| 电感饱和 | 电流尖峰、限流误触发、效率骤降 | Isat > 峰值并留高温裕量 | 满载+高温下看 SW 电流波形 |
| EN 悬空 | 状态不确定 | 明确上/下拉 | 断网测试 |

## 11. 验证办法

- **工具检查：** 网表确认 CIN 跨 VIN/PGND、COUT 跨 VOUT/PGND、FB 分压只连 FB；ERC 查 EN/PG；DRC 查 SW 铜与 FB 间距；BOM 核对电感 Isat/Irms 与电容耐压/介质。
- **计算复核（角落条件）：** `VIN(max)+IOUT(max)+fS(min)+L(min)` 复算峰值；`VIN(min)+Dmax` 复算最小关断时间；`ILIM(min)` 复算 `IMAXOUT`；`TA(max)+θJA(max)` 复算结温；用最小/最大电容复算纹波与过冲。
- **仿真：** 未执行。若做：用控制器厂商模型 + 实际 L/C/ESR，激励为 `VIN` 阶跃与负载阶跃，观察 SW 波形、IL 峰值、VOUT 跌落/恢复、是否触发限流；通过标准为峰值 <`ILIM(min)`、VOUT 在容差内、无次谐波振荡。模型不含 PCB 寄生与热，不能替代实测。
- **测量（效率）：** 四线法测 VIN/IIN/VOUT/IOUT，覆盖 10%/50%/100% 负载与 VIN(min/max)；记录温度与 fS。
- **测量（SW 与纹波）：** 示波器 20 MHz 带宽限制、弹簧地环、探头尖端直接跨器件引脚；不能用地线夹长引线。看 SW 振铃、IL 斜坡、VOUT 纹波。
- **测量（瞬态）：** 电子负载 10–90% 阶跃，重复频率低于热时间常数；记录跌落、过冲、恢复时间。
- **测量（热）：** 热电偶/热像仪，稳定 30 min；记录 TA、各器件壳温；停止条件为超过目标结温。
- **通过标准：** 全范围 VOUT 在容差内；峰值电流低于 `ILIM(min)`；纹波/过冲满足预算；器件温度低于目标；无持续振荡。
- **不能证明：** 相位裕度、EMI、极端温度下的电感饱和、长期可靠性、输入源阻抗极端情况。

# 主流硬件领域路由

用本表决定查哪些资料、处理哪些约束。它是任务覆盖目录，不是预先验证过的设计库。具体型号、接口速率和产品标准必须现场核对。主入口统一，按项目加载，不要求用户懂分类。

| 领域/常见产品 | 优先拿到的工程输入 | 重点资料与交付 |
|---|---|---|
| 日常常用硬件（测温/称重/压力/液位/风扇/电池/屏幕/按键） | 用户原话、量程、介质、安装、校准、供电 | [常用硬件](common-hardware/README.md) 的 A–M 组与 12 个组合应用；电气理论再回设计卡 |
| MCU/物联网/消费控制 | 模块或裸芯片、供电、外设、调试方式 | 原厂硬件指南；最小系统、启动/复位/下载、电源峰值、GPIO表 |
| SoC/嵌入式Linux/SOM | 核心板接口、上电时序、存储/显示、热设计 | SOM载板指南/SoC设计指南；电源序列、载板约束、关键网络规则 |
| FPGA/CPLD | 具体封装、bank电压、I/O标准、配置方式、时钟 | pin planner/电源估算/器件指南；bank表、去耦、配置与约束一致性 |
| 电源转换/充电/储能 | 电源范围、负载曲线、拓扑、散热、电芯资料 | 控制器与电芯原厂资料；功率级、补偿/稳定性、保护、时序和测试 |
| 工业PLC/传感器/仪表 | 现场电平、线缆、地电位差、隔离/浪涌环境 | 收发器/AFE/保护指南；24V域、4-20mA/0-10V、隔离屏障、故障处理 |
| 电机/电磁阀/继电器/功率执行 | 额定/堵转/浪涌电流、母线、电感/回生、控制方式 | 驱动器/MOSFET/SOA资料；功率环路、栅驱、死区、保护与热 |
| 模拟/精密采集/传感器 | 输入范围、源阻抗、带宽、精度/噪声、供电 | AFE/运放/ADC参考；误差预算、建立时间、滤波、校准与测试 |
| 有线通信/网络/接口板 | 协议版本、速率、连接器、线长、对端、电源域 | USB/以太网/CAN/RS485等官方资料；PHY外围、端接、保护与回流 |
| 无线/RF/GNSS/蜂窝 | 频段、模组/裸片、天线、认证目标、外壳/空间 | 原厂RF参考layout与天线指南；匹配/馈线/净空、供电脉冲、测试口 |
| 显示/摄像头/音视频 | 面板/传感器型号、lane/时序、电平、供电、FPC方向 | MIPI/LVDS/HDMI/I2S/Codec资料；接口定义、时序、电源和约束 |
| 高速计算/DDR/PCIe/SerDes | 平台、速率、叠层、拓扑、厂商约束与模型 | 平台布局指南/IBIS或其他可用模型；阻抗/延时/过孔与SI验证需求 |
| LED照明/背光 | 串并联、温度、电压范围、调光、散热/光学 | LED与驱动器资料；恒流/电压裕量、功率/热和故障状态 |
| 音频功放/声学 | 负载阻抗、功率/THD目标、供电、线缆 | Codec/功放layout指南；增益、滤波、散热、输出与负载保护 |
| 汽车/医疗/安防等行业产品 | 实际功能、应用场景、目标地区/标准、失效后果 | 先按电路领域设计，再加载项目适用的资格/安全/EMC要求；独立签核 |

## 判断复用深度
- 参考设计条件一致：保留关键拓扑与厂商layout意图，记录替换件和差异。
- 同芯片不同封装/电压/接口：重新核对引脚、参数、保护和布局，不能按外观复制。
- 高速/RF/隔离电源：无叠层、模型、控制器资料等关键输入时只能交付带条件候选，不能宣称完成性能验证。
- 现有执行器无法表达特殊铜结构/屏障/盲埋孔/差分约束：明确能力缺口，输出工程师可落实的约束，并交付能实际完成部分。

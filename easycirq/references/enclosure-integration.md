# PCB、外壳与安装协同

需要外壳、面板、安装、线束或成品装配时加载；用户只要求画原理图时不强加外壳。先查已有壳体/固定结构与真实环境，优先用嘉立创体系内适用服务，具体编辑/导出/加工能力按当前官方文档和工具确认。不能因有3D预览就宣称有可制造壳体模型。

## 一起确定的接口

| 约束 | Agent核对内容 | 修改后的联动 |
|---|---|---|
| 板框/孔 | 基准、闭合外形、板厚、孔/槽类型、成品公差与紧固件 | PCB、壳体/支柱、夹具和制造版本 |
| 外露接口 | 插头本体、卡扣、插拔扫掠、弯线空间、接触面、线束出口 | 连接器位置、壳体开孔与线序图 |
| 按钮/LED/屏 | 按压行程、导光、可见性、屏/FPC堆叠与装配顺序 | PCB位置、高度、面板和用户说明 |
| 最高与最低点 | 正反面器件、焊脚、螺钉/垫圈、屏蔽罩、电池和热件 | 壳内高度/禁布、绝缘和热路径 |
| 天线/传感器 | 实际天线净空、金属/电池位置，气路/声孔/光窗与应力 | 壳体材料/窗口、PCB摆位与装壳实测 |

3D文件可能只画元件本体、不含线缆或卡扣，缺失模型必须单列。对规则盒子可评估当前EDA外壳功能；复杂卡扣、曲面、密封或多件装配用适用CAD接续，不编造执行器动作、不用临时JS替代缺失协议。模型来源可用不代表已核对尺寸。

## 选择工艺而不是默认一种材料

按温度、日晒、冲击、尺寸、细节、表面、绝缘和成本比较树脂/尼龙/其他适用打印或CNC。壁厚、公差、卡扣、螺纹/嵌件、支撑面和后处理按所选材料与服务当前能力，不把“树脂件”“铝壳”一概视为耐候、防水或屏蔽有效。

金属壳可能提供散热/屏蔽，也可能妨碍无线；按天线方案设计窗口/外置天线和接地，不写“无线一律不能金属壳”。电池空间需兼顾实际规格、固定、更换、保护与适用胀气/热条件，不能靠压紧壳体解决尺寸不符。

## 潮湿、测量和装配

密封、通风、防凝露、气压/湿度响应及散热可能冲突。传感器透气孔、接触点、连接器、测试点的涂覆/清洗按原厂限制；电容式土壤探头也需验证涂层、吸水、长期腐蚀与土质校准，不能承诺不腐蚀。

防溅水结构、密封圈、线缆固定、防呆、排水和材料是候选措施，不等于已达IP等级。电气绝缘、安规与耐候各自评估，不由外壳外观保证。高压或大功率装置的试验方法须与实际风险相符，不能给新手套通用淋水测试。

冻结前用真实PCB模型与壳体做装配干涉/公差检查；打印小样或首件后验证插拔、按压、散热、无线/测量和维修。STEP、STL/3MF等按工具和服务真实接受格式输出，核对单位、坐标、装配版本与网格精度；源模型与制造文件分开保存。能加工外壳不等于包含电子装配或整机测试。

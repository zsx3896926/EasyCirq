# F20 商城有货但 SMT 不可贴

> **证据等级：** B 嘉立创/立创商城官方说明明确“商城库存与 SMT 选料/库存独立”“只有部分可以贴”；本次没有具体订单的可贴状态数据。
> **适用边界：** 只适用于所列拓扑、器件、板版和工况；不得推广成通用规则。
> **关联：** [立创商城选型与采购](../lcsc-sourcing.md)、[嘉立创业务衔接](../jlc-handoff.md)、[故障定位](../troubleshooting.md)；检查 MF22、MF23；任务场景 S26。

## 现象

BOM 在立创商城逐行都能买到，但 SMT 下单出现下列一种或多种情况：

- 某些行显示无法匹配/无库存/不可贴，或只能选到不同型号/封装；订单无法按原 BOM 提交。
- 用户自行在商城买料寄给工厂，工厂拒收/不入库/仍按自有料匹配；或寄料只接受部分封装。
- 同一料号商城有货，但 SMT 可贴列表没有；换一个“看起来一样”的型号后平台可匹配，但电气参数/封装/固件配置未必等价。
- 小批量订单因 MOQ/编带/包装/料盘/飞达不匹配无法贴，或费用明显增加。
- BOM 匹配显示“完全匹配”，但实际贴出来是不同品牌/后缀/封装。

## 工况

- 器件：完整 MPN、品牌、封装、引脚间距、包装（编带/管装/散料）、湿度等级。
- 平台状态：立创商城库存/价格、嘉立创 SMT 可贴列表/库存、基础库/扩展库、是否“已上架”、交付方式。
- 订单：板数、单套用量、备损、MOQ、拼板、SMT 经济型/标准型。
- BOM：匹配结果（完全匹配/待确认/无法匹配）、C 号、替代料、装配变体。

## 原因假设

- **H1 商城库存与 SMT 库存独立。** 立创商城和嘉立创的元件购买是独立流程，库存和价格都独立；商城有货不代表工厂有货/可贴。成立时同一 MPN 在商城可买、SMT 页面不可选。
- **H2 不在 SMT 可贴库/未上架。** 器件不在当前 SMT 选型库，或状态不是“已上架”；基础库可能不支持寄料。成立时选型工具搜不到或状态不符。
- **H3 封装/间距超工艺。** 引脚间距、封装尺寸、BGA 球距等超出所选 SMT 路线能力；寄料页面（2020）明确仅接受引脚间距 ≥0.4 mm 的器件。成立时标准型可贴、经济型不可，或寄料被拒。
- **H4 包装/MOQ/料盘不匹配。** 商城售卖包装不是编带/料盘，或数量低于 MOQ/订购步进；工厂无法上飞达。成立时订单页要求更换包装/数量。
- **H5 BOM 匹配选错料。** 平台按 C 号优先或 AI 推荐匹配到不同品牌/后缀/封装；“完全匹配”只是平台字段匹配，不等于电气等价。成立时匹配行红字/黄字或参数与原始需求不同。
- **H6 把个人购料当工厂库存。** 用户认为“我已经买了/寄了”就等于 SMT 已备料；实际寄料需审核、上架、签收入库，且嘉立创库存优先。成立时订单仍显示缺料/未入库。

## 区分假设的检查

按“先安全、再无损、再侵入”的顺序：

1. **在 SMT 侧查同一 MPN（无损）。** 用嘉立创 SMT 选型工具/下单页搜完整 MPN，而不是只看立创商城商品页；记录库类型、状态、封装、包装、可贴/库存显示。动态状态以当前页面为准。
2. **核对封装/间距（无损）。** 查器件手册的引脚间距/球距/本体尺寸，与所选 SMT 路线（经济型/标准型）能力对照；不要只看封装名。
3. **核对包装/MOQ（无损）。** 查当前交付方式、包装、最小包装/订购步进、备损；确认工厂能否上料。
4. **核对 BOM 匹配行（无损）。** 展开匹配结果：原型号/原品牌/原封装/原 C 编码 vs 匹配型号/品牌/封装；完全匹配也要看参数与后缀。AI 只处理“无法匹配”行，结果标“AI”，仍需工程复核（MFG-S02）。
5. **核对寄料状态（无损）。** 若走寄料：确认器件是否在可寄料范围、是否“已上架”、是否已签收入库；基础库是否支持；引脚间距是否满足。页面规则可能更新，以当前流程为准。
6. **替代料电气审查（无损）。** 对任何替换型号核对引脚、封装、电压/电流/温度、时序、固件配置；不能因为平台可匹配就判等价（MF22）。
7. **小批试贴（侵入）。** 先下最小可行批量/首件，确认实际贴装与来料；不要直接大批量。

## 根因证据

- **官方业务边界（B）。** 嘉立创 EDA《元件购买》页（MFG-S04）明确：“立创商城和嘉立创的元件购买是独立的”“包括库存和价格都是独立的”；并举例“在立创商城有库存的元件，但在嘉立创无法贴或者没有库存”“因为元件的库存是独立的”“只有部分才可以贴”。这是把“商城有货”与“SMT 可贴”分开的直接官方依据。
- **寄料规则（B）。** 嘉立创《SMT元器件寄料操作相关流程》（MFG-S10，2020-11-30）说明：基础库不支持邮寄；器件需审核通过并显示“已上架”才能进入寄料流程；状态包括已上架/待邮寄/寄出/还未入库/签收入库；“嘉立创库存优先原则”；“目前仅接受引脚间距大于等于 0.4mm的电子元器件邮寄”；5 元/种邮寄服务费是 2020 页面条件。规则可能调整，不能当当前费率承诺。
- **匹配状态语义（B）。** 立创商城 BOM 智能云表帮助页（MFG-S02）给出匹配状态只有完全匹配/待确认/无法匹配；完全匹配也可手动改；AI 仅处理无法匹配行；页面不说明“完全匹配”等于电气等价或可贴。
- **选型工具边界（B）。** 嘉立创 EDA SMT 选型工具页（MFG-S15）说明工具用于查找 SMT 器件并生成 BOM；页面未说明基础库/扩展库/私有库分类，也未说明可贴状态列；不能由“能选型”推断“能贴片/有库存”。
- **合理推断（C）。** 若同一 MPN 在商城可买、SMT 侧不可选，则库存/库独立是可解释根因；若 SMT 侧可选但寄料被拒，则封装/间距/状态更可能。两者都需要当前订单页面确认。
- **仍待验证（D）。** 本案例没有本次作者的实际订单、可贴截图或工厂回复；没有具体 C 号、价格、库存、MOQ、交期，不能写“某料一定不可贴/一定可贴”。

## 修复

- **BOM 变更（主）。** 选当前 SMT 可贴、库存/包装满足的等效器件；替代必须做电气/封装/固件审查，不能只换 C 号。若替代改变引脚/封装/配置，同时触发原理图/封装/固件变更。
- **封装/布局变更。** 若为了可贴换封装（如更粗间距），必须重画 footprint、核对焊盘/丝印/装配，不能只改 BOM 封装名。
- **装配变体变更。** 同一功能保留“SMT 可贴版/手焊版”时，用装配变体区分位号与料号；不能在同一 BOM 行放两个待选件。
- **采购路线变更。** 若器件必须自购/寄料，先确认当前寄料范围、状态、包装与费用；不符合时改手焊/外协/换料，不承诺工厂一定代贴。
- **固件变更（条件）。** 替代 MCU/存储器/接口芯片可能改变配置/时序，必须同步固件；不能把固件不改当“pin-to-pin”。
- **不要做：** 为了通过 SMT 匹配而删保护件、换低额定料、改封装名而不改 footprint。

## 复验

未执行。复验条件与通过标准如下：

- 工况：最终 BOM、目标板数、所选 SMT 路线（经济型/标准型）、当前下单页面；如走寄料，按当前寄料流程。
- 检查：逐行在 SMT 侧确认可贴/库存/包装/MOQ；匹配型号与原需求参数/封装/后缀对照；替代料完成电气审查；寄料状态“已上架/已入库”。
- 通过标准：BOM 每一行都能在当前订单中匹配并提交；首件贴装型号/极性/封装正确；替代料功能/时序/固件验证通过。
- 还需补：小批量一致性、不同包装批次、交期变化；修复后重跑原失败订单与必要回归。

## 适用边界

- 只适用于嘉立创/立创商城的国内业务；JLCPCB/LCSC 海外站点的库存、币种、费用规则不同，不能混用。
- 可贴状态、库存、价格、MOQ、交期是动态字段；本案例不给出任何具体 C 号或“当前有货”的承诺。
- “完全匹配”是平台字段匹配，不是电气等价；本案例不能反过来说“所有替换料都不可用”。
- 基础库/扩展库/寄料规则会变化；0.4 mm、5 元/种等是特定页面/年份条件，不能当永久规则。
- 没有当前订单页面与实际 BOM 时，不得判定某具体型号可贴或不可贴。

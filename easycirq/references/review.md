# 设计审查、故障与验证

嘉立创制造任务按 [生产规则接入](jlc-production.md) 复核当前渠道与工艺、规则回读、同版制造包及厂方意见；分别列已证实超限、条件/证据不足和工艺优化。厂方报告未取得时保持未执行，不把所有目录建议当全板硬错误。

对关键缺陷用“条件/原因 → 设计动作 → 检查证据”说明，可按需用 [原理图机制卡](schematic-lessons.md) 与 [PCB机制卡](pcb-lessons.md)。几何脚本仅按 [离线工具契约](offline-tools.md) 提示候选，不能代替实际图面、网络、制造与实测审查。

## 审查方法
先读实际工程和相关资料，再按严重性检查：供电/极性/短路/额定 → 功能链路/时序/引脚 → layout/回流/热/保护 → 可制造/可测 → 可读性。
将检查结论绑定位置与条件，区分“已证实缺陷”“条件性风险”“需实测”“工程优化”。避免把所有经验建议标成错误。
有明确正确修法且用户已授权修复时直接实施；多个方案会改变功能/成本/认证边界时，给出必要取舍再求关键输入。

## 轻量失效分析
仅对重要接口、电源、功率和关键功能列失效情景：断线/短路/反接、器件开路/短路、上电/掉电、负载突变、热插拔、通信异常/控制器复位。
逐项写原因 → 局部后果 → 系统后果 → 检测/缓解 → 验证方法。高后果即使概率未知也单独处理，不让单一RPN分数遮盖。
把安全状态、失效后功率路径、可恢复性和故障传播作为设计输入。不要编造故障率、MTBF或认证等级。

## 调试流程
先记录现象和复现条件，保护当前工程/样机证据。按电源 → 复位/时钟/启动 → 调试链路 → 接口 → 业务功能定位。
每轮提出能区分假设的测量，记录预期正常/异常结果；不要同时换多颗器件造成因果丢失。
例如I2C不通：核对供电/地址/模式/引脚/波形、电平与上拉、SCL/SDA时序、对端掉电拖低，再改阻值；不是先随便换4.7k。

## 仿真与实测
仿真按问题选DC/AC/瞬态/热/SI/PI等，模型和拓扑条件匹配；SPICE收敛不等于电路真实正确，模型缺失部分保留限制。
上电计划说明输入限流、测点、预期电压/波形、允许范围、停止条件、分阶段负载、启动/关机/温度等工况；高能量/高压/市电等采用匹配设备和专业操作条件。
实际未做测试就交付测试计划，不生成假波形、假温升、假认证结论。

## 关闭问题
缺陷修复后复核原问题及受影响对象/模块，必要时整体重跑。某个问题通过不能关闭其他没有覆盖的风险。
检查错误、警告、缺测、无法执行、用户接受的例外分别统计。例外包含原因、范围、责任和后续措施；没有用户/项目依据不擅自豁免。

## 几何告警与电气事实
- 几何/可读性告警（overlap、间距、out-of-board、文字压迫、连通提示）只能靠布局、走线、修检查器或带证据的豁免解决。
- 禁止用浮空/支撑假脚、改网络名、删器件、伪造 NC、降低约束或放宽阈值来让告警消失；这会改变电气事实并在报告里制造假通过。
- 任何电气设计变更必须有：变更依据（手册/计算/实测）、影响分析（受影响器件/网络/检查）、变更记录（触发需求、改了哪些对象、复验范围）；变更后重跑受影响门禁，不静默扩大范围。
- 判定为检查器误判时，先保留原始输入与复现步骤，修检查器或把误报写进报告（标 `false_positive` 与依据）；不允许“改图迁就检查器”。

## 交付级别
- 概念方案：设计意图与选型初步明确，未写入或未完成验证。
- 原理图候选：已实际绘图与保存，连接/资料/检查结果分项报告。
- PCB候选：已实际布局/布线到报告范围，尚有未布/缺测则说明。
- 制造候选：交付可复核制造文件与BOM/坐标，列出制造/设计复核证据及剩余限制。
- 样机验证：列已测板版、工况、样本与结果；不自动升级为量产/认证通过。

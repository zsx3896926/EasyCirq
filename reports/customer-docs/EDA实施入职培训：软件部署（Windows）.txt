EDA实施入职培训：软件部署（Windows）
开始实操部署软件前，需要先了解几个知识点：
什么是嘉立创 EDA 私有部署？
嘉立创 EDA 私有部署是为企业量身打造的专属版本，核心是将 EDA 系统直接部署于企业局域网服务器，而非使用嘉立创公有云服务。该模式支持与外部互联网完全隔离，既能为企业数据提供更高级别的安全管控与隐私保护，也可根据企业自身需求进行定制优化，助力团队实现更高效的内部协作与管理。
私有部署适合对数据安全有较高要求的企业，尤其是那些不希望将敏感数据存储在第三方服务器上的企业。通过私有部署，企业可以实现对EDA工具的全线管控，同时满足内部多方协作的需求。
部署嘉立创 EDA 私有部署版，需要组建一个局域网
什么是 B/S 架构?
B/S架构（Browser / Server，浏览器 / 服务器架构）是一种常见的网络应用架构，它将用户界面和数据处理分离开来。在这种架构中，用户通过浏览器（Browser）访问运行的服务器（Server），服务器端负责处理业务逻辑和数据存储，然后将处理结果返回给用户浏览器。
嘉立创 EDA 私有部署是 B/S 架构的，分为服务器端（Server）和用户端（Browser & Electron），部署时需在服务器和用户机上安装部署/配置，数据存在服务器上。
MySQL 是什么
MySQL 是一种专门用来管理关系型数据的数据库，数据库能把用户信息、业务记录、交易数据等所有需要保存的信息都规整地存起来，既保证数据安全不丢失、有条理不混乱，又能在需要时快速找到、调取或修改这些数据，为网站、APP、企业系统的正常运行提供核心的数据支撑。
嘉立创 EDA 私有部署使用 MySQL 数据库进行数据储存与数据管理。
HTTPS 与 443 端口之间的关系
HTTPS 是网络数据传输的安全协议，核心是在 HTTP 协议基础上增加 SSL/TLS 加密层，而非使用未加密的 HTTP 明文传输；
443 端口则是互联网通信中为 HTTPS 协议默认分配的专用传输端口，二者搭配使用时，不仅能通过加密实现数据传输全程的机密性保护，还可借助端口的专属映射确保协议通信的精准对接，既有效防范数据篡改、信息窃取等风险，也为企业与用户的敏感信息交互、在线交易等场景提供更高级别的安全管控，助力实现更安全、稳定的网络通信。
嘉立创 EDA 私有部署使用 HTTPS 加密，服务器需开通 443 端口
服务器端 SSL/TLS 证书 与 用户端信任证书
服务器端 SSL/TLS 证书与用户端信任证书是 HTTPS 加密通信不可缺少的核心组成部分，二者共同构成安全通信的关键闭环：前者确保服务器能够合法证明自身身份并实现数据加密，后者让用户户端可以验证服务器身份的可信度，只有二者配合工作，才能实现安全、可信的 HTTPS 网络传输。
HTTPS 加密通信需要服务器证书和用户端证书配合工作，嘉立创 EDA 的服务器证书文件为 ecrt 格式，需在服务器上安装；用户端证书为 crt 文件，需在用户机上安装。
DNS 解析与 hosts 文件
DNS 解析和 hosts 文件都是互联网上用于将域名转换为 IP 地址的机制。在没有 hosts 文件记录的情况下，DNS 解析是默认的域名解析机制。
DNS（Domain Name System，域名系统）是互联网上用于将域名（如 example.com）转换为 IP 地址（如192.0.2.1）的系统。
hosts 文件是一个简单的文本文件，通常位于操作系统中，它包含了域名到 IP 地址的映射关系。当一个域名需要被解析时，系统会首先检查 hosts 文件，如果找到了对应的 IP 地址，就不需要进行 DNS 解析。
嘉立创 EDA 私有部署的用户端需要通过将域名解析为服务器 IP（服务器 IP 地址需要固定不变），才能正常访问到服务器。
综上，部署嘉立创 EDA 私有部署版本时
需要在服务器上：
安装服务端软件
安装 MySQL 数据库
安装服务器证书
开通 443 端口
需要在用户机上：
安装用户端软件 或 安装用户机证书
配置 DNS 解析 或 配置 hosts 文件
嘉立创 EDA 私有部署软件已简化部分操作，数据库和服务器证书可直接由服务端安装程序引导安装；用户机的 hosts 文件可由用户端安装程序自动配置。
实操环节
实操环节省略搭建局域网步骤，使用个人电脑既当做服务器，又当做用户机进行实操。服务器 IP 地址在不固定情况下，hosts 文件配置 IP 地址为 127.0.0.1。
